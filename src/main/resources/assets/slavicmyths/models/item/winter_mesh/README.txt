Palette uses separate UV swatches for polished ice, indigo metal and gold. GUI paired models use both copies of the same geometry. In-game transforms must be verified in the client.
High-rank royal models use royal_palette.png; Silence weapons and beast claws use silence_palette.png. Both retain the existing 8x4 swatch UV layout. Vanilla-recolor inventory textures and the base faceted palette remain unchanged.
