# Славянская зима — тестовый мир

Создание мира → Мир → Тип мира: Суперплоский → Настроить → Шаблоны → «Славянская зима» → Использовать → Готово. Не изменяйте слои этого шаблона: при создании точный набор слоёв переключается на многобиомный зимний генератор. Отдельный тип мира больше не показывается; внутренний пресет нужен только как источник генератора. Режим Creative, сложность Normal или Hard; для чистого полигона отключить ванильные структуры. Обычные миры и пресет Буяна не заменяются.

Настоящие биомы Minecraft: снежная тайга, замёрзший океан, роща, снежная равнина. Основа плоская, Y≈64, океан покрыт плотным льдом, под которым вода. Декорации биомов остаются ванильными плюс зимние деревья и месторождения.

Сетка 512×512. Точка встречи выбирается не далее 64 блоков от центра, минимальное расстояние между центрами фактических мест появления 384 блока по разделяющей оси. Боссы создаются в загруженных чанках при исследовании; один за интервал в 100 тиков на сервер. Сохранённые ячейки не заселяются повторно после убийства или перезапуска. Океанический капитан требует ледяную опору; королева, Аука и Глухея (если отдельная сущность зарегистрирована) — лесной биом. Росомаха — зимние наземные биомы, филин — любые зимние биомы, включая замёрзший океан в обычных мирах. В тестовом пресете океанические ячейки закреплены за капитаном.

Ориентиры в тестовом мире (приблизительные центры, реальная позиция может отличаться на 64 блока):
* 256, 256 — снежная тайга / Ледяная королева.
* 768, 256 — замёрзший океан / капитан.
* 1280, 256 — роща / Аука.
* 1792, 256 — снежная равнина / северная росомаха.
* 256, -256 — снежная равнина / зимний филин.

Отдельная Глухея пока не зарегистрирована в этой ветке, правило готово для ID slavicmyths:gluheya; Аука не подменяется ею. Отдельные будущие строения должны использовать тот же реестр встреч, а не создавать второй независимый спавн.

Проверка: clean build, наличие зимнего шаблона рядом с океанами, отсутствие отдельного типа, новый мир, F3 на каждом биоме, загрузка центров, проверка капитана на льду, сохранение/перезапуск, убийство босса и повторное посещение, обычный снежный мир, отсутствие автоматического Буяна в зимнем пресете.
