# Буян: тестовый океан глубиной четыре блока

Отдельный шаблон суперплоского мира для Minecraft Java 1.21.1 / NeoForge.
**Он не изменяет обычный Overworld, старые сохранения и генерацию других структур.**
Не использовать существующее сохранение для испытаний.

## Создание

1. Запустите клиент из этой ветки (`gradlew.bat runClient`).
2. Создайте **новый** мир с разрешёнными командами и режимом Creative.
3. На вкладке `Мир` выберите тип **Суперплоский** (`Superflat`) и нажмите **Настроить** / **Шаблоны**.
4. Выберите пресет **Буян: мелкий тестовый океан (4 блока воды)**
   (`Buyan: Shallow Test Ocean`). Он доступен в перечне пресетов благодаря
   `data/slavicmyths/worldgen/flat_level_generator_preset/buyan_shallow_ocean.json`.
5. Убедитесь, что мир содержит бесконечную воду без выступающих естественных
   островов; сохраняйте мир под отдельным именем, например `BuyanQA-01`.

Для ручного воспроизведения без встроенного пресета строка слоёв:
```text
minecraft:bedrock,122*minecraft:stone,minecraft:gravel,4*minecraft:water;minecraft:deep_ocean
```

Мир начинается с Y=-64: bedrock -64; stone -63…58; gravel 59;
вода 60…63 (4 блока). Уровень моря — Y=63. Все 4 слоя воды видимы,
но под ними есть твёрдая опора, необходимая генератору Буяна.
Биом `minecraft:deep_ocean` соответствует проверке океанского биома.

## Запуск и прогресс

Стоя в воде с правами OP, выполните одну команду:

```text
/slavicmyths dev generate buyan
```

Затем:

```text
/slavicmyths dev buyan status
```

После окончания фундамента природа начнёт строиться **сама**.
Общий прогресс показывается от 0 до 100 процентов в трёх фазах:
0–50 основание, 50–75 природный рельеф и грунты, 75–100 лес и подлесок.
Это доля обработанных колонок/чанков, а не оценка времени или количества блоков.

При необходимости поддерживаются `/slavicmyths dev buyan pause`
и `/slavicmyths dev buyan resume` (оба действия относятся к текущей фазе).
Не начинайте два острова одновременно.

## Проверки

Проверьте после сообщения о 100%: непрерывность основания и природных холмов,
отсутствие квадратных провалов, 3 проходимых выхода, поляна 70–100 блоков,
леса, прочность основания, скорость и TPS. Сохраните мир, выйдите и зайдите
повторно; запросите `status`. Повторите с несколькими seed.
Не проверяйте на основном сохранении. Фактические игровые проверки
должны быть выполнены вручную или через отдельные GameTests.

## Портовые постройки (в этой же ветке Буяна)

После автоматического завершения основания, рельефа и растительности генератор
делает попытку разместить у северного берега три готовых помещения (жилой дом,
торговую лавку и склад с интерьером), основную и малую пристани, а также тропы.
Постройки не используют генератор кораблей или другую ветку. Повторное размещение
на одном участке запрещено постоянной записью в SavedData.

Если порт не поставился из-за занятого участка или старого сохранения, используйте
на полностью завершённом острове команду:

```text
/slavicmyths dev buyan harbor
```

Сообщение об отказе означает, что участок не менялся — проверьте сохранение и
при необходимости испытайте на новом отдельном мире. Для интеграции обязательны
успешная Java 21 сборка и осмотр фасадов, помещений, проходов и пристаней в клиенте.
