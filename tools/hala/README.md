# Hala VII — approved V2 geometry
The authoring source is the approved 2,781-cuboid Matplotlib prototype. The build exporter samples the same 12 tracks without remeshing or replacing feathers. Geometry, collision groups and staff origin share one coordinate system (14 prototype units per block). The Java reader interpolates between 13 sampled poses per non-idle track.
No AI-generated image is shipped as a mesh. Sounds are original deterministic non-vocal creature/magic effects. Python dependencies are the existing Sand King requirements.
