# Slavic Myths 0.9.10 RC1

## Added
- Сохранённые encounter-slots для курганных врагов и общий эффект Порез.
- Метаданные командных курганов; фиксированные Воевода/Волхв/Князь по типу кургана.
- Локальная RC-сборка, release-документы и checksum.

## Changed
- Смешанная наружная палитра насыпи и поднятого грунта через пространственные patches.
- Круглая модель щита дружинника, читаемая непрозрачная страница книги и кухня с выбором рецепта/условиями приготовления.
- Сохранены ранее выполненные изменения текущего рабочего дерева, включая port 1.21.1, worldgen/болото/навигацию. Новый overhaul разбойников и Соловья в RC1 не выполнялся.

## Fixed
- Нормализованы shield UV, восстановлена blocking-модель и shield durability enchant tag.
- Зарегистрирован клиентский экран существующего RPG-меню: Камень пути и рунная наковальня.
- Shift-click и первый слот наковальни; серверные операции и существующие item components сохранены.
- Исключены повторные melee/accessory бонусы из периодического Пореза.
- Расчистка подхода к кургану сохраняет каменную кладку.
