# Palette randomization rule

Do not choose each block independently from weighted random every coordinate.
That creates static noise.

Use coherent patches:
- 2×2 to 5×4 weathered regions;
- vertical damp bands;
- support structures;
- cracked sections.

Material placement must look constructed and aged, not randomized.
