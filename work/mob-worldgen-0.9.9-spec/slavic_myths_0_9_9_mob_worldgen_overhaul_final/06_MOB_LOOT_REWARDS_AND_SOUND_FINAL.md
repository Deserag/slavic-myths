# 06 — MOB LOOT / REWARDS

Before adding items:
audit current item registry and loot tables.

Prefer existing materials.

Only add a new item if there is no existing equivalent.

---

# 1. REWARD TIERS

Ambient/passive wildlife:
small useful drops only.

Normal hostile spirit:
common thematic material + modest rare component.

Elite:
useful guaranteed material + rare trophy/component chance.

Miniboss:
reliable meaningful reward + rare/unique component.

Boss:
guaranteed unique/relevant reward plus supporting loot.

---

# 3. WILDLIFE DROPS

Bear:
hide/leather equivalent;
meat if current design has meat;
claw chance.

Mother Bear:
increased normal materials;
Great Bear Claw/trophy.

Cub:
no valuable drops.

Deer:
venison/hide/antler according to existing registry.
Stag can have antler chance.
Doe/fawn should not produce superior trophy loop.

Boar:
meat;
tusk chance;
hide if existing.

Wolf:
hide/fang only if already part of progression; otherwise modest drops.

---

# 4. BOSS REWARD AUDIT

For every boss/miniboss:
verify loot table exists and fires exactly once.

Specifically verify:
- Restless Prince;
- world bosses;
- Elder Vodyanoy;
- Ataman;
- Solovey 250 HP;
- Mother Bear miniboss.

No boss can die and produce generic low-value loot only.

---

# 5. XP

Use tier-based XP.
Do not use huge numbers.

Suggested:
normal hostile: 5–10
strong/elite: 12–25
miniboss: 35–60
boss: 80–150

Preserve existing intentional values if consistent.

---

# 6. LOOT SAFETY

No reward should require killing:
- cubs;
- fawns;
- service NPCs.

Do not incentivize degenerate baby-animal farms.
