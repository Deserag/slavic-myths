# HOW_TO_GIVE_TO_CODEX

1. Передай Codex весь этот пакет целиком.
2. Основной файл: `PROMPT_CODEX_KURGAN_0.8.6_CREATURES.md`
3. Папка `references/` обязательна и является частью ТЗ.
4. Короткая инструкция для Codex:
   `Implement PROMPT_CODEX_KURGAN_0.8.6_CREATURES.md exactly. Treat references/ as mandatory constraints. Do not redesign the feature. Do not launch Minecraft.`
5. Если Codex начинает фантазировать, возвращай его к разделам 0, 1 и 25.
