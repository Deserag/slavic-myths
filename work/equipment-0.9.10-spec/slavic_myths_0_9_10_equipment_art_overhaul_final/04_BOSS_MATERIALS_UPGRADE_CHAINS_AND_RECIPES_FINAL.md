# UPGRADE CORE

Recipe concept:
`Primary boss material + 2–4 thematic secondary materials -> Upgrade Core`

Full set target:
roughly 1–3 boss victories, not 20.

Document exact drop/core counts.

# TEMPLATE

Prefer ONE:
`slavic_equipment_upgrade_template`

Avoid one template per set unless actual progression strongly requires it.

Template:
clear acquisition + sensible duplication recipe.

# SMITHING

Concept:
`Slavic Template + Diamond Equipment + Upgrade Core -> Upgraded Equipment`

Preserve:
- enchantments;
- custom name;
- safe components;
- durability ratio where appropriate.

# UNIQUE WEAPONS

If current boss already directly drops weapon, keep that path if established.
If weapon logically upgrades an existing item, use smithing.

# REPAIR

Define repair material for every new set/weapon.

# JEI
