# 6. ВНЕШНИЙ ВИД БАБЫ-ЯГИ — ОБЩЕЕ

Яга должна быть:
- старой;
- сутулой;
- визуально сильной как персонаж;
- слегка страшной, но не чистым монстром;
- сразу узнаваемой.

Нельзя делать:
- Witch reskin;
- generic old villager;
- стандартную женщину-NPC с серой texture.

Рост:
примерно `1.75` блока nominal height.

Из-за сутулости в idle визуально выглядит ближе к `1.6–1.65`.

# 7. ВНЕШНИЙ ВИД БАБЫ-ЯГИ — ГОЛОВА И ЛИЦО

Обязательно:
- длинный крючковатый нос;
- острый подбородок;
- глубокие морщины;
- узкие светящиеся/ярко читаемые глаза жёлто-янтарного оттенка;
- густые седые брови;
- впалые щёки;
- немного недовольное/ироничное выражение лица.

Глаза:
- не neon laser;
- лёгкое свечение допустимо только как слабый emissive/fake highlight.

Кожа:
- pale beige / weathered / old;
- тени серо-коричневые.

Не делать зелёную ведьму.

# 8. ВНЕШНИЙ ВИД БАБЫ-ЯГИ — ВОЛОСЫ, ПЛАТОК, УКРАШЕНИЯ

Волосы:
- длинные седые;
- спутанные;
- часть выбивается наружу.

Поверх волос:
- тёмно-красный/бордовый платок;
- ткань старая, но не рваная в лохмотья полностью;
- белые/серые точки/узор допустимы только если не конфликтуют с reference-style.

Украшения:
- множество бусин/костяных амулетов;
- маленькие черепа/кости;
- красные/деревянные bead strings;
- 1–2 амулета на груди.

На шее и груди украшения должны формировать отдельный силуэт.

# 10. ВНЕШНИЙ ВИД БАБЫ-ЯГИ — КОСТЯНАЯ НОГА

Это обязательный элемент.

# 15. PLACEMENT ИЗБУШКИ

Controlled placement, а не tiny RNG.

Предпочтительный диапазон:
`800–2500 блоков` от world spawn.

Предпочтительные биомы:
- Forest;
- Birch Forest;
- Dark Forest;
- лесная опушка / граница леса.

Должен быть safe anchor.

Одна избушка на мир — предпочтительно.
Если архитектура проще поддерживает очень редкий ограниченный набор, допускается 1–2, но основная и каноничная должна быть одна.

README должен описывать фактическое поведение.

# 16. ИЗБУШКА — ГАБАРИТЫ И СИЛУЭТ

Ориентир footprint:
примерно `9×11` или `11×13`.

Основа:
- деревянный сруб;
- поднят на двух больших куриных ногах;
- виден просвет под домом;
- есть небольшое крыльцо/вход;
- крыша массивная, слегка кривая;
- есть труба.

Силуэт должен быть уникален даже издалека.

# 17. КУРЬИ НОГИ ИЗБУШКИ

Обязательно:
- 2 большие ноги;
- суставы читаются;
- 3 передних пальца;
- 1 задний палец;
- тёмные когти;
- грязно-жёлто-костяной/серо-коричневый цвет.

Ноги НЕ просто столбы.

Они должны выглядеть как большие живые куриные ноги.

Если полная динамическая анимация ног слишком опасна для структуры:
- использовать mostly static pose;
- допускается лёгкая ambient animation/particles/creak effect без real block relocation.

# 21. ПЕРВОЕ ЗНАКОМСТВО С ИЗБУШКОЙ

Нужен scripted intro.

На первом посещении:
- избушка initially «не реагирует»;
- игрок получает короткое сообщение/текст;
- после повторного взаимодействия запускается событие признания.

- избушка замечает игрока;
- скрипит;
- топает;

Минимум эффектов:

# 23. БЛАГОСКЛОННОСТЬ — UX ПРАВИЛО

Пользователь отдельно утвердил поведение:

## На основном экране
`Благосклонность` показывает ТОЛЬКО текущий статус.

Например:
- `Чужак`
- `Гость`
- `Доверенная персона`

Можно визуально показать progress band/icon, но без вывода полного длинного объяснения уровня прямо постоянно.

## Подробности открываются ТОЛЬКО по `?`
Рядом с блоком благосклонности должна быть маленькая кнопка `?` / help / info.

Только после нажатия открывается всплывающая панель / popup / side sheet с объяснением:
- все уровни доверия;
- что каждый открывает;
- как двигаться дальше.

То есть по умолчанию подробный текст спрятан.

# 24. УРОВНИ БЛАГОСКЛОННОСТИ

Всего 3 статуса:

## 24.1 Чужак
Начальный статус.

Смысл:
- Яга относится с осторожностью;
- открыты простые поручения;
- обмен ограничен;
- награды за поручения на карточках НЕ показываются.

## 24.2 Гость
Средний статус.

Смысл:
- Яга начинает доверять;
- открываются новые поручения;
- открывается часть полезных услуг;
- начиная с этого статуса на карточках поручений показывается `Награда`.

## 24.3 Доверенная персона
Высший статус.

Смысл:
- Яга считает игрока своим;
- открываются особые поручения;
- открываются лучшие услуги/обмен/ритуальные возможности.

# 25. `?` ДЛЯ БЛАГОСКЛОННОСТИ — СОДЕРЖИМОЕ POPUP

Popup/tooltip/panel по кнопке `?` должен содержать:
- название `Уровни благосклонности`;
- список всех 3 статусов;
- короткое описание каждого;
- что unlock each status;
- подсказку, что статус повышается через помощь Яге/выполнение поручений/принесение нужных вещей.

Popup НЕ должен занимать весь экран.

Он должен быть компактным и удобным.

---

# 26. `?` ДЛЯ ПОДСКАЗОК И УСЛУГ — UX ПРАВИЛО

Пользователь отдельно зафиксировал:
`Подсказки и услуги Яги` НЕ должны висеть постоянно на экране.

По умолчанию они скрыты.

Должна быть маленькая кнопка `?` / info / book icon рядом с разделом или в правой части интерфейса.

Только при нажатии открывается:
- popup/side panel с подсказками;
- список сервисов/услуг;
- короткие пояснения по интерфейсу.

То есть:
- базовый экран чище;
- лишний текст не шумит;
- подробности доступны по желанию.

# 30. ВКЛАДКА `ПОРУЧЕНИЯ` — ОБЩИЙ ПРИНЦИП

Это один из главных экранов версии.

Отображаются карточки активных/доступных поручений.

Карточка должна показывать:
- название;
- короткое описание;
- требования;
- кнопку принять/сдать;
- награду — только если статус >= `Гость`.

При `Чужак`:
- секция `Награда` скрыта или заменена фразой типа `Яга сама решит, чем одарить.`

При `Гость` и `Доверенная персона`:
- награда показывается явно.

# 31. СТАРТОВОЕ ПОРУЧЕНИЕ

Название:
`Не с пустыми руками`

Суть:
Яга просит доказать серьёзность намерений.

Требовать набор из уже существующих трофеев ранних охот.

Допустимая конфигурация:
- ovinnik ash / аналог 0.9.0;
- volkolak fang / шкуры / аналог 0.9.0;
- pylayuschaya_cheshuya / ognennoe_pero или другой огненный трофей 0.9.1;
- uzel_podveya / vihrevaya_nit или другой ветровой трофей 0.9.1.

После выполнения:
- игрок переходит в статус `Гость`.

# 32. ПОРУЧЕНИЕ `ЖАР ДА ВЕТЕР`

Средняя стадия прогрессии.

Суть:
принести подготовленные трофеи стихий.

Обязательно использовать:
- `sosud_ognennogo_dyhaniya`
- `sosud_podveya`

Это было заранее заготовлено в 0.9.1, поэтому здесь эти вещи должны наконец получить назначение.

После выполнения:
- открывается новая линия услуг Яги;
- открывается/усиливается Котёл;
- выдаётся одна из ключевых наград 0.9.3 (например Путеводный клубок или доступ к следующему поручению — выбрать фактическую последовательность ниже).

# 33. ПОРУЧЕНИЕ `ДОКАЗАТЬ СИЛУ`

Поздняя стадия.

Смысл:
Яга должна убедиться, что игрок справился с бедствиями большего масштаба.

Проверка может строиться:
- через наличие advancement за убийство `likho_one_eyed` и `tugarin_zmey`;
- и/или через принесение определённых предметов.

Предпочтительно не отнимать единственные критичные предметы, если они нужны для других крафтов.

Поэтому:
- либо проверять kill advancements;
- либо требовать дополнительные/побочные трофеи, а не обязательно забирать `oko_likha`, если оно нужно игроку.

После этого статуса игрок становится `Доверенная персона`.

# 34. REPEATABLE CONTRACTS

После открытия `Гость` и особенно `Доверенная персона` Яга может выдавать повторяемые поручения.

Типы:
- охота на существ прошлых версий;
- сбор ингредиентов;
- редкие предметы леса/болота.

Основная фокус-группа repeatable targets:
- Ovinnik;
- Volkolak;
- Fire Serpent;
- Podvey.

Редко:
- Likho;
- Tugarin.

Награды:
- ингредиенты котла;
- редкие материалы;
- полезные расходники;
- небольшие ритуальные компоненты.

Не делать бесконечную сложную procedural quest system. Достаточно controlled pool.

# 35. ВКЛАДКА `ОБМЕН`

Яга может обменивать:
- редкие трофеи;
- алхимические/ритуальные ингредиенты;
- уже существующие предметы hunt-ветки;
- 0.9.3 utility items.

Это НЕ обычный villager trading GUI с emerald cost.

Лучше сделать thematic exchange entries:
- слева требования;
- справа результат;
- кнопка `Обменять`.

При низком статусе часть обменов locked.

Не нужно 50 рецептов.

Для 0.9.3 достаточно 6–8 уникальных рецептов.

# 38. КОТЁЛ — ПРИМЕРНЫЕ РЕЦЕПТЫ 0.9.3

Нужны 6–8 рецептов, но в PROMPT фиксируем ядро:

## 38.1 Отвар очищения
Снимает некоторые обычные негативные эффекты.

НЕ снимает:
- persistent kurgan curse;
- special boss/world flags.

## 38.2 Летучая мазь
Используется для already-existing flight items.

Так как пользователь указал, что:
`метла и ступа уже есть`,
в 0.9.3 НЕ нужно заново проектировать их базовую систему с нуля как новый контент.

Вместо этого Яга должна:
- обслуживать/улучшать/поддерживать уже существующие системы метлы и ступы;
- давать доступ к связанным расходникам.

Летучая мазь:
- частично снижает cooldown полёта у метлы/ступы;
- не обнуляет полностью.

## 38.3 Отвар лесной зоркости
Короткий utility effect для исследования леса/сумерек.

## 38.4 Ягин настой стойкости
Короткая временная защита/utility.

Остальные рецепты можно реализовать по тем же правилам, не уезжая в power creep.

# 41. КАК ОТОБРАЖАТЬ НАГРАДЫ
