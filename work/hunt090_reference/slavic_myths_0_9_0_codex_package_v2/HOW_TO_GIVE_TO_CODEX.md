# HOW TO GIVE THIS TO CODEX

Передай Codex весь ZIP/папку.

Одно стартовое сообщение:

`Implement PROMPT_CODEX_SLAVIC_MYTHS_0.9.0_V2_DETAILED.md exactly. Treat references/ as mandatory visual constraints. Read only the minimum repository context required by section 1. Do not redesign anything and do not launch Minecraft.`

Важно:
- не отправляй Codex отдельный широкий запрос «придумай 0.9.0»;
- дизайн уже находится в PROMPT;
- если Codex начинает предлагать варианты вместо реализации, вернуть его к разделам 0, 1, 2;
- если Codex упрощает предметы до 16/32px — вернуть к разделу 4;
- если упрощает AI — вернуть к разделам 8 и 9.
