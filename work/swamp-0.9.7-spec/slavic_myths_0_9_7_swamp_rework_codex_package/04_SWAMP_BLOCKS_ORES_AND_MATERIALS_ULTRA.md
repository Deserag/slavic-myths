# 04 — SWAMP BLOCKS / ORES / MATERIALS — ULTRA DETAIL

Swamp update may include targeted material improvements.
Do NOT bloat content with dozens of unnecessary blocks.

## Core rule
Any ore/block touched in this version must read properly in Minecraft.

---

# ORE STYLE RULES

If swamp-related ores are reworked:
- the host stone/deepslate texture must remain visible;
- ore insertions must read like mineral inclusions;
- do not draw a flat icon on a stone square;
- keep contrast readable;
- ensure ore clusters fit Minecraft conventions.

Examples from approved overall direction:
- swamp iron;
- swamp gold;
- swamp coal or bog-dark mineral variant;
- muddy stone / mossy natural construction stone if justified.

Only keep/implement ore variants that make design sense and are useful.

---

# NATURAL DECORATIVE BLOCKS

Useful candidates if needed:
- damp stone / wet stone;
- mossy structural stone for ruins;
- marsh timber / ruined wood set dressing pieces (if not already handled through vanilla block use);
- natural debris blocks only if they really improve atmosphere.

Blocks must have clear usage in:
- swamp structures;
- environmental storytelling;
- world detail.

---

# MATERIAL USEFULNESS

If a block is added, it must answer:
- what is it used for?
- where does it generate?
- why should the player care?

No filler decorative block with zero purpose.
