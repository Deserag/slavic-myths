# 05 — LOOT / REWARDS / INTERACTION LOOPS — ULTRA DETAIL

Main user complaint:
Swamp locations currently lack reward and purpose.

This file defines how swamp content becomes meaningful.

## Structure reward rule
Every meaningful swamp structure must provide one or more of:
- practical survival reward;
- swamp-specific crafting/relic reward;
- clue/map/note reward;
- stronger rare loot at rarer sites;
- encounter-linked reward;
- utility item chance.

## Suggested reward themes by structure

### Fisher Hut
- fish/fishing utility;
- herbs;
- rope/net style materials if supported;
- food/supplies;
- occasional map/clue.

### Watchtower
- arrows / ranged supplies;
- coins;
- tools;
- travel/survival stash.

### Ritual Shrine
- charms;
- ritual ingredients;
- relic fragments;
- rare mystical component.

### Abandoned Hut
- salvage;
- small valuables;
- hidden cache;
- low-to-mid utility.

### Rare Shrine Cluster
- strongest swamp loot band;
- guarded reward;
- rare component/relic/material.

## Interaction loops
Examples of good loop:
- see watchtower → approach landmark → fight or clear area → get usable loot and view area.
- find hut → obtain clue/note or materials → hint toward stronger shrine.
- enter shrine → face stronger mob encounter → gain better ritual reward.

Bad loop:
- see structure → open one empty chest → leave.

## Loot density
Do not overfill common structures.
But avoid “all risk, no payoff”.

Common small structures:
- 1–2 meaningful loot points.
Medium structures:
- 2–4.
Rare cluster:
- several meaningful rewards distributed across sub-areas.

## Mob-reward link
A stronger swamp creature should often protect a better reward.
