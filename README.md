# Slavic Myths

**Slavic Myths is a Minecraft 1.21.1 NeoForge mod about Slavic folklore, exploration, character stories, crafting and rural life. Active development; Slavic Myths 2.0 has not been released.**

Славянские сказания здесь становятся приключением: можно обустроить хозяйство, познакомиться с духами, заслужить доверие сказочных персонажей, исследовать курганы и пройти испытания богатырей. Исследование, истории, ремёсла и развитие персонажа соединяются с обычным выживанием. Это игровая интерпретация фольклора: народные сюжеты, поздние реконструкции и авторские механики не следует принимать за единое историческое учение.

## Версия, установка и сборка

Каноническая ветка — **main**. Текущая версия исходников — **1.9.7.9**, историческое обозначение с четырьмя компонентами. Это не опубликованный стабильный релиз. `master` служит совместимым указателем основной версии, а не отдельной линией разработки.

На 18 октября 2026 года опубликованы только [0.9.10 RC1](https://github.com/Deserag/slavic-myths/releases/tag/v0.9.10-rc1) и [0.9.10 RC2](https://github.com/Deserag/slavic-myths/releases/tag/v0.9.10-rc2). Их содержимое значительно старше текущих исходников. Публичного JAR 1.9.7.9 на GitHub Releases нет; локальные кандидаты 1.6–1.9 и отчёты об установке не означают публикацию.

Текущая сборка требует **Minecraft 1.21.1, NeoForge 21.1.255, Java 21, Curios API 9.5.1 для 1.21.1**. JEI и Xaero Minimap необязательны. Точные зависимости: [build.gradle](build.gradle), [метаданные](src/main/resources/META-INF/neoforge.mods.toml).

Поместите совместимый JAR и обязательные зависимости в `mods` отдельного профиля. Не оставляйте две версии Slavic Myths одновременно. Перед обновлением сохраните копию мира. ZIP из меню Code — исходники, а не готовый мод. Старый профиль Minecraft 1.16.5 не подходит и не должен перезаписываться портом.

Для сборки из исходников используйте Java 21 и `gradlew.bat clean build` на Windows либо `./gradlew clean build` в другой поддерживаемой среде. Результат — `build/libs/slavicmyths-1.9.7.9.jar`. Номер задаётся в [gradle.properties](gradle.properties). Обычный build не требует запуска игры. Старые одноразовые установщики в `tools` переведены в архивный режим и не предназначены для нынешнего дерева.

## С чего начать

1. Подготовьте жильё, еду, броню и место для находок. Грядки и хозяйство полезны параллельно исследованию.
2. Пользуйтесь **Книгой сказаний**: встречи, предметы и сюжетный прогресс открывают сведения о существах, ремёслах и ритуалах. Читайте подсказки предметов и условия заданий.
3. Исследуйте новые территории: деревенские места, леса, болота, водоёмы, лагеря и курганы дают разные маршруты. Постройки зависят от биомов и условий мира, а не гарантируются рядом со спавном.
4. Разговаривайте с мирными персонажами правой кнопкой мыши. Доверие и выполненные поручения открывают больше, чем случайное нападение.
5. Выберите класс в его интерфейсе, изучите навыки и подготовьте подходящую экипировку. Класс не заменяет знание механик противника.
6. К боссам и ритуалам переходите после чтения сказаний и подготовки компонентов. Победа может требовать очищения, разговора или завершения истории.

В природе живут бурые медведи и медвежата, лесные волки, кабаны, олени и оленухи; в воде — щука, карп и раки. Охота и домашнее животноводство дают разные цепочки ресурсов.

### Серый Волк

После начального испытания доступна последовательная цепочка из четырёх заданий: разбойники, главный противник кургана, Лихо и проклятый волколак. Первое требует 15 разбойников; следующие связаны с отдельными встречами и предыдущим прогрессом. Интерфейс показывает состояние, условия, отслеживание цели и выдачу награды. Некоторые награды раскрываются через вопрос персонажу. Для получения нужен свободный инвентарь, который проверяет сервер.

Источники: [quests.json](src/main/resources/data/slavicmyths/wolf_story/quests.json), [GreyWolfStory](src/main/java/org/slavicmyths/military/GreyWolfStory.java). Историческое слово `future` в ID последнего задания само по себе не означает отсутствия текущей реализации.

### Яга, Кузя и Баюн

У Яги есть основные этапы поручений, дополнительные задания и обмены. Поздние услуги требуют прогресса, в том числе в столкновениях с Лихом и Тугарином. Одного наличия ингредиентов недостаточно для закрытого обмена. Котёл, хозяйство избы с Кузей, метла и ступа образуют отдельную линию ремесла и путешествий.

Баюн обладает собственными диалогами, песнями и доверием. Он может быть опасен: очарование и нападение являются частью поведения. Подарки имеют ограничения, новые разговоры зависят от пережитых историй. Творческий спавн не воспроизводит прохождение естественной встречи.

## Постройки и исследование

В ресурсах определены **20 worldgen structure ID**: малый, средний и большой лагеря разбойников; городище, рыбацкий лагерь, заброшенное поселение; подземный город Чуди и заброшенный комплекс; малый, воинский и большой курганы; болотная гать, изба, остатки построек и башня; затопленное святилище и подводные руины; Обитель Чистого Источника, Святилище Неугасимого Пламени и Змеиная гора.

Святыни связаны с хранителями, гора — с Горынычем, лагеря и курганы — со своими противниками и трофеями. Условия задают текущие biome tags, structure JSON и генераторы. Некоторые места встреч создаются features и событиями, поэтому перечень structure ID не охватывает все места мода. Новые постройки ищите в новых чанках; они не обязаны появляться в уже исследованной местности. Схемы и mesh preview в документации — технические иллюстрации, не игровые скриншоты.

## Классы и способности

Три основы — **Дружинник, Ведун, Разбойник**. Активные приёмы, пассивные навыки и срабатывающие способности имеют требования, ранги и серверные cooldown. Максимальный уровень — 50; первое разветвление доступно с 10-го, второе — с 25-го. Финальное направление связано с поздним уровнем и испытанием, его способность занимает отдельный слот.

| Основа | Первое разветвление | Следующие специализации |
|---|---|---|
| Дружинник | Витязь / Гридень | Богатырь, Ратоборец / Щитоносец, Воевода |
| Ведун | Волхв / Колдун | Обережник, Знахарь / Моровик, Чернокнижник |
| Разбойник | Ушкуйник / Главарь | Налётчик, Стрелок / Атаман, Резник |

Дружинник развивает ближний бой и защиту, Ведун — знаки, обереги, лечение и проклятия, Разбойник — движение, стрельбу, ловушки и выгодный момент атаки. Поздние направления: Громобой, Мастер Сечи, Несокрушимый, Верховный Воевода, Хранитель Круга, Животворец, Повелитель Мора, Тайновед, Вихревой Налётчик, Соколиный Глаз, Теневой Атаман и Кровник.

Актуальные определения: [ClassDefinitions](src/main/java/org/slavicmyths/rpg/classes/ClassDefinitions.java), [ClassUltimates](src/main/java/org/slavicmyths/rpg/classes/ClassUltimates.java). `docs/CLASS_SYSTEM.md` — ранняя концепция, не текущее дерево. Это игровая классификация, а не исторические сословия.

## Оружие, экипировка и руны

Существуют мечи, кинжалы, копья, топоры, булавы/кистени, посохи, щиты, луки и арбалеты. Семейства различаются назначением, дистанцией и приёмами; именные трофеи не равнозначны очередному материалу обычного меча. Модели и читаемость силуэтов ещё проходят визуальную приёмку.

Оружейное ремесло, броня и рунические гнёзда связаны со специальными рабочими местами. Руны имеют совместимость, требования к основе и ограничения установки. Рецепты доступны в интерфейсе рунического ремесла, при установленном JEI — также в его категории. Не каждая руна подходит любому слоту, копии редкого эффекта не обязаны складываться.

Редкие руны: Полёт, Парящее оружие, Защита, Смерть, Берсерк и Жертва. Их источники — трофеи, именные осколки и поздние обмены Яги; восстановление требует осколков именно нужной руны. Обычная и редкая Защита имеют разные ID. Подробнее: [редкие руны](docs/RARE_RUNES_1.3.4.3.md).

Амулеты, кольца и сказочные награды используют предусмотренные слоты и серверные проверки. Curios нужен для поддерживаемых аксессуаров. Оберег двух зим объединяет зимние награды, имеет режимы и условия действия. Творческая копия предмета не даёт автоматически персонального права на сюжетную награду.

## Хозяйство и ремёсла

- **Земледелие и сад:** культуры, семена, овощи, ягоды и садовые ресурсы для еды и ремесла. Составы рецептов различаются, любые ягоды не считаются взаимозаменяемыми.
- **Животные и охота:** гуси, утки и домашние козы, кормушки и хозяйственные предметы; дикая фауна, охота и обработка туш образуют другую цепочку.
- **Кухня:** жернова, мука, крупа и тесто; ржаной хлеб, тушёные овощи, овсяная/ячменная/ягодная каши, гороховый и грибной супы, овощное и мясное рагу. Кухонный стол обслуживает отдельные рецепты.
- **Напитки:** пресс, сусло, бродильный чан и бочка; светлое, тёмное, хмельное, медовое, лесное, громовое, тёмное Велесово и ведьминское ягодное пиво. Учитываются созревание и порча: позднее не всегда лучше.
- **Лён и текстиль:** льняная цепочка, ткани, ткацкое рабочее место и одежда, связанные с хозяйственными ресурсами.
- **Мебель и хранение:** деревянная мебель, места для сидения, домашние ёмкости и специализированные хранилища. Декоративная модель не обещает универсальный контейнер.
- **Деревни:** дополнительные профессии дружинника, мельника, пивовара, ткача, скотника, охотника и повара; их рабочие места — военный стол, жернова, бродильный чан, ткацкий стол, кормушка, охотничье хранилище и кухонный стол. Доступность рабочего места важна для профессии.
- **Строительство и производство:** семейства древесины, потемневшая курганная древесина, производственные и ремесленные блоки дополняют строительство и экипировку. ID и реальные рецепты собраны в каталоге.

## Книга, ритуалы, достижения

Книга сказаний связывает обнаруженные существа, предметы, постройки и сюжет. Знание, доверие, репутацию и выполненные условия проверяет сервер. Ритуалы требуют конкретных компонентов и условий: декоративного круга самого по себе недостаточно.

Достижения Minecraft сохраняются, собственные находятся в namespace `slavicmyths`. **Переработка V3 с 75 видимыми карточками остаётся отдельной активной локальной работой и не входит в main.** Отклонённый вариант на 55 карточек её не заменяет. Зависимые fixes учитываются при отдельной интеграции V3. Баланс PR #27 также не включён в консолидацию. Открытый PR и соседняя рабочая копия не являются частью основной версии автоматически.

## Управление

Сочетания меняются в настройках Minecraft. Некоторые клавиши совпадают между контекстами — проверьте конфликты в своей сборке.

| Действие | По умолчанию |
|---|---|
| Разговор / использование предмета и рабочего места | Правая кнопка мыши |
| Интерфейс класса | K |
| Три активных классовых слота | G / H / J |
| Финальная классовая способность | U |
| Интерфейс богатырской истории | L |
| Действие редкой руны | R, при подходящей экипировке |
| Снижение в системах полёта | X |
| Торможение / груз сказочного полёта | R / B |
| Сосульки / волна / зеркало зимней экипировки | G / V / M |
| Дыхание / жатва / крыло ночной экипировки | G / V / B |
| Кольцо истории Волка | V |

Клавиша отправляет запрос: неизвестный навык, неподходящий слот, cooldown или стадия истории могут блокировать действие. Управление сверено с клиентскими key mappings, без новой игровой проверки.

## Качество и ограничения

**Мод находится в доработке; стабильная 2.0 не объявлена.** Остаются сообщённые владельцем повторяющиеся звуки, проблемные анимации, дизайн Русалки и некоторых других существ, сломанные модели и несогласованная пиксельная детализация. Успешный build не подтверждает их исправление. Прежние отчёты могут относиться к старой сборке или отдельной ветке.

В консолидации #43 выполнены Java 21 clean build, офлайн-проверки и проверка production JAR/ресурсов. Minecraft, игровой сервер и GameTest не запускались: **0 запусков**. Новые проверки звука, внешнего вида, полного прохождения, мультиплеера и FPS/MSPT не заявляются. Удаление временных массивов в рендере не является измеренным ростом FPS.
