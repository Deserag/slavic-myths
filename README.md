# Slavic Myths — Славянская мифология

Мод для **Minecraft 1.21.1 / NeoForge 21.1.255**: славянские сказания, исследование мира, встречи с духами, ремёсла и развитие персонажа. Можно обустроить хозяйство, заслужить доверие Яги и Баюна, исследовать курганы и поселения Чуди, помогать богатырям и проходить истории боссов.

Это игровая интерпретация фольклора: народные сюжеты, поздние реконструкции и авторские механики не выдаются за единый исторический источник.

## Версия и ветки

- **release** — ветка мода для установки и принятой базы второй версии. Текущая техническая сборка — **1.9.7.67**, на основе принятой владельцем 1.9.7.66. В этом обслуживающем обновлении игровой код не менялся.
- **main** — дальнейшая разработка и управление проектом. Содержимое соседних веток и открытых PR не входит в release автоматически.
- Историческое обозначение 1.9.7.x сохранено. Название «вторая версия» не означает смену mod ID или автоматическое создание GitHub Release с номером 2.0.

## Установка

| Компонент | Требование |
|---|---|
| Minecraft | 1.21.1 |
| Загрузчик | NeoForge 21.1.255 |
| Java | 21 |
| Обязательная зависимость | Curios API 9.5.1 для Minecraft 1.21.1 |
| Необязательные интеграции | JEI, Xaero Minimap |

1. Создайте отдельный профиль Minecraft 1.21.1 с NeoForge. Старый профиль 1.16.5 для этой сборки не подходит.
2. Установите Curios и JAR Slavic Myths в каталог `mods`. В папке должна быть только одна версия `slavicmyths`.
3. Перед обновлением сохраните копию мира. Не удаляйте конфигурации и сохранения ради переустановки мода.
4. Для совместной игры установите одинаковые версии мода и обязательных зависимостей на сервере и у клиентов. JEI и миникарта относятся к необязательным клиентским дополнениям.

ZIP из кнопки **Code** содержит исходники. Готовый JAR получают сборкой ниже либо из проверенного артефакта [Production Java 21](https://github.com/Deserag/slavic-myths/actions/workflows/production-java21.yml). Существующие публичные RC-релизы 0.9.10 существенно старше этой ветки.

## Первые шаги

1. Подготовьте жильё, еду и обычную экипировку.
2. Откройте **Книгу сказаний**: записи открываются по мере встреч и выполнения условий. Категории сворачиваются; боковую панель можно скрыть, описания и достижения просматривать отдельно.
3. Разговаривайте с персонажами. Репутация, знания и поручения открывают обмены, исследования и новые встречи.
4. Выберите класс, изучите навыки и назначьте их в три активных слота.
5. Изучайте новые территории: постройки зависят от биома и условий мира. Для сюжетного противника сначала получите направление или прочитайте связанные сказания.

## Основные возможности

- **Духи и персонажи:** Домовой, Кузя, Леший, Кикимора, водные и полевые духи, Баба-яга, Кот Баюн, Серый Волк и другие сказочные встречи.
- **Проводники и истории:** репутация, поручения, поиск противников и поселений Чуди, подсказки в общей книге.
- **Четыре богатыря:** Илья, Добрыня, Алёша и Финист. Право призыва получают за помощь; в совместной игре вклад хранится отдельно для каждого игрока. На весь сервер допускаются два призванных богатыря.
- **Исследование:** курганы с комнатами и наградами, святилища, поселения и шахты Чуди, лагеря и деревенские места.
- **Развитие:** Дружинник, Ведун и Разбойник, специализации, активные и пассивные навыки, финальные способности.
- **Экипировка:** разные семейства оружия, броня, аксессуары Curios, рунические гнёзда и именные награды.
- **Хозяйство:** культуры и ягоды, домашние животные, кухня, напитки, текстиль, мебель, хранение и деревенские профессии.
- **Перемещение:** метла, ступа со вторым пассажиром и другие сказочные средства; инструменты Чуди для добычи и безопасного подъёма.

Подробности, условия и ограничения собраны в [описании содержимого](MOD_CONTENT.md). Технические ID и ссылки на исходники — в [каталоге](docs/CONTENT_CATALOG.md).

## Управление

| Действие | Стандартная привязка |
|---|---|
| Разговор, использование предмета или рабочего места | ПКМ |
| Окно класса | K |
| Активные слоты навыков | Ctrl+1, Ctrl+2, Ctrl+3 — верхний цифровой ряд |
| Финальная классовая способность | U |
| Окно богатырской истории | L |
| Действие редкой руны | R, при подходящей экипировке |
| Снижение / торможение / груз в системах полёта | X / R / B |
| Смена режима кирки и формы мультиинструмента Чуди | Shift+ПКМ по воздуху |

Привязки меняются в настройках Minecraft и в интерфейсе класса. Поддерживается Ctrl, Shift или Alt вместе с одной клавишей либо кнопкой мыши. Пользовательские настройки PolyMC могут отличаться от стандартных; обновление JAR их не сбрасывает. Остальные контекстные действия: [памятка управления](docs/CONTROLS.md).

## Сборка из исходников

Windows PowerShell с установленной Java 21:

```powershell
$env:JAVA_HOME = 'C:/Program Files/Java/jdk-21.0.12'
./gradlew.bat clean build
python tools/verify_current_resources.py
```

Linux/macOS с Java 21:

```bash
chmod +x gradlew
./gradlew clean build
python3 tools/verify_current_resources.py
```

Для Python-проверки ресурсов нужен Pillow. Итоговый файл: `build/libs/slavicmyths-<mod_version>.jar`; версия определяется в [gradle.properties](gradle.properties). Сборка не запускает Minecraft. Дополнительные тесты и временные миры не входят в production JAR.

## Совместимость и известные ограничения

Существующие mod ID `slavicmyths`, registry ID и система сохранений сохраняются. Проверены совместные поручения, общий лимит союзников и сохранение прав после перезапуска с двумя настоящими сетевыми клиентами. Это не утверждение о полном прохождении всех историй на каждом сервере.

При первой генерации крупных новых поселений наблюдались задержки примерно 7–10 секунд. У части прежних художественных и звуковых задач остаются отдельные ограничения; принятие базы не превращает отсутствующее аудио или непройденную проверку в готовый результат. Актуальные границы проверок: [богатыри и мультиплеер](docs/implementation/heroes-coop/REPORT.md), [очистка принятой базы](docs/implementation/cleanup-2.0-20261024/REPORT.md).
