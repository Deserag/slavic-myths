# Slavic Myths — 0.4.0

Minecraft **1.16.5**, Forge **36.2.42**, Java **8**, mod ID **slavicmyths**.
Постепенное проникновение славянской мифологии в обычное выживание.

## Сборка и установка

JDK 8, JAVA_HOME на его каталог. Windows: `./gradlew.bat build`; Linux/macOS:
`sh ./gradlew build`. Gradle Wrapper 7.3.3, ForgeGradle 5.1.77, official mappings 1.16.5.
Локальный JDK: `.tools/jdk8/jdk8u504-b01`; в PowerShell:
`$env:JAVA_HOME = "$PWD/.tools/jdk8/jdk8u504-b01"`.
Production JAR после reobfJar: **build/libs/slavicmyths-0.4.0.jar**.
Установить его в `mods` экземпляра Forge 36.2.42 / Minecraft 1.16.5, удалив прежнюю
версию этого же мода из этой папки (не хранить два JAR slavicmyths одновременно).
Dev-клиент: `./gradlew.bat runClient`. Сервер: `./gradlew.bat runServer`;
EULA принимает владелец сервера самостоятельно.

## Контент и получение

Все 20 предметов, включая шесть блоков, находятся во вкладке **Славянские мифы**.

Домовой принимает хлеб, молоко, мёд и печенье раз в минуту. Четыре подношения
дают дружбу: используйте Домовой очаг рядом с ним, чтобы поселить духа дома.
Леший получил лесной зов, замедляющие удары и короткое исчезновение при ранении.
Капища редко появляются на ровной земле новых чанков Overworld. Идол открывает
знание; сундук хранит древние монеты и осколки. Жертвенник принимает полынь,
берестяной свиток и оберег по очереди, выдавая Древний знак.
Книга сказаний (книга + свиток + льняная нить) объясняет механику и открывает статьи
по мере встреч. Очаг: костёр в центре, булыжник по сторонам, береста по углам.
Все эти правила — авторская игровая интерпретация.

| Ресурс | Получение / применение |
| --- | --- |
| Береста | 1 берёзовое бревно → 4 бересты; бревно расходуется |
| Берестяной свиток | 2 бересты + ванильная нить, бесформенно |
| Лён | Дикое растение равнин и лесов; ломается рукой, можно пересадить |
| Льняная нить | 2 льна → 1 нить, бесформенно |
| Полынь | Дикое растение равнин, лесов и тайги; можно пересадить |
| Оберег | Льняная нить + полынь + золотой самородок, бесформенно |
| Перунитовая руда | Маленькие редкие жилы в новых чанках Overworld ниже Y=16 |
| Перунит | Руда: железная кирка или лучше; поддерживаются Удача и Шёлковое касание |
| Громовой камень | ` L /RPR/ F `: P перунит, R редстоун, L лазурит, F кремень |
| Цветок папоротника | Шанс 0,2% при разрушении низкого vanilla-папоротника без ножниц и Шёлкового касания |

Лён и полынь — простые дикорастущие растения, без роста, семян и размножения
костной мукой. Новые растения и руда появляются при генерации новых чанков;
ретрогенерации нет. Старые предметы сохраняют registry ID.
Цветок папоротника не крафтится, не выпадает из высокого папоротника;
существующее выпадение семян/папоротника не заменяется. Текущий шанс — временная
авторская игровая механика; редкое событие оставлено на будущую итерацию.
Магия и классовые бонусы пока не реализованы; книга и первый ритуал уже работают.

Дерево содержит 24 видимых advancements и 7 открытий рецептов. Названия и описания
есть на русском и английском. Родитель — визуальная связь, не запрет получить
дочернее достижение раньше него.
