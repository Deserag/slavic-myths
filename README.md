# Slavic Myths — Славянская мифология

Minecraft-мод о славянских сказаниях, исследовании мира, духах, ремёслах и развитии персонажа. Проект рассчитан на **Minecraft 1.21.1, NeoForge 21.1.255 и Java 21**.

Мир мода соединяет обычное выживание с историями Яги, Баюна, Волка и богатырей, исследованием курганов и поселений Чуди, классами, рунами и хозяйством. Фольклорные мотивы и авторские игровые механики различаются; мод не является исторической реконструкцией.

## Что представляет собой мод

- **Исследование и сказания:** Книга сказаний, постепенное открытие знаний, достижения, ритуалы и сюжетные условия.
- **Персонажи:** домашние, лесные, водные и полевые духи; Яга, Баюн, Волк, богатыри и самостоятельные истории противников.
- **Места:** курганы, поселения и шахты Чуди, святилища, лагеря и деревенские места.
- **Развитие:** Дружинник, Ведун и Разбойник, специализации, активные и пассивные способности.
- **Снаряжение:** разные семейства оружия, броня, Curios-аксессуары, рунические гнёзда и трофейные предметы.
- **Хозяйство:** огород, сад, домашние животные, кухня, напитки, текстиль, мебель, хранение и деревенские профессии.
- **Сказочное перемещение:** полётные средства и связанные с предметами возможности.

Условия совместной помощи богатырям, лимит призывов, управление и конкретное содержимое принятой сборки описаны в [путеводителе release](https://github.com/Deserag/slavic-myths/blob/release/MOD_CONTENT.md). Планы новых направлений не перечисляются как готовые функции.

## Установка игровой версии

Понадобятся Minecraft 1.21.1, NeoForge 21.1.255, Java 21 и **Curios API 9.5.1 для 1.21.1**. JEI и Xaero Minimap необязательны. Для сети согласуйте версии мода и обязательных зависимостей сервера и клиентов.

Устанавливайте JAR в отдельный совместимый профиль, оставляя одну версию Slavic Myths в mods. Перед обновлением сохраняйте копию мира. Не перезаписывайте старый профиль Minecraft 1.16.5 портированной сборкой. Подробная последовательность — в README release.

## Работа с исходниками main

Сначала прочитайте [AGENTS.md](AGENTS.md), [статус](docs/PROJECT_STATUS.md), [план](docs/ROADMAP.md) и [архитектуру](docs/ARCHITECTURE.md). Сохраняйте пользовательские изменения и идентификаторы существующих миров. Серверные проверки не должны зависеть от клиентских классов, а необязательные интеграции — становиться обязательными.

Windows PowerShell:

```powershell
$env:JAVA_HOME = 'C:/Program Files/Java/jdk-21.0.12'
./gradlew.bat clean build
python tools/verify_current_resources.py
```

Linux/macOS с Java 21:

```bash
chmod +x gradlew
./gradlew clean build
python3 tools/verify_current_resources.py
```

Для Python-проверки нужен Pillow. Итог: `build/libs/slavicmyths-<mod_version>.jar`. Точные зависимости закреплены в [build.gradle](build.gradle). Обычная сборка не запускает игру; игровые запуски выполняются по правилам AGENTS.md, только в отдельном тестовом мире.

Build и статическая проверка ресурсов не доказывают прохождение истории, качество звука, FPS или мультиплеер. Результаты записываются с границами проверки; FAIL/BLOCKED/NOT_RUN не заменяются формулировкой «готово».
