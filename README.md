# Slavic Myths

Мод для **Minecraft 1.21.1 / NeoForge** по мотивам славянской мифологии: сказочные существа, исследование построек, курганы, сюжетные испытания, ремёсла, хозяйство, руны и классы.

> **Статус: активная доработка, не готовый стабильный релиз 2.0.**
> Текущее значение `mod_version` в `main`: **1.9.7.5**. Открытые pull requests и локальные тестовые сборки могут содержать другие изменения; они **не входят в `main` автоматически**.
> Успешная сборка не означает, что модели, анимации, звук, интерфейс и прохождение проверены в игре.

**Каноническая ветка — `main`.** `master` — историческая совместимость, не параллельная актуальная версия. [Проверенный план консолидации и очистки #43](docs/maintenance/issue-43/REPORT.md).

## Возможности

- Баба-яга, Серый Волк, Кот Баюн, русалки, духи, мифологические противники и боссы с собственными историями.
- Деревни, городища, подземные города и заброшенные комплексы Чуди, курганы, святилища и лагеря разбойников.
- Книга сказаний, ритуалы, руны, классы и достижения.
- Земледелие, домашние животные, блюда, пивоварение, текстиль и хозяйственные занятия.
- Оружие, артефакты, экипировка и испытания.

## Известные проблемы и статус качества

**К выпуску 2.0 открыта работа по качеству игрового опыта.** Владелец сообщил о повторяющихся или слабо различимых звуках, дефектах анимаций существ, проблемных моделях/текстурах (в том числе у водных существ), чрезмерно детализированных пиксельных блоках/предметах и недостаточно связном игровом опыте.

Эти проблемы **не считаются исправленными** по одним только отчётам Codex или успешному Gradle build. Приёмка должна опираться на видимый/слышимый результат и проверенные изменения исходников. Сейчас запуск Minecraft агентами не требуется и не разрешён.

## Установка и скачивание

Готовые опубликованные сборки, **если они доступны**, ищите в [GitHub Releases](https://github.com/Deserag/slavic-myths/releases). Не путайте ZIP исходников из меню **Code** с модом для установки. Проверяйте версию и известные ограничения конкретного релиза: публикация стабильной **2.0** пока не подтверждена.

Для совместимой сборки требуется Minecraft **1.21.1**, NeoForge **21.1.255**, Java **21** и **Curios API 9.5.1** для Minecraft 1.21.1. Поместите **JAR выбранного релиза** в папку `mods/`, предварительно удалив другую версию Slavic Myths из этой же папки. Перед обновлением мира создайте резервную копию сохранения. JEI и Xaero Minimap необязательны.

## Сборка из исходников

Для разработчиков: JDK 21 и команда Windows:

```powershell
.\gradlew.bat clean build
```

Ожидаемый файл находится в `build/libs/`; его точное имя определяется `gradle.properties`, а не устаревшими примерами из документации.

Сборка **не является** игровой приёмкой. Не запускайте игровые клиенты или серверы автоматически в рамках текущих задач сопровождения.

## Контрибьюторам

Читайте [AGENTS.md](AGENTS.md) и текущие документы проекта. Работайте в отдельных ветках, сохраняйте существующие идентификаторы и данные старых миров, не сливайте и не удаляйте чужие PR без отдельного решения. Крупные бинарные отчёты, временные миры и кеши не должны автоматически попадать в коммиты.

Исторические подробности прошлых версий находятся в `docs/` и [CHANGELOG.md](CHANGELOG.md); они не заменяют актуальный статус.
