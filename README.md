# Slavic Myths — 0.6.5

Мод для **Minecraft 1.16.5**, **Forge 36.2.42** и **Java 8**. Mod ID: `slavicmyths`.
Славянская мифология постепенно входит в обычное выживание через духов, редкие
места, подношения, ритуалы, снаряжение и развитие персонажа. Фольклорные мотивы и
поздние реконструкции отделяются от авторской игровой интерпретации.

## Начало игры

Все предметы находятся во вкладке **Славянские мифы**. Книга сказаний постепенно
открывает статьи после встреч и находок. Домовой принимает простую еду; после
нескольких даров его можно связать с очагом. Капища и другие места следует искать
в новых чанках. Камень Пути открывает выбор пути и навыков, а Рунная наковальня
используется для гнёзд и рун. Подробные рецепты и обряды доступны в книге и JEI.

## Сборка и установка

Локальный JDK находится в `.tools/jdk8/jdk8u504-b01`. В PowerShell:

```powershell
$env:JAVA_HOME = (Resolve-Path '.tools/jdk8/jdk8u504-b01').Path
.\gradlew.bat clean build
```

Production/reobfuscated JAR: `build/libs/slavicmyths-0.6.5.jar`. Скопируйте его в
папку `mods` экземпляра Minecraft 1.16.5 с Forge 36.2.42. Одновременно должна быть
установлена только одна версия `slavicmyths-*.jar`.

Java 8 и содержимое production JAR. Актуальные ограничения и ручные сценарии:
