# Slavic Myths 2.0 — Русалка: утверждённые референсы

Владелец выбрал **смешанный образ «красивая, но пугающая»**: славянская речная/болотная русалка с ногами, длинными болотными волосами, бледными глазами и обветшавшей светлой одеждой. Направление голоса — **«песня из-под воды»**.

События: спокойное дыхание/напев; начало песни; спокойный повторяемый loop; опасное усиление того же мотива; обрыв песни при атаке/провокации; влажный рывок; hurt; death. Фраза на 3–5 нот и пауза, мягкий seamless loop, без музыки, звучащей постоянно поверх обычных звуков игры. Поддержать затухание, расстояние и лимиты одновременного воспроизведения, субтитры RU/EN. Старые OGG использовать как source-baseline, их адекватность на слух **не доказана**.

## Игровые способности, согласованный дизайн
1. **Песнь омута**: сохранить существующее накапливаемое `SlavicWaterCharm` и сопротивление гуслями/амулетами, отчётливо показать градации и предупредить игрока.
2. **Объятия глубины**: выразительная атака короткого рывка/утягивания в воду, без гарантированного утопления и без неконтролируемого лишения управления.
3. **Нырок утопленницы**: короткий управляемый манёвр в достаточно глубокой воде; не телепортироваться через сушу/сквозь блоки и не создавать чанки.
4. **Срыв песни**: при агрессии прервать голос/позу, короткая жуткая пауза, затем боевые движения.
 
Главная gameplay-идея: красивая/настораживающая вдали → песня/притяжение → предупреждение → резкая враждебная фаза. Сохранить имя/id, встречу/спавн, `Knowledge` награды, защитные вещи и NBT. Длительность, дистанции и cooldown сначала ориентировать на уже работающий код; не менять баланс скрытно.

## Применение
Сначала показать **реальный рендер изменённой геометрии и кадров анимации** до/после, затем офлайн-compile/resource tests. Запуск Minecraft/PolyMC запрещён. `art/references/` — только материалы для разработки, не production assets.
