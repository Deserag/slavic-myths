# Dependencies

## Required

- Minecraft 1.21.1; Java 21.
- NeoForge 21.1.255 (metadata: >=21.1.255, <21.2).
- Curios API 9.5.1+1.21.1, NeoForge (metadata: >=9.5.1, <10).

## Optional / Recommended

JEI — необязательный client adapter; остальные моды ниже нужны только для удобства тестового профиля. Они не входят в JAR Slavic Myths. Версии взяты из Gradle/metadata и фактического lock файла профиля:

- jei 19.51.0.418 — optional; https://www.curseforge.com/minecraft/mc-mods/jei/files/8792638
- jade 15.10.6 — optional; https://www.curseforge.com/minecraft/mc-mods/jade/files/8591319
- xaerominimap 26.5.0 — optional; https://www.curseforge.com/minecraft/mc-mods/xaeros-minimap/files/8849842
- xaeroworldmap 1.45.0 — optional; https://www.curseforge.com/minecraft/mc-mods/xaeros-world-map/files/8698659
- fallingtree 1.21.1.11 — optional; https://www.curseforge.com/minecraft/mc-mods/falling-tree/files/6835168

Xaero bridge скомпилирован против Minimap 26.5.0; без Xaero core работает. JEI metadata допускает 19.x. Это список проверенного профиля, не заявление совместимости со всеми будущими версиями.
