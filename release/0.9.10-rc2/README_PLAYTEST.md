# Slavic Myths 0.9.10 RC2

Публичная тестовая сборка, не финальный релиз. Minecraft 1.21.1, NeoForge 21.1.255, Java 21.

1. Создайте отдельный профиль Minecraft 1.21.1 с NeoForge 21.1.255 и Java 21.
2. Установите обязательный Curios API 9.5.1+1.21.1 (NeoForge).
3. Поместите slavicmyths-0.9.10-rc2.jar в папку mods. Уберите другой JAR Slavic Myths из этого профиля.
4. Для первого теста используйте отдельный мир или копию существующего мира.

Основной файл скачивается из GitHub prerelease v0.9.10-rc2. SHA256SUMS.txt содержит его SHA-256. Нужен обычный JAR, не sources/dev JAR. Дополнительные моды перечислены в DEPENDENCIES.md.

При сообщении об ошибке приложите версию RC2, версии модов, шаги воспроизведения и relevant latest.log/crash report. Для визуального бага нужны скриншот и GUI scale. Issues: https://github.com/Deserag/slavic-myths/issues

Minecraft-клиент при подготовке сборки не запускался. Реальный first/third-person вид, масштаб UI, multiplayer и бои проверяются вручную. Подробности: KNOWN_ISSUES.md. Полный Equipment & Art Overhaul не заявлен завершённым; RC2 стабилизирует существующие системы.
