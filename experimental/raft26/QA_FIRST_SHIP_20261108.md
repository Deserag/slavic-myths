# Slavic Myths 2.6 — первый деревянный корабль 7×11, QA 08.11.2026

**Ветка:** `feature/2.6-first-two-deck-ship-20261108`  
**Черновой PR:** https://github.com/Deserag/slavic-myths/pull/442  
**Основа:** `fix/2.6-raft-safety-audit-20261108` (PR #440).
**НЕ СЛИВАТЬ** до игрового приёмочного теста на клиенте и выделенном сервере. Сохранённые плоты имеют прежние ID и NBT.

## Реализовано в Java и ресурсах

- Отдельная сущность `ship_wooden_7x11_entity`, предмет `ship_wooden_7x11`, не заменяющие объекты плотов.
- Суженные нос и корма, деревянный высокий борт и открытая палуба, нижний трюм, люк 2×2, лестница, мачта, парус и кормовой штурвал.
- Математическая модель локальных координат `FirstShipHull`, два уровня контактов и стенки трюма `FirstShipDeckEvents`.
- Рулевой режим: ПКМ по видимому кормовому штурвалу пустой рукой через отдельный клиентский обработчик и серверную проверку; настоящий один пассажир только для управления. Свободно ходящие игроки НЕ являются пассажирами.
- Посадка с воды: ПКМ пустой рукой по борту стоящего корабля с проверкой на сервере; единичное перемещение к краю палубы, далее обычная свободная ходьба без пассажирского места.
- Ветер из `RaftWind`, ограничение скорости, плавание, проверки глубокой воды и воздушного пространства при размещении.
- Модули сундука, бочки, верстака и печи на двух этажах. Установка/доступ через Shift+ПКМ на корабле, включая Shift+ПКМ в воздух с палубы.
- Содержимое модулей и состояние печей в `FirstShipPack` версии 1; упаковка верфяным ключом запрещена с экипажем, в движении или при испорченных данных.
- Корабельная информационная панель поверх обычного инвентаря по **E** (схема двух этажей, число модулей). Сами предметы сундуков по сети в HUD не передаются.
- Отдельная сборка через корабельную верфь: брёвна ×48, доски ×96, железо ×32, канаты (нить) ×24, ткань (шерсть) ×20, палубные секции ×32, борта ×4, руль ×1, парус ×1.

## Повторный аудит после Python-реконструкции внешнего вида

- Первое изображение оказалось неэквивалентным игровому Java-рендеру: прежняя версия действительно выглядела как квадратный трюм с парусом. Выполнена отдельная программная реконструкция настоящих cuboid/PoseStack деталей, затем изменён сам FirstShipRenderer.
- `FirstShipHull.halfBeam` переработан: более острый нос (+Z), широкая корма (-Z), ширина 7 блоков посередине, 9 рядов дощатой обшивки и выраженный киль. Убрал глухую высокую стенку по бокам и заменил ступенчатыми судовыми рядами.
- У нижнего трюма собственная меньшая рабочая ширина `holdBeam`; верхняя палуба пользуется `confineDeck`. Исправлен баг, при котором верхних игроков ограничивало узкой границей трюма.
- Исправлен сход с верхней палубы при обычной ходьбе: сначала ограничивается позиция у борта, а только прыжок выше борта освобождает игрока.
- `FirstShipNavigation` проверяет реальный повернутый корпус 7×11, воду, глубину, берег, потолки и парус; нативный малый хитбокс Boat сохранён во избежание конфликтов с ходьбой игроков. Без игровых испытаний возможны резкие серверные коррекции у препятствий.
- Груз Shift+ПКМ по удалённым участкам судна теперь явно отправляет C2S-пакет и меняет серверные инвентари только после серверной проверки; запрещено ставить ящик в люк, на мачту, штурвал и лестницу. Исправлены подписи двух уровней в E HUD.
- Переоформлена оригинальная модель предмета `ship_wooden_7x11.json` с отдельными бортами, носом, парусом и кормовым рулём. Creative → «Кораблестроение» проверяется статическим тестом.
- Добавлены `experimental/raft26/audit_first_ship.py` и workflow `first-ship-assets-audit.yml` для автоматической проверки модели, ID, Creative регистрации, рендера и серверных сообщений.

**Это статический код-аудит и процедурная визуализация, а не акт приёмки клиента Minecraft.**

## Получение на Windows

```powershell
git fetch origin
git switch --track origin/feature/2.6-first-two-deck-ship-20261108
.\gradlew.bat clean build
```

Если локальная ветка уже существует: `git switch feature/2.6-first-two-deck-ship-20261108` и `git pull --ff-only`. Не переключаться с незакоммиченными изменениями без их сохранения.

JAR после успешной сборки находится в `build/libs/` (выбирайте mod JAR, не sources/dev). В GitHub Actions экспериментальный JAR сохраняется как artifact `first-ship-2-6-unverified-java21`.

## Проверка в Minecraft (сделать владельцу)

1. Сделать **резервную копию тестового мира**; запускать только тестовый мир.
2. `/give @p slavicmyths:ship_wooden_7x11`, `/give @p slavicmyths:shipyard_workbench`, `/give @p slavicmyths:shipyard_key`.
3. Проверить размещение на воде минимум двух блоков глубиной, чистая площадка 7×11 и свободная высота для мачты. Отдельно проверить отказ у берега/под крышей, без расходования предмета.
4. Сначала верхняя палуба на месте: шаги, прыжки, края, нос и корма. Затем спуск через люк и лестницу в трюм, ходьба вдоль бортов.
5. С воды ПКМ **пустой рукой** по борту стоящего корабля, убедиться, что игрок попал на палубу и может ходить. У штурвала на корме — ПКМ пустой рукой по колесу, управление, выход Shift. Игрок не должен оказываться на краю. Другой игрок должен при этом свободно ходить.
6. Запустить парусную тягу, сделать несколько быстрых поворотов с двумя игроками на разных этажах. Отследить рывки, телепортации, отставание клиента, проваливание под пол и передачу скорости при прыжке.
7. На каждом этаже Shift+ПКМ с сундуком, бочкой, верстаком, печью. Проверить меню, фактические слоты и плавку, затем выгрузить чанк, перезапустить мир и повторить. Помните, что взаимодействие с установленными модулями выполняется по клетке **под ногами**, это ещё не прицеливание в конкретный объект.
8. Открыть `E` на каждом этаже, посмотреть схему модулей и личный инвентарь. Проверить создание корабля в верфи без Creative, точное списание материалов (включая несколько типов брёвен, досок и шерсти).
9. Выйти всем игрокам, остановить судно, упаковать ключом; переустановить, сверить каждый ItemStack (имя, количество, NBT) и состояние печи. Повторить после перезапуска сервера.
10. Проверить существующие плоты 3×3, 3×5, 5×5 и 5×7 со старым грузом: предметы и сохранения не должны преобразовываться в корабль.

**Блокеры до merge:** любое дёргание/сползание по движущемуся кораблю; невозможность перехода на нижний уровень; неверная посадка за штурвал; потеря или дублирование груза; неполадки E/верфи; баги существующих плотов.
