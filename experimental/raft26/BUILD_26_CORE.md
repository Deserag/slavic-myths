### Установка и управление

1. Выбрать размер, установить ПКМ на достаточную свободную водную поверхность (проверка прямоугольника соответствующего размера).
2. Для гребли посадка за весла у кормы (приблизительно центральная задняя часть), движение привычными клавишами лодки.
3. На платформу можно попробовать подняться **без посадки**: эксперимент `RaftDeckEvents` поддерживает высоту ног и переносит игрока с кораблём при движении и поворотах. Это НЕ подтверждённый физический sub-level, а собственный алгоритм вертикальной опоры. Движение 2–4 игроков и прыжок за борт необходимо проверить в Minecraft и на dedicated server.
4. Для установки модификации — Shift+ПКМ по плоту с ограждением, парусом, рулём или дополнительными вёслами. 3×3 допускает 1 парус, 5×7 — 2 паруса. Дополнительные вёсла требуют удлинения. Установленный парус + руль позволяют управлять плаванием без удержания гребли; ускорение паруса и ручные вёсла совместимы, тяга ограничена по максимальной скорости. Парус не является Create-механизмом.
5. Разрешённые судовые модули — Shift+ПКМ сундуком, бочкой, верстаком или печью по свободному месту палубы. Shift+ПКМ без предмета открывает хранилище либо рабочий интерфейс. Состояние сундуков, топлива и переплавки сохраняется в серверной сущности судна. Не используйте ценный груз до реального runtime QA.
6. Для **безопасной упаковки** высадить всех игроков, остановить плот, ПКМ **Верфяным ключом**. Сервер создаёт предмет плота с данными корабельного оборудования и грузом. При повторной установке именно этого предмета должно произойти восстановление; средняя кнопка мыши даёт **пустой** плот, а не клон существующего груза. Нельзя полагаться на операцию упаковки при аварийном выключении сервера — транзакционный журнал ещё не реализован.

### Работа с корабельным верстаком

- Обычный ПКМ пустой рукой открывает стандартную **сетку крафта**. Это ещё не финальный специализированный экран модификаций, хотя станция имеет собственный 3D-блок.
- Чтобы изготовить **малый плот**, держать палубную секцию и нажать ПКМ по верстаку: требуется всего 9 палубных секций и 1 комплект вёсел из инвентаря.
- Чтобы увеличить существующий упакованный плот, держать **предмет плота** и нажимать ПКМ по верстаку. Порядок: 3×3 → 3×5 (6 секций) → 5×5 (10 секций) → 5×7 (10 секций). Сервер сохраняет модульные клетки, все ItemStack-компоненты, паруса/ограждения и не заменяет оригинальный экземпляр пустым.
- Чертежи частей пока являются обычными crafting-рецептами (можно собрать в сетке Crafting Table); **отдельная вкладочная UI судостроения ещё не реализована**.

```powershell
git fetch origin
git switch --track origin/2.6-shipbuilding-core-20261108
.\gradlew.bat clean jar --no-build-cache --no-configuration-cache
```

Если ветка уже локальная, вместо `git switch --track` использовать `git switch 2.6-shipbuilding-core-20261108` и `git pull --ff-only origin 2.6-shipbuilding-core-20261108`. Проверять только в отдельном профиле и **копии** мира, не удалять JAR текущей основной сборки и не заменять его в рабочем мире. Для этой ветки **Create, Aeronautics, Sable не требуются**.

## Модель качества и обязательные проверки

- [ ] Java21 clean build & valid recipe/model JSON — автоматический CI; факт проверки фиксировать по конкретному commit.
- [ ] Плот 3×3, 3×5, 5×5 и 5×7 устанавливается, держится на поверхности 30+ секунд и гребёт на воде.
- [ ] Игрок стоит, ходит, прыгает за борт и сохраняет положение относительно палубы при плавании и **повороте**, без посадки на невидимые места.
- [ ] На плоту стабильно работают сундук, бочка, верстак и судовая печь; рецепты, прогресс и топливо переживают рестарт.
- [ ] Парус едет быстрее вёсел и добавляет скорость при одновременной гребле; управляется рулями. Большой плот поддерживает два паруса.
- [ ] Ограждения ограничивают движение по краям и не телепортируют игроков.
- [ ] Ключ корректно пакует/распаковывает заполненные сундуки и печи; Creative, full inventory, повторная упаковка, multiplayer.
- [ ] Клиент и dedicated server NeoForge 1.21.1/Java21 + 2–4 игроков без ошибок.
- [ ] Итоговая художественная приёмка владельцем.

**Известные ограничения:** вместо настоящего движущегося мира из блоков сейчас используется изменённый Boat + экспериментальная поддержка пешеходов; временная квадратная collision-envelope у длинных судов; свободная ходьба не подтверждена в игре; физический крен/переворот, спасение толканием и полноценный UI судостроения пока не доведены до приемки.
