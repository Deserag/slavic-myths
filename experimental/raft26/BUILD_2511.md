# 2.5.1.1 «Логика плавания» — первый игровой тест плота (WIP)

Связанные: #433 и draft PR #434. **Целевое крупное обновление остаётся 2.6 «Океан».** Техническая ветка 2.5.1.1 изолирована от `main` и `release-2.5`.

## Что здесь действительно реализовано

- Зарегистрированный тестовый предмет `slavicmyths:raft_2511_test` (отображается как «Плот — испытательный») и отдельный `EntityType`; ПКМ по поверхности воды для установки.
- Отдельная вкладка творческого инвентаря **«Кораблестроение»**. В ней лежит тестовый плот; в будущем сюда попадут корабельные детали, модификации и верстак.
- **Исправлен баг первого отчёта пользователя:** прежнее `posY + 0.15` помещало плот внутрь воды; теперь позиция берётся с поверхностного попадания луча. Установка требует свободный участок воды **3×3**, иначе показывается предупреждение.
- Первичная плавучесть и гребля на базе нативного `Boat` в NeoForge 1.21.1, без Create и Sable.
- Визуальный **временный** настил 3×3 из дубовых брёвен с поперечными связками и двумя вёслами (без новых финальных PNG; анимация вёсел не утверждена).
- До четырёх пассажирских мест. **Они временно закреплены, а не являются свободно ходящими игроками.**
- Shift + ПКМ с сундуком/бочкой по плоту: ближайшая к лучу взгляда свободная клетка на палубе заносится в серверный список модулей. 27 реальных слотов `SimpleContainer` на каждый модуль, синхронизация внешнего состояния размещения и NBT ItemStack для чанков/обычного сохранения. Shift + ПКМ пустой рукой по выбранному модулю: стандартный интерфейс хранения.
- Хранение внутри судовой сущности; **никаких** операций слома/создания блоков мира при каждом перемещении. Урон не разрушает базовое судно.
- Разрешены пока только `minecraft:chest` и `minecraft:barrel`. Для верстака и печи нужны отдельные работающие контейнеры и тикание рецептов; нельзя считать завершёнными.

## Как попробовать в независимом тестовом мире

Java **21**, Minecraft **1.21.1**, NeoForge **21.1.255** и существующие штатные зависимости сборки Slavic Myths. **Create / Aeronautics / Sable пока не требуются; ничего дополнительного скачивать для этого теста не нужно.**

В отдельном клоне репозитория:

```powershell
git fetch origin
git switch --track origin/2.5.1.1-raft-navigation
.\gradlew.bat clean build
```

Использовать чистый тестовый профиль и мир. Не заменять существующий мод в рабочем сохранении. После проверки сборки и JAR открыть Creative → вкладка **«Кораблестроение»** → взять предмет **«Плот — испытательный»**. Команды для получения не нужны.

Затем ПКМ по **открытой воде 3×3** — появится плот у поверхности; обычный ПКМ — сесть и проверить греблю. Shift + ПКМ при взгляде на палубу с сундуком/бочкой — попытаться закрепить модуль; Shift + ПКМ пустой рукой — проверить содержимое. Учитывать текущие ограничения: реальная плавучесть, высота палубы, позиции установки/доступность GUI, замедление на суше и четырёхместная рассадка требуют новой фактической проверки в Minecraft. Старые экземпляры из предыдущей сборки могут оставаться под водой: **проверять новый плот**, не уничтожая уже наполненные старые экземпляры.

- Модель крена, совместное ручное восстановление, расширения, паруса, корабельный верстак и корректная разборка — NOT_IMPLEMENTED.

## Зависимости и инженерное решение

Никакие новые JAR не включены и не скачаны. Create: Aeronautics требует Create и Sable и **не подходит для обязательной зависимости Slavic Myths**. Sable без Create можно исследовать отдельно в полностью чистом экспериментальном профиле; его интрузивные mixin/лицензия/совместимость требуют реальных проверок. Решение о подключении пока не принято.

Полный сценарий доказательства свободной ходьбы: сравнить автономную collision-обвязку и проверенный Sable sub-level (если совместим); игрок без режима пассажира должен спокойно двигаться по палубе 3×3, прыгать за борт, открывать хранилище, пересекать границы чанков и восстанавливаться после перезапуска на dedicated сервере с 2–4 игроками.

**Статус: WIP / первичная проверяемая игровая заготовка. Не сливать в release-2.5 и не переустанавливать в основную PolyMC сборку до приёмки.**
