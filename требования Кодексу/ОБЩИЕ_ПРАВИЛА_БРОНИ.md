# Общие правила разработки брони

**Область действия:** создание и изменение комплектов и отдельных элементов брони Slavic Myths (шлем, нагрудник/кираса, поножи, ботинки). Это постоянный стандарт разработки, а **не задача на переделку уже существующих комплектов**. Оружие, инструменты и аксессуары описываются отдельно.

## 1. Четыре типа внешнего вида

**До моделирования** в индивидуальном ТЗ указать тип основы и все изменения.

1. **Recolor ванильной брони.** Силуэт, геометрия и пропорции основы не меняются; перекрашиваются отдельные части либо весь элемент. Один участок может сочетать **несколько цветов и материалов**. Не требовать полной перекраски без необходимости.
2. **Изменение пропорций ванильной брони.** Сохраняется исходная основа, но **согласованно** меняется толщина, объём или размер определённых частей. Пример: более массивная кираса с увеличенным объёмом груди/живота. Конкретные изменения размеров прописывать отдельно.
3. **Полностью оригинальная модель брони.** Возможна как **редкое исключение** при прямом согласовании. Самостоятельно выбирать новую конструкцию вместо ванильной основы нельзя.
4. **Ванильная броня с добавленными элементами.** **Предпочтительный тип** для большинства новых наборов: прежняя основа плюс рога, корона, перья, шипы, пластины, чешуя, накладки и иные явно описанные детали. Тип 4 может совмещаться с recolor и согласованными небольшими изменениями формы.

Внешность каждого элемента комплекта согласуется отдельно. **Не заменять предусмотренную объёмную деталь нарисованным пятном на текстуре**, если по ТЗ эта деталь должна выступать.

## 2. Геометрия и отображение

1. Разделить элементы брони на **основу, перекрашиваемые зоны, изменённые объёмы и добавленные детали**; для каждой зоны зафиксировать материал, цвета, форму и расположение. Не выдумывать сложный декор без согласования.
2. Если выступающий элемент реально выходит за пределы ванильной модели (например, рога, корона, выраженные шипы, объёмные перья), **на персонаже использовать корректную 3D-геометрию**, соответствующую утверждённому дизайну.
3. Утолщение кирасы, крупные накладки и подобные изменения должны быть видны **на надетой броне**. Конкретная степень объёма устанавливается индивидуально: объёмная модель не является поводом произвольно менять пропорции.
4. **В инвентаре отдельная 3D-модель предмета не требуется**: достаточно правильной обычной иконки/спрайта. Отображение брони на модели персонажа в предпросмотре инвентаря при этом должно оставаться корректным.
5. Проверять вид комплекта спереди, сбоку и сзади, в движении, при смене позы, с отдельными надетыми частями; отсутствие клиппинга, неверной привязки и заметной потери деталей.
6. Сохранять ванильную пиксельную/воксельную стилистику, если конкретным утверждённым дизайном не установлено другое.

## 3. Обязательная карточка каждой части

**Каждый** шлем, нагрудник, поножи и ботинки должны иметь конкретно согласованные значения и ограничения:

| Параметр | Что указать |
| --- | --- |
| Защита | Число очков брони для элемента |
| Прочность | Запас и правила расхода |
| Твёрдость брони | Значение armor toughness |
| Сопротивление отбрасыванию | Значение knockback resistance |
| Зачарования | Разрешённые/запрещённые чары, уровни и совместимость |
| Руны | Разрешённые руны, слоты, ограничения и взаимодействие с чарами |
| Получение | Крафт, награда, лут, покупка, кузнечное улучшение либо иной согласованный путь |
| Ремонт | Материал/способ восстановления прочности |
| Индивидуальное свойство | **Точное описание эффекта** или явное отсутствие |
| Принадлежность к набору | Идентичность комплекта, необходимая для определения бонуса полного сета |

Не задавать параметры автоматически только по редкости/названию предмета. Все численные значения утверждаются в задаче комплекта.

## 4. Индивидуальные свойства и полный комплект

1. **Индивидуальный эффект** принадлежит конкретной части и работает, когда эта часть надета, в рамках её собственных условий.
2. **Бонус полного комплекта** работает **только при одновременном ношении всех четырёх частей одного предусмотренного набора**: шлема, нагрудника, поножей и ботинок.
3. **Смешанная броня:** индивидуальные свойства каждого надетого элемента сохраняются, но **бонус полного комплекта не включается**. По умолчанию не создавать бонусы за две/три части, если отдельно не согласован другой дизайн.
4. Условные эффекты допустимы: в Аду, другом измерении/биоме, ночью, при определённом здоровье и т. п. **Конкретные условия** прописываются для каждого эффекта.
5. Эффекты могут быть пассивными, постоянными или временными/зависящими от условий. Время действия, мощность, проверка условий и правила выключения должны быть определены заранее.
6. **Связку «броня + обязательное оружие» не создавать.** Броня и её сетовые бонусы работают независимо от типа удерживаемого оружия.
7. **Активные способности — исключение, а не стандарт.** Добавлять их только по отдельному одобрению; предпочтение пассивным эффектам. Не назначать новые комбинации клавиш без согласования и проверки конфликтов с существующим управлением.
8. **Дополнительные ауры, сияния и частицы ради эффектов отдельных элементов или полного сета по умолчанию не добавлять.** Существующего визуального отображения зачарований и рун достаточно. Не наслаивать лишние декоративные эффекты; исключение — только отдельно утверждённая механика/визуал.
9. Не придумывать эффекты по внешнему виду: рога, чешуя или адская палитра сами по себе не означают автоматически удар молнией, защиту от огня и т. п.

## 5. Зачарования, руны, ремонт и улучшение

1. **Зачарования** и **руны** — отдельные поддерживаемые системы. Для элемента прописываются совместимость, уровни, слоты, ограничения и правила работы с индивидуальными/сетовыми свойствами. Предусмотренные эффекты не должны сбивать или дублировать друг друга.
2. **Крафтовая броня** по умолчанию ремонтируется основным материалом изготовления по ванильной аналогии, если отдельный рецепт не устанавливает другое.
3. Для **уникальной некрафтовой брони, добываемой с боссов**, по умолчанию предусмотрены **«Починка» за опыт** и **объединение двух одинаковых предметов на наковальне**. Дополнительные материалы ремонта не вводить самовольно.
4. **Кузнечное улучшение** допускает создание одного типа брони из другого с помощью дополнительных материалов, как алмазная → незеритовая. Для каждого перехода явно задаются исходный предмет, материалы, результат, новые характеристики и внешний вид.
5. Кузнечное улучшение **не обязательно для каждого комплекта**, может проходить в несколько ступеней. Новые способности после улучшения **не обязательны**: возможно только повышение характеристик. Любое новое свойство — лишь по отдельному ТЗ.
6. **При каждом кузнечном улучшении обязательно сохраняются ВСЕ зачарования с уровнями, ВСЕ руны и их настройки, имя, накопленный износ и другие пользовательские данные исходной брони.** Запрещено молчаливое удаление, обнуление или замена улучшений. При техническом конфликте до сдачи необходима реализация сохранения либо решение владельца, а не потеря данных.

## 6. Проверка и сдача

1. Предоставить фактическую модель **каждой** части на персонаже и отдельную иконку в инвентаре. Сравнить с утверждённым дизайном, ванильной основой и перечнем добавленных/изменённых частей.
2. Проверить крепление, анимацию движения, положение рогов/корон/перьев/объёмных элементов, отсутствие клиппинга при типовых движениях и при надевании частей по одной.
3. Отдельно протестировать все характеристики, ремонт, чары и руны; сохранение свойств и пользовательских данных после кузнечного улучшения.
4. Протестировать **каждый индивидуальный эффект**; полный сет из четырёх; все предусмотренные смешанные варианты; снятие любой одной части; восстановление полного набора; перезаход и смену измерения.
5. Проверить каждое утверждённое условное свойство в условиях **включено/выключено**. Проверить отсутствие ненужных хоткеев и лишних визуальных эффектов.
6. Отчёт должен различать сборку, фактический запуск/тест в игре и принятие владельцем. Для непроверенного — **NOT_RUN**, нарушения — **FAIL**, препятствия — **BLOCKED**. Финальная визуальная и игровая приёмка только за владельцем.
