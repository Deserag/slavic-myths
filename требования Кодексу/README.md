# Требования Кодексу

Эта папка — единое место для обязательных требований, критериев приёмки и инструкций исполнителю по Slavic Myths.

## Как работать с файлами
- Для каждой новой части работы создавать **отдельный Markdown-файл** в этой папке. Не смешивать независимые подсистемы и этапы.
- Название файла должно однозначно обозначать объект и задачу (например, `биом-02.md`, `модели-персонажей.md`, `сивка-бурка.md`). 
- Не объявлять задачу завершённой, пока **каждый** обязательный пункт не выполнен и не представлен проверяемый результат.
- Если критерий не проверен, отмечать `NOT_RUN`; если не выполнен — `FAIL`; если есть препятствие — `BLOCKED`. Сборка `PASS` сама по себе не означает приёмки модели, механики или биома.
- Для каждого отдельного файла задавать: точный объём работы; обязательные свойства и запреты; измеримые критерии; способ проверки; ожидаемые доказательства; критерии отклонения.
- Новые задания не подменяют старые без прямого решения владельца. Не придумывать недостающие визуальные решения или механику вместо утверждённых спецификаций.
- Фактическую приёмку игры и визуала проводит владелец; Codex не присваивает себе право подтверждать итоговую готовность.

## Приоритет и ограничения
- Указания в файлах этой папки являются обязательными **для соответствующей части работы**; общие правила репозитория в `AGENTS.md` и действующие указания владельца также сохраняются.
- Сохранять существующие ID, данные старых миров и рабочие механики, если отдельным заданием не предписано обратное.
- Не делать фиктивные заглушки или простые перекраски там, где требуется уникальная модель.
- Каждый отчёт разделяет: сделано в коде, проверено сборкой, проверено в игре, принято владельцем. Не заявлять проверки, которые не проводились.

## Статус
Это **индекс и правила хранения**, а не отдельное исполнительное задание. Конкретные требования будут оформляться далее в самостоятельных файлах этой папки.
