# Slavic Myths 1.2.5

Minecraft 1.21.1, NeoForge 21.1.255, Java 21. Требуется Curios API `[9.5.1,10)` для Minecraft 1.21.1; JEI 19.x необязателен на клиенте.

- Редкое нативное городище: 240 NBT-шаблонов, три климатические палитры, два плана улиц, терем, торговый дом, площадь, стены, ворота и башни; существующие жители и дружинники.
- Исправлены опоры домов и крыша наблюдательной башни.
- Мешок: пять слотов по 64, шесть размеров; объёмные модели кружек и бутылок напитков.
- Сохранены деревни, профессии, производство, логистика, дружина и налёты предыдущих 1.2.x, ранние приключенческие и хозяйственные системы.
- Подготовка релиза: аудит размера и ресурсов, резервное перемещение старых QA-запусков, ignore runtime-папок и воспроизводимая compile-only зависимость Xaero.

Установка: один `slavicmyths-1.2.5.jar` и Curios в `mods` клиента и сервера. Перед обновлением сохраните копию мира. Registry IDs сохранены.

Клиентская визуальная приёмка, полный natural city на обычном рельефе и пользовательский перезаход непроверены. Нет измерений FPS/MSPT. README содержит подписанные схемы NBT и текстуры, не игровые скриншоты. Будущая княжеская экономика/AI не входит в версию.

Git-публикация ещё не выполнена. Результаты проверок: [отчёт](docs/maintenance/RELEASE_PREPARATION_1.2.5.md).
