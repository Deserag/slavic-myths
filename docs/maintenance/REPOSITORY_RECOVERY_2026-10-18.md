## Локальный проект: сначала определить, откуда 10–20+ ГБ

Нет прямого доступа к папке на компьютере владельца. Предлагаемая последовательность строго **READ-ONLY**; выполняется пользователем в PowerShell **из основной папки мода**.

```powershell
$root = (Resolve-Path .).Path
Get-ChildItem -LiteralPath $root -Force -Directory |
  ForEach-Object {
    $bytes = (Get-ChildItem -LiteralPath $_.FullName -Force -File -Recurse -ErrorAction SilentlyContinue |
      Measure-Object -Property Length -Sum).Sum
    [pscustomobject]@{ Directory = $_.Name; GiB = [math]::Round(($bytes / 1GB), 2) }
  } | Sort-Object GiB -Descending | Format-Table -AutoSize
git status --short
git worktree list
git count-objects -vH
(git ls-files work).Count
```

Команды **ничего не удаляют**. Последние команды показывают грязное состояние Git, присоединённые worktree, размер базы Git и наличие уже отслеживаемых файлов в `work/`.

Типовые категории для раздельного изучения после получения измерений:

| Категория | Предварительная политика |
|---|---|
| `build/`, временный `run-*/`, `logs/` | Обычно воспроизводимые; проверять наличие рабочих данных, считать размеры, только потом предложить удаление |
| `.gradle/`, кеши проекта | Могут потребовать повторной загрузки зависимостей; не путать с глобальным Gradle cache |
| `work/` | Может содержать уникальные спецификации и исходники; массовое удаление запрещено |
| `.git/`, `.git/worktrees/` | **Не удалять вручную**. Сначала `git worktree list`; stale worktree удалять только штатными командами после проверки |
| `docs/verification/**/pre-edit/**`, старые binary snapshots | Могут хранить доказательства/референсы; оценивать размер, tracked-статус и ссылки |
| PolyMC, `saves/`, пользовательские текстуры/проекты | Неприкосновенно без отдельного явного разрешения и backup |
| Глобальный Gradle cache за пределами проекта | Не включать в расчёт размера папки проекта; не удалять ради данного этапа |

После инвентаризации составить `LOCAL_CLEANUP_MANIFEST`: полный путь, реальный размер, tracked/untracked, роль, ссылка/владелец, можно ли пересоздать, предложенное действие, резервная копия. Пока нет этих данных — **0 удалений**.
