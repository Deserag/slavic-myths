# 2.2.12 — экономика Пекельного посада (#373)

**Ветка:** `feature/2.2.12-posad-economy-20261031` → интеграционная `2.2`. Зависимость **PR #380**, пока draft/unmerged. Основано на конкретном SHA жителей `0279145bcf63bc59be9229b51498fe4e43a24d74` (а не на старом `hell`). **`main` не изменять.**

## Реально внесено
- В `PosadResidentEntity` добавлен vanilla `Merchant` (ПКМ) без 13-го NPC, собственной валюты или вмешательства в обычную деревню/Чудь. Торгует и посадник, но никаких поручений в этом меню.
- 142 записи в `data/slavicmyths/posad/trades.json`: 108 продаж, 22 закупки ресурсов, 12 независимых натуральных бартеров. 10 профессий имеют по 2 предложения I–V. Посадник и обычный житель имеют фиксированный набор.
- Цена одного товара всегда хранится в `ancient_coin`, при элитной сделке — 64 монеты + материал во втором входе. Один тип сделки — два входа Merchant и один выход. Таблица осталась data-driven, уровень открывает предложения предыдущих уровней.
- У каждого NPC отдельные торговые XP, пороги `0/10/70/150/250`, исходные лимиты использования, NBT по постоянным ID офферов, не более двух реальных пополнений в игровой день при наличии NPC у привязанного `home`/поста, не во время открытого меню. Прежний 900-секундный per-city timeout агрессии не меняется, торговля для агрессора закрыта.
- Для бартера `iron_spear` требуется нулевая повреждённость и отсутствие чар. Не создаются новые предметы/квесты/сущности. Не начисляются очки доверия.
- Зависимые от будущих #363/#371 предметы явно помечены `deferred`; пять временно заменяемых **продаж** используют уже утверждённые цены и товары той же профессии. Две закупки `garlic_flatbread` до его регистрации скрыты. Оффер не заменяется AIR, а при появлении действительного ID используется основная запись.
- Утверждённый бартер повара `8 raw_boar_meat + 4 barley_groats → 2 meat_stew` реализован **двумя последовательными** сделками `4 + 2 → 1`, поскольку похлёбка не стакается, а Merchant допускает только один output ItemStack.

## Краткий сценарий для владельца в Minecraft
1. Открыть мир с **полностью построенным вручную** Пекельным посадом и реально заселёнными NPC из #380. При отсутствии заселения использовать только предусмотренную команду разработчика `/slavicmyths dev posad populate` в подходящем городе, не спавнить копии жителей.
2. ПКМ по кузнецу: обмен 20 ancient_coin → 4 iron_ingot, обратная скупка 8 iron_ingot →14 монет, бартер 8 iron_ingot + 4 coal → 2 purified_iron_ingot.
3. ПКМ по стражнику/сотнику/оружейнику: обычный и смешанный `64 ancient_coin + материал` оффер V; у оружейника обмен **целого** iron_spear +2 silver_ingot → silver_spear, повреждённое оружие должно быть отклонено.
4. У грибовода проверить 16 crimson_fungus →8 warped_fungus без монет, у кладовщика 32 basalt →16 blackstone, у повара две сделки по одной нестекаемой похлёбке.
5. Набрать у одного профессионального NPC 10/70/150/250 накопленных XP, убедиться, что новые ранги добавляют товары, другие NPC сохраняют собственный прогресс, а посадник/обычный житель не прокачиваются.
6. Распродать сток, закрыть GUI, перезайти, затем ждать допустимого рабочего пополнения (не более двух раз за день). Во время активной агрессии от удара по NPC — торговля с этим игроком должна закрыться, а через 900 секунд реального времени снова открыться.
