# Поиск через книгу → создание места: IN_PROGRESS

24.10.2026. Исправления в рабочем дереве `codex/on-demand-generation`, без автоматического коммита. Установленный PolyMC не изменён. Приёмки владельца нет; связанные Issues остаются OPEN.

## Причина

Кнопка поиска Яги вызывала очередь, внутри которой `getChunk` синхронно ожидал FULL далёкого кандидата. Ограничение «одна попытка за тик» не ограничивало продолжительность самого вызова. Старый общий поиск мог загрузить 32 кандидата; Чудь планировалась по 96 регионам, а командная постройка выполнялась одним большим вызовом. Это выявлено по исходникам, не по стеку работающего сервера пользователя.

## Реализованные изменения

- `YagaDiscovery/YagaHut/YagaPlacement`: книга и команда используют одно строительство канонической избушки. Сначала проверяются загруженные лесные площадки, затем максимум одна выбранная незагруженная площадка за запрос. Записи блоков и откат порционные; чужая правка не откатывается. Неудачная исходная лесная точка помечается проверенной. Совместные запросы объединяются; координаты отправляются после успешного размещения NPC и интерьера.
- `SiteChunks`: одна нативная подготовка FULL в полёте на измерение, вызов future вне потока тиков, опрос завершения без ожидания. Отмена потребителя не освобождает ограничитель до завершения уже начавшейся нативной работы. Подготавливается выбранный строительный участок, а не множество естественных стартов. Нативный генератор Minecraft может сам готовить соседей — запретить это данным адаптером нельзя.
- `GuideQuests/BossSiteJobs`: сохранённые реальные встречи переиспользуются; отсутствующие арены Лиха/Тугарина создаются небольшой очередью. Условия биома и ночи Лиха сохраняются. Соловей получает фактически построенный укреплённый лагерь через существующую очередь. Старые непостроенные резервации не выдаются за готовое место.
- `CampCommands/KurganCommands/OnDemandStructures/ManualStructureJobs`: поиск естественных стартов заменён сохранённой точкой либо строительством. Одинаковые запросы объединены; подготовка чанков последовательная и асинхронная. Прежние 16 переносов площадки сокращены до четырёх; размещается один пересекающийся piece на срез 16×16×4 за шаг. Один нативный вызов piece остаётся неделимым, поэтому строгий предел MSPT здесь не доказан.
- `ChudResearch/ChudSearchCommands/ChudGenerateCommands/ChudCreationJobs`: общий путь фактической постройки вместо поиска 96 регионов. Чистая геометрия рассчитывается рабочим потоком, проверки и записи выполняются порциями с целевым бюджетом 2 мс и ограничением операций. Содержимое/NPC добавляются после геометрии; затем записываются native start/references и существующий SavedData-индекс. Вход подстраивается под высоту выбранной поверхности. Для следующего отдельного задания выбирается отдельная площадка, исключающая уже созданные города. Резервация незавершённой выемки сохраняется для запрета наложения, но автоматического возобновления прерванной Чуди пока нет.
- `BayunCreation/BayunCommands/BayunFeature/TaleService`: явный запрос записи о Баюне/команды создаёт одно место; обычное открытие книги не запускает создание. Небольшая терраса подготавливается порциями. Исходная feature остаётся для естественной генерации.
- `TemplateSiteJobs/SwampCommands/MilitaryCommands`: старый синхронный перебор болотных стартов удалён; команда казарм/болотного объекта использует сохранённое место либо одну выбранную постройку. Биом проверяется по метаданным без загрузки кандидатов, глубина руин проверяется на выбранной площадке.
- `CommandTree/ManualStructureCommands/OnDemandStructures`: стандартные `/locate structure slavicmyths:…` для лагерей, курганов и болотных объектов направлены в те же очереди, с сохранением OP2. Старого поиска через vanilla для этих литералов больше нет. Чудь уже использует свой общий маршрут.
- `DepthsService/DepthsCommands`: существующая отдельная механика Глубин сохранена; подготовка её участка переведена на `SiteChunks`, число удалённых проб сокращено с 16 до одной. Отсутствующая точка locate инициирует существующее создание.
- `NavigationEvents`: исключительно `getChunkNow`, в том числе для ссылок. Завершение поиска Яги/Чуди отправляет небольшой delta книги вместо полного повторного snapshot.
- Проверки контейнеров, строительных блоков, занятых областей и существующего журнала поставленных игроками брёвен сохранены/добавлены. Искусственный блок на выбранном месте вызывает отказ; бесконечного удалённого перебора после отказа нет. Для старых поставленных игроками натуральных блоков без сохранённого происхождения невозможно надёжно отличить постройку от ландшафта — это ограничение требует игровой проверки защиты.

Большая Чудь по-прежнему требует подготовки собственной большой области (до 17×17 чанков), но эти чанки относятся к одной фактически создаваемой постройке. Быстрота завершения и отсутствие просадок на сервере пока НЕ подтверждены. Старые showcase/place-команды городища, святилищ и Змеиной горы не переписаны этим пакетом; это не пути кнопки книги/поручений, и объявлять все генераторы мода оптимизированными нельзя. Vanilla `/locate` для остальных структур (включая городище/Змеиную гору) не заменён; нельзя распространять результат пакета на эти команды.
