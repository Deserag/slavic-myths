# 2.1.6.2-TEST: ручное ядро посада и яйца

Команда /slavicmyths dev generate nether_posad [shell] реализована через общий PosadShell. Два прохода: проверка территории без записи, затем ограниченная подготовка113×113 и физическое строительство; стены/башни/ворота/улицы/площадь/платформа/опоры. Районные здания и автоматический мост к берегу не реализованы этой командой. Полноценный город не заявлен, natural StructureSet выключен. Неприродные блоки/инвентари отклоняются; натуральные блоки игрока неотличимы от рельефа. См.docs/GENERATION_COMMANDS.md.

Оба яйца зарегистрированных боссов доступны в Creative mobs. Команды /give требуют двоеточие: slavicmyths:morova_deva_spawn_egg и slavicmyths:trizna_prince_spawn_egg.

Java21 clean build/resources PASS.17/17 настоящих серверных GameTest PASS, включая физическое основание/улицу/проход после выполнения нового обработчика. Новый локальный GUI не запускался, проверка вида вкладки владельцем PENDING.
