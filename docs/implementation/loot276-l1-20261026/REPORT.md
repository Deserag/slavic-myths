## Как проверить в Minecraft владельцу

Сборка для этой проверки **2.0.3-HELL**, SHA выше; в установленной2.0.2новых наград нет. Перед своим запуском сделать backup старого JAR и мира, установить ровно один mod JAR2.0.3в HELL1.21.1/NeoForge21.1.255, оставить1.16.5в покое. Codex эту установку/запуск не выполнял. Source commit указан в publication.json после коммита.

1. Создать новый Survival-мир без OP (для повторения предлагаемые world seeds276301/276302/276303, это НЕ обещание известных координат). Через книгу/обычную разведку найти по одному малому/среднему/большому лагерю и кургануI/II/III. Записывать действительный seed,координаты,размер/уровень; источники поиска/частота не менялись. Собрать **все** контейнеры и отдельно дроп мобов/личные награды.
2. В малом лагере открыть палатку старшего, в среднем главаря, в большом дом атамана; должны быть конечные полезные материалы и возможные дополнительные rolls. Нулевая руна в одном сооружении ожидаема. В большом отдельно проверить forge/warehouse/Соловья: прежние тематические награды, не второй новый main. Ни в одном лагере не должен появиться новый незерит/IIIруна.
3. В каждом кургане дойти до финальной комнаты. Главный ларец должен помещать весь новый результат, максимум5стаков, без warning о переполнении. Прочие ларцы сохраняют археологические находки. Отсутствие скрапа/алмазной брони в одной зачистке нормально:85%/97%отказа соответствующего roll.
4. Полученную крафтовую руну установить на совместимый предмет обычным существующим способом → её описанный эффект; фрагмент сохранить, собрать3одинаковых → существующий рецепт восстановления. Книгу применить на наковальне к совместимой вещи → настоящий enchant, не пустая книга. Надеть найденную броню/взять оружие → видны прочность/зачарование; template применить на кузнечном столе с допустимым материалом отделки → vanilla trim.
5. Негативный сценарий: при полном инвентаре открыть/закрыть ларец, забрать частично, сохранить/выйти/перезайти, вернуться в те же чанки → прежний остаток, никакой повторной main-награды. Сломать уже опустошённый контейнер → награда не восстанавливается. Монетная торговля Чуди1→2karavai/старые цены прежние.
6. На **копии старого мира** проверить уже открытый сундук и сохранённый неоткрытый: старый лут/старые references сохраняются, не принудительно заменяются новыми. Для новой награды исследовать новые размещённые структуры, не ждать её в уже загруженных.
