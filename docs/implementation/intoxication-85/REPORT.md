## Время и сохранение

`Points`/`LastDrink` и `drink_overload` сохранены. Lazy decay считается перед следующим
алкогольным напитком: 1199 тиков — без спада; 1200 — минус 1; 2400 — минус 2.
После каждой алкогольной порции LastDrink становится текущим gameTime.
Паузы по 1200 тиков между обычными кружками оставляют максимум 1 дозу.
Негативные MobEffect имеют конечную длительность и без питья не обновляются;
снижение накопленной нагрузки не является ежесекундным переустановлением эффектов.
После молока скрытая нагрузка сохраняется как прежде; безалкогольные напитки её не обнуляют.
Время — игровые тики, не wall clock: остановленный мир не трезвеет офлайн.
Attachment сериализуется, copyOnDeath отсутствует (смерть сбрасывает нагрузку).
Это анализ существующего lifecycle, НЕ доказанный игровой relog/death/world reload.

RU/EN tooltip показывает настоящие константы порога/спада. Сервер после питья отправляет
в action bar текущую дозу и ступень; это снимок на момент питья, не постоянно обновляемый HUD.
Значения добавлены и в brewing_resources.py; весь старый генератор не запускался,
чтобы не перегенерировать несвязанные ассеты. AST-проверка подтверждает новые значения.
