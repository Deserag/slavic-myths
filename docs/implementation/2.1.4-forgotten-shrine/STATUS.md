## Реализация и первоисточники

SPEC/BLUEPRINT/VARIANTS/CONCEPT из `docs/concepts/nether-structures/2.1.4_*`,
Issue #344, requirements 00/01/02/07/12/13. Оригинальный PNG по-прежнему недоступен.
`VOXELS.tsv`, `LAYERS.svg`, `SURFACE.png` здесь **выгружены из фактического Java
voxel-генератора через GameTest**, не являются игровыми скриншотами.
Скрипт воспроизведения: `tools/generate_nether_structure_atlas.py`.

`ForgottenShrine{Worldgen,Structure,Terrain,Piece}`: отдельная native structure
`slavicmyths:forgotten_shrine`, один атомарный piece 15×15, Y=-5…8 либо -10…8,
четыре варианта × четыре поворота. Центральный каменный алтарь с костром на камне,
базальтовые/багровые опоры и реальный крепёж двух/одного/нулевого фонаря по степени
разрушения. Ровно один chest на нижнем этаже, в (7,bottom+1,5), с открытым верхом.
Новых item/block/entity ID, мобов, загадок, квестов и скрытых наград нет.

Точная поправка к концептуальному маршруту: первый широкий спуск — X6…8,
Z13→9, Y0→-4, с выходом на пол Y=-5 у Z8. Входной пандус — X6…8,Z14,Y0,
ступени facing NORTH; основная лестница facing SOUTH. Начало на Y=-1 потребовало
бы прыжка при обратном выходе, поэтому оно технически уточнено. Второй спуск:
Z3…4, X11→7, Y-5→-9, facing EAST, выход на пол Y=-10 у X6. Сундук Z5 не пересекается
со второй лестницей. Потолки прорезаны над ступенями; минимум 2 клетки headroom.
Залы 11×11, полностью каменные стены/полы и минимум три свободных уровня внутри.

## Безопасность и сохранения

Предварительный поиск использует только кэшированные noise columns внутри одного
чанка, конечный диапазон Y24…104, четыре легальных footprint-центра и поворота.
Подземный envelope должен состоять из естественного материала: нет лавовых карманов,
пещерных пустот/bedrock. Основание устойчивое, гравий под несущими блоками запрещён.
Магма, которую полностью закрывает каменный пол, не является жидкостью/чужим домом;
естественный гравий внутри заменяемого объёма можно заменить при устойчивой нижней опоре.
Поверхность допускает локальную срезку не более двух слоёв естественной породы.

Перед записью — полный повторный actual-world preflight: жидкости, bedrock,
block entities и неестественные solid blocks запрещены. При поздней cave/lava/gravel
коллизии ограниченно проверяются четыре footprint в том же чанке, четыре поворота
и Y±2. Ни один блок не пишется до полного fit. Переместившийся piece сохраняет
обновлённые координаты/поворот и **новый StructureStart с верным bounding box**.
При полном отказе start INVALID, vanilla locate cache обновляется серверным потоком.
Нет глобальных ticks, chunk tickets, ретрогена или вырезания лавы.

Поздние соседние грибные кроны удаляются только из авторского AIR-envelope уже
размещённой структуры в финальном decoration pass. FULL-чанки, жидкости, чужие
твёрдые блоки и BE не очищаются. Полная поддержка сторонних claims НЕ доказана.

Persisted `Placed` запрещает повторную вставку и повторную инициализацию лута,
в том числе после восстановления piece из NBT. Тест NBT ≠ реальный stop/start мира.

## Лут и численная модель

Одна vanilla chest table `chests/forgotten_shrine`: две настоящие руны I и третья
84% I / 15% II / 1% III, кости 2…6, гнилая плоть 2…5; независимые шансы оберегов
6%/3%/2% из SPEC. Только действующие зарегистрированные rune IDs, без blank_rune.
III IDs существуют в AdvancedRuneRules/RuneRework, новые руны не вводились.
Это предложенный в SPEC baseline для численного QA, не объявлен владельческим
финальным балансом. 10 000 реальных unpack операций: третья руна I/II/III
**8401/1490/109**, минимум две I во всех пробах, повторный unpack не выдаёт новый лут.

структуру в 4/5 seed; на 20261025 все шесть noise proposals в 236 кандидатах
отвергнуты настоящими caves/lava/неустойчивой опорой. Они НЕ засчитаны размещениями.

доказательство survival-находимости без OP; отдельный большой census ещё NOT_RUN.

## Проверка владельцем позднее / риски и откат

В новом survival-мире исследовать новые чанки Незера без OP: увидеть открытый алтарь,
спуститься по обычным ступеням, открыть единственный сундук, вернуться без прыжка.
У Б/Г есть второй зал; у А/В один. Проверить два блока над головой, верх сундука,
реальные цепи/фонари, отсутствие лавы и висящих подземных комнат. Затем опустошить
сундук, save/relog и проверить отсутствие нового лута, повторить на копии старого
мира и с двумя игроками. Отдельная OP-диагностика: `/locate structure slavicmyths:forgotten_shrine`.
Это не заменяет поиск без OP. Старые миры не ретрогенерируются. Для отката вернуть
один предыдущий JAR из backup, не оставляя две версии; сохранения не удалять.
