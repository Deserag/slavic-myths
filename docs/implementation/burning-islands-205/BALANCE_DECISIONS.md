Вопросы Normal/Hard/вертикального ranged-cheese не закрыты.

Для природного этапа ещё нужна доказанная количественная граница «крупного лавового океана» и безопасная геометрия арены/вулкана; исторические гипотезы размеров не превращены в утверждённые числа. Для временной магмы whitelist/provenance/expiry не утверждались: блоковая часть отключена.
