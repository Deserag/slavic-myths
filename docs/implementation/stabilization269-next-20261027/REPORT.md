## Как проверить в Minecraft — владельцу

Точную сборку, SHA, source commit и установленный JAR см. BUILD_RESULT.json. Сначала закрыть игру и сделать копию мира. Кандидат 2.0.8 не подменяет автоматически установленную 2.0.7; не смешивать два JAR. Preview #298 не является production-текстурами.

1. В отдельном новом мире без OP пройти существующий путь доступа к Яге. В копии старого мира проверить уже заработанный доступ. Настоящие убийства Лиха/Тугарина/Соловья должны давать прежние условия доступа и не исчезать после перезахода.
2. Открыть исследование Чуди и Книгу сказаний. Подсказка показывает приблизительные X/Z и радиус, без фиктивного Y. Если эта сессия уже загружала подходящий неисследованный город, должна использоваться известная цель. Неизвестные чанки всего мира не сканируются.
3. Для первого запроса без известной цели дождаться окончания прежнего безопасного создания. До завершения стройки координаты не выдаются. Повторное обращение во время работы не создаёт вторую задачу. Отказ на неподходящей площадке не оставляет ложную цель.
4. Дойти до города, посетить его, вернуться к Яге: получить один древний знак. Повторить обращение — другой существующий неисследованный город допустим; новая бесконечная раскопка после награды нет. Перезайти во время активного поручения и после сдачи: цель/завершение сохраняются, знак за тот же site повторно не выдаётся.
5. Открыть «Разговор», «Поручения», «Проводники», «Обмен», «Котёл». Портрет остаётся в своей панели, навигация доступна, кнопка помощи одна. Помощь закрывает модель и предметы; Enter не выполняет скрытое действие, Esc сначала закрывает помощь. Повторить RU/EN, 854×480 GUI2, затем свою обычную конфигурацию с JEI.
6. Негативные проверки: нет доступа к Яге без условий; нет награды за непосещённый город; повторный запрос после сдачи не создаёт новый город; старый выбранный Target не теряется после перезапуска.
7. MP остаётся за отдельной проверкой: два игрока с разными поручениями, независимые награды, перезапуск сервера и отсутствие повторной выдачи. Не запускать второй клиент на ноутбуке одновременно без нового решения владельца.

Только для диагностики в отдельной копии QA-мира seed 2692026: `/tp @s 1378 40 1140` — ранее подтверждённый вход города, owner chunk 88,63. Эти координаты не гарантируются для нового мира с другим seed/порядком генерации. Диагностическое перемещение не засчитывается как Survival-доступ.
