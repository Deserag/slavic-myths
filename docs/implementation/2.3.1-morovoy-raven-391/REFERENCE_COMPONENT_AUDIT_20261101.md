## Звуки: кодовая карта

В `MorovoyRaven.java` нет вызовов `playSound`, `level().playSound` и своих `getAmbientSound/getHurtSound/getDeathSound`. В `sounds/boss` имеется только `tugarin`; подтверждённых отдельных raven OGG нет. Наличие `sounds/karachun/raven_*.ogg` **не** делает эти записи утверждённым звуком Морового Ворона. Голоса, крылья, взлёт/посадка, ближние атаки, мор, призыв, урон и смерть: **BLOCKED_NEEDS_AUDIO_SOURCE / NOT_RUN**. Запрещено копировать синтетический placeholder или сообщать, что события слышны без реального клиента.

## Приёмка

- Источник художественной истины: два **оригинальных** PNG, не SVG и не догадки.
- Измерить 5–6 блоков туловища, не размах; фронт/бок/спина/верх/¾, размеры со Steve.
- Для каждого бокового пера и моровой линии: самостоятельное наблюдение и кадр, затем `соответствует` / `исправлена и проверена` / `не соответствует`.
- `clean build` Java 21, dedicated server, рендер, анимации, hitbox, звуки, два игрока, релог и пять seed — **NOT_RUN в рамках этого source-only аудита**.
