# #262 — техническая часть контракта Чёрной гари

Источник: #261–#267, актуальный STRICT_ACCEPTANCE_2.0.3 от 27.10.2026.

не зарегистрированы и не заменяют утверждённый PNG. SOURCE gate BLOCKED_REFERENCE.

## Игровой путь и границы

Обычный игрок строит портал → исследует существующий Nether → находит открытую
Чёрную гарь → использует пепельные безопасные проходы между магмой/лавовыми прудами
→ добывает грунт/камень/чернодрево → встречает четыре вида → находит доступную
арену Жареницы → побеждает и получает все гарантированные трофеи. Естественная
доступность этого пути реализуется только #267; команды не заменяют её.

Три необходимых вида рельефа для исходных чертежей/проверки:

| Вид | Что должно читаться | Что исключено |
|---|---|---|
| Сверху | Связная сеть пепельных проходов обходит небольшие лавовые водоёмы; редкие деревья вне проходов | Полное перекрытие пути магмой/лавой, искусственная регулярная сетка |
| С уровня игрока | Невысокие мягкие холмы, широкий обзор, чёрно-серый грунт и локальные оранжевые жилы | Высокогорный лес, вертикальные этажи Навьей рощи |
| Боковой разрез | Неровный берег локального пруда, безопасный обход, редкие ствол/пень/крона | Изменение глобального lava sea level или стены лавы |

Числа доли лавы, ширины дорог, высоты холмов, плотности деревьев/частиц, mob weights
не выбираются здесь произвольно. Их согласование и измерение — зависимости #267.
Рисовать финальные texture sheet/UV без исходного PNG запрещено контрактом.

| #263 семейство | Top/front/side требования | Владелец ресурсов |
|---|---|---|

| Треснувший камень | Выраженные трещины/жилы, без дополнительного урона | #263 |
| Частая магма | Существующий `minecraft:magma_block`, не новый mod Block/Item | vanilla |
| Чернодрево | Обычная/обгоревшая кора, top/bottom торцы; одна порода | #264 |

У камня — stairs/slab/wall с loot/recipes/tags/rotation; у дерева — полный принятый
строительный набор/листва. Саженец в биоме и превращение живого дерева от огня не
входят. «Жаркая гарь» и новый «Частая магма» отменены. Палитра — угольный чёрный,
серый пепельный, тёмно-коричневый и локальные оранжево-красные акценты; точные RGB
извлекаются из подлинных PNG после SHA-проверки, не придумываются здесь.

Предлагаемый namespace для будущего анализа — `slavicmyths`; candidate biome path
`black_cinder` **не утверждённый/зарегистрированный ID**. Имена всех блоков и дерева
зафиксировать после сверки источников; никакого «резервирования» пустыми объектами.
Окончательные четыре EntityType и boss ID также пока не регистрируются.
В `hell` есть `slavicmyths:navya_grove`/`navya_heart`, `soul_fragment`/`soul` и другие
существующие souls: их сохранять. Текст задачи о частичной печати на main требует
точного ID/source: поиск по heatproof/heat_resistant_seal/Жаростойкая не дал совпадения;
не считать ни реализацию печати доказанной этим поиском, ни гарантированно отсутствующей.
