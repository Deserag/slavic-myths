## Актуальное решение 25.10.2026: четыре моба обсуждены, но арт-файлы переданы не полностью

**Договорённость владельца:** Углеполз — враждебный (рывок с укусом, адаптация к магме); Пепельный дух — **НЕЙТРАЛЬНЫЙ, атакует только в ответ** (дымовой рывок и пепельный всплеск); Пекельник — враждебный (когти и бросок углей); Искровик — мирный, без атак (парение и искры). **Шлаковый жук исключён.** 1–2 обычные боевые способности, без перегруза.

**Важные реальные файлы для Codex:**
1. [Развёрнутые требования к модельным частям, AI, анимациям, звукам и тестированию](https://github.com/Deserag/slavic-myths/blob/main/docs/concepts/black-cinder/mobs-2.0.3.4.md).
2. [SVG — технический чертёж четырёх силуэтов](https://github.com/Deserag/slavic-myths/blob/main/docs/concepts/black-cinder/mobs-blueprint-2.0.3.4.svg) (**НЕ точная копия принятого рисунка**).
3. **Принятый оригинальный референс из этого чата:** «Обитатели Чёрной гари — мобы и навыки» (согласован владельцем). **PNG ещё НЕ загружен в репозиторий**; Codex не может считать художественную часть полного задания закрытой без него. До загрузки — `BLOCKED_REFERENCE` для художественного соответствия, даже если по SVG можно начать техпроработку.

**Добыча:** существующие `soul_fragment`, `soul`, `empowered_soul`, `bound_soul` не дублировать. «Обугленный панцирь», «Пепельная эссенция», «Калёный коготь», «Живая искра» пока **предложения, НЕ утверждённые loot tables**. Все конкретные проценты/HP/урон/кулдауны — предмет баланса.
