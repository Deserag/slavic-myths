Заранее заданные признаки существенной регрессии не обнаружены: в обоих B нет падения uncapped FPS >5%, роста среднего CPU/кадр >10% или устойчивого роста хвостов >max(10%, 0,5 мс) относительно диапазона A. Ранее подозревавшееся двукратное падение FPS не воспроизвелось. Малое число JVM, разные даты, отсутствие температурного контроля и изменённые интервалы запуска не позволяют обещать конкретный процент ускорения на любом оборудовании. Это практическая проверка регрессии, а не статистическое доказательство универсального прироста.

В допустимых trimmed окнах нет кадров >50 мс. В нативном event tick body встречались единичные значения >50 мс: A2 54,805, A5 53,491, B1 58,494; максимум B2 40,442 мс. Это не устойчивое падение TPS и не доказанная проблема cube; полные сырые интервалы сохранены. Tick body в этом probe не выдаётся за весь нативный MSPT.

1024 bitwise теста всех атрибутов 24 вершин прошли во всех четырёх допустимых JVM; снимки сцены проверены отдельно. Аллокации actual production: main 1808 → PR #37 576 байт/вызов, −68,14%. Удалены 38 собственных массивов; оставшиеся 24 Vector3f создаются нативным setNormal. JFR B1/B2 не содержит собственных float-array samples cube, A2/A5 содержит. Веса JFR оценочные и не равны retained heap.

A1/A3/A4 исключены по заранее заданным условиям, не скрыты и не обозначены регрессиями. Всего в этой итерации cube: **7 клиентов / 7 integrated servers**, из них 4 допустимых для сравнения и 3 с нарушенными условиями. Это отдельный счёт от старого отчёта PR #37.

Размах времён событий JFR не равен длительности записи или измерительного окна: длительные ThreadPark/ChunkGeneration могут начаться до включения recording. GC-count/паузы приведены для событий файла; FPS и CPU/кадр вычисляются по явным возрастам из CSV. Точные rates нельзя получать делением на event span.

NOT_RUN для этой проверки: все состояния/анимационные циклы стражей в настоящем бою, несколько GPU/драйверов, connected dedicated/multiplayer, uninstrumented profiler-overhead baseline, GPU frame time. Фиксированная сцена содержит нативные рендереры без server AI и не является приёмкой всего игрового процесса.
