## C. Найденные проблемы

**Подтверждён критический серверный краш main:** `PolozEvents.BodyMelee.tick`, Heavy bandit, NPE при пустой цели. Нативное вытеснение `BanditEntity.CombatGoal` очищает цель в `stop()` уже после `BodyMelee.canUse()`. Отдельный GameTest воспроизводит ту же последовательность, а также ClassCastException при другом типе цели. Это причина завершения игры, а не просто падение FPS. Исправление изолировано в `codex/poloz-body-melee-lifecycle`, коммит `8b49c5ca`; main не менялся.

Подтверждённые временные аллокации описаны в PR #37, происхождение звуков/частиц — в PR #36. В обычном мире также зарегистрирован единичный OpenAL `Stop: Invalid name parameter` до боссов; причинная атрибуция и связь с заметной задержкой не доказаны. [Топ-10 приоритетов](HOTSPOTS.md) отдельно помечает доказанные дефекты, симптомы и пробелы: десять доказанных production-дефектов этот аудит не нашёл.

## D. Оптимизации

В этой ветке production-оптимизаций нет. Существующее исправление PR #37 сохраняется: удалены 38 собственных массивов на вызов cube; временные Vector3f нативного setNormal остаются. Измерение выделений на вызов: 1808 → 576 байт (−68,14%), с точным сравнением всех атрибутов 24 вершин. Эти значения относятся к конкретному вызову, а не к общему расходу памяти игры. JFR-веса — оценка выделенных, а не удерживаемых байтов. Новое исправление допускается только для доказанной проблемы, в отдельном PR с сопоставимой проверкой до/после. Визуал, звуки, модели, анимации, способности и механики не упрощаются.

Отдельное исправление краша проверяет текущую живую цель непосредственно в BodyMelee.tick. На main: 5 ошибочных подслучаев и положительный контроль атаки/cooldown PASS. После: 1/1 native GameTest, 6/6 подслучаев PASS, clean build/ресурсы/JAR PASS; около51min обычных сцен и отдельный12min flat не повторили NPE. [Идентичность пяти классов исходного v1 probe до/после](world-probe-parity.json) подтверждена отдельно; исправление disconnect v2 касается fixture, не production.
