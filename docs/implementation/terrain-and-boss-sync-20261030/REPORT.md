## Как проверить в Minecraft

Открыть существующий профиль **Slavic Myths 2.1.6.2 - HELL - TEST**. В новом обычном плоском мире включить читы и выполнить без аргументов:

```
/slavicmyths dev generate nether_posad
```

Дождаться сообщения о завершении. Управление: `/slavicmyths dev posad status` и `cancel`. На отдельной снежной или лесной площадке выполнить `/slavicmyths dev generate veche_hall` или `nether_watchpost`: ожидаются расчистка, исправный проход и основание, а не отказ на снег. Полный единый список: `docs/GENERATION_COMMANDS.md`. В Незере проверить то же явное административное размещение. Обычный survival-поиск без OP идёт по прежним worldgen-правилам и не засчитывается этой командой.

В Creative-категории «Мобы» должны быть яйца Моровой девы и Князя Тризны. Их предметы, компоненты, рецепты и ритуалы импортированы из существующей реализации. Диагностический spawn не заменяет ритуальный survival-путь. Без OP команды генерации недоступны. Негативно: свой сундук с предметами на площадке не должен уничтожаться. После сохранения и перезахода проверить постройки, сундуки и яйца; повторить вдвоём. Эти пользовательские сценарии агентом не выполнены.
