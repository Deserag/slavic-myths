### Набор ассетов/блоков
- **Ствол чернодрева** (тёмная коричнево-угольная кора, различимые кольца) и **обгорелый ствол** той же древесной породы (сухая почерневшая кора, локальные красно-оранжевые угли). Направления осей X/Y/Z, `wood`/stripped варианты — после анализа стандартных регистров, не плодить ненужные дубли.
- **Обугленная крона** (редкие сухие обрывки без пышной зелёной листвы); пни/сухие ветви — как экономные модельные элементы, не обязательно каждый как новый ID. Редкие приземистые/наклонённые деревья, их древесина должна быть доступна игроку.
- **Стандартное семейство из досок:** доски, ступеньки, плита, забор, калитка, дверь, люк, кнопка и нажимная плита. Проверить таблички/подвесные таблички, лодку и другие стандартные формы на соответствие логике **Nether-древесины**; не требовать ванильной лодки из огнестойкой древесины без согласования. Для двери/люка проверить анимацию и звуковые события.
- Рецепты верстака/резака (если применимо), топоры/теги, loot-добыча, локализации, creative inventory, текстуры top/side, связность листвы/ствола с модом FallingTree (учесть прежний сбой сосны), отсутствие дубликатов item IDs.
- **Саженцы НЕ выпадают** из обгоревших деревьев в этом биоме, дерево не должно естественно расти из этих остатков. Предложение о живом дереве в следующем биоме и превращении при поджоге **отложено и не реализуется** без отдельной задачи; не выбирать за владельца, какой именно биом получит живое дерево.

### Приёмка
- [ ] Два варианта стволов узнаваемо различаются; доски и все предусмотренные строительные формы соответствуют Minecraft-пиксельному стилю.
- [ ] Сруб дерева полностью и корректно работает с FallingTree без поломки существующих деревьев; без саженцев из Чёрной гари.
- [ ] Рецепты, теги, sounds, drops, русская/английская локализация, анимации двери/люка, форма дерева и QA на Java21+NeoForge; worldgen отдельно в 2.0.3.6.
