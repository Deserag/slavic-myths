**Задача:** согласовать технический контракт утверждённой природной формы и ассетов (пока **без генерации**).

### Требования
- Просторная равнина с мягкими невысокими холмами, широким обзором; локальные курганы/берега маленьких лавовых озёр, редкие чёрные деревья, открытые безопасные пепельные тропы, дым из ограниченных очагов.
- Палитра: угольно-чёрный, серый пепельный, темно-коричневый, магма оранжево-красная. Художественный ориентир — **vanilla Minecraft Nether**, читаемые пиксельные текстуры 16×16, никакого PBR/фотореализма.
- Подготовить полный тех-референс: план сверху и боковой силуэт холма/озера/дерева, палитру, таблицу поверхностей верх/бока, схемы стволов/крон, UV/модели, предлагаемую карту registry ID и ownership ресурсов без переименования уже зарегистрированных.
- Отделить **подтверждённое** от предложенного: блок «Жаркая гарь» отменён, обычные `minecraft:magma_block` используются массово, отдельный новый магма-блок не нужен. Магмовые прожилки у обугленного камня — визуальная черта, **огненный урон от него не утверждён**.
- Проверить пригодность Minecraft 1.21.1 для нового Nether биома на рельефе после #147, не вмешиваясь в существующий worldgen.
