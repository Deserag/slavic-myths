## Изменения

- Яга: до трёх новых лесных площадок по метаданным, затем до 12 уже загруженных площадок вокруг игрока. Сохранённая незагруженная резервация также проверяется первой. Каждый участок готовится очередью SiteChunks; нет синхронного поиска мира. Предел запроса 180 секунд. Режим создания принимает естественный склон/мелкую воду, строит основание до верхней отметки площадки; режим строгой естественной проверки сохранён. Контейнеры, известные брёвна игроков, искусственные блоки защищены. Успех после размещения и NPC, а не резервации. Большая глубина воды, высотная граница, защищённые строения ещё могут исключить конкретную площадку; затем пробуется следующая.
- Чудь: до шести площадок; отказ до начала записи переключает площадку с освобождением tickets. Незавершённая запись не объявляется успехом, не переносится поверх другого участка. Подземная геометрия не зависит от поиска ровной поверхности; вход привязан к поверхности.
- Баюн: новая лесная площадка первой, затем до девяти локальных попыток при отказе preflight; естественная площадка допускает деревья и перепад до четырёх блоков. Редкость feature 3200 → 128, генератор ресурсов синхронизирован.
- Волк: устранена нулевая квота без Тугаринов (минимум три места на мир), доля подходящих регионов 10% → 35%, расстояние между местами 1024 → 768. Поиск поверхности спускается через стволы; крона не запрещает лесную встречу. Порог ровной свободной арены 80% → 35%, перепад 2 → 4. Защита от пересечений структур сохранена.
- Сивка: удалён дополнительный бросок 0,2% поверх веса biome spawn. Сохранены проверка места для тела, дневной свет и трава под центральной точкой.
- Жар-птица: первая доступная ночь без ожидания 20–30 дней; интервал следующих визитов 2–4 дня. Старое далёкое ожидание мигрирует. Окно — вся ночь, попытки в 32–64 блоках от игрока вместо 65–112. Лимит одной встречи сохранён.
- Мор: естественное заражение после двух игровых суток, 12% подходящих спавнов вместо седьмых суток/4%; дистанция от spawn и локальный предел сохранены.
- Малые лагеря: spacing 20 → 32, separation 15 → 24: расчётная плотность новых кандидатов 39% прежней. Уже построенные лагеря остаются.

Это ограниченные попытки, не математическая гарантия постройки в произвольном мире. Защищённая игроком территория и границы мира не уничтожаются ради успеха.
