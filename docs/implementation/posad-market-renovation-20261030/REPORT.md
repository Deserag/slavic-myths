# Slavic Myths 2.2 — Меновые ряды: меблировка и перемещение наград (schema 9)

**Дата:** 30.10.2026. **Ветка:** `codex/hell-posad-districts-227-228-20261030`. База для этого коммита: `0835dcee`. Целевая ветка PR #368 — `hell`; `main` не менять.

## Задача

Убрать пустоту в интерьерах 2.2.6, отодвинутые от стен сундуки и монотонные фасады, не нарушая уже созданный общий город. Исходный авторский `2.2_6_MARKET_VOXELS_DRAFT_A.json` **оставлен без изменений** как история модели: 2203 блока, 675 клеток пола и 8 оригинальных именованных таблиц лута.

## Изменения в новом городе

1. `PosadMarketRenovation.java` (schema >= 9) переносит **все восемь** original chest positions в свободные клетки, прилегающие к боковым стенам помещений: x3 или x23 в координатах рынка. Старые клетки задаются явно как AIR, новые — `minecraft:chest`, обращённые лицом к центру помещения, с точной исходной LootTable на каждом сундуке. Между двумя сундуками одной кладовой есть свободная клетка: они не превращаются в большой двойной сундук.
2. Металл, пища, ремёсла и разные товары получают отдельные тематические pine/linden столы, полки, скамьи, табуреты, стойки оружия. Всего **12 новых блоков мебели** и **6 напольных soul lantern**. Все добавления только в исходные пустые клетки на оригинальном багровом полу, с воздухом над ними.
3. Ритмичные багровые вставки на существующих кирпичных стенах, без перекрытия окон и дверей.
4. `PosadPiece` применяет слой поверх immutable R1 источников; только новые города с schema 9, сохранённые старые версии не ретрофитятся. Полная ручная команда сохраняет прежний preflight/reservation/clip.
5. Бинарный `structure/posad/menovye_ryady_2_2_6.nbt` **перегенерирован** на 2203 блока: в нём физически существуют только 8 сундуков на **новых** позициях с их оригинальными `LootTable`, поэтому отдельная команда `dev generate menovye_ryady` не создаёт дубликаты. Java-обработчик standalone после размещения дополняет интерьер, но **не переписывает уже созданные в NBT block entities сундуков**.

## Проверки

`python tools/verify_posad_market.py` сверяет поблочно исходную модель и компактный runtime JSON, затем независимо проверяет все восемь chest relocations, 12 furniture и 6 lantern координат на отсутствие пересечений и наличие пола. Декодирует реально поставляемый gzipped NBT, сравнивает 2203 пары coordinate/state, 8 NBT block entities и точные loot IDs; также проверяет непрерывность существующих кровель четырёх лавок и двух кладовых и сохранение шанса 20% на 1–2 древние монеты только в купеческом тайнике.

Другие скрипты схем 8 обновлены на номер схемы 9 (без изменения их прежних предметных контрактов).

Локально после получения GitHub-ветки выполнить:

```powershell
python tools/verify_posad_market.py
python tools/verify_posad_hall_refinement.py
python tools/verify_posad_house_renovation.py
python tools/verify_posad_v6.py

.\gradlew.bat clean build
```
