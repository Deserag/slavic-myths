# Краткая ручная приёмка

Автоматизированный dev-client уже проверил текущий skin/оба главных направления руки, реальные server actions,6 эффект×залп сценариев в Survival. Это не ручной свободный проход.

- Коса: прежние лезвие/подвески, горизонтальный круговой взмах, совместный хват; first/third-person.
- Арбалеты: размер/рука; три головы, три болта при зарядке, корректные иконки в инвентаре.
- Shift+ПКМ/Shift+ЛКМ: эффект/веер-очередь; все3 выхода, попадания/Слабость/горение/Буря.
- Позже отдельно: второй skin, multiplayer, настоящий перезаход и длительные бои.

Для новых запусков Minecraft соблюдать пользовательское ограничение: интервал≥10мин. Для этой версии новые запуски не требуются; автоматические повторные клиенты не создавать.
