# Восстановление оружия и три головы арбалета — 1.9.7.3

Работа по регрессиям пользователя, 2026-10-14. Реальная визуальная приёмка предыдущей 1.9.7.2 провалена: прежний simplified overlay был не принят игроком; static gates не доказывали внешний вид. Полоз, эффекты/управление арбалета, HP/руны/броня и творческие вкладки сохранены.

## Финальная реализация

- Восстановлены исходные 60 деталей косы и исходная 32px иконка из Git1bad7c80. Изогнутое лезвие, зубцы, подвески и материалы сохранены. Примитивная восьмидетальная модель больше не генерируется. Копии исходных ресурсов лежат в tools/weapon-art-original, без зависимости генератора от Git history.
- Исправлен block/item texture atlas: четыре прежние entity-texture ссылки (Карачун, Морозко/кристалл, голова Полоза) включены через additive single sources. Первый реальный клиент обнаружил missing texture, которой static gates не видели.
- Коса first-person: held baked geometry рисуется ровно один раз через NONE, без builtin/entity рекурсии и повторного применения display transforms. Рука и оружие движутся вокруг общей точки плеча/хвата. Древко становится горизонтальным и направлено от игрока на протяжении четырёхтикового sweep140°. Середина дуги совпадает с серверным Windup/hit, recovery возвращает idle. Third-person имеет собственный ItemInHandLayer той же геометрии с хватом у кисти и горизонтальным древком. Серверные NightCombat hit cone/damage/cooldowns сохранены.
- У двух арбалетов UV0..31 на 32px атласах преобразованы в Minecraft model units0..16 во всех12 состояниях. Это устраняет выбор чужих atlas sprites, включая брёвна. Базовый змеиный арбалет сохраняет прежние geometry/materials/GUI scale.
- First-person размер арбалетов увеличен с .65 до .85 (примерно31%). Рука/рукав видны, weapon mesh и кисть используют одну точку. Прежняя проблема oversized detached forearm устранена положением/наклоном предплечья.
- По новому запросу three_breath_crossbow получил три полноценные драконьи головы вместо трёх камер: морды, пасти, зубы, рога, глаза. Ложе/плечи/тетива сохранены. ID/рецепт/Shift+ПКМ эффект/Shift+ЛКМ веер-очередь не меняются. До построения зафиксированы силуэт, размеры и материалы в DESIGN.md. Основная модель65 деталей, заряженные68; каждый из трёх выходов показывает болт. Серверный lane0/1/2 сохраняется в двух отложенных rounds. Место появления зависит от взгляда и руки; block clip предотвращает выстрел сквозь стену. Прицел — текущий ограниченный32b ray, выбранный эффект фиксирован на весь залп. Только локальные запросы при выстреле, без global scans/tick polling или AI chunk forcing.
- BreathCloud раньше был isPickable и физически перехватывал второй/третий болт очереди Мора. canBeHitByProjectile=false позволяет стрелам проходить через область; isPickable и bottle interaction сохранены. Адресный повтор подтвердил три попадания во врага вместо одного.
