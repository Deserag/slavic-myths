# #298 — утверждённый текстовый референс, 27.10.2026

Источник: прямой ответ владельца в текущем чате. Этот текст заменяет ожидание старого изображения. Утверждён подход, а не готовые варианты PNG.

- Плоский vanilla-like Minecraft item sprite. Для всех четырёх предметов `parent: minecraft:item/handheld`.
- Основной металл графитовый; вторичный — бронза/медь; рукоять тёмная деревянная, допустимы обмотки/кольца. Бирюза только небольшими акцентами.
- `chud_master_pickaxe`: сохранить обычный ванильный силуэт кирки; recolor/retouch, без нового фантазийного силуэта; 2–6 бирюзовых пикселей максимум.
- Мультиинструмент: простая компактная комбинация знакомых частей. Основа кирка, с одной стороны топор, с другой мотыга, лопата в верхней части. Без сложной геометрии и перегруза.
- `chud_multitool_pickaxe`: доминирует кирка; остальные части вторичны.
- `chud_multitool_axe`: доминирует топор, сохраняется общая конструкция семейства.
- `chud_multitool_shovel`: доминирует лопата, сохраняется общая конструкция семейства.
- Запрещены псевдо-3D, вычурные формы, чуждый Minecraft вид, чрезмерная бирюза. Не менять механику, характеристики, рецепты и ID.
- Сначала preview каждого sprite, в GUI и руке, с пояснением базы. Внедрение в production — после подтверждения владельца.

## Текущий preview

В `references/` лежат исходные ванильные PNG из установленной зависимости; в `proposed/` — неизменённые результаты imagegen, увеличенные растровые эскизы. Это кандидаты для обсуждения: они ещё не являются утверждёнными финальными 16×16 текстурами. Изображения не уменьшались программно и не выдаются за точную пиксельную копию ванильной маски.

Временный resource pack применяется только к отдельному QA-профилю. Production PNG и item models не заменены. Снимки `before-*` и `preview-*` показывают фактический рендер Minecraft, а не нарисованный макет GUI/руки. `runtime-receipt.json` подтверждает только захват кадров; художественную приёмку выполняет владелец.

База: кирка — ванильная netherite_pickaxe; формы мультиинструмента — узнаваемые части netherite_pickaxe/axe/hoe/shovel с общей деревянной рукоятью. Цветовая обработка ориентирована на графит и медь. Требуют оценки: компактность головки, читаемость вторичных частей и единообразие всех трёх форм. До принятия этих вариантов дальнейшее внедрение остановлено только для визуала #298.
