# Пекельный посад — patch 2.3, визуальные исправления и отдельный QA Зелейной избы

Рабочая ветка: `feat/2.3-pekelny-posad`. База подтянута из `hell` fast-forward; `main` не меняется.

## Реально изменено в runtime

- `PosadShell`: оба верхних прохода привратных башен соединяются по настилу Y8, свободный коридор Y9–10; дополнительные светильники не ставятся в трёхблочный патрульный проход. Освещены башенные этажи и свободные участки улиц.
- `PosadVisualRepairs`: подкладка под ступенчатые швы двух крыш (Вечевая палата и Общинный дом), фонари в двух интерьерах и исправление внешних петель двойной багровой двери Общинного дома.
- `PosadGeometry.SCHEMA_VERSION=4`: исправления через `PosadPiece` применяются только в НОВОМ поселении схемы 4. Сохранённые версии 0–3 не модернизируются; лут не обновляется.
- `NetherBossItems` и `tools/netherboss-assets/generate.py`: пользовательские названия яиц и исходник русской/английской локализации (JSON языков нужно регенерировать отдельно).
- Команда `/slavicmyths dev posad templates <anchorX> <deckY> <anchorZ>` теперь показывает **пятую** NBT-команду для Зелейной избы 2.2.7 отдельно от четырёх интегрированных зданий. Саму избу в единый runtime `PosadPiece` пока НЕ подключали.

## Проверки

- `gatewayBridgeAndLighting`: входы башен и надвратный проход, улицы и башенные этажи.
- `newCityRoofUnderlapsStaySealedWithoutRetrofits`: поддержка ступеней крыши и отсутствие изменений в старой схеме; проверка интерьерного света и петель обеих створок двери при четырёх поворотах.
- Обычные `openGate`, `patrolAndSlots`, `physicalChunkPlacement` и chest/loot tests остаются обязательными.
- Прогоны Java 21 / NeoForge публикуются в Actions новой ветки. Без успешного GameTest и скриншотов игрока визуальный патч НЕ считается принятым.

## Ручная проверка в новом одноразовом мире

Для `posad create`: название мира должно начинаться с `posad-qa-`, права OP4, Незер, предварительно загруженные все нужные чанки; нельзя применять к пользовательскому миру. Пример значений **не гарантирует подходящий рельеф**:

```mcfunction
/slavicmyths dev posad layout 0 0 0
/slavicmyths dev posad create 0 0 64 0 confirm_disposable_world
/slavicmyths dev posad status
```

Для отдельного просмотра новой Зелейной избы (на свободной площадке в одноразовом тестовом мире, vanilla /place не делает preflight и может перезаписать блоки):

```mcfunction
/place template slavicmyths:posad/zeleynaya_2_2_7 ~ ~ ~
```

Расположение по плану города для ориентации 0°, anchor (0,64,0): `/place template slavicmyths:posad/zeleynaya_2_2_7 76 64 44`. Это только просмотр одобренного NBT, **не** достройка существующего города.

## Известные ограничения / следующие работы

1. Два отдельно опубликованных R1 NBT-файла Вечевой палаты и Общинного дома ещё **не экспортированы** заново со schema-4 исправлениями. Для проверки исправленной крыши/дверей используйте новую общую `PosadPiece`, а не старую `/place template`.
2. Дружинный и Кузнечный дворы требуют отдельного визуального прохода по дверям, мебели и освещению; их утверждённые R1-модели не менялись.
3. Зелейная изба #355 пока не входит в естественную/целую ручную генерацию посада; следующий этап — интеграция в схему новой постройки и проверка 5 лут-сундуков.
4. Естественная генерация всего города в Незере остаётся OFF до проверок производительности, безопасной целостности, сохранений, мультиплеера и anti-dupe.
