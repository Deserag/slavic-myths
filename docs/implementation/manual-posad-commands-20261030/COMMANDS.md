# Ручное создание — исправленная сборка

Работает в обычном мире и Незере, с включёнными читами / OP2. Имя мира не проверяется. Координаты можно опустить для отдельных зданий или указать `~ ~ ~`.

## Постройки 2.1
```
/slavicmyths dev nether create nether_watchpost ~ ~ ~
/slavicmyths dev nether create broken_nether_bridge ~ ~ ~
/slavicmyths dev nether create wayfarer_camp ~ ~ ~
/slavicmyths dev nether create forgotten_shrine ~ ~ ~
/slavicmyths dev nether create ancestor_shrine ~ ~ ~
/slavicmyths dev nether create trizna_pyre ~ ~ ~
```
Это явное административное размещение исходной геометрии, не попытка естественной генерации. В обычном survival адские постройки по-прежнему генерируются только по прежним правилам. У моста сундука нет; у остальных по одному исходному lazy-loot сундуку. Для диагностики выбран один воспроизводимый вариант каждого здания; это не рандомный новый баланс.

## Отдельные здания Посада
```
/slavicmyths dev posad building veche_hall_2_2_2 ~ ~ ~
/slavicmyths dev posad building communal_house_2_2_3 ~ ~ ~
/slavicmyths dev posad building druzhinny_dvor_2_2_4 ~ ~ ~
/slavicmyths dev posad building kuznechny_dvor_2_2_5 ~ ~ ~
/slavicmyths dev posad building zeleynaya_2_2_7 ~ ~ ~
/slavicmyths dev posad building granary_2_2_8 ~ ~ ~
```
Размещать по одному на разных площадках. Команда проверяет весь объём здания, затем освобождает его от природного грунта и ставит исходную модель/NBT. Чужие сундуки, зарегистрированные постройки, порталы, bedrock и распознаваемые искусственные блоки отклоняются до записи. Универсального распознавания дома из обычного камня и сторонних claims не заявляется. Повтор поверх уже поставленной постройки отклоняется; это не достройка города.

## Посад целиком — текущая реализация
```
/slavicmyths dev posad create 0 ~ ~ ~
/slavicmyths dev posad status
/slavicmyths dev posad cancel
```
Первое число — поворот 0/1/2/3; координаты — угол платформы 113×113, Y — уровень настила. Мир может называться как угодно. Достаточно OP2, без дополнительной фразы подтверждения. Чанки запрашиваются постепенно штатными tickets; статус сообщает фазу. Нужны свободные17блоков над платформой, опоры и выход к берегу: при физически неподходящей площадке будет конкретный отказ до строительства. Это текущая реализация оболочки и подключённых зданий, не заявление о завершении всей2.2. Отдельные здания можно проверять независимо от большой площадки города.

## Ручной smoke/regression
- В новом мире включить читы и выполнить каждую команду на отдельной свободной площадке. В обычном мире и Незере ожидается физическое здание, сообщение «Построено», читаемые двери и комнаты. Повтор в той же точке отклоняется.
- Поставить свой сундук на площадку, положить предмет и повторить: отказ, предмет остаётся. Без OP/читов команда недоступна.
- Для целого города подобрать ровную площадку и выполнить create; status должен дойти до завершения. Cancel до записи не меняет блоки. После начала записи отмена может оставить часть города и резерв: автоматического повторного лута нет.
- Сохраниться, выйти и войти: здания и открытые сундуки не должны сбрасываться. Повторить с двумя игроками. Проверить новый и сохранённый мир; исходные пользовательские миры агент не открывал.
- Без OP естественная доступность проверяется обычным исследованием новых чанков Незера; успешная ручная команда не засчитывает этот survival gate.

НЕ ПРОВЕРЕНО: реальный пользовательский перезаход/старые сохранения, сетевой MP, визуальная приёмка, все claims/непомеченные каменные дома. Риски: административное размещение изменяет природные блоки внутри проверенного объёма; отменённый город может остаться частичным. Откат JAR не откатывает записанные блоки.
