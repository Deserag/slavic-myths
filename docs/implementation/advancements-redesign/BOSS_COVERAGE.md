# Полный состав крупных встреч и элит

Все entity IDs ниже — `slavicmyths:`; registry-ссылки проверяются по перечисленным `*Content`, `ModEntities` и `UndergroundMobs` в main. Это состав из исходного кода и реестра, **не новый runtime census**. Наличие bossbar не делает NPC обязательной целью убийства. Ниже учтены все классы с `ServerBossEvent`, а также сюжетные и элитные противники без полосы.

Общие правила **предлагаемого achievement adapter**: не выдавать за creative/spectator/debug/admin kill/отменённую смерть/PvP, не брать proximity за заслугу; использовать существующий accepted callback, а где персональных данных нет — добавить ограниченную encounter-local фиксацию участия только для достижений. Это не изменение права на старый loot. Исторические award/criteria не отзывать. `C` = один challenge toast + chat впервые, `G` = один goal toast без chat, `—` = без отдельного toast. Повторная победа не повторяет advancement toast. `native-only` означает нынешнюю персональную политику сервиса, а не обещание нового общего кооп.

MVP не является универсальным условием: там, где native сервис признаёт нескольких участников, каждый получает свою медаль. У Картауса/Калина native owner-only оставляется; расширение их правил кооп выходит за scope. Для рядовых элит нужен player-causal actual death (включая projectile owner), не раздача nearby. Итоговая политика новых awards и её отрицательные случаи должны быть подтверждены native тестами до merge реализации.
