# P39 — накопительный журнал ветки: кистени

Ветка `feat/weapons87-p39-flail-motion-5issues`. Журнал сохраняется в истории коммитов ветки, но перед слиянием исключается из итогового `main`.

## Пакет P39 — #115 / #116 / #164 / #167 / #181

- **#164 — действительная анимация удара:** пик импульса цепи перенесён со старта движения на середину замаха (`sin²(π × swing)`), в начале и после удара эффект плавно нулевой.
- **#167 — семь звеньев:** амплитуда разлёта повышается от звена возле рукояти к звену возле груза. Оригинальные 7 звеньев, расстояние 2.4 единицы и фактическая геометрия замкнутых звеньев сохранены.
- **#181 — кистень атамана:** для тяжёлой головки амплитуда импульса снижена до 80% обычного, без изменения боевого урона, MaceItem и существующих моделей.
- **#115/#116 — реальный рендер:** вместо жёсткого сравнения объектов Java `binding.stack==stack` используется совпадение ItemStack с компонентами; на фактической руке владельца проверяется тот же предмет. При несоответствии безопасный показ неподвижной модели, а не чужая анимация.
- **Проверки:** обновлены численные фазы offline-примера `Weapons87FlailMotion.java`, регрессионные условия `tools/verify_weapons87_p39.py`, Java21 clean build и JAR-gate.
