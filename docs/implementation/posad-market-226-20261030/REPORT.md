# Реализация 2.2.6 — Меновые ряды (30.10.2026)

Базовая ветка для этой итерации: `codex/hell-posad-districts-227-228-20261030` (содержит #355/#356 и PR #368). `hell` и `main` не изменялись.

## Выполнено
- Полностью подключена исходная цифровая модель `2.2_6_MARKET_VOXELS_DRAFT_A.json` в составе единого 113×113 Пекельного посада. Строго X75..101, Z75..99; четыре лавки, две кладовые, 2203 блока, 675 фундаментных блоков, восемь сундуков; центральный проход 5 блоков.
- Новые города сохраняют schema 5, старые schema 1–4 не перестраиваются автоматически.
- `PosadMarketBuildings` читает полный исходный набор координат/BlockState из компактного JSON без произвольного изменения модели. `PosadPiece` использует штатные повороты/чанковые ограничения/резервирование.
- Восемь утверждённых исходных таблиц лута перенесены без изменений в production `loot_table/chests/nether_market_*.json`. Только купеческий тайник имеет дополнительный независимый 20% шанс 1–2 `ancient_coin`; остальные 7 сундуков древних монет не дают.
- Создан действительный `structure/posad/menovye_ryady_2_2_6.nbt` с 2203 блоками, полной палитрой и 8 LootTable-NBT записями. Отдельная административная команда: `/slavicmyths dev generate menovye_ryady`. Для целого города: `/slavicmyths dev generate nether_posad`.
- Обновлён `dev posad building`, `dev posad templates`, справочник команд.

## Тестируемые ограничения
Повторяющиеся/внеплощадочные блоки, отсутствие маркеров сундуков, переставленный источник, и изменение исходного расчёта лута приводят к отказу проверки. Воспроизводимый тест: `python tools/verify_posad_market.py`; он проверяет равенство всех 2203 блоков исходной модели/compact/runtime NBT, восемь записей LootTable, 675 блоков пола, независимый монетный шанс и неперекрытую центральную ось.

**Нельзя считать пройденными:** Java 21 Gradle build, native NeoForge GameTest, performance/native Nether starts, четыре поворота в клиенте, MP и релог. Не запускались в среде удалённых GitHub-записей. PR #368 оставлен draft; естественная генерация StructureSet остаётся выключенной до QA. Исходные художественные PNG ещё необходимо подтвердить с владельцем.
