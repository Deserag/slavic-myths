## Существенные ограничения

- Первое создание больших мест занимает8–63секунды; скорость не принята. Все приведённые обычные прогоны на одномseed2432026.
- Высота потолков и туман ещё не исправлены. Естественные частоты всех существ, весь сюжет, achievements/довериеЯги и полное прохождение обоих святилищ не подтверждены.
- Захват клиентского окна не сработал; рубкаFallingTree,HUD/карта и визуальный результат моделей в клиенте не проверены. Точечные изменения настроек не равны runtimePASS.
- Полноценный multiplayer, старые сохранения и гонки строительства остаютсяNOT_RUN. Факт устранения отдельных ошибок чанков не доказывает отсутствие всех ошибок генерации.
- ProductionJARне содержит тестовыеfixtures. Поднять вспомогательные проверки можно init-скриптами tools/generation-runtime.gradle; фикстуры лежат tools/generation-runtime/. Клиент автоматически не запускать вне разрешённой исполнительной задачи. МирыQAотдельны от миров владельца.
