## Реально изменено

- SiteChunks: нативные region tickets, чтение готовности через getChunkNow только на серверном потоке; до4 незавершённых запросов на измерение; нет worker-world access, blocking join или дальнего обхода мира. У каждого задания свой ticket token: закрытие одного задания не снимает ticket другого. Tickets освобождаются при окончании/остановке.
- Исправлен bootstrap Навьи. Constructor-mixin создавал несвязанный holder; проверка lookup убирала падение, но теряла биом и потому отвергнута. Текущий вариант добавляет существующий holder к уже загруженному Nether preset в ServerAboutToStartEvent; настоящий обычный сервер подтверждает navya_in_nether=true.
- Яга: новая локальная лесная площадка прежде удалённого сохранённого anchor; затем загруженная местность. Природные песчаник/снег/породы допустимы для террасы; контейнеры, известные поставленные брёвна, строительные материалы защищены. Координаты выдаются после реальных блоков и Яги/Кузи.
- Баюн: поиск грунта под кронами, подготовка просвета над площадкой. В проверенном мире реально появились дом и кот.
- Чудь: исправлены ошибочные отказы на воде, льду, заражённом камне, собственных рудах, незераке и скалковых жилах. Подземная область может находиться под наземной структурой; защита действует по затрагиваемым блокам. Природный камень/грунт можно перекрывать; bedrock, контейнеры, известные брёвна и искусственные блоки остаются защищены. Шесть локальных вариантов вокруг игрока вместо ухода на тысячи блоков. Геометрия считается вне серверного потока, мир читается/записывается порциями на сервере.
- Для gorodishche, serpent_hill, sanctuary_unfading_fire и abode_pure_spring точные /locate structure slavicmyths:<id> больше не вызывают дальний блокирующий vanilla locate. Запись реального места в пределах1024блоков возвращается сразу; иначе создаётся настоящее место на ограниченной локальной площадке256–768блоков. Используются прежние фактические pieces/templates. Это явное создание при первом запросе, а не мгновенный поиск существовавшей постройки. Подготовка и проверка каждого чанка чередуются; неудачная площадка отбраковывается до загрузки всей территории. Проверяется фактическая вертикальная область записи, без лишних16блоков под горой/городищем. Перед резервированием повторно проверяется занятость другим заданием.
- /slavicmyths generation status и cancel подключены к большим местам и Чуди. Отмена после начала записи сохраняет резерв незавершённой области; она не выдаётся за построенное место.
- В обычном сундуке огненного святилища гарантирован Священный уголь1–2, добавлено железо2–4. Убраны устаревшие обещания будущих хранителей/фрагментов; подсказка указывает взять уголь из сундуков и нажать ПКМ по центральной чаше. Генераторы соответствующих ресурсов обновлены.
- Деревья Навьи не должны соприкасаться чужими брёвнами ни в одном из26 направлений: FallingTree соединяет также диагонали. Это исправляет один источник объединения нескольких деревьев сверх лимита100, но настоящая рубка ещё NOT_RUN.
