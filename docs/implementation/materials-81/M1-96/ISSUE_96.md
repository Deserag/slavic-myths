# Подзадача #81 • пакет M1 — основные металлы
**Цель:** исправить четыре наиболее слабые иконки на первом игровом скриншоте; не менять посторонние материалы.
## Конкретные ID и утверждённый художественный принцип
| ID | Что сейчас не так | Требуемый результат |
|---|---|---|
| `silver_nugget` | бледное почти бесформенное крошечное пятно | маленький, но читаемый неровный **серебряный самородок**, серебристо-белый, прохладные серые тени, чёткий контур |
| `silver_ingot` | тонкая плоская полоска, почти не отличается от железа | **благородное серебро**: более светлый бело-серебряный оттенок, особая аккуратная/скошенная геометрия слитка, **тонкие изящные голубовато-белые прожилки** (не толстые железные «трещины»); отличим от очищенного железа по силуэту и контрасту |
| `perunite` | тёмная невыразительная прямоугольная заготовка | редкий сине-стальной металл, глубокий индиго/синий, бирюзовые/ярко-голубые жилы; отчётливые грани и масса, не просто перекрашенное серебро |
| `iron_blank` | узкая плоская тёмная полоска | **незавершённая кованая заготовка**: вытянутый, но плотный серо-графитовый металл с грубыми краями; визуально не равен готовому слитку |
**Важно:** синие прожилки — рисунок PNG, **никаких новых эффектов, свечения/шейдеров, enchantment glint или механик**. Серебро и очищенное железо должны быть заметно разными при размере реального слота.
## Реализация
1. Снять baseline SHA и полные пути для этих 4 ID: `src/main/resources/assets/slavicmyths/textures/item/<id>.png`, `src/main/resources/assets/slavicmyths/models/item/<id>.json` или фактические модели.
2. Изменить только 4 согласованных иконки; item model JSON только если реально нужен для отображения, сохранив остальные параметры.
3. В общем A/B ряду показать **все 4 вместе** плюс сопоставление серебра с `purified_iron_ingot` и `hardened_iron` (не меняя соседей).
4. Записать фактические pixels/палитры, пути, изменения и проверки.
