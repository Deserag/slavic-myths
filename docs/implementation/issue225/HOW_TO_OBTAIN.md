# Где получить проверяемые предметы

Это справка по фактическим рецептам/коду, а не заявление о прохождении всей кампании.

| Предмет | Получение |
|---|---|
| Кистени7материалов | Верстак оружейника: рукоять кистеня + цепь + шар нужного материала. Железный сохраняет registryID `flail`, обычный старый рецепт отключён. |
| Атаманский кистень | Верстак оружейника: алмазный кистень + знак атамана + цепь + обмотка оружия (`rare_ataman_flail.json`). |
| Охотничий рог | Обычный верстак, рецепт `ohotnichiy_rog.json`:3кости,кожа,железный самородок,палка. Shift+ПКМ меняет цель, ПКМ вызывает охоту при выполнении условий. Для Огненного змея требуется ночь и открытое небо; активная охота повторно не создаётся. |
| Сабля Воеводы | Обычный верстак, рецепт `trophy_kalin_sabre.json`:королевское железо,алмазный меч,золотой слиток. Точную раскладку смотреть в JEI. ПКМ: сектор5.5блоков, до6врагов,7секунд перезарядки. |
| Плеть Полоза | Добыча Великого Полоза: `GreatPoloz.die`, при включённом doMobLoot. Полный бой с боссом в этом прогоне не проходился. |
| Древние фигуры | Огненное святилище. В тестовом NORMAL мире seed2252026 святилище найдено около X=-2240,Z=1952; курган около X=-720,Z=-640. Для другого seed координаты другие. |

37рецептов оружейника проверены через настоящее серверное ArmorerMenu.quickMoveStack:74изготовления, расход ровно1ингредиента на слот, запрет третьего изготовления при пустых входах. Дневной отказ рога, ночной вызов Огненного змея и запрет дубликата проверены через настоящий Item.use/нативные записи охоты. Это не проверка всех биомов/всех боссов/многопользовательской кампании.
