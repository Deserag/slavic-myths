Крафтовые I: rune_strength/speed/resilience/heat; II: rune_crushing/wind/blood/fortitude. Ancient_rune_fragment остаётся существующим ингредиентом. Все выбранные целые руны имеют существующий рецепт, проверенный тестом.

Poloz helmet/chestplate/leggings/boots — прежняя функциональная броня на Netherite material с существующими durability×37 и reduction/knockback параметрами; исходный рецепт/награды Полоза не менялись. Это разрешённый альтернативный source, а не начисление победы над Полозом.

## Как проверить в Minecraft — владельцу

Использовать указанную2.0.4-HELL и сверить SHA выше. Скопировать старый мир в отдельный тестовый и подготовить новый Survival-мир; основной мир не перезаписывать. Первичное прохождение без OP, действующими рецептами/поиском книги. Записать seed, coords, вариант/tier, сколько контейнеров найдено, суммарный лут и затраченное время.
1. В новом мире пройти по одному кургануI/II/III и лагерюsmall/medium/large. Найти основной тайник и обычные/скрытые контейнеры. Ожидается прежний L1: не более одной главной раздачи; никакихIII/IV и незерита в лагерях. ВIII возможен один scrap/одна enchanted diamond armor, не гарантированы. Проверить награды князя/Соловья отдельно.
2. Найти оба святилища естественно/существующим заработанным поиском. До ритуала попытаться открыть cache: он должен оставаться закрытым. Взять ember/powder из внешних коробок, выполнить прежний ритуал и победить/пройти guardian как требует текущая механика. После открытия собрать все5fire/4spring контейнера; cache должен дать гарантированные ресурсы и целую руну. Проверить эффекты flame_vial/spring_tear привычным способом.
3. Найти новую крепость, подготовив прежнюю защиту от мора. Собрать6сундуков и5бочек; суммарно1–2Poloz armor, минимум2крафтовыхII,3–6perunite в main; прочие perunite могут быть вобычных сундуках. Бочки — еда/очистка. Проверить, что сундук не даёт сюжетный seal/победу над боссом. Пройти Горыныча: личная награда отдельно, повторный immediate claim не дублируется. 3%/8% нельзя подтвердить одной крепостью.
4. Если найден Likho staff — main/offhand пассивное лечение и ПКМ по допустимой цели/стене, cooldown/износ; если зеркало — надеть в существующий necklace slot, проверить прежнюю активацию/снятие, отсутствие победы над Морозко. RuneIII/IV поставить только в поддерживаемую вещь через существующую мастерскую, проверить эффект и неподходящий слот как отрицательный случай.
5. В болоте найти дом, fisher, landing/remnants, boardwalk, tower, ruins, ritual иcluster. Записать все контейнеры: бытовые не должны выдавать магический jackpot; cluster имеет5контейнеров, только один main. Сеть/удобрение/вода/очистка должны работать обычным применением. Проверить3 варианта по мере естественного нахождения, не считать их отдельными независимыми шансами главной награды.
6. Пройти среднюю и великую заброшенную Чудь и обычный город Чуди: шахты преимущественно инженерные, богатая treasury сохранена; отсутствие конкретной optional точки на плохом terrain записать отдельно. Проверить город/деревню, Ягу, баню, сарай, омут и путевой камень: обычные роли/торговля/станки без случайной сильной реликвии. Найти Баюн/Волка, проверить прежний путь союзника без требования сундука.
7. Получить/использовать карту глубин, пройти12врагов, два guard coin и2 сундука. Стартер прежний, во втором может появиться рунаI/книга/серебро/перунит. Заново войти в ту же instance — награды не восстановились.
8. Сохранить часть новых находок в новом сундуке; один основной тайник опустошить. Выйти из мира и зайти, уйти/вернуться с выгрузкой чанков. Сохранённые вещи остаются, пустой тайник не пополняется; в копии старого мира ранее заполненный и старый неоткрытый сундуки сохраняют прежнее содержимое/таблицу. Для MP: два игрока открывают один main одновременно, общий1–2Poloz максимум на крепость, а личная награда Горыныча остаётся по его прежним правилам.
OP-диагностика отдельно от Survival: `/locate structure slavicmyths:serpent_hill`, `sanctuary_unfading_fire`, `abode_pure_spring`, `kurgan_great`, `bandit_camp_large` (подставить полный ID после structure). `/data get block X Y Z LootTable` до открытия сверяет назначенный ID; сервер может отказать для не-loot container. `/loot`/ручной summon не доказывают естественный путь и не заменяют прохождение. Для валидной whole-site статистики не выдавать main отдельно в каждом сундуке.
