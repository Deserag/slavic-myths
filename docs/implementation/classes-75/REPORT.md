## Наблюдение и поставка

Статический аудит исходного ClassScreen: игроку строился вертикальный список кнопок; ClassTreeLayout не вызывался. Это описание кода, не воспроизведение в запущенной игре.

Подключены фактические узлы ClassTreeLayout и связи из prerequisites для всех 40 навыков трёх классов. Выбор узла открывает существующую карточку изучения/улучшения/назначения; сетевые действия и серверная авторитетность сохранены. Ранг виден на значке, состояние и первая причина блокировки — в подсказке. В карточке перечислены уровень, очко, предшественник с рангом и нужное направление. Максимальный ранг не изучается повторно. Узлы заблокированных навыков можно выбирать для чтения.

Дерево прокручивается вертикально колесом, горизонтально Shift+колесо либо стрелками; минимальный масштаб 60% сохраняет размер значков. Офлайн проверяется достижимость каждого узла при шести сочетаниях разрешения/GUI scale. Подсказка второго пассивного слота больше не затирает причину его блокировки. Генератор RU/EN дополнен текущими строками.

[source-layout.png](source-layout.png) — иллюстрация координат из реально исполненного Java ClassTreeLayout с фактическими PNG ресурсов, а НЕ игровой скриншот. Она показывает полный логический граф, без viewport, интерактивных состояний и игровых шрифтов. Исходные координаты: [layout.json](layout.json).
