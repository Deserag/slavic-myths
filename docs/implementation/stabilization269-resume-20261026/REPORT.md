## Как проверить в Minecraft

1. Сначала согласовать установку указанного SHA в отдельный тестовый профиль. На установленной старой копии новые исправления проверять нельзя. Новый мир или копия; исходное личное сохранение не перезаписывать. Громкость30%.
2. Без читов пройти предусмотренное кормление Сивки: яблоко → пшеница → морковь → черника → черничные блины → бутылочка мёда → золотое яблоко, не менее24 активных тиков между этапами. Сесть без седла; Space — прыжок через блок, W+Sprint+Space — быстрый взлёт, A/D — боковой сдвиг, камера — направление, отпускание W — торможение, X — снижение/посадка. Негативные случаи: низкий потолок, узкий проход, чужой игрок.
3. Выйти верхом в полёте, войти и полностью перезапустить клиент. Ожидается прежний конь/владелец и работающее управление, без двойника. Проверить открытие новой местности на полной скорости и посадку на неровном рельефе.
4. Найти сооружения обычным исследованием; попробовать тайники до ритуала, выполнить ритуал, забрать награды, выйти и перезапустить. Ожидаются ограничения до ритуала, открытие после и отсутствие повторного лута. Повторить двумя игроками, отдельно одновременно. Автоматический сохранённый контейнер не заменяет этот полный путь.
5. OP-диагностика отдельно: `/locate structure slavicmyths:kurgan_small`, `/locate structure slavicmyths:bandit_camp_large`, `/locate structure slavicmyths:sanctuary_unfading_fire`, `/locate structure slavicmyths:abode_pure_spring`, `/locate structure slavicmyths:serpent_hill`. Поиск не должен начинать строительство. Отсутствие загруженного старта допускает честный ответ «не найдено»; центр bbox не гарантирует безопасный Y телепортации.
