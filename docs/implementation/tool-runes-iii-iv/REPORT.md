## Серверные действия и защита

- **Подтверждение центра.** LeftClick intent хранит исходный stack/dimension/pos и грань реального серверного BlockHitResult (ray по текущим координатам/взгляду, совпадает с packet face). Неизвестная грань → safe одиночное действие. Mixin ServerPlayerGameMode.destroyBlock фиксирует успех именно `removeBlock`: native destroyBlock может вернуть true при false removal. Без принятого и реально удалённого центра никакой очереди. Центр повторно не попадает в targets.
- **Кирка/лопата.** 3×3 плоскость по оси фактической грани; IV добавляет слой ровно внутрь (9/18 всего). Only correct native mineable tag/tool/harvest tier, hardness≥0, no fluid/BE. Каждая extra идёт через `gameMode.destroyBlock`: настоящий BreakEvent, normal tool mineBlock, playerDestroy/loot/XP/stat/enchantment callbacks; нет setBlock(AIR), собственного повторного loot roll или бесплатного массового wear. Fortune/Silk Touch/Unbreaking/Mending не имитируются вручную.
- **Мотыга.** ItemStack.useOn redirect оборачивает настоящий CommonHooks.onPlaceItemIntoWorld только после принятого ITEM_AFTER_BLOCK event. Проверяет итог после snapshot commit/rollback, source world/mode/slot/stack; вспашка запускает queue лишь при фактическом ожидаемом native tool-modified state. Дополнительные till вызывают полный `gameMode.useItemOn` (RightClick/Use/Place hooks), со свободным верхом. Сбор зрелых культур начинается только после обычного Hoe PASS, вне capture/restoring snapshots; центральная культура и extras разрушаются native pipeline. Поддержаны зрелые одноблочные vanilla CropBlock, проверенный FarmingCrop(age6), отдельно NetherWart(age3). HopsCrop/double crops, berry bushes и неопознанные культуры пропускаются. Нулевой hardness поддержанных культур гарантирует, что native Hoe.mineBlock не начисляет wear; отдельно одно hurtAndBreak(1) usage по каждой действительно удалённой культуре, с native Unbreaking. No replant, no seed/loot bonuses, no farmland destruction.
- **Лесоруб.** Строго одинаковая namespace/family `*_log`/`*_wood`; stripped исключён. Детектор проверяет прямой вертикальный 1×1 или 2×2 ствол на природном грунте, высоту4–32, совпадающую непостоянную крону, отсутствие подозрительных соседних logs/построечных blocks/BE. Соседние отдельные основания в XZ R4/R7 и ΔY≤2, близкие первыми; для2×2 берётся расстояние ближайших стволов, не произвольного угла. Листья не targets. Full candidate trees, не помещающиеся в остаток48/96, пропускаются целиком; root unknown/oversize → первичный vanilla block only. Максимум16 проверенных деревьев/8192 unique read positions.
- **Происхождение древесины.** Новый реально используемый dimension SavedData `slavicmyths_tool_log_origins` фиксирует Place/MultiPlace и native piston-moved logs; tombstones не удаляются/не вытесняются. При невозможности безопасного piston resolver на полностью загруженном локальном окружении chunks помечаются unsafe, без загрузки/сканирования; overflow65536 positions или4096 unsafe chunks отключает autofell в измерении. Unknown/corrupt/future schema fails closed, future root сохраняется opaque. Это не замена RuneBase/ItemState.
- **Ограниченный worker.** Не более4 дополнительных попыток действий/player tick; tree snapshot sampler ≤256 новых чтений/player tick, ≤8192 за job. Нет широкого синхронного BFS, глобального world/player traversal или chunk acquisition. Использован прежний RpgEvents PlayerTick hook: нет отдельного tick subscriber. Context bound to same live player/world/game mode/selected slot/actual stack and components (нормальная смена damage допускается), distance≤8 blocks from origin, TTL160 ticks. Во время queue инструмент ломается/меняется, игрок умирает/клонируется/выходит/меняет мир/mode/slot → прекращение; server stop clears maps. Re-entry guard не даёт native extras породить новое массовое действие.

## Честные ограничения

**Нет 100% распознавания старых player-made logs:** до установки provenance event tracking старый вручную собранный объект, точно имитирующий естественный ствол/листву, может пройти геометрический детектор. Это показано отдельным positive fixture как предел доказательства, не скрыто за assertion о полной защите. Требуется отдельная копия мира для игровой приёмки. Известные поставленные/перемещённые logs и очевидные крыши/стены/контейнеры/горизонтальные соединения/persistent leaves отвергаются. Пространственно слишком близкие/соприкасающиеся стволы, ветвистые acacia/jungle/mangrove/специальные деревья, oversized candidates, неопознанные families/crowns часто пропускаются консервативно. Вид распознаётся независимо от того, пройдёт ли сложная геометрия.

Массовый режим поддержан **в основной руке, Survival/Creative**. Adventure/spectator/offhand оставлены обычному native действию; это безопасное ограничение, не bypass CanBreak/protection. Дополнительные blocks используют per-block spawn/border/claims hooks, но фактическая совместимость с произвольным сторонним plugin требует игрового теста. Если мод запрещает removal поздно в onDestroyedByPlayer, vanilla pipeline может начислить durability до отказа; это штатный порядок, не обещание собственного rollback сторонних callbacks. Полнота crop/modded tool extensions ограничена проверенными типами. Native events/permissions/durability/loot/GUI не выполнены в мире.
