# Интеграция, проверки, критерии приёмки

## Границы существующего проекта

Сначала **локальное рабочее дерево** и `git status`, затем исходный код. Предыдущие патчи рун и параллельная работа с оружием/бронёй могут быть не закоммичены и существовать только в локальной ветке `runs`. Нельзя переписать эти изменения или автоматически брать старый `main`. Если рабочее дерево содержит пересекающиеся изменения, требующие действий с чужими файлами, отчёт BLOCKED с минимальной разблокирующей просьбой.

Потенциальные места интеграции — проверять по фактическому коду, названия ниже ориентировочные, не являются предписанием к переписыванию:
`org.slavicmyths.rpg.Runes`, `RuneRework`, `RuneBalance`, `RuneDefinition`, `RuneFoundation`, `RuneBase`, `RuneCraftRecipe`, `RuneRuntime`/server events, `org.slavicmyths.industry.MiningRunes`, `ModItems` registration, `JeiRunes`, `ItemState`, item tags, resource locations, ru_ru/en_us. Не вводить дубль NBT/DataComponents и вторую параллельную систему установленных рун. Prefer new isolated `ToolRuneRules`, `ToolRuneRuntime`, `ToolRuneContent` where this lowers cross-chat collisions.

Примечание: в базовом снимке `rune_crafting` допускает максимум 3 входных ингредиента; `Runes.compatible` имеет большой switch-like chain; существующие I/II можно дублировать согласно modern rules, **8 новых не должны считаться stackable copies только ради удобства регистрации**. Для них отдельный узкий обработчик.

## Тесты/проверки, которые ОБЯЗАТЕЛЬНЫ

1. Регистрация 8 уникальных IDs и доступность предметов в ожидаемом каталоге / JEI / creative; рецепты возвращают именно их.
2. Установка через текущую наковальню на правильный класс инструмента; невозможность установки на оружие/броню; отказ при III+IV одной группы (оба порядка), одинаковых повторных рунах и неготовых сокетах.
3. Рецепты III с корректным `RUNE_BASE tier3/perunite`; IV с корректным компонентом; сохранение старых рецептов/установленных рун/ID и resource paths; никакого reset данных.
4. Не Shift = одиночное действие; с Shift: pickaxe/shovel 9/18; ориентация всех шести направлений; центровка; отказ при неизвестной hit side; чужие типы блоков не разрушаются.
5. Hoe: till 9/25 только допустимые block states; crop-harvest 9/25 только зрелые; отсутствие автобесконечной пересадки и нулевой стоимости обработанной культуры.
6. Axe: radius R4/R7 между основаниями ближайших деревьев, порода совпадает; разные деревья рубятся целиком в рамках 48/96; листья, постройки/доски/дома/сундуки, stripped/placed logs не меняются; ограничения на unloaded chunks и huge trees.
7. Серверная защита: отменённые события, adventure/creative/spectator, no-permission, смена предмета, сломанный инструмент, независимые операции двух игроков, серверная queue и cleanup, no recursion.
8. Дроп и XP без дублей; Silk Touch/Fortune, Unbreaking/Mending без обходов; по-блочная стоимость прочности, не начислять дроп от инструмента с недостаточным уровнем добычи.
9. Assets: 8 × PNG с корректной альфой и узнаваемым глифом; 8 × item model JSON; RU/EN item names и описания; JEI/crafting resource validation; JAR содержит assets+recipes+регистрацию.
10. `./gradlew clean build` (или официальная Gradle-команда проекта) PASS. Если старые unrelated tests падают — приложить baseline/evidence, не «чинить» другие подсистемы из этого патча.

## Что не допускается

- `level.setBlock(air)` в обход охраняемой процедуры и loot tables;
- чисто клиентские эффекты вместо рабочей серверной механики;
- массовое разрушение на один tick без жёсткого лимита/защиты;
- рубка любых стволов вокруг независимо от породы/природного происхождения;
- ложное утверждение, что детектор природного дерева гарантированно отличает player-placed logs без дополнительного provenance;
- крафтовая руна, которая делает уникальные боссовые руны обычными рецептами;
- изменение версии мода, версий игровых модов, мира или PolyMC ради успешного патча;
- изменение иконок старых рун, weapon model files, armor assets;
- запуск Minecraft/PolyMC/сервер/GameTest без разрешения;
- git commit, push, merge без разрешения.

### Игровая приёмка пользователем ПОЗЖЕ (не выполняется Codex без разрешения)

1. Выдать кирку III и IV, поставить руну через наковальню, выкопать в каменной стене 9/18 блоков при Shift, 1 без Shift.
2. Аналогично лопата III/IV; проверить сбоку и сверху.
3. Мотыга III/IV: 3×3/5×5, незрелые посевы не трогаются, зрелые собираются с корректным лутом.
4. Два дуба на расстоянии 4/7 и рядом берёза/постройка из дуба: срабатывает только нужное на соответствующем расстоянии, дом цел.
5. Проверить расход прочности, оба зачарования (Fortune и Silk Touch), Unbreaking, ограничения по участкам сервера.
