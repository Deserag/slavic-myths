# Крафт и прогрессия

Это **8 новых рун**, а не замена предыдущих реализованных III–IV. Существующие `rune_depths_iii`, `rune_mastery_iv` и уникальные `rune_earth_lord_iv`, `rune_veles_oath_iv` (если есть в локальном патче) **не удалять, не менять ID, не подменять рецептом нового предмета**. Их баланс/совместимость с новыми инструментальными эффектами проверить отдельно.

## Регистрация и архитектура

- Логические IDs: `miner_iii`, `excavator_iii`, `farmer_iii`, `lumberjack_iii`, `miner_iv`, `excavator_iv`, `farmer_iv`, `lumberjack_iv`.
- Предметы: `rune_miner_iii`, `rune_excavator_iii`, `rune_farmer_iii`, `rune_lumberjack_iii`, `rune_miner_iv`, `rune_excavator_iv`, `rune_farmer_iv`, `rune_lumberjack_iv`.
- Recipe IDs: `tool_rune_miner_iii`, `tool_rune_excavator_iii`, `tool_rune_farmer_iii`, `tool_rune_lumberjack_iii`, и аналогичные `_iv`.
- Для III использовать существующий `blank_rune_3` c `RUNE_BASE={tier:3,material:"perunite"}`. Для IV использовать `blank_rune_4` с его корректным компонентом **если он уже есть в реальной локальной кодовой базе**. Если IV нет — допроектировать его без удаления данных I–III. Нельзя делать `blank_rune_4` копией `blank_rune_3` без валидации компонента/codec/crafting/JEI.
- `rune_crafting` в текущей базе допускает не более трёх Counted-ингредиентов; рецепты ниже под это ограничение: ровно один blank + два вспомогательных материала. Сверить реальные имена в регистрах.
- Не добавлять новый набор crafting stations. Сохранять существующие ограничения и стоимость рунической наковальни и сокетов.

Если IV-основа отсутствует: один рецепт `blank_rune_4`: `blank_rune_3 ×1 + bound_soul ×1 + perunite_dust ×8` и новый корректный `RUNE_BASE` (материал/тier как единая принятая IV-основа). Учесть ограничение валидатора `RuneBase.valid` и гарантировать чистую serialisation. При наличии уже реализованной IV-основы/рецепта ничего не менять. Для существующего `rune_crafting` обязательно проверить, что его рецепт совместим с component-тэгом нужной заготовки, и работает в JEI. Если предмет `bound_soul` на предыдущем патче доступен только через скрытую цепочку — не упрощать его получение.

**Внимание:** Это предложенные точные рецепты для новых инструментальных рун; не ослаблять по собственной инициативе. Если какие-то ресурсы отсутствуют в актуальном local branch — указать BLOCKED или согласовать минимальную адаптацию, не подменять ими случайные предметы. Не плодить новых ресурсов без необходимости.

## Тooltip RU/EN

Руны должны содержать:
- Название с III или IV и правильной категорией (крафтовая).
- Совместимый тип инструмента и способность только при Shift.
- Конкретную область: 3×3, 3×3×2 или 5×5, количество 9/18/25 включая центр.
- Лесоруб: тот же вид дерева, основания деревьев в R4/R7, максимум 48/96 брёвен, лишние/сложные деревья могут быть пропущены ради безопасности.
- Расход прочности за каждый фактически обработанный блок, корректная работа с зачарованиями.
- Неявно не обещать бонус к луту топора — это ускоренная заготовка, не Fortune.
- Для мотыги: отдельные режимы вспашки и сбора зрелого урожая; без автопосадки.

## Качество прогрессии

Тier III — ранняя массовая работа, Tier IV — качественно увеличенная площадь/охват. III/IV не дают одновременных эффектов на одном инструменте; IV приоритетен. Нет бонуса к добыче *поверх* Fortune; Fortune и Silk Touch — только ванильное поведение. Старые руны скорости/«Глубин» и «Мастерства» могут взаимодействовать с инструментом согласно существующим правилам, но не множат площадь и не обходят cap'ы. Рецепты будут видны в JEI и обрабатываться сервером после синхронизации.
