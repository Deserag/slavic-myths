# Художественное ТЗ: чертежи = референсы, не готовые sprites

В `blueprints/` приложены **два полноразмерных чертежа уровня III и IV**, а также **8 отдельных вырезок**. Их следует использовать как арт-направление и рисунки формы/глифа. Не копировать крупные декоративные листы целиком в `textures/item`, не переносить мелкие надписи в 64×64, не использовать blur/автомасштаб фотокарточки — перерисовать пиксельно читаемые иконки предметов, стилистически согласованные с текущими рунами Slavic Myths. В случае неточности надписи или изображения приоритет у `01_GAMEPLAY_SPEC.md` и `02_RECIPES_AND_PROGRESS.md`.

**Общие художественные правила:** ромбовидный/шестигранный камень с металлической окантовкой, читаемый центральный знак, объёмная огранка, лёгкая подсветка по граням; чёткий силуэт 64×64, разумная детализация, прозрачный PNG. Руна III — тёмный камень с бронзовой/медной рамой, четыре характерных цвета; руна IV — более дорогой камень, усиленная золотая геометрия, выраженный ромб с маркировкой IV, но без мелкого нечитабельного текста в sprite. В одной категории узнаваемость формы IТЕМ III→IV сохраняется при новом уровне сложности.

Референсы:
- `blueprints/III_TOOL_RUNES_BLUEPRINT.png` — четыре руны III уровня (в том числе схемы работы);
- `blueprints/IV_TOOL_RUNES_BLUEPRINT.png` — четыре руны IV уровня;
- `blueprints/individual_previews/*.png` — отдельно каждая карточка / схема.

**Ожидаемые игровые файлы:** `assets/slavicmyths/textures/item/rune_<id>.png` для 8 новых рун; `assets/slavicmyths/models/item/rune_<id>.json` для 8 новых рун, валидный parent/textures. Не менять старые иконки рун и броню. Проверить читаемость в инвентаре, creative, JEI при доступности клиента; без разрешения игру для скриншота не запускать. Не выдавать превью на чертеже за скриншот Minecraft.
