# Как использовать этот архив

Архив содержит **отдельный новый патч инструментальных рун**, а не замену предыдущего ZIP по боевым и защитным рунам III–IV. Здесь **восемь новых предметов**, включая две версии каждой из четырёх специализаций инструментов.

1. Прикрепить ZIP к сообщению Codex или распаковать в отдельный временный каталог ТЗ.
2. Отправить содержимое `docs/00_READY_PROMPT_FOR_CODEX.md`.
3. Codex должен прочитать четыре других технических документа и использовать 2 полноразмерных чертежа вместе с 8 индивидуальными вырезками.
4. Запускать только после того, как параллельные кодовые работы сведены к безопасному текущему дереву; иначе сообщить о конфликтах, не перезаписывать.
5. По окончании получить подробный отчёт, без автоматического commit/push и без запуска Minecraft/PolyMC.

Механики: III — 3×3 кирка/лопата, 3×3 мотыга, R4 топор на той же породе; IV — 3×3×2 кирка/лопата, 5×5 мотыга, R7 топор той же породы. Топор 48/96 брёвен, Shift для активации.

**Про рисунки:** это концептные ЧЕРТЕЖИ, не готовые игровые спрайты. Точный итоговый графический ресурс — 64×64 пикселей с узнаваемым центральным символом. Любые декоративные надписи, числа и выноски на иллюстрациях уступают точным требованиям Markdown.
