# Пекельный посад — защищённая ручная сборка всего города, QA gate (30.10.2026)

## Состояние

Команда **реально размещает единый `PosadPiece`** по подготовленному `PosadTerrain.Plan`, а не четыре независимо вращаемых `/place template`. Она нужна **только для отдельного одноразового QA-мира**, не является командой восстановления старых городов, автоматическим worldgen или разрешением на rollout. Здания #352/#355 НЕ подключены.

Текущие реальные здания схемы 3: Вечевая палата #347, Общинный дом #348, Дружинный двор #350, Кузнечный двор #351; стены, дороги, лестницы, ворота, платформа, опоры и мост идут тем же piece. Внешний 113×113 генплан не менялся.

## Обязательное ограждение QA

1. Создать **новый одноразовый мир** с игровым именем, начинающимся на `posad-qa-`, например `posad-qa-20261030`. Проверяется `MinecraftServer.getWorldData().getLevelName()`, а не имя игрока или системный путь. В иных мирах команда **не запускается**.
2. Выдать себе права **OP уровня 4** и перейти именно в **Незер**.
3. Выбрать местоположение с настоящим берегом, достаточным воздушным объёмом и доступной опорой в пределах 48 блоков. Подготовить чанки заранее с `/forceload` только в **этом QA-мире**; команда сама **не запрашивает загрузку чанков**. Пример для anchor=(0,0), всех четырёх направлений моста: `/forceload add -48 -48 160 160`. Это много чанков и не подходит для обычного игрового сервера.
4. Только после этого исполнить:

```mcfunction
/slavicmyths dev posad layout 0 0 0
/slavicmyths dev posad create 0 0 64 0 confirm_disposable_world
/slavicmyths dev posad status
/slavicmyths dev posad cancel
```

`create <turns> <anchorX> <deckY> <anchorZ> confirm_disposable_world`: `turns` принимает 0–3. Значения `0 0 64 0` — **пример синтаксиса**, не обещание, что при конкретном сиде существует пригодное место. Если native-планировщик не подтвердил выбранное направление или опоры, команда отказывает без записи блоков. `cancel` до резервирования не меняет мир; после него оставляет постоянный запрет повтора.

## Безопасность и сохранения

- Только главный поток сервера, поэтапный preflight (до 8192 обследованных точек за тик); затем по одному chunk clip на тик.
- Строгие проверки: `Level.NETHER`, высота, world border, загруженность **всех затрагиваемых чанков**, native terrain/shore/bridge, занятые вручную структуры, блок-сущности, бедрок, размещённые/защищённые объекты из `ToolLogOrigins`, посторонние блоки в целевых вокселях.
- `ManualStructureRecords` создаёт **резервацию `construction` ДО первого изменения блока** и синхронно сохраняет `SavedData`; при завершении записывается `nether_posad`, также сохраняемый после перезахода. Если процесс отменён/упал после резерва, запись **сохраняется**, автоматического повторного строительства или сброса наград нет. Ручное снятие резерва этой командой не предусмотрено.
- `PosadPiece` сохраняет фиксированную schema и привязывает loot table **только к впервые поставленному сундуку**. Повторная обработка уже существующей блок-сущности не перевыписывает её. Отдельный GameTest `chestRewardsAreNotRearmed` проверяет, что после открытия и опустошения сундука повторный проход не создаёт лут заново.
- Обратите внимание: **невозможно доказать полную защиту пользовательских блоков из натуральных материалов только по BlockState**; дополнительно используется `ToolLogOrigins`, но моды claims могут иметь другие правила. Поэтому hard-gate имени QA-мира обязателен, а не заменяем разрешениями OP.

## Непройденные проверки и запрет на преждевременную активацию

- Требуются: Java21 `clean build`, настоящий NeoForge GameTest с новой проверкой антидюпа, **полноценный запуск самой ручной команды**, QA save/reload, перезагрузка уже открытых сундуков, два игрока/мультиплеер, fail/retry после имитации обрыва, four-turn checks, серверный TPS и исследование реальных пяти Nether seed.
- Исполнение `create` в обычном мире должно быть отвергнуто. Не запускать разрушительный `/place template` как замену.
- Естественный `StructureSet` остаётся **отключённым**: доказательства runtime производительности плотного `PosadTerrain.inspect` и безопасного native chunk-gen отсутствуют; старые города **не обновлять**. Утверждённые параметры `spacing=80, separation=32, salt=22022026, frequency=0.75, weight=1` — только baseline, **не активные runtime данные**.
- Нет автоматического обновления NBT/схемы уже созданных городов. Статус безопасного native rollout: **BLOCKED**.
