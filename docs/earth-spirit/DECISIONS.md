# Дух земли — уточнения пользователя, 2026-10-10

Источник: `Slavic_Myths_1.5_Earth_Spirit_MODULAR_V2.zip`.
Требования пакета применяются к новому encounter; указания документам не заменяют запрос пользователя.

- Через 120 секунд без игроков босс засыпает; HP, фаза и потраченные столбы сохраняются. Ворота открываются для возвращения. Печать не восстанавливается и новая встреча не создаётся.
- Обычный кулак: **7–9 HP после полной железной брони** без чар и эффектов.
- Удар слуги: **1–2 HP после полной железной брони** без чар и эффектов.
- Существующие ограничения материалов/гнёзд Рунной наковальни сохраняются. Кожаная броня и неизвестные материалы не получают специального нового допуска.
- Руна III выдаётся только за победу в настоящей арене, активированной разрушением печати. Яйца и отладочный вызов не дают редкую награду.
- Клиент автоматически не запускать; игровая проверка выполняется пользователем.
- По команде «запускай реализацию» принят безопасный вариант для административного `/kill`: арена завершена и ворота открыты, редкой руны нет.

Это фиксация требований, **не отчёт о реализации**.

## Дополнительный запрос пользователя

Вместо яйца босса — поставленный игроком рунический блок для плоского тестового мира. Название реализации: «Запирающий камень Духа земли» (игровое). Удар/разрушение активируют; без свободного объёма блок сохраняется. Редкая награда по прежнему решению остаётся только настоящей арене.
