# Новые обязательные тесты: 1.8.5 финальная версия — раннее очищение

1. Лихо убит, Овинник жив, Полоз НЕ призван. Яга изучает Око, выдаёт ×4 порошка и показ рецепта; повторный диалог НЕ дублирует награды.
2. Овинник убит РАНЬШЕ Лиха: после Лиха всё равно срабатывает ранний unlock, Q3 можно закрыть без повторного Овинника.
3. Крафт точно shaped: костная мука / одуванчик / костная мука в верхней строке; древесный уголь в центре второй; результат ×4; иных рецептов не оставлять. Проверка 2×2 не должна ошибочно выдавать результат; charcoal НЕ coal, а dandelion НЕ любой flower tag.
4. Крафт вручную до выполнения квеста работает, а открытие Ягой корректно добавляет рецепт в книгу: квест не блокирует самостоятельное исследование.
5. ПКМ по заражённой земле, камню, булыжнику, дереву, песку; уверенная 3-секундная последовательность возвращает настоящий исходный blockstate (orientation/axis сохраняются) и не затрагивает обычные соседние блоки.
6. Радиус4: позиции на расстоянии <=4 могут очищаться, >4 не могут; очистка максимум9 **связанных** заражённых позиций, стабильный порядок обхода. `0` позиций → не списывать.
7. Защита 90с: попытка повторно заразить излеченный блок Полозом отменяется, но его физическое разрушение не отменяется; после 1800 тиков блок вновь может заражаться. При block replacement метка снимается, не передаётся чужой кладке.
8. 20 реально излеченных блоков в мире или на учебном участке +1 за каждую позицию, не +9 за клик. Один блок не засчитывается двум параллельным заданиям, один и тот же очищенный блок повторно не считается.
9. Если постоянной порчи до Полоза нет, обучение Яги позволяет честно завершить 20 без призыва; при невозможности разместить учебные реальные блоки работает диалоговый обучающий fallback, без griefing чужих claims.
10. Награда за 20 = 8 порошков +175 XP однократно, основная цепочка Q3/Q4/Q5/Q6 НЕ блокируется этой подзадачей.
11. Q6 при поражённой земле и ранее изученном рецепте даёт только свой сюжетный финал/800 XP, а не вторую партию 12 порошков.
12. Save/restart: cleaning task midflight, 90-sec land immunity, 0/20 и 19/20 progress, claimed flags; нет дюпа и исчезновения порошка. Server authoritative, клиенты показывают эффект.
13. Проверка Creative, Spectator, прав изменения блоков, сундуков, block entities, чанков unloaded, 2 игроков near Yaga и разных размерностей.
14. Texture 16×16 соответствует мешочку из `refs/02_...`, а не алхимическому зелью; отдельные русские строки без key-имён в интерфейсе.
15. Проверить валидные ресурсы `sounds.json`, `.ogg` или корректное подключение существующего mod/vanilla event; не допускается битовая/электронная музыка.
