# Готовность / Definition of Done

## Блокирующие требования
[ ] Утверждённый референс физически находится в архиве; Codex открыл и использовал.
[ ] Первая смерть морового после знакомства вызывает приглашение только один раз; Баюн может пригласить, но ВСЕГДА к Яге.
[ ] Свободный вариант «Приду сам» рабочий; teleport safe без void, без генерации избы.
[ ] Сцена на пороге существующей избы: Яга обязательна; Баюн/Волк участвуют только при знакомстве + trust≥II; встреча не создаёт постоянных дубликатов.
[ ] Полный сценарий RU диалогов и анимаций персонажей/звуков; отсутствие участника не ломает scene UI.
[ ] 6 основных этапов работают и имеют реальные цели/награды; 3 задания Волка доступны отдельно.
[ ] Старые квесты и trust Серого Волка сохраняются, summon Волка не нарушает оригинальный NPC.
[ ] Волчий зов (клык), оберег (амулет), чутьё (фонарь), порошок (мешочек), глава книги (закладка) узнаваемо перенесены из референса и имеют настоящие ассеты.
[ ] Волчий зов 5мин КД / до 120сек поддержки вне боя, Волк может помочь против Полоза и выделяет реальные weakpoints.
[ ] Оберег ×0.5 infected block damage / 20 мин, tracker 64б/3мин/CD10мин.
[ ] После исследования Ока мора от Лиха игрок ДО Полоза получает ×4 порошка и shaped-рецепт bone_meal+dandelion+charcoal.
[ ] Порошок за 3 секунды очищает до 9 связанных заражённых блоков в радиусе4, защищает фактически очищенные на 90 секунд; не чинит разрушенные постройки и соблюдает protection.
[ ] Отдельный прогресс 20 вылеченных блоков даёт ×8 порошка/175 XP ровно 1 раз, достижим ещё до Полоза (безопасное обучение или fallback).
[ ] Q6 не даёт повторно порошок/рецепт, только завершает сюжет.
[ ] Нет непреодолимой сюжетной блокировки из-за уже побеждённого Полоза или использованных в роге трофеев.
[ ] Не изменены глобальные ванильные блоки и уже утверждённые модели Полоза/рога/его наград.
[ ] Русская локализация текстов/субтитров работает, книги/GUI не дублируются.
[ ] Нет placeholder звуков, нерегистрированных предметов, вымышленных API и `TODO` в реализации основных механик.
[ ] Серверная authoritative логика и атомарная сдача не дублируют награды, прогресс и CD переживают relog/restart.
[ ] Компиляция/статические проверки успешны; итоговый JAR 1.8.5 готов; PolyMC установлен/объективно объяснён, клиент не запускали.
