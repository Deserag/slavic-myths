## Запрет
Не использовать прошлые искусственно синтезированные бас-«рёвы» и случайные интернет-звуки под видом подлинных. Звук Полоза из 1.8.3.2 не перерабатывать без отдельной задачи: пользователь выбрал аллигатороподобный низкий голос, это не требует новой музыки при квесте.

## Требование проверки
Все игровые события имеют sound event registration, subtitle RU. Допустима композиция из двух коротких существующих звуков при отсутствии нового оригинального ogg — но она должна быть не громче окружения, без бессмысленного повторения.
