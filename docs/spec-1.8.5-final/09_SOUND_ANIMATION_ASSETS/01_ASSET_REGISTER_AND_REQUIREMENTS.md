# Реестр ассетов и контроль качества: нет заглушек

## Что должно появиться (новые ассеты)
| type | логический resource | назначение | где описан |
|---|---|---|---|
| texture item | `wolf_call.png` | 16x16 клык/свисток | wolf item |
| texture item | `mor_ward.png` | 16x16 подвеска | ward |
| texture item | `tracker_sense.png` | 16x16 фонарь | tracker |
| texture item | `cleansing_powder.png` | 16x16 мешочек | cleansing |
| book icon | `cleansing_knowledge.png` | закладка уже существующей книги | book |
| particles | `purify_spark`, `purify_green_spark`, `mor_inspection`, `cleansed_land_ward` | белые частицы порошка / светло-зелёные искры / багровая исследовательская фигура / редкая искра 90с защиты | сцена/очищение |
| events | `quest_invite`, `quest_turn_in`, `quest_complete`, `purification`, `wolf_howl`, `wolf_summon` | использовать существующие если подходящие, иначе реальные assets | звуки |

## Звуковой стандарт
- Ощущение натуральных магических/физических событий, не синтезатор/бит. Если событиям нужен голос, использовать существующие натуральные NPC звуки или аккуратно обработанный живой материал с допустимой лицензией, не изобретать невалидные файлы.
- Любой новый `.ogg`: валидный Ogg Vorbis, 44.1/48 kHz, моно для позиционных, без клиппинга, корректный `.json` registration, subtitle `ru_ru` и pitch/volume bounded.
- Если нет прав на внешний фоли-звук — разрешено комбинировать существующие модовые/vanilla sound events корректно, но не оставлять пустой `sounds` и не делать `TODO` на реальный звук.
- При `sound = existing event` не копировать байты ванильного ассета с новой лицензией. Использовать resource location vanilla или уже имеющийся ресурс.

## Визуальный стандарт
- Не использовать сгенерированные рисунки-постеры как игровые текстуры.
- Цветовая гамма тёмное дерево/кость/старорусские орнаменты, красный Мор — только опасность, мягкий янтарный — магия союзников.
- Не добавлять неоновые градиенты, realistic PBR, полупрозрачную гладкую 3D кожу или крупные кристаллы, которых нет на референсе.
- Каждое изображение из refs MUST be explicitly inspected and matched; для каждого item в отчёте фото/путь текстуры/скриншоты рендера если можно построить headless preview, но запуск Minecraft запрещён.

## Перформанс
Серверные particle packets только близким игрокам; не создавать по 50 объектов каждый tick. Чистка до 9 блоков радиус4 за 3 секунды использует 2–5 частиц на блок; сценические частицы до 20 в общей сцене.
