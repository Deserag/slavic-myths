# Защита вылеченной земли — 90 секунд

## Правила
- После окончания очистки каждой целевой позиции записать серверно `world dimension, BlockPos, block fingerprint, immuneUntilGameTick = currentLevelGameTime + 1800`.
- На попытку **повторного заражения** Полозом/моревой механикой: сначала посмотреть, не защищён ли именно этот стоящий блок. Если защищён → **не превращать** blockstate, можно вызвать 1-2 белых пикселя как отказ; это не щит от физического столкновения или разрушения Полозом.
- Новая установка блока игроком вместо защищённого снимает метку; если `blockstate` совпадает, хранить дополнительный generation token/событие изменения позиции, чтобы запретить перенос защиты на новый блок. При разрушении удалять запись. При повторной очистке той же всё ещё заражённой позиции (когда время вышло) задавать новый срок 90 с.
- Состояние только для фактически излеченных блоков; не отмечать все блоки в сфере радиуса4, обычную траву рядом не защищать бесплатно.
- При выключении/перезапуске сервера срок продолжает отсчитываться по игре (не по системным часам компьютера). На чтении чанка удалять просроченные записи; обработка ticket/load без принудительного удержания чанка.
- Противозаражение всех 1.8.3.1 infected types, когда они создаются естественным путём: внедриться централизованно в существующий путь преобразования или общий event hook, НЕ делать защиту только для 1 вида dirt.

## Визуальная индикация
При наведении на недавно излеченную землю (только если инструменты HUD уже поддерживают): краткая подсказка «Защита земли: {sec} с». Не добавлять новую большую панель. Светло-зелёный слабый эффект у отдельных очищенных блоков примерно 1 раз в 20–40 ticks, только около наблюдателя. Не вызывать бесконечные particles в unloaded chunks.
