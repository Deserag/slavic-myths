# Безопасное восстановление блока, сохранение оригинального состояния

## Конфликт, который НЕЛЬЗЯ пропустить
Для 1.8.3.1 заражённые ванильные аналоги появляются локально вместо исходных блоков. При очищении важно вернуть исходный blockstate, в том числе orientation и свойства (например `oak_log[axis=x]`, `oak_stairs[facing=north]`, `oak_leaves[distance=...]`), а не вслепую заменить всё на dirt.

## Приоритет восстановления
1. Если блок при заражении сохранил `originalBlockState` (и metadata при необходимости), вернуть ровно его с валидацией доступности registries. Это точный способ.
2. Для старого сохранения без origin metadata использовать утверждённую mapping-таблицу из текущего патча 1.8.3.1 (corrupted_dirt → dirt; corrupted_grass → grass_block; stone → stone; cobble → cobble; sand → sand; gravel → gravel; oak_log → oak_log; oak_planks → oak_planks; oak_leaves → oak_leaves; birch_log → birch_log; sandstone → sandstone; obsidian → obsidian, если эти варианты реально уже зарегистрированы).
3. Если заражённый блок имеет неизвестный оригинал и нет однозначной соответствующей пары: **оставить его**, сообщить «Не удалось определить исходный материал», отметить в диагностике, не делать грязь по умолчанию.

## Точное хранение
- При заражении Полозом зарегистрировать `dimension+BlockPos → origin state`, если реально ещё не сделано в 1.8.3.1. Сохранение per chunk или существующий chunk attachment / SavedData, не миллионы unbounded разрозненных глобальных NBT структур.
- Не перезаписывать origin при повторном заражении того же блока; следить за чанком и очисткой.
- После очищения удалять запись `origin`, чтобы предотвращать утечку памяти. Если игрок сломал заражённый блок, cleanup origin metadata при destruction.
- BlockEntity со своим инвентарём (сундуки, печи и другие контейнеры) вообще НЕ превращать мором через эту механику, если предыдущий патч не сделал безопасное отдельное решение, чтобы не терять предметы/дюпать лут. Порошок не модифицирует содержимое контейнера.

## Ограничения доступа
- Соблюдать mod hooks на block break/place/protection/claim, не обходить protections чужих территорий.
- Не пытаться очистить bedrock, portal frame или обычный (незаражённый) block.
- При очищении травы/листвы обновить соседей (минимально необходимый update) и корректные свет/heightmap; не гонять дорогостоящие полные chunk relight каждый блок без причины.

## Таблица эффектов после очищения
- `Weakness I`, `Slowness I`, periodic damage от конкретного заражённого блока прекращаются сразу после его удаления; если рядом ещё есть другие поражённые блоки, эффект может сохраняться по их обычным правилам.
- Оберег от мора остаётся активным по таймеру, очищение не продлевает его.
