# Старт, условия выбора говорящего, чат

## Server event hooks
- При смерти подходящего морового врага обновить `killsByMorType`, `sawMor`, timestamp, persistent progress; считать только реальное убийство / участие игрока, которое существующая система уже фиксирует.
- Перед записью сообщения проверить флаг `invitationShown` и наличие ранее известной Яги или Баюна (хотя бы одна реально завершённая первичная беседа, не просто загрузка чанка).
- Если оба знакомы: инициатор — с более поздним `lastMeaningfulDialogAt`. При равенстве — Яга. Это детерминировано и не требует RNG.
- Если известна только Яга — пишет Яга; только Баюн — Баюн.
- Если никого не знает, книгу всё равно обновить, приглашение не теряется навсегда: при следующем разговоре с одним из них предложить старт.
- Если игрок хочет отложить: пригласительную карточку оставить в книге, ответ не спамить повторно при очередной смерти морового.

## Точный текст сообщений (ru_ru)
**Яга:** «Чую, ты встретил хворь не здешнюю. Даже нечисть от неё шарахается. Ступай к моей избе — разговор будет тяжёлый. Перенести тебя ко мне?»
**Баюн:** «Почую я чужой след, человече. Баба-яга ждёт тебя у избы. Пойдёшь сам или доставить тебя по сказочной тропе?»
Кнопки/интерактивные варианты: **«Перенести к избе»**, **«Приду сам»**. Не отдавать вопрос в простом чате без рабочего способа ответа: сделать системное диалоговое окно либо кликабельное подтверждение по существующим безопасным UI паттернам. Кликабельные команды нельзя принимать от другого игрока.

## Если игрок отказывается
- Отклоняет лишь телепорт, а НЕ квест и НЕ знакомство.
- Книга показывает краткий ориентир к **последней известной** избе Яги (без выдуманных координат). Если изб несколько — известная по истории конкретного игрока.
- У крыльца или в диалоге с Ягой есть пункт «О хвороби» и запуск встречи.

## Не отправлять
- Повторно после перезапуска/смерти, если invitationShown=true.
- Войну/диалог в момент игрока в титульном меню/без server player connection.
- Если игрок уже прошёл intro/главу: только запись в журнале.
