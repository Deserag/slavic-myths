# 1.9.7 + патч оружия — ревизия брони

Ревизия существующей экипировки по заданию 1.9.10 выполнена поверх актуальной
совместной 1.9.7. Основной номер не менялся. Новые комплекты не добавлены.
[Аудит всех 29 предметов и показатели](AUDIT.md), [точный список файлов](CHANGED_FILES.md).

Переработаны 22 иконки: все 21 из списка пользователя и сапоги-скороходы.
Каждая —32×32 на 16px сетке без сглаживания. Три трофея, богатырский нагрудник,
ясный взор и неукротимость получили самостоятельные материалы и декоративные
центры; стёганка — швы/рукава, кираса — широкие пластины, ветер — перья.
Перунит — синяя сталь/молния, Полоз — золотая чешуя/сердце, дракон — сталь/костяные
рога/огненный центр. Подробности каждого предмета в таблице аудита.

Переработаны текстуры на персонаже всех 22 предметов: четыре unique atlas family
(оба существующих слоя), семь-верстовые сапоги, стёганка, кираса, оба слоя перунита,
три 128px атласа трофеев,64px Полоз и дракон. Сохранены существующие bone models;
изменены четыре client class: UV/солнечная застёжка уникальной брони,
UV перунитового гребня/брови, UV и небольшие передние вставки дракона,
профиль и ступенчатые хвосты Маринки/ширина стяга Картауса.

Изменены ровно три существующие item model: gambeson, plate_cuirass,
seven_league_boots. Теперь minecraft:item/generated с собственными иконками.
Остальные item model уже использовали generated и остаются той же схемой.
Надетые модели не заменялись item-спрайтами.

**Свойства не изменены**: защита, toughness, KB, прочность, руны, способы получения,
ремонт, зачарования и все пассивы сохраняются. Их роли уже выражены фактическим
кодом; глобальное усиление не оправдано. Семь ClothingItem и Curios исключены из правок.
Оружие не изменялось этой задачей. Параллельный патч оружия f53447cc принят как
проверенный установленный baseline, его gameplay classes и ресурсы сохранены.
Финальный diff JAR относительно него содержит только 4 client armor classes и armor assets.
