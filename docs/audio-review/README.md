## Метод сравнения

Первый старый envelope-screening и его aligned correlation сохранены как историческая
выборка. Новый [всефайловый анализ](PROJECT_SIMILARITY_METHOD.json) рассматривает
все409965 пары906 файлов;187949 пар проходят фильтр отношения длительностей .5–2.
32 mel bands ×16 временных bins, cosine≥.985 →187 кандидатов; выравнивание
waveform ±200ms при8kHz даёт67 совпадений≥.98. Это акустический screening,
не слуховой вердикт: фазовые/семантические/pitch/time изменения могут пропускаться.
[Результаты](PROJECT_SIMILARITY.csv). Отдельно exact bytes/PCM: DUPLICATES.csv.
