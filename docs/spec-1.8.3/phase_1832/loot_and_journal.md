# Лут, рецепт, трофеи и Книга сказаний

## Обязательные 3 компонента для Морового рога
- **Моровой прах** `slavicmyths:mor_dust`: чёрно-бордовая пиксельная щепотка с красными искрами, inventory 16x16, stack 64, локализация ru_ru/en_us. Основной источник:
  - Моровой Леший: 1–2 с вероятностью 70% при убийстве любым боевым источником, но только если корневая entity не summoned-minion от Полоза.
  - Моровая Полудница: 1–2 с вероятностью 70%.
  - Моровая Кикимора: 1–2 с вероятностью 60%.
  - Моровой Огненный змей (1.8.1): гарантированно 2–4 праха из **основной** сущности мини-босса, копии по 30 HP ничего не дают.
  - Если уже есть собственный утверждённый лут в 1.8.1, новый прах добавить к нему, не заменять старый. Looting максимум +1 шт., не удваивать дроп из физически соседних частей.
- **Око мора** `slavicmyths:eye_of_mor`: один уникальный глаз с пепельно-чёрной радужкой и багровой вертикальной зрачковой вспышкой, пиксель-спрайт 16x16/32x32. **1 гарантированно** с Высшего морового Лиха после death только root entity. Не добывать с обычного Лиха. stack16.
- **Пепельное сердце** `slavicmyths:ashen_heart`: разломанное чёрное сердце с внутренними красными пикселями, 16x16/32x32. **1 гарантированно** с Высшего морового Овинника. Не с обычного. stack16.
- Требуется **1** ванильный козий рог, **1** vanilla gold ingot, **5** Mor dust. Крафт и использование — строго `horn/01_ITEM_VISUAL_AND_RECIPE.md`.

## Дроп самого Великого Полоза
- Гарантированно **1 × `slavicmyths:poloz_core` «Сердцевина Полоза»**: 32x32 чёрно-золотой каменный осколок с красной щелью; stack1; трофейный предмет используется как доказательство победы для Книги сказаний. **Сейчас НЕ вводить крафт 1.9 с этим предметом**. Его немедленная функция: сдача через существующее окно/интеракцию Книги сказаний «Победа над Великим Полозом» не расходует предмет, только по факту наличия в инвентаре обновляет запись/знание.
- **8–12 × `slavicmyths:poloz_scale` «Чешуя Великого Полоза»**: тёмная золотая пластина с багровой прорезью, 16x16, stack64. На этой версии выполняет функцию трофея/материала коллекции в Книге, не притворяться уже имеющимся рецептом меча/брони. Пользователь планирует дальнейшее использование в 1.9, сейчас не делать фейковый крафт.
- **16–24 золотых слитка**, **1 500 vanilla XP** (разрешено делить orb stack без множества тысяч сущностей). Обычный item pickup respects doMobLoot.
- Из призванных копий/миньонов Полоза **нет** дропа/XP, чтобы не было фермы.
- При сражении нескольких игроков награда предметами появляется **один раз на босса** на месте смерти; не дублировать отдельно каждому игроку, всем близким участникам (в пределах 256 блоков и с участием за последние 120 sec) засчитывать Книгу сказаний и achievement только если существующие механики знают участников.
- Новые registry IDs для трофеев не пересоздавать при последующих загрузках; добавить ItemModel/texture/lore и ru_ru/en_us.

## Книга сказаний
- После появления самого первого поражённого блока в видимости игрока: «След мора: тёмные прожилки в земле», краткое предупреждение об эффектах. Это дополнение к уже имеющейся 1.8.1 записи, без её перезаписи.
- После рецепта Морового рога: раздел «Моровой рог», ингредиенты, точная схема 3×3, существующее капище, реальная катастрофа, предупреждение об разрушениях.
- После первого призыва: «Пробуждение Великого Полоза», направление поиска без фиксированных координат, подсказка о слабых точках «голова, хвост, шрамы», далее в фазе II запись «Броня раскалывается».
- После победы: «Падение Великого Полоза», полученный трофей, устойчивое заражение мира, пока нет специальной очистки, легенда о хранителе земли; не раскрывать Ад/Змея Горыныча как существующий контент раньше 1.9.
- RU текст обязательный, отсутствие русских строк в GUI — блокирующий дефект.

## Creative-тестирование
Все новые Items/Blocks в **существующей creative tab** мода, рецепты и loot можно проверить через vanilla командами и существующую книгу. Не добавлять spawn egg Полоза или косметические пробирки.
