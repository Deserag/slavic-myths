# Моровой рог — ритуал, защита от случайного вызова, местоположение босса

## Где применить
У **уже существующего действующего капища / обрядового объекта** (найти точечную реализацию в текущем моде), **никаких новых капищ/структур генерировать не нужно**. Игрок с рогом в основной руке стоит на расстоянии <=5 блоков от существующего ритуального блока. Проверка `ServerLevel` + permission + dimension = Overworld + статус капища. Не путать с любой декоративной каменной плитой.

## Двухшаговое подтверждение (реальное разрушение построек!)
1. Первый `sneak + right click` на действующем капище показывает **красное предупреждение** с акцентом: «Великий Полоз разрушает постройки, деревья и землю. Последствия сохраняются. Повторите действие в течение 10 сек. для призыва». На этом этапе ничего не расходуется.
2. Второй `sneak + hold-use` в пределах 10 секунд запускает 3-секундное поднятие рога. Игрок должен продолжить удержание; при отпускании/уроне, смене измерения/слота/смерти / отходе >8 блоков — отмена без расхода праха/запуска события.
3. После 3 сек — атомарный commit: проверить нет ли уже активного Полоза, cooldown, необходимые 4 праха для повторного использования; зарезервировать место для появления; расходовать прах; пометить рог использованным; сохранить одно активное событие. Только затем начинается 9-секундный звуковой/визуальный сценарий из `02_SOUND_DESIGN.md`.
4. На 9-й секунде **спавн** Полоза на заранее проверенной позиции 200–300 блоков от капища (полная методика в `poloz/04_SPAWN_MOVEMENT_AND_WATER.md`).
5. Обе руки пользователя заняты управлением предметом? Не запускать повторное событие при нажатии в анимации. После commit отмена не возвращает прах (мировое событие уже вызвано), но если server spawn физически завершился ошибкой — восстановить 4 праха и флаг через идемпотентное возмещение + записать failed event.

## Интерфейс / направление
- В момент commit всем игрокам Overworld сервер посылает action-bar/title «Хворь пробудилась. Великий Полоз пришёл в мир!» и тревожный низкий sound cue с нормальными настройками громкости; игрокам в других измерениях нет фальшивого локального звука.
- На месте появления красный столб всполохов **120 блоков вверх в течение 20 секунд**; это **частицы**, не разрушительная lightning explosion.
- Рог показывает направление: пока Полоз жив и игрок держит рог, раз в 2 сек маленькая красная стрелка/буквенный компас возле hotbar (использовать существующий navigation-HUD если есть) + по right-click без sneak action-bar: «Полоз: СЗ, 243 блока»; обновление расстояния server-to-client раз в 40 ticks, не каждый тик. Клиент не ищет boss entity глобально.
- После гибели босса рог остаётся, показывает «Полоз повержен» до следующего события.

## Ограничения
- 1 Полоз одновременно во всём Overworld на сервере. Сеть/кросс-игроки не вызывают второй, даже если подтвердили одновременно.
- После гибели нового призыва нельзя делать 20 реальных минут (`24000 ticks` активного Overworld времени). Рог сообщает оставшийся cooldown; если мир пуст, не нужно гонять offline tick.
- Любой игрок с любым рогом может сделать призыв после cooldown, если выполнил требования; защита не привязана к одному уникальному игроку.
- Если `mobGriefing=false`, рог требует явно сообщить «Включите mobGriefing для полного мирового события» и НЕ запускает Полоза, не тратит прах. Отдельно отключаемый конфиг позволен для серверов, но нельзя тайком запускать декоративного Полоза и считать feature готовой.
