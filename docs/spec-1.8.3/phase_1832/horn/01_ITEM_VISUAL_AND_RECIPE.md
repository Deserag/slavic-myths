# 1.8.3.2 — Моровой рог: предмет, референс, точный крафт
**Обязательный утверждённый референс:** `refs/02_approved_morovoy_horn_recipe_and_use.png`. Не менять форму инструмента и не подменять его современным музыкальным прибором. Рог — отдельный игровой предмет **`slavicmyths:mor_horn`**, русский UI **«Моровой рог»**, количество в стеке 1. Референс показывает именно *искажённый древний козий рог*, а не бутылку/палку/знамя.

## 3D-инвентарь и модель в руке
- Основа — **изогнутый светлый костяной рог**, расширяющийся раструб сверху и узкая тёмная трубка/мундштук внизу, 2 потемневших металлических обода и грубая тёмно-коричневая кожаная обмотка.
- Один из ободов перевязан тёмными рваными красно-чёрными лентами. На теле 1–3 тонкие светящиеся красные трещины, 1–2 маленьких багровых пикселя-руны; висячие ленты не заслоняют силуэт рога.
- Minecraft/Blockbench-подобная геометрия: максимум 12–16 простых cuboid элементов, 16×16 или 32×32 ближайшее текстурирование (никакого фотореализма). Габарит held model примерно 0.65 × 1.1 × 0.35 блока; диагональный изгиб нарисован ступенями 3–4 сегментов. Направлен раструбом вверх и немного от лица.
- Inventory icon 32×32 с alpha, рог диагонально от нижнего левого к верхнему правому углу; чёткий светло-костяной раструб, чёрные ободы, багровые швы; icon без чёрного background.
- Анимация удержания и использования как козьего рога: поднимается к лицу, при зарядке красные квадратные частицы вдоль ободов; не добавлять огромную анимированную 3D сцену в GUI.

## Рецепт 3×3: ПОЗИЦИИ ЖЁСТКО ЗАДАНЫ
```
[ ОКО МОРА          ][ ЗОЛОТОЙ СЛИТОК ][ ПЕПЕЛЬНОЕ СЕРДЦЕ ]
[ МОРОВОЙ ПРАХ      ][ КОЗИЙ РОГ      ][ МОРОВОЙ ПРАХ     ]
[ МОРОВОЙ ПРАХ      ][ МОРОВОЙ ПРАХ    ][ МОРОВОЙ ПРАХ     ]
```
JSON recipe pattern (не буквально mod class):
```json
{
  "type": "minecraft:crafting_shaped",
  "pattern": ["EGH", "MRM", "MMM"],
  "key": {
    "E": {"item": "slavicmyths:eye_of_mor"},
    "G": {"item": "minecraft:gold_ingot"},
    "H": {"item": "slavicmyths:ashen_heart"},
    "M": {"item": "slavicmyths:mor_dust"},
    "R": {"item": "minecraft:goat_horn"}
  },
  "result": {"id": "slavicmyths:mor_horn", "count": 1}
}
```
**Не ошибаться с количеством:** 1 Око мора + 1 Пепельное сердце + 1 **обычный ванильный козий рог в центре** + 1 золотой слиток + **5 Моровых прахов**. Крафт любой vanilla-козий рог, независимо от instrument variant, результат — один фиксированный Моровой рог.

## Полная цепочка получения
- `eye_of_mor`: 1 шт **гарантированно** после победы над **Высшим моровым Лихом** (1.8.2); не из обычного Лиха, не из творчества только. Если loot hook ещё не появился, добавить его только в drop высшей формы.
- `ashen_heart`: 1 шт **гарантированно** после победы над **Высшим моровым Овинником** (1.8.2); не из обычного Овинника.
- `mor_dust`: дроп из обычных моровых версий **Лешего, Полудницы, Кикиморы, Огненного змея**; таблица в `phase_1832/loot_and_journal.md`.
- `minecraft:goat_horn`: ванильные механики добычи; **не вводить новый козий рог**.
- `minecraft:gold_ingot`: ванильный слиток.
- Предметы Eye/Heart/Dust: реальные Item registries, inventory assets, localized tooltips, loot tables/гейт дропа; не оставлять placeholder. Дропы высших форм не удваиваются при смене фаз.

## Использование после первого раза
Рог не расходуется. Первый успешно подтверждённый вызов **бесплатен** по моровому праху (5 прахов уже потрачены при крафте). Для КАЖДОГО следующего вызова этим же предметом требуется ещё **4 Моровых праха в инвентаре**, которые сервер расходует атомарно только после успешного commit призыва. Флаг `hasSummonedOnce` хранится в data component ItemStack (не в transient client property); перенос между мирами не обнуляет флаг. В Creative стоимость игнорируется. Рог не может использоваться как обычное оружие.
