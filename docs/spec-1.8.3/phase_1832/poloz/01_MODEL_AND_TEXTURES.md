# Великий Полоз — точная Minecraft-геометрия, палитра и текстура

**Важное:** отдельного утверждённого PNG Полоза в архиве НЕТ. НЕЛЬЗЯ подменять его Огненным змеем или Змеем Горынычем. Ниже — обязательная спецификация геометрии, не предложение найти внешний арт. Стиль: ванильный Minecraft / Blockbench, квадратные пиксели, набор кубоидов и сегментов, без сглаженного реалистичного рендера.

## Масштаб
- Тип: **огромный бескрылый земляной змей, а не дракон с четырьмя ногами**. Длина в распрямлённом состоянии **около 40 блоков**, допускается 38–42 для равномерных сегментов.
- Головная коробка ~4.5 блока в длину, 3.5 в ширину, 3.0 в высоту, морда выступает ещё на 1 блок.
- Шея/начало туловища ~3 блока толщиной; самый толстый участок корпуса 3.6–4.0 блока в ширину, 3.0–3.5 в высоту; к хвосту сужается до 0.9–1.2 блока.
- Тело состоит из **20 видимых сегментов туловища** длиной примерно 1.5 блока и гибкого хвоста ещё ~4.0 блока из 4 меньших сегментов; добавить длину головы, итог ~40 блоков. Сегменты соединяются без заметных щелей, даже при изгибах и в воде.
- Силуэт узнаваем сбоку: тяжёлая широкая голова, массивное тело с золотистыми чешуйчатыми гребнями, сужающийся каменный хвост; **никаких крыльев или ног**.

## Голова
- Сильно уплощённая треугольная «змеиная» морда, но целиком из низкополигональных прямоугольных деталей. Две симметричные тёмные глазницы и **два янтарно-красных глаза** (это не Лихо — один глаз не нужен).
- Пасть — отдельная открываемая нижняя челюсть 2.8×0.6×2 блока, 4–6 крупных зубных кубов по краям; глубокий тёмный рот, светящиеся трещины в уголках.
- 2–4 небольших каменных гребня/нароста назад по голове, не сплошная корона рогов; в затылке «старый» моровой шрам как явная цель.

## Чешуя и золото
- Исходный цвет: тёмный золотистый `#A18136`, потускневший жёлтый `#C39F51`, земляной `#5D4C31`; нижняя сторона песочно-каменная `#8B7A5A`.
- Мор: обуглённый `#20171D`, бордовый `#5B1923`, трещины `#AF2333` / `#E34550`. Не красить всю модель красным: золотая основа обязана просматриваться.
- Крупные перекрывающиеся геометрические чешуйчатые пластины по 3–5 на видимую сторону сегмента. Каждая пластина ступенчатая (пиксельные ступеньки), толщина 0.12–0.2 блока; между ними тонкие красные участки.
- Шрамы: **реальные отдельные ярко видимые V-образные/рваные багровые зоны на геометрии сегментов**, а не случайные частицы без hitbox. Шрам виден с земли при типовой дистанции 10–20 блоков.
- Текстуры сегментов 64×64 для repeat atlas/своя карта головы 64×64; nearest-neighbor. Пиксельная плотность близка существующим большим мобам. Контроль UV швов при изгибании.

## Анимация и визуал
- Голова может подниматься на 3–6 блоков во время атаки; под ней остаётся тело на поверхности. Body сегменты следуют по server path-history с client interpolation.
- Постоянная, НО не экранозасоряющая красно-чёрная аура и осыпающиеся песочные частицы при скольжении по земле. На поверхности тела не допускать flickering/z-fighting.
- При переходе второй фазы новые красные шрамы **постепенно раскрываются** по всем сегментам за 3 сек, оставляя первоначальные золотистые чешуйчатые пластины ещё видимыми. Третья фаза — сильные багровые прожилки и низкое дрожание головы, не превращать в сплошной столб света.

## Анимации
`idle_coil` (медленная волна тела, покачивание головы), `crawl` (протяжённая волна), `swim` (более широкая волна хвоста, голова над водой), `surface` (выход из воды), `burrow_in/out`, `bite`, `tail_sweep`, `body_crash`, `mor_breath`, `ring_constrict`, `summon_call`, `phase2_scars_reveal`, `phase3_rage`, `hurt_weakspot`, `death` (последний оглушительный срыв и распад багрового свечения).
