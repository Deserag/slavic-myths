# Полоз — отдельные звук, анимация, спецэффекты; связь с фазами

## Звуковые события (собственные OGG; никакой пустой регистрации)
- `poloz_ambient_rumble`: низкое рокотание под землёй, редкие (каждые 12–20 сек) звуки скольжения тяжёлой чешуи; радиус 48–80 блоков.
- `poloz_surface_roar`: ответный длинный 2.0–2.5 сек низкий рёв при появлении из земли/воды; громкий, но без клиппинга.
- `poloz_move_crush`: смешение глубокого грохота, хруста дерева и сыплющихся камней при реальном разрушении; не более 1 активного loop в зоне для пользователя и не более 1 transient каждые 0.7 sec.
- `poloz_armor_deflect`: сухой тяжёлый удар по чешуе (малой громкости на дистанции >20 блоков).
- `poloz_weakspot_hit`: глубокий болезненный шипящий рёв плюс вспышка трещины; не на каждый tick.
- `poloz_tail_slam`: физический массивный каменный удар ~1.5 sec.
- `poloz_mor_rain`: воздушный рёв + свист летящих сгустков, один sound event per salvo.
- `poloz_burrow` / `poloz_emerge`: нарастающий подземный гул; emergence более резкий и громкий.
- `poloz_phase2_cracks`: звук раскалывающегося каменного панциря и багровой энергии, 3 сек.
- `poloz_phase3_roar`: финальный протяжный яростный ответ, 2 сек.
- `poloz_minion_call`: гортанный зов 1.2 sec.
- `poloz_death`: тяжёлый обваливающийся рёв 5 sec с угасанием багрового свечения.
Все ключи регистрировать по стандартам текущего ModSounds. Свои записанные/синтезированные звуки OGG моно. Звук рога отдельно в `horn/02_SOUND_DESIGN.md`.

## Правила эффектов
- Красный мор на поверхности тела — мелкие квадратные пиксельные particles; умеренно в фазе I, больше во II и III.
- За каждым движением ползущего тела красные землистые частицы появляются **только при реальном соприкосновении** с поверхностью; над водой — багровые пузырьки/всплески; не генерировать блоки в воде.
- Шрам I фазы: 2–4 медленно пульсирующие красные частички вокруг каждого из 3 чётких пятен, distinct от неуязвимой брони.
- На 70% за 3 сек вдоль каждой пластины открывается много маленьких трещин; красный glow на новых слабых местах; после этого вся модель действительно hurt-able.
- На <30% яркость +25%, несколько крупных темно-красных волн вдоль тела (одна волна раз в 8 сек), но не полная непрерывная экранная заливка.
- Рука/камера: локальная лёгкая тряска на 0.25–0.4 sec от ударов, максимум 0.8°. Config toggle `polozCameraShake=true` client; respect reduced effects.

## Привязка движения к hitboxes
Клиент не должен рисовать тело в одном месте и попадание в другом. Положение каждого render segment интерполирует реальные server track points с допустимым рассогласованием <=0.5 блока. На телепорт/перезаход корректно reinit history, не рисовать 40 блоков, вытянутых к 0,0,0.

## Minecraft стиль
Всё синтезировать/рисовать как низкополигональную блочную анимацию. Не использовать плавные реалистичные кости/алебастровые мышцы, киношные motion blur shaders, невоспроизводимые в ванильном NeoForge.
