# Версии, зависимости, границы интеграции

## 1.8.3.1
Самостоятельно добавляет блоки/опасные поверхности и обратимое в коде сопоставление исходных состояний -> новых. Может быть проверено отдельно без Полоза.

## 1.8.3.2
Зависит от реально реализованных **1.8.1 «Моровые»** и **1.8.2 «Высшие моровые»**:
- Моровые Леший, Полудница, Кикимора, Огненный змей;
- Высшее моровое Лихо, Высший моровой Овинник;
- единое состояние мора, взаимоотношения/моровые варианты;
- их готовность выдавать необходимые трофеи (если дроп отсутствует, добавить адресно **только** loot hooks в этих сущностях).

Если рабочий `main` всё ещё до 1.8.1/1.8.2: НЕ выдавать полной реализации Полоза за успешно законченную. Допустимо выполнить и отгейтить 1.8.3.1, подготовить код независимых частей второй фазы без фиктивных сущностей, затем в отчёте явно указать блокирующие зависимости. Не переписывать 1.8.1/1.8.2 «для вида», не менять широкий scope. Если зависимости доступны — пройти весь объём данного архива без дополнительных согласований.

- `AGENTS.md`: сохранить mod ID `slavicmyths`, прежние registry IDs и существующие сохранения.

## Полоз / терминология
Один новый мировой босс **«Великий Полоз»** (не «Змей Горыныч», не «Огненный змей»). Фольклорная основа — уральский сказовый образ гигантского подземного змея, игровая форма и механика мора авторские. Рабочий registry ID: `slavicmyths:great_poloz` (если реестр ещё не содержит схожий ID). Без крыльев и без внешности стандартного дракона.

## Нет утверждённого отдельного изображения модели Полоза
Не притворяться, будто приложен третий референс. Его точная игровая геометрия, палитра, габариты и анимации жёстко заданы в `phase_1832/poloz/01_MODEL_AND_TEXTURES.md`. ДВА утверждённых изображения относятся к материалам и рогу. Для будущего визуального утверждения отдельная перерисовка Полоза возможна после задачи; сейчас модель должна строго следовать геометрическим параметрам ТЗ, не искать стоковые драконы.
