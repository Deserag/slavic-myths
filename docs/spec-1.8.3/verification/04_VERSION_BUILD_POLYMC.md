# Версия, сборка, интеграция в PolyMC — обязательная финальная часть

## Перед изменениями
- Убедиться в правильной локальной рабочей копии `Deserag/slavic-myths`, актуальной `main`, `git status --short`. Не делать reset, clean чужих незакоммиченных файлов, commit/push автоматически.
- Minecraft 1.21.1, NeoForge 21.1.255 (или фактическая установленная совместимая версия проекта), JDK 21; не менять runtime platform.
- Проверить точные пути real PolyMC instance из существующей `packaging`/`release`/локального окружения, а не считать гарантированным `C:/...`. Из прежнего контекста профиль мог называться `Slavic-Myths-1.21.1-Testing` — проверить по факту.

## Сборка
1. После реализации 1.8.3.1: корректно установить mod version 1.8.3.1, выполнить `gradlew.bat clean build` (или `./gradlew clean build` под Linux) с `JAVA_HOME` на существующий **JDK21**. Отметить gates, не выдавать визуальную проверку за выполненную.
2. После реализации 1.8.3.2: mod version 1.8.3.2, повторить все automated verification и production assets check, `clean build`, проверить `build/libs/slavicmyths-1.8.3.2.jar` либо фактическое имя produced jar. Убедиться, что нет runtime-missing sound/resource/texture.
3. Обновить только относящиеся разделы `CHANGELOG`, `docs/PROJECT_STATUS`, `docs/ROADMAP`, `docs/ARCHITECTURE`, release notes; не перечислять старые работы как свои.

## PolyMC
- Установить **финальный успешно собранный JAR 1.8.3.2** в фактически найденный профиль **1.21.1 тестового мода**, НЕ в старый 1.16.5.
- Перед заменой сделать копию текущего JAR мода с датой/версией в `backup/`, удалить из `mods` только предыдущие `slavicmyths-*.jar`, остальные моды и настройки не трогать. Новый JAR положить в `mods`.
- Сверить sha256 установленного JAR с результатом build. В `mods` ровно один JAR `slavicmyths`.
- **Запрещено открывать/запускать PolyMC, Minecraft или `runClient`**. Если тестовый профиль в среде Codex не доступен, дать точный JAR path и честно сообщить «PolyMC не установлен» (не выдумывать выполнение).

## Минимальный итоговый отчёт (на русском)
- Выполнено 1.8.3.1 / 1.8.3.2 по пунктам.
- Краткий реестр реальных изменённых файлов, реальная ветка, production JAR path/version/SHA256.
- Build + resource gates (+ headless, если были) с фактическими результатами.
- Указан **точный** PolyMC instance, установка / причина отсутствия, сохранённая предыдущая версия.
- Честно: «Minecraft клиент не запускался, визуал и звук требуют ручной проверки». Нет обещаний «проверено в игре», если игры не было.
