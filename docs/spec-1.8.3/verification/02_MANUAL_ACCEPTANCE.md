# Ручная приёмка игроком — краткий чеклист после установки JAR

- [ ] В новом/резервном тестовом мире обычные 12 ванильных блоков без изменений.
- [ ] `/sm test mor_block` меняет только нужный конкретный блок; textures точно по ref, block item in creative.
- [ ] Поражённая почва, камень, дерево и листва дают ожидаемые Slowness/Weakness/damage в нужное время; не убивают в Creative.
- [ ] Дропы basic Mor, Eye/Heart from high bosses; рецепт 3×3 со **СТАРЫМ ванильным козьим рогом в центре**.
- [ ] Рог выглядит как на референсе в инвентаре и руке; 9-секундный страшный громкий, но не клиппирующий звук.
- [ ] У действующего капища двойное подтверждение/3-сек hold предупреждает о необратимых разрушениях.
- [ ] Полоз появляется 200–300 блоков от ритуала, указатель на роге помогает найти, красный всполох видим при достаточной дальности.
- [ ] Полоз 35–45 блоков длиной, бескрылый золотисто-каменный змей с багровыми шрамами; движения и сегменты цельные.
- [ ] В фазе 1 броня не пробивается, голова/хвост/3 шрама пробиваются. В фазе 2 шрамы открываются, можно бить всё тело.
- [ ] Полоз ломает обычные деревья/постройки/блоки, оставляет заражение **после смерти**, вокруг нет «подземелья» или созданной арены.
- [ ] Вода: появляется в озере/реке, умеет выползти, не застревает.
- [ ] Богатыри могут быть вместе; зомби/скелеты/дружинники дерутся с Полозом, жители убегают; первая фаза ordinary mobs часто бьют броню.
- [ ] Все 6 активных навыков работают с телеграфом, нет невозможной постоянной смерти от каждой атаки.
- [ ] В конце один набор трофеев + запись в Книге сказаний; другие моровые живут по старым правилам.
- [ ] Перезаход в мир не удаляет Полоза и не удваивает его/лут; пришедший позднее второй игрок видит правильное событие.
- [ ] PolyMC обновлён, старые JARы вынуты из `mods`, остальные моды/миры не тронуты.

**Огромный риск:** Полоз уничтожает постройки реально. Тестировать только на резервной копии мира! Реализация не должна маскировать этот риск.
