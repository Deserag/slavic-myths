## Обязательная точечная процедура
1. `git status --short`, текущий номер версии и `AGENTS.md` — один раз; дальше в docs читать **только необходимые разделы** по регистрам, ритуалам и состоянию моровых, текущему `main`.
2. Найти реальные регистрации и базовые имена 1.8.1/1.8.2 по узким строкам `mor`, `likho`, `ovinnik`, `kapishche`, `fairy_tale` (русские аналоги где есть). Сохранить ID и совместимость сохранений.
3. Новые модули — маленькие и изолированные: группа инфицированных блоков/таблица преобразований; единственный менеджер события Полоза (SavedData); entity Полоза и сегменты, рог/предмет, звук, частицы; минимальные target/flee-goal хуки; datagen/ресурсы. Следовать фактической архитектуре, не навязывать свои пакеты.
4. Сначала 1.8.3.1, компиляция/ресурсы/тесты, затем 1.8.3.2. При несоответствии базовой версии остановить только зависимый модуль, НЕ создавать фиктивные заглушки и НЕ переписывать прежние версии.
5. Последовательные тесты: unit/structure/network/loot/recipe, затем `gradlew.bat clean build` с JDK 21, затем Production JAR inspection, затем установка в PolyMC; отчёт по каждому gate.

## Точное правило о vanilla
- Не менять vanilla `minecraft:*` block registry и не подменять текстуры vanilla resource pack глобально.
- Изменять конкретные позиции **в мире** путём замены на соответствующий блок `slavicmyths:mor_*`, поддерживающий форму/прочность/теги/физические свойства исходного. **Только внешний вид и локальные эффекты отличны** от прототипа; сохранённый мир вне зоны должен выглядеть/работать как прежде.
- 1.8.2: если реализована временная заражённая земля от Лиха/Овинника, НЕ превращать её поведение в постоянное без причины; расширить общий визуальный язык, но постоянное block-conversion действует только для Полоза.

## Производительность и безопасность данных
- Всегда server authoritative. Конфигурация действий мира по очереди, лимиты `verification/03_PERFORMANCE_GATES.md`.
- Нельзя терять NBT/инвентари Tile/BlockEntity незаметно; разрешённое уничтожение контейнеров должно выдать их содержимое *ровно один раз* vanilla-путём.
- Предупреждение до призыва обязательно: разрушение мира реально и сохраняется.
- Никакого server-wide постоянного заражения без активного Полоза. Мир не должен «случайно» погибнуть из-за оставленного tick-сервиса.
