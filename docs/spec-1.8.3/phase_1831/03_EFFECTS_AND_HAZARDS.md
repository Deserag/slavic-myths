# 1.8.3.1 — последствия контакта с поражёнными блоками

## Триггер и ограничения
- Проверять **только живых игроков** раз в 20 тиков (1 сек), через окружение игрока. На сервере. Не обходить весь мир, не искать заражённые блоки в каждом чанке.
- Ноги: блок под ступнями и на уровне ног. «Рядом»: в пределах 1.5 блока до видимой заражённой поверхности (малый радиус для дерева/листвы/стены). Не накладывать сквозь толстые стены/потолки; считать только доступные позиции с line-of-sight до поражённой грани или физическим соприкосновением.
- 3 сек непрерывного контакта для дебафа, 5 сек для периодического повреждения; при уходе из зоны через 1 сек накопитель обнуляется; не наказывать за краткий прыжок.
- Статус только уровень **I**, эффект обновляется на 40 тиков не чаще раза в 20 тиков, не суммируется с собой, не удаляет более сильный эффект другого источника.
- Если рядом несколько типов, выбирается худший **один** тип постепенного урона, урон max 1 HP (полсердца) / 5 секунд, не суммировать каждый блок/тик.
- Режимы Creative/Spectator не получают урон/дебафы; gamerule/серверный config `morBlocksHurtPlayers=true` по умолчанию, отключает только механический урон (визуал остаётся). Другие мирные существа пока не теряют здоровье просто от статичных блоков, не превращать мир в бесконечную ферму мобов.

## Дополнительно
- Damage source мода `mor_block` с русским death-message; никакой silent generic / undefined damage source. Проход на грани объединённых заражённых зон не должен сбрасывать 3-секундный прогресс искусственно.
- Не применять эффект от заражённого блока через полный solid блок.
- При игре нескольких игроков каждый получает **только свой** счётчик контакта.
- В бою с Полозом у «живого морового следа» свои более сильные, строго описанные эффекты; не суммировать сразу два полных периодических урона от земли и следа, использовать максимум, а не сумму.
