# SLAVIC MYTHS 1.8.3 — РЕАЛИЗАЦИОННОЕ ТЗ ДЛЯ CODEX
**Два последовательных патча:** 1.8.3.1 «Поражённая земля» и 1.8.3.2 «Пробуждение Великого Полоза». Minecraft 1.21.1 / NeoForge / Java 21. Мод `slavicmyths`. Целевая кодовая база — фактическая актуальная `main` репозитория `Deserag/slavic-myths` с сохранением всех текущих изменений пользователя.

## ПРИОРИТЕТНЫЕ ПРИКАЗЫ ПЕРЕД ЧТЕНИЕМ ОСТАЛЬНОГО
1. **ЭТО ЗАДАНИЕ НА РЕАЛИЗАЦИЮ, НЕ НА ПОДГОТОВКУ ПЛАНА.** Реализовать обе части по очереди, проверить обе, собрать production JAR, обновить тестовый PolyMC без открытия клиента.
2. **ЭКОНОМИЯ ТОКЕНОВ И ВРЕМЕНИ.** Запрет полного анализа репозитория, всей Git-истории, глобального поиска сущностей, сканирования всех ассетов и постороннего рефакторинга. Единожды `git status --short`, затем адресно проверить существующие Mor/моровые, Лихо, Овинника, 1.8.1–1.8.2, капища/ритуальные взаимодействия, реестры/AI/рендер/звук, Книгу сказаний, конфигурации сборки и ресурсы. Прочитать `AGENTS.md` и только относящиеся к задаче разделы `docs/PROJECT_STATUS.md`, `docs/ROADMAP.md`, `docs/ARCHITECTURE.md`, чтобы выполнить правила репозитория. Если класс/метод не подтверждён кодом, не выдумывать API.
3. **НЕТ ОТДЕЛЬНОЙ АРЕНЫ И ГЕНЕРАЦИИ ПОДЗЕМЕЛЬЯ.** Бой происходит в СУЩЕСТВУЮЩЕМ мире; любой лес, берег, поле, деревня или постройки игроков могут стать местом катастрофы. Рог лишь инициирует событие у уже существующего капища; Полоз появляется на расстоянии 200–300 блоков и перемещается.
4. **Настоящая катастрофа**: Полоз разрушает препятствия/постройки, заражает уцелевшие обычные блоки и оставляет последствия даже после победы; никакого автоматического отката ландшафта. Но не трогать ванильные registry/глобальные текстуры, не разрушать bedrock/неисправимые служебные блоки, не дублировать содержимое контейнеров, не нагружать весь мир бесконтрольно.
5. **ОБЯЗАТЕЛЬНЫЕ ПРИЛОЖЕННЫЕ РЕФЕРЕНСЫ**: `refs/01_approved_corrupted_vanilla_blocks.png` и `refs/02_approved_morovoy_horn_recipe_and_use.png`. Это утверждённые пользователем референсы: воспроизводить по ним Minecraft-облик текстур блоков и рога, положение ингредиентов 3×3, анимационную идею и эффекты. Не заменять реалистичным 3D/чужими модами. Текстовое ТЗ ниже конкретизирует фактические численные правила, надписи на картинках могут быть стилизованными.
6. **РЕЛИЗ:** промежуточный билд 1.8.3.1 для блоков, итоговый JAR 1.8.3.2 с блоками, рогом и боссом. Обновить тестовый профиль PolyMC соответствующим итоговым JAR; не запускать игру, `runClient`, PolyMC, окно/UI. Пользователь тестирует сам.
7. **Русская локализация обязательна**: названия, lore, уведомления, Книга сказаний, подсказки. `en_us` — тоже, если проект поддерживает.
8. **НЕ ДОБАВЛЯТЬ** новые измерения, Ад, Змея Горыныча, «хворь души», новую арену, побочные квесты/предметы без рецептов и применения, декоративные mock-модели вместо рабочих, отдельные яйца призыва.
