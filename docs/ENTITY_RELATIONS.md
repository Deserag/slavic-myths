## Контракт

CombatTargeting.relation/canAttack разделяет физическую допустимость и инициативу. Сначала союз/owner/team, затем жизнь/мир/PvP/creative/spectator/неуязвимость, затем состояния и directed intent. Принадлежность читается из действующих owner UUID, scoreboard, encounter и ChudCity, без нового persistent ledger. Команда помощника наследуется от игрока; offline lookup профиля только локальный. Призыв не обходит запрет PvP. Native player projectile сохраняет разрешённый scoreboard friendly fire; навыки/питомцы союзников не выбирают.

| Контекст | Значение |
|---|---|
| ACQUIRE | инициатива против допустимого hostile, без hostile↔hostile войны |
| RETALIATION | адресная ответная агрессия |
| SETTLEMENT | hostile либо конкретный агрессор поселения, спокойный NeutralMob не общая цель |
| DIRECT / PROJECTILE / AREA / CONTROL | только допуск, выбор цели остаётся вызывающему контроллеру |
| NATIVE_HUNT | существующий сценарий охоты, в том числе Monster→житель; не новый AI |
| NATIVE_DAMAGE | действующий физический hurt-контракт, без превращения сюжетных NPC в бессмертных; отзыв/восстановление героев защищены |

STORY_PROTECTED ограничивает самовольное вмешательство NPC, но не даёт общей неуязвимости игроку. Native boss/encounter проверки остаются последним владельцем фаз, целей и допустимого урона.

## Чудь и ограничение работы

Guard acquisition ищет LivingEntity в пределах 24, а не только Monster. Локальные guard nodes одного поселения обновляются раз в 40 тиков с bounded запросом 32; защита ограничена 48 от дома/узла. Погоня 200 тиков, возврат 100, задержанный удар повторно проверяет цель/дистанцию/LOS. Нативный home restriction для стража 48 (гражданские 10), иначе vanilla TargetGoal отбрасывал допустимую групповую защиту. Адресная тревога действует 1200 тиков, распространяется только рядом и внутри поселения. Это статические пределы, **не измеренный MSPT**.
