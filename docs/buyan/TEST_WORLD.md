# Буян — отдельный водный плоский тестовый мир

Ветка: `feature/buyan-port-buildings-20261116`; базовая ветка: `fix/ships-3-4-wip`.

## Запуск
1. Собрать мод с Java 21: `gradlew.bat clean build`.
2. Установить свежий JAR именно из этой сборки в изолированный тестовый профиль Minecraft 1.21.1 / NeoForge.
3. Создать **новый** мир, тип мира **«Буян — водный плоский мир»** (в английском интерфейсе: **Buyan — Ocean Test World**).
4. При первом входе генератор в мире распознаёт точные слои: bedrock ×1, stone ×16, sand ×2, water ×12; **только** для такого Overworld. Он создаёт остров у X=0, Z=0 и телепортирует игрока на безопасную площадку. При повторном входе остров не перестраивается.
5. Для ручной проверки на таком же мире: `/slavicmyths dev generate buyan island`. Эта команда не перестраивает уже готовый остров. Требуются права оператора.

В тестовом острове размещаются: дом рыбака с кроватью и предметами интерьера, лавка с прилавком и коптильней, склад с ёмкостями хранения, основная и малая пристани, дорожки. Диаметр территории около 90 блоков, плоский океан вокруг.

## Ограничения
- Это **изолированный тестовый остров**, а не интеграция в естественную генерацию исторического/сюжетного острова Буян.
- Автогенерация не запускается на обычных мирах и обычных Superflat-мирах с другим набором слоёв.
- Ручные тестовые команды отдельных зданий доступны в форме `/slavicmyths dev generate buyan house|market|warehouse|main_pier|small_pier`; выполняются только для проверки и не формируют полноценный остров.
- Не мержить эту ветку, пока не выполнены сборка `clean build`, запуск нового мира, проверка входов в помещения, сундуков/печей, кровати и проверки после перезахода.
- Генерация мира выполняется синхронно один раз в игровом потоке; измерить задержку на первом входе и при необходимости перевести создание на поэтапное исполнение.
