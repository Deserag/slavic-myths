Ничто не удалено из истории Git: OGG доступны как исходная контрольная версия, но события больше не ссылаются на них. Старый JAR PolyMC пользователя **не обновлён** через эти изменения.

Это **не** подтверждение качества остальных OGG. Иная частая проблема — reuse vanila `ravager.roar` (17 событий), `player.attack.sweep` (16); заменить содержательно в #60, а не автоматически заглушить всю игру.

## Страховка от восстановления запрещённого аудио

- `tools/water_070.py` теперь не создаёт синтетические OGG воды.
- `tools/generate_spirits.py` не создаёт старые голоса Домового/Лешего и больше не перезаписывает глобальный `sounds.json`.
- Старые `tools/nochnitsa_audio.py`, `tools/pesigolovtsy_audio.py`, `tools/firebird_audio.py` прекращают выполнение с ошибкой вместо тихого перезаписывания некачественных образцов.
- `RusalkaSound.java` не запускает старый 8-секундный синтетический loop без новой согласованной песни.
- Gradle `processResources` зависит от `verifyRejectedVoiceQuarantine`: сборка должна **упасть**, если одно из отвергнутых событий снова ссылается на любой звук без адресного снятия блокировки после согласования новых OGG.
- Реальный Gradle build/actual game hearing этой правки **не запускались** при обновлении через GitHub API. Проверить офлайн на машине Codex и вручную в PolyMC у владельца.

## Как ВЕРНУТЬ голосовые события

1. Изготовить различимые оригинальные записи с правами: Русалка — настоящий женский 3–5-нотный мотив, разные эмоции; Водяной — артикулированный влажный низкий голос и реальные водные foley; лесные — кора/ткань/листья; Песиголовцы — живые собачьи голоса и оригинальные foley и т. д.
2. Owner сначала прослушивает `OLD/NEW` вне Minecraft. Пустота, синусоида, измененный pitch, повтор из другой роли не принимаются.
3. При принятии конкретного события вместе с новыми файлами и его `sounds.json` записью **точечно** снять именно его из build gate списка, проверить `ModSounds`, ru/en subtitles, JAR content, event callsites.
4. Обновить фактический тестовый PolyMC через файловый installer с backup/hash/version; владелец сам запускает Minecraft, слушает и принимает. **До этого #49/#59/#60 остаются открытыми**.
5. Не строить следующий «готовый» моб, оставив критичную часть озвучки открытой, и не закрывать задания самостоятельно: `AGENTS.md`.

**Важный UX эффект:** пока аудио не заменено, часть существ будет молчать в указаных событиях. Это сознательное временное избавление от неприемлемого звука; *качественная озвучка ещё не реализована*.
