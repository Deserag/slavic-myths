# SLAVIC MYTHS 0.8.1 — БОЛЬШОЙ РАЗБОЙНИЧИЙ СТАН

Продолжай разработку СУЩЕСТВУЮЩЕГО проекта Slavic Myths в текущем рабочем чате.

Техническая база проекта остаётся прежней:

- Minecraft 1.16.5
- Forge 36.2.42
- Java 8
- Mod ID: `slavicmyths`
- текущая рабочая версия развивается после `0.8.0` и `0.8.0.1`

## КРИТИЧЕСКОЕ ПРАВИЛО РАБОТЫ

СРАЗУ переходи к реализации.

Не пересказывай ТЗ.
Не составляй длинный план.
Не проводи повторный полный аудит проекта.
Не перечитывай весь repository.
Не исследуй заново уже существующие системы, если достаточно найти конкретную реализацию через targeted search.

Работа идёт в том же проекте и в продолжение уже выполненных версий.

Используй существующую архитектуру.

Основной принцип:

**найти нужное → понять существующий pattern → изменить/расширить → перейти дальше.**

Пользователь сам запустит Minecraft и визуально проверит результат.

Не трать токены на автоматические игровые запуски.

# 1. ЦЕЛЬ 0.8.1

Создать полноценный **разбойничий стан III уровня**.

Это крупнейшее поселение разбойников на текущем этапе развития мода.

Это уже не временный лагерь.

Это постоянное укреплённое поселение, где разбойники:

- живут;
- спят;
- едят;
- тренируются;
- хранят награбленное;
- ремонтируют оружие;
- держат лошадей;
- охраняют пленников;
- патрулируют территорию;
- защищают укрепления.

Локация должна выглядеть ОБЖИТОЙ.

Не создавать набор пустых деревянных коробок.

# 2. СУЩЕСТВУЮЩАЯ ИЕРАРХИЯ

Сохраняем три уровня.

## I уровень

Малая стоянка.

Примерно:

- 2–3 шатра/навеса;
- костёр;
- несколько разбойников.

Без Атамана.

## II уровень

Укреплённый лагерь.

Есть постоянные строения и защита.

Есть:

**1 Атаман.**

Эта механика уже существует — не переделывать без необходимости.

## III уровень — НОВОЕ В 0.8.1

Большой разбойничий стан.

Есть:

- крупный частокол;
- ворота;
- башни;
- казармы;
- кузница;
- склад;
- кухня;
- конюшня;
- тюрьма;
- дома/хозяйственные здания;
- два Атамана;
- центральный двор;
- Соловьиный двор;
- секретные помещения;
- полноценная система тревоги.

# 5. РАСПОЛОЖЕНИЕ СОЛОВЬИНОГО ДВОРА

Не размещать сразу за воротами.

- ближе к задней части поселения;
- либо на небольшом естественном возвышении.

# 6. ГЛАВНОЕ ДЕРЕВО

В центре Соловьиного двора находится большое старое дерево.

Предпочтительно:

- крупная сосна;
- либо старый дуб в зависимости от layout.

НЕ использовать обычное маленькое vanilla tree.

Дерево должно быть заметной частью силуэта поселения.

---

# 7. ПОМОСТ СОЛОВЬЯ

На высоте примерно:

**6–9 блоков**

среди крупных ветвей находится деревянный помост.

Помост:

- грубо построен;
- частично обхватывает ствол;
- поддерживается балками;
- имеет небольшой навес;
- имеет лестницу/переходы.

В 0.8.1 он пуст.

# 107. ГЛАВНОЕ ПРАВИЛО ПРИ НЕХВАТКЕ БЮДЖЕТА

Лучше оставить:

`60% требований DONE + рабочий JAR`

чем:

`90% кода написано + проект не собирается`.

НИКОГДА не заканчивать проход намеренно со сломанной сборкой, если остаётся возможность вернуть её в рабочее состояние.

# 108. PARTIAL — ЭТО НОРМАЛЬНО

Если токены заканчиваются:

НЕ притворяться, что задача DONE.

Поставить:

`PARTIAL`

и точно описать:

- что реализовано;
- что не реализовано;
- откуда продолжать.

# 109. НЕ ТРАТИТЬ ПОСЛЕДНИЕ ТОКЕНЫ НА ОТЧЁТ

При приближении лимита приоритет:

**рабочий код → build → JAR → PolyMC → checklist/continue → короткий ответ.**

Не писать пользователю длинное объяснение.

# 110. POLYMC — ОБЯЗАТЕЛЬНО

После каждого успешного завершённого прохода:

собрать production JAR.

Найти существующий Slavic Myths PolyMC instance.

Удалить ТОЛЬКО предыдущие:

`slavicmyths-*.jar`

из его `mods`.

Другие моды НЕ трогать.

Скопировать новый JAR.

В папке должна остаться одна актуальная версия Slavic Myths.

Minecraft НЕ запускать.

# 113. GIT

Не выполнять destructive git operations.

Не reset чужих изменений.

Не удалять пользовательские файлы.

Подготовить repository так, чтобы пользователь мог самостоятельно:

`git add`

`git commit`

`git push`

и вечером продолжить на другом ПК.

Если git identity не настроена — НЕ тратить время на попытки commit.

Пользователь сам выполнит commit.

# 116. КРИТЕРИЙ КАЧЕСТВА 0.8.1

При ручном запуске игрок должен увидеть не:

**«большую Minecraft-деревню с разбойниками»**

и не:

**«огромный квадратный лагерь из одинаковых домов».**

Он должен увидеть:

**укреплённое поселение банды, которое существует независимо от игрока.**

В нём должны читаться:

- оборона;
- жилая часть;
- командование;
- ремесло;
- хранение;
- лошади;
- пленники;
- тренировки;
- дороги;
- хозяйственная деятельность;
- и отдельная странная внутренняя территория, явно подготовленная для кого-то значительно опаснее обычных Атаманов.

При этом Соловья-разбойника в 0.8.1 НЕТ.

Его полноценная реализация начинается только в 0.8.2.
