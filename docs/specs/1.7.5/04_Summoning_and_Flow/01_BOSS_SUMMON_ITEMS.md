# Boss summon items

## Required items
1. Kalin-tsar Battle Seal (main repeatable encounter starter)
   - reusable / non-consumable preferred
   - activates only on suitable open terrain
2. Kalin-tsar Spawn Egg (creative / test use)
3. Optional Horse Spawn Egg (creative test use only)

## Visual design guidance
Battle Seal should look like a heavy royal military token:
- dark metal base
- crimson enamel or cloth insert
- war emblem / command symbol
- not mystical witch-like iconography

## Use restrictions
- Cannot start encounter inside cramped unsuitable terrain
- Warn player if two bogatyrs are not selected / unlocked
