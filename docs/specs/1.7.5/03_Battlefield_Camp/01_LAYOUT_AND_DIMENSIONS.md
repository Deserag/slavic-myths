# Battlefield camp — layout and dimensions

## Type
A compact temporary military encampment / war camp generated or placed as a scripted encounter.
No large persistent fortress system.

## Size
- Whole camp: about 65 x 65 blocks
- Core combat circle / central arena: about 15 x 15 blocks in front of the main command tent
- Several side lanes for troop entry

## Required elements
- Main royal tent of Kalin-tsar
- Smaller soldier tents
- Banner lines
- Wooden palisade and 2–4 watch towers
- Fires / braziers
- Weapon racks / supply props
- Clearly marked edge spawn points for reinforcements

## Navigation requirements
- Mounted charge must have a clean path
- Two heroes + player + summoned troops must have enough space
- Avoid over-cluttering the center
