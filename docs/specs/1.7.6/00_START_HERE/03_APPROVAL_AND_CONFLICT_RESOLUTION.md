# Reference priority, explicit interpretations and non-invention policy

Reference priority: (1) user's last approved written changes; (2) attached three approved image boards; (3) per-item mechanical and texture documents; (4) existing repo API only for implementation details. If a sheet contains art typo or old mechanic, use written specification.

Locked shield: factor 1.5 for reflected original attack; shield block protects player normally. Reflected damage is based on damage that would have landed after player armor/effects but before shield. Reflection must NOT call again on block/reflect callbacks; one source per attack. No implicit cap replacing factor.

Ring factor was not numerically approved by user, only a stronger multiplier. Proposal selected for implementation is 1.75x on one direct post-block melee strike. Keep one named constant so balancing may adjust. Avoid constant always-on bonus.

Previous discussion: no natural new ore veins, only boss trophy crafting materials. No new loot boxes and no additional item types outside 19 count. Use native JEI support if already present.

A reference rune board may visually depict effects differently than finalized text. Detailed rune files govern actual gameplay. The 64x64 icons are starter art but must retain approved silhouette and colors. Armor pieces require actual wearable geometry/texture compatible with current renderer in addition to item icon.

If earlier bosses have victory flags with different names, use a tiny adapter to the real flags rather than create a new, incompatible parallel quest progression system. If no old flag exists, do not fabricate retroactive victories: implement evidence collection from prior quest completion and document limitation; never silently give out rewards.
