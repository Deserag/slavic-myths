# Reward economy and upgrade policies

- 5 rune stones: unique boss-identified rare rewards, associated Runes are unstackable or existing rune stack limit.
- 4 hero gifts: unique once-only, rarity highest appropriate in existing creative inventory; no other hero gifts in this patch.
- 5 boss materials: stacks up to 64, their rarity comes from legitimate boss encounters; no new mineable ore.
- 5 trophy equipments: wearable or sword, stack size 1; reuse existing armor durability and enchantment compatibility frameworks.
- Completion grants precise material count in respective source doc; on repeat runs modest materials +15% chance rune. This preserves repeat play but prevents infinite first-clear farms.
- Boss loot must not be generated just because a player uses creative spawn egg or debug command. Do not remove existing vanilla/other boss loot unless exact conflict.
- Default first-clear gifts are distributed through story completion/reward retrieval, not custom recipe requiring grind.
- Crafted equipment is designed as sidegrades: shields can reflect but only on successful timed block, ring requires counter timing, armor sacrifices chest slot, Skim necklace competes with Finist amulet, belt consumes belt slot, saber excels at crowds but should not beat every single-target weapon.
- Any protective/survival effect should be displayed with actual values in tooltip and JEI so older runes' unexplained effects problem is not repeated.
