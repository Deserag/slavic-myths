# СТАРТОВЫЙ ПРОМПТ CODEX — 1.9.3 «Пробуждение древних сил»

Реализуй в **текущем существующем** Minecraft Forge проекте `slavicmyths` полноценный патч **1.9.3** по этому ZIP как задачу программирования, worldgen, assets, механик, рецептов, лута, эффектов, звуков, интеграции и компиляции. Перед редактированием прочитай весь `00_START_HERE`, `01_SPEC`, `03_IMPLEMENTATION`, `04_QA`, затем открой изображения `02_REFERENCES/approved_full` и соответствующие crops. Изучай только релевантные части кода (worldgen, registry, 1.8 mor, Book of Tales, loot, items, PolyMC). **Не выполнять повторный полный аудит всего репозитория**. Не придумывай несуществующие API. Ориентир известной конфигурации: Minecraft 1.16.5 / Forge 36.2.42 / Java 8, но фактический build config в репозитории приоритетнее.

### Что создать
1. **Святилище незатухающего огня** — уникальный наземный каменно-деревянный ансамбль ~80×76 блоков по `01_SANCTUARY_UNFADING_FIRE_APPROVED.png`: вход с резными воротами, кольцевой двор, центральная слабогорящая огромная чаша, боковые алтари, древние идолы и символы, склад, запечатанный зал будущей реликвии. Тёплый огонь/дерево/камень, местами копоть и ограниченное багровое заражение; пламя сдерживало мор и теперь ослабло. Пользователь может восстановить основной огонь локальным ритуалом на Священном угле, получив небольшой разовый бонус/открытие бокового тайника **но не самого сюжетного амулета**.
2. **Обитель чистого источника** — уникальное полуподземное святилище ~96×86 блоков по `02_ABODE_PURE_SPRING_APPROVED.png`: входные руины, безопасный спуск, зал подземного родника, водные каналы, очищающие бассейны, ритуальный склад, запечатанный зал второй реликвии. Палитра холодного камня, прозрачная вода, голубые отсветы, зелень, фонари, локальные багровые/чёрные заражённые участки. Несколько бассейнов можно локально очистить, получив доступ к **неосновным** боковым тайникам. Не создавать глобальные свойства для всех водных блоков.
3. Полностью рабочие тематические предметы, рецепты и лут (описаны в `01_SPEC/08` и `09`), книга сказаний/достижения, собственные звуки и деликатные анимации окружения. Все предметы доступны в обычном прохождении; реликтовые комнаты сейчас **недоступны**.
4. Worldgen на сервере только Overworld, структурный сундук/контейнер без дюпа, multiplayer/старые миры/dedicated server, настраиваемая редкость, безопасные спавн/вода/повороты и оптимизация.
5. Реальные NBT/шаблоны или соответствующая архитектура программной генерации, модели/blockstates/текстуры 16×/32× пикселей, sounds.json+аудиофайлы, lang ru_ru/en_us, loot tables/recipes/advancements; не только README.

### Граница версий
В 1.9.4 будут **два мини-босса-хранителя** и **две реально выдаваемые детали амулета** — по одной в каждой постройке, персонально нескольким участникам. В 1.9.3 делаем места для будущих encounters, надежно закрытые помещения и структурные hooks, **не** вставляем готового босса, не выдаём деталь ни обычным сундуком, ни крафтом. Победа над заражённым Лихом потребуется для конечного крафта амулета входа на Змеиную гору позже. Этот амулет **не** «Оберег двух зим» Морозко/Карачуна для Ада.
