# Slavic Myths — пакет ТЗ 1.9.3 «Две древние святыни»

**Назначение**: самостоятельное техническое задание для Codex для создания двух естественно генерируемых строений Overworld по согласованным Minecraft-референсам. Это **архитектурный и исследовательский патч**, не патч с мини-боссами.

## Как читать
1. `00_START_HERE/01_NON_NEGOTIABLE_RULES.md` и `02_CODEX_START_PROMPT.md`.
2. Все файлы `01_SPEC/` по порядку.
3. Изучить `02_REFERENCES/approved_full/*.png`, затем `crops/*.png` и рабочие схемы `blueprints/*.png`.
4. `03_IMPLEMENTATION/` — точечное подключение, порядок задач, build/PolyMC.
5. `04_QA/` — тесты, критерии приёмки и отчёт.

**Два одобренных визуальных эталона:**
- `01_SANCTUARY_UNFADING_FIRE_APPROVED.png` — Святилище незатухающего огня.
- `02_ABODE_PURE_SPRING_APPROVED.png` — Обитель чистого источника.

**Приоритет источников:** последнее пользовательское согласование → этот текст ТЗ для механики/параметров → изображения для архитектуры/материалов/цветов → рабочие схемы для размеров. Подписи внутри изображений не являются обязательной игровой логикой. На художественных референсах видны кинематографические эффекты, не требующие шейдеров. Схемы планировки — ориентир размеров, **не точные схемы существующей игры**.

Папка **не содержит исходники мода, готовые `.nbt`, `.ogg` или production JAR**: Codex создаёт реальные файлы в текущем репозитории и отчитывается по факту. Картинки — визуальные эталоны, а не готовые блоки/модели.
