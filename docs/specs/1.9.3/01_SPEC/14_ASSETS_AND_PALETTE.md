## Ресурсная реализация
- Для каждой крупной секции создать **реальную Minecraft-геометрию**: structure pieces/template NBT + block models/беречь stair/facing. Для декора допустимы отдельные 3D block models, но не мешать игроку пройти.
- Текстуры оформлять с различимым pixel grid: 16×16/32×32; без рендера фото и HD-полотен, никакой отдалённо похожей «каменной коробки».
- Протестировать читаемость ночью/днём без шейдеров, из 30/60 блоков; нужны landmarks и основная высотная композиция.
- Для несуществующих «священных символов» допустимы собственные пиксельные орнаменты без реальных религиозных утверждений; пару символов повторять в обеих постройках, чтобы визуально связать их.
- **Нужны инвентарные референсы-спеки предметов из `09_ITEMS_RECIPES.md`**; утверждённые два изображения задают архитектуру, а item sprites следует создать из описаний, не брать случайные фотореалистичные иконки.
