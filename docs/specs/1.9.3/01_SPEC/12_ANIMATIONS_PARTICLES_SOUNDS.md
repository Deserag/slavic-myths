# Внешние эффекты, анимации, полноценные звуки

## Анимации и состояния окружения
| Объект/состояние | Что делает | Ограничение |
|---|---|---|
| Малый священный огонь | Низкая анимация пламени, нечастый тёмный дым, редкие искры; при восстановлении становится выше и ярче | Никаких распространяющихся fire blocks / tnt-like explosions |
| Ритуал возобновления | Подъём пламени за 1.5–2.5 сек, кольцо краткоживущих оранжевых пиксельных глифов и короткий звуковой акцент | Видно всем близким игрокам; событие единожды, no client duplicate |
| Водные каналы | Настоящее видимое течение/небольшие ванильные потоки, мягкие пузыри и блики на специальных местах | Vanilla water; без рендеринга полупрозрачных текстур на всем чанке |
| Очистка бассейна | Багровые частицы схлопываются, чистая вода ярче, 1–2 секунды мягких голубых волн | Состояние сохраняется, частицы ограничены radius |
| Устойчивый Мор | Локальные багровые трещины 1.8 + очень редкие частицы/слабый пульс на ограниченных блоках | Никакого роста порчи на весь мир / чанки |
| Запечатанные двери | Еле заметный пульс огненного/водного символа; при попытке входа — отказ/подсказка | Не открывать в 1.9.3, no infinite glow spam |
| Лут/тайник | Типовая ванильная анимация открытия chest + короткая мягкая вспышка если тайник ритуальный | Нет чужих дублирующих сетевых событий |

**Не вводить обязательные анимации мобов** — мини-боссы появятся в 1.9.4. Не требуется кастомная animation library, если для структуры достаточно blocks/BE/particle sprites.

## Звуковая карта (реальные ogg + sounds.json, если нет переиспользуемого зарегистрированного звука)
- `sanctuary_fire_ambient`: низкий треск, спокойное гудение, редкие искры.
- `sanctuary_fire_restore`: короткая вспышка костра/возрождения, без взрывного урона.
- `sanctuary_fire_seal`: тихое каменное гудение возле закрытого зала.
- `sanctuary_fire_relic_hint`: отдельный нечастый мягкий сигнал от двери/символа.
- `pure_spring_ambient`: мягкая журчащая вода и капли подземного источника.
- `pure_spring_channel`: негромкий поток в боковом водоводе.
- `pure_spring_purify`: лёгкий колокольчик/струя воды, короткий момент очищения.
- `pure_spring_tainted`: неприятный низкий шорох/плеск из заражённых углов.
- `relic_door_blocked`: короткий металлически-каменный отказ без фальшивого открытия.
- `flame_vial_throw/hit`: звук броска и короткое огненное попадание.
- `purified_water_use`: стеклянный звон и мягкое журчание.
- `spring_tear_use`: короткий нежный восстанавливающий звук.

Не требовать создавать по одному уникальному OGG для 12 event IDs, если уже есть подходящие внутренние звуки проекта: можно переиспользовать с изменением высоты/громкости, но **зарегистрировать корректные ссылки**. Если создаётся уникальный ресурс — это реальный кликабельный `.ogg`, не пустой placeholder. Проверить аттенюацию, громкость, циклы ambient и отсутствие loop leakage при unload. Использовать серверные события для игры рядом и локальный клиент для ambience без глобального вещания по миру.
