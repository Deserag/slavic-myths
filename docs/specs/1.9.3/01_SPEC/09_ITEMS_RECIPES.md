# Новые предметы, инвентарь, применение, рецепты (конкретика)

Любой новый предмет = иконка в Minecraft pixel style (16×16/32×32 не растянутая фото-текстура), lang `ru_ru`, recipe/JEI visibility если применимо, понятная подсказка, единообразные stacks, никакого пустого функционала. Ниже числа — **настраиваемые стартовые ориентиры**. Если система уже существует под другим ID, использовать/расширить её, не плодить дубликаты.

## Святилище огня
1. **Священный уголь**: визуал — неровный тёмный кубик древесного угля с янтарной сердцевиной и 2–3 багрово-оранжевыми пикселями жара. Stack 16/64 по балансу. Гарантированно используется для разового возобновления центрального огня, а также для рецептов Пепла/Огненной склянки. Не обычный vanilla charcoal recolor без отличимого силуэта.
2. **Пепел очищения**: горсть светло-серебристого пепла в маленьком бумажном свёртке. Расходный ингредиент для очищающих составов 1.8; если общий механический интерфейс очищения есть — применить к нему; иначе рецептурно использовать в «Огненной склянке» и «Обереге угасающего пламени» (не добавлять новую глобальную систему Мора).
3. **Огненная склянка**: квадратная стеклянная колба с оранжево-янтарной жидкостью и красноватой полосой, одноразовый метательный item. При ударе локальный огненный всплеск радиус ~2.5 блока / 2.5–4 сек, накладывающий короткий огненный урон по враждебным мобам; заражённым мором существам при наличии существующего marker — доп. +25%, без terraforming и долговечного огня на деревянных блоках. Friendly fire и обжиг союзников — по текущим правилам мода, предпочтительно не задевать владельца/союзников. Рецепт: стеклянная бутылочка + Священный уголь + Пепел очищения, путь через существующий подходящий crafting station. Дистанция взрыва с реальной коллизией.
4. **Оберег угасающего пламени**: маленький бронзовый по виду жетон с красноватой искрой, **одноразовая активация** с 40-секундной защитой (предложение) от огня и локальных неблагоприятных эффектов Мора на ~30% (если механизм реально существует); эффекты видны в tooltip, не полный иммунитет. Рецепт: Пепел очищения + Священный уголь + Камень очищения + **iron nugget** (1.16.5 не имеет vanilla copper). Не занимать постоянный accessory slot и не конфликтовать с сюжетными амулетами.
5. **Древние обломки рун**: общий мелкий каменный осколок с тонкой белой линией старого глифа, добывается в обоих сооружениях. Сделать корректный minor recipe/upgrade к **существующему** руническому материалу/руне через текущее API без изменения global rune tiers. При отсутствии понятного рецепта в проекте — использовать обломок как гарантированно доступный компонент рецепта особого оберега/иного реально вводимого расходника, но никогда не оставлять без функции.

## Обитель источника
6. **Капля чистого источника**: светло-голубая капля в коротком бутылёчке со светлыми бликами. Ingredient для **Очищенной воды**, **Слезы источника** или оберега.
7. **Очищенная вода**: бутылочка со светлой водой и белым символом, одноразовый use. Уменьшает суммарную длительность обычных применимых отрицательных статусов, например Weakness/Slowness/Poison, на 35%; эффекты иных систем не обнулять полностью. Не удаляет опасное содержимое мира и не даёт иммунитет от Карачуна/Морозко/Мора.
8. **Слеза источника**: голубая капля-кристалл с серебряным ореолом, одноразовый use, восстанавливает **8 HP за ~8 секунд** (стартовый баланс; серверные тики + cooldown 45 сек, без мгновенного отхила/спама, не выше максимального HP). Избегать бессмертия и stacking эффектов.
9. **Камень очищения**: овальная светлая речная галька с вырезанным бирюзовым глифом, редкий ремесленный компонент. **Обязательно используется в рецепте Оберега угасающего пламени** (см. п. 4); его польза не должна зависеть от ещё не выпущенной 1.9.4.

### Логика рецептов
- Обычные рецепты должны ссылаться только на **существующие сейчас** items/blocks/registry. Не создавать недоступный новый станок без запроса.
- Закрытая сюжетная дверь **не связана** с готовностью этих обычных рецептов.
- Использовать `recipes/*.json`/существующую систему crafting с реальными registries; крафт и JEI видны в survival; альтернативные рецепты не делают rare материалы бесконечными.
- Tooltip явно отделяет «снижает определённые негативные эффекты» от «полный иммунитет к мору».
