# Огненное святилище — интерактив, лут, эффекты

### Ритуал возобновления огня в 1.9.3
- Центральная чаша выделяется отдельным block/BE/state или совместимым эквивалентом; `DORMANT` (слабое тление) → `AWAKENED` (сильный управляемый огонь). Для активации игрок расходует **1 Священный уголь** из инвентаря/руки; server-side проверка предмета/состояния и единичная атомарная выдача результата.
- При первом восстановлении выдать всем реально участвовавшим/впервые активировавшим **не сюжетную** награду — например 1 Пепел очищения; открыть **один боковой** тайник. Гарантия — **один раз на структуру/персонажа**, конфиг без бесконечной фермы. Не выдавать фрагмент амулета из 1.9.4.
- Визуал: на 1.5–2.5 секунды искры/вспышка, затем ровное усиленное пламя, слабые кольца огненных символов; честная яркость, без client FPS-перегруза.
- Если интеракция недоступна/не найден предмет — русское сообщение/подсказка без изъятия угля.
- Повторные вызовы, разные игроки и unload/load сохраняют состояние (world saved data или block entity, не глобальная static map).

### Честный обычный лут
**Священный уголь** (базовый редкий ингредиент), **Пепел очищения** (ремесло/очищение), **Огненная склянка** (метательная), **Оберег угасающего пламени** (расходуемая защита), **Древние обломки рун** (общий компонент), vanilla уголь/хлеб/верёвки и т.п. Подробный эффект и вероятности — `08_LOOT_ECONOMY.md` и `09_ITEMS_RECIPES.md`.

### Тайники
- 2–4 обычных контейнера, разбросанных по боковым помещениям, без гарантированного легендарного снаряжения.
- **В одном фиксированном ритуальном контейнере — гарантированно 1 Священный уголь** поверх обычного seeded лута. Иначе из-за 65% рандома игрок мог бы застрять, не имея чем разжечь главный очаг; повторно при перезагрузке этот предмет не генерируется.
- 1 боковой тайник, открываемый ритуалом огня. Не открывать главный запечатанный зал.
- Заражённые декоративные блоки можно локально очищать существующим очищающим предметом 1.8, **не переписывая** общие блоки/механику заражения. Нет обязательного lock-on очистку всех трещин.
