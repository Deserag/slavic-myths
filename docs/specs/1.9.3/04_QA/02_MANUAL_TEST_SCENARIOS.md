# Ручные сценарии для игрового QA пользователем (не запускай Minecraft автоматически)

**1. Новый мир:** несколько seed/terrain, две структуры реально появляются целиком, на склоне нет летающей стены, вход виден снаружи, сундуки доступны; разные rotations сохраняют лестницы/воду/двери.

**2. Святилище огня:** осмотр фасада/сбоку/сверху по crop refs; пустая рука на центральную чашу → подсказка; Священный уголь → эффект/звук/открытие одного бокового тайника; повторное использование не выдаёт бесконечный лут; выйти/перезапустить → огонь остался восстановленным.

**3. Обитель:** пройти до родника без утопления/сломанной лестницы; очистить загрязнённые бассейны (каждый видимо меняется); получить побочный тайник; прогрузка чанка и restart сохраняют состояние; вода не убегает в мир.

**4. Loot и crafting:** открыть 3–4 нормальных сундука; испытать каждую новую одноразовую вещь, проверить уменьшение негативных эффектов, невозможность спам-хила, видимость рецепта в JEI/книге (если установлены), локализацию, icons, возможный конфликт с рунами.

**5. Сюжет:** в обоих зданиях виден красивый запечатанный зал/постамент, но нельзя получить фрагмент амулета/спавнить мини-босса. Даже если креативно проломать стену — на 1.9.3 внутри нет доступного фрагмента.

**6. 2–4 игрока:** одновременно активируют чашу → не дюпится общий лут и предмет; персональные открытия Книги не конфликтуют; сундуки не дублируются, one-time rewards не выдаются при reload.

**7. Регрессии:** морозко 1.9.1, Карачун 1.9.2, 1.8 Мор, rune sockets, dedicated server, существующие миры, звук и FPS рядом с источником.
