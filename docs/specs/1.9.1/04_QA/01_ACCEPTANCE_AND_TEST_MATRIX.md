# ПРИЁМКА / QA: без запуска Minecraft Codex'ом

Codex выполняет только доступные для него неигровые проверки (compile, unit tests, resource validation), после чего пользователь проводит визуальные и боевые тесты вручную. Нельзя заявлять «Minecraft tested», не запуская его. Все пункты **являются критерием готовности**; если нет автоматического теста, оставить явные manual QA steps.

## A. Компиляция/ресурсы
- [ ] Сборка target Forge/Java конфигурации проекта проходит без compile errors (не делать upgrades зависимостей).
- [ ] Все новые item/entity registry IDs реально имеют русское имя, собственную icon/model, рабочий renderer и assets, нет стандартного pink-black checkerboard.
- [ ] Ни одно имя/сообщение не отображает raw lang key; English fallback есть.
- [ ] PNG/geo модели воспроизводят два приложенных игровых референса, в том числе задние узоры и ледяные наконечники.
- [ ] Одинаковая модель посоха у босса и предмета, в руке игрока не уменьшается в незаметный пиксель.
- [ ] `sounds.json` без отсутствующих .ogg, звуки на событиях включаются только один раз.

## B. Ритуал и NPC
- [ ] Получение предмета у Бабы-яги и **альтернативно** у Баюна реально доступно без участия второго NPC.
- [ ] Квест использует существующую progression и не требует неполучаемых ингредиентов.
- [ ] Тотем многоразовый, сохраняется после использования/прохождения, нельзя вызывать второго boss рядом с активным.
- [ ] В обычном Overworld на свободном пространстве появляется Морозко; Nether/End/небезопасная теснота — понятный отказ без потери предмета.
- [ ] Морозко не появляется сам по себе и не создаёт здания/постоянных блоков.

## C. Бой и фазы
- [ ] Морозко 1000 HP, не инфицирован, фазы реально переключаются на 60% и 30%.
- [ ] Аура 8 блоков: при 0–3 cold набирается быстрее 6–8, на расстоянии >8 cold спадает, HUD обновляется.
- [ ] Cold на 25/50/75/100 приводит к правильным уровням Slowness/Weakness, на 75+ действительно уходит **текущее HP** 1 HP/3c или 2 HP/2c.
- [ ] Дистанционные способности имеют телеграфы, 12-секундную локальную метель, растущие пики, дыхание перед лицом, расходящуюся волну. Уклонение и укрытия функционируют.
- [ ] Три ледяных двойника **50 HP каждый**. Они полупрозрачные, имеют тот же силуэт и посох, бьют не слабее оригинального базового удара, разбиваются, не дают loot/exp.
- [ ] Оригинал не создаёт 4+ двойников, ни один не живёт после завершения/отмены.
- [ ] На 50 HP оригинала любой overkill приводит к `YIELDING`, **не обычной смерти**, нет kill drop/exp.
- [ ] Богатыри игрока могут атаковать Морозко/двойников; Морозко может поражать богатырей, но их аура только 50% скорости набора.

## D. Награды и математика выпадения
- [ ] Первая победа на каждого игрока: 1 зерцало, **ровно одна** из двух рун, 1 сердце, staff при chance15%.
- [ ] Повторные победы: **каждый раз** 1 руна и 1 сердце, staff с новым шансом 15%, **не дюпается зерцало**.
- [ ] Unit test или deterministic seeded test на 1000 симуляций проверяет, что в каждой выборке ровно одна руна (не обе/ни одной); 50/50 шанс задан в коде, а не два 50%-ных отдельных roll.
- [ ] Случайный шанс посоха 15% независим от руны.
- [ ] У 2–4 игроков предметы выдаются каждому отдельно, item стаки не «один общий в середине».
- [ ] Повтор packet/reload не выдаёт второй комплект, full inventory не теряет Heart.

## E. Зерцало
- [ ] Амулет вставляется в реальный слот аксессуаров, имеет иконку из референса, рука не обязана его держать.
- [ ] Одна ледяная копия игрока с **15 HP** живёт до 30 c, cooldown **180 c**, не сбрасывается переэкипировкой, death/reconnect.
- [ ] Клон показывает настоящий player skin, экипировку, enchanted weapon+armor, полупрозрачное тело. Не выдаёт свои копии инвентарных предметов.
- [ ] Копия повторяет ходьбу, прыжок, приседание, melee/ranged движения.
- [ ] **Ключевой тест:** игрок бьёт широкого босса, копия физически находится **слева** игрока — её удар тоже должен попасть по тому же боссу при LOS и reach; повторить **справа**. Урон нанесён по действительной bbox, не только показана анимация.
- [ ] За стеной/за пределом reach клон не атакует невидимо и не телепортируется к врагу; при смерти 15 HP действительно ломается.

## F. Посох и руны
- [ ] Посох из референса с 4 разными visual animation/attack, G/V настраиваемые через Controls, не срабатывают без посоха в руках.
- [ ] ЛКМ: ледяные снаряды, CD и hit registration; ПКМ: 3-секундный поток, stop при отпускании, 10c CD.
- [ ] G после удара по врагу: **5 сосулек** сверху, 0.8 с telegraph, движение врага может заставить промахнуться, каждое попадание даёт слабость/замедление. Если цели не было — понятный toast, CD не тратится.
- [ ] V: реально летит радиальная холодовая волна, поражает только близкие цели.
- [ ] Руна морозостойкости вставляется в поддерживаемый бронеслот и выключает Weakness/Slowness; **не отменяет морозный damage**.
- [ ] Руна мороза вставляется в поддерживаемый weapon slot, 25% по допустимым ударам, статус ≤4 c, нет рекурсивного infinite proc.

## G. Dedicated/multiplayer/сохранения
- [ ] Клиент с модом соединяется с dedicated server без `ClassNotFound client-only` и world desync.
- [ ] Независимая выдача наград 2–4 игрокам, действия богатырей привязаны к владельцу, boss HP/двойники одни для всех.
- [ ] Выход/возврат/смерть/смена dimension не создают второго Морозко/клона/второго лута.
- [ ] Block/world editing отсутствует, при отключении испытания частицы/призрачные сущности исчезают.
- [ ] Нет тяжёлого перебора всей dimension/world на каждом tick.

## Нефункциональные визуальные стоп-факторы
Реализация считается НЕПОЛНОЙ, если использованы: реалистические портреты вместо моделей, Steve с синей маской вместо Морозко, простой перекрашенный зомби для ледяного двойника, синий прямоугольник вместо посоха/руны/амулета, отсутствие отдельного back texture, generic snowball вместо больших падающих сосулек, нерабочий tooltip/переключатель, модель/кристалл без анимации, placeholder `TODO` в обязательном действии.
