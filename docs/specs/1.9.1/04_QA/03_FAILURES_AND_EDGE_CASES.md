# Дополнительные крайние случаи, которые нельзя игнорировать

## Морозко
- **Overkill** 1000→0 одним ударом: boss остаётся с 5% и отдаёт один reward-set, нет vanilla death.
- Двое одновременно наносят последний удар: только один переход в `YIELDING`, оба при участии получают **свои** награды.
- Смена dimension одного из 4 участников: он не влияет на цели, boss не телепортируется, остальные продолжают бой.
- 3 ледяных двойника умерли в 0.5c: boss не спавнит ещё 3 в том же tick, соблюдает cooldown.
- Игрок в радиусе 7.9 затем 8.1: холод не мигает мгновенно, падает по таймеру; при высоком cold damage с окончанием боя прекращается.
- Включённая Руна морозостойкости: Slowness/Weakness от Морозко и иных игровых источников не появляются, но 75+ cold всё ещё снимает HP.
- Игрок с low HP: на последнем тикe ауры перед `YIELDING` может погибнуть, но после `YIELDING` нельзя погибнуть от остаточного пассивного урона ауры.
- Защита мира: все пики/сосульки — temp geometry; после перезахода блоки под ними остались исходные.

## «Морозное зерцало»
- Два одинаковых амулета у игрока: максимум 1 активная копия, общий player cooldown, не две независимые cooldown цепи.
- Armor enchant glint и модовое оружие у копии обновляется на snapshot summon, при раздаче loot предмет не выпадает с копии.
- Игрок меняет меч посреди существования: copy сохраняет snapshot, не меняет weapon неожиданно (или обновление только визуальных слоёв без недокументированного роста damage — выбрать snapshot полностью).
- Босс стоит справа, copy слева: hit в bounding box если хватает reach; не наносит удар через стену; прыжок/движение игрока копия повторяет.
- Игрок бьёт временного морозяного двойника: mirror target по UUID корректно перенаправлен, не идёт friendly fire.
- Умирает в момент summon/отключает клиент до packet confirm: не создаётся ghost copy на сервере, CD не обнуляется эксплойтом.

## Посох
- G на цели умершей >8 с — отказ без cooldown. G при быстром враге — сосульки реально промахиваются, нет tracker homing.
- Игрок атакует большой boss с хитбоксом на 3 блока — сосульки соприкасаются с bbox, даже когда центр не под центром экрана.
- G/ V настраиваемая клавиша пересекается с существующим class skill — UI отмечает конфликт; при отсутствии посоха не перехватывать другой предмет.
- Поток RMB обрывается отпусканием, потерей посоха, сменой мира, открытием меню; нет вечного звука/урона.
- ЛКМ по блоку не создаёт бесконечные projectile из-за обычного mining loop.

## Награды
- Inventory 36/36 при выдаче heart: персональный резерв/дроп не теряет гарантированное сердце.
- Несколько NPC выдачи тотема: id одного предмета, не два несовместимых токена.
- 2 игрока выполняют один trial, одному staff выпадает, другому нет; руну каждый получает одну; RNG не общий.
- Наградный скрипт вызвался 2 раза в один server tick: 1 + 1 heart на каждого не превратилось в 2 + 2.
