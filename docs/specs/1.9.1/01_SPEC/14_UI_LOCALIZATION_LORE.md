# HUD, Книга сказаний, достижения, GUI и переводы

## RU/EN keys
Создать/дополнить `ru_ru` и `en_us` *тем же способом, который уже используется в mod*. Сначала проверить существующие языковые файлы, затем добавить новые пути для:
- `entity.slavicmyths.morozko = Морозко`;
- `entity.slavicmyths.morozko_ice_double = Ледяной двойник Морозко`;
- `entity.slavicmyths.player_ice_double = Ледяная копия %s` (выбор форматирования по API);
- `item.slavicmyths.morozko_trial_totem = Ледяной тотем призыва Морозко`;
- `item.slavicmyths.frost_mirror = Морозное зерцало`;
- `item.slavicmyths.frost_resistance_rune = Руна морозостойкости`;
- `item.slavicmyths.frost_rune = Руна мороза`;
- `item.slavicmyths.morozko_staff = Посох Морозко`;
- `item.slavicmyths.heart_of_eternal_cold = Сердце вечной стужи`.
Имена — пример ID (если registry conventions иные, адаптировать локализацию к итоговым реальным ID). Названия для игрока **именно такие**, в одном падеже и стиле по всем экранным сообщениям.

## Сообщения и подсказки
- Вызов недоступен: «Для испытания Морозко нужно больше свободного места», «Здесь уже проходит испытание», «Морозко можно призвать только в Верхнем мире», «Пока подожди, прежде чем вновь призывать Морозко», «Сначала заслужи доверие Бабы-яги или Кота Баюна».
- На начале: «Морозко явился на зов. Выдержи его стужу!»; при 5%: «Испытание пройдено. Морозко признал твою стойкость».
- При закрытии: «Морозко возвращается в зимнюю даль»; выход всех: «Испытание прервано — все участники покинули место боя».
- По наградам показывать конкретный список без конфликтов: «Получено: Сердце вечной стужи, Руна мороза» (+Посох, +Зерцало по факту).
- Посох: tooltip объясняет все 4 режима, CD, выбираемую последнюю цель для сосулек; клавиши по текущему назначению пользователя. При G без цели — короткий toast, но не toast per tick.
- Руна морозостойкости: «Защищает от Замедления и Слабости. Не отменяет морозный урон»; Руна мороза: «25% шанс наложить Замедление I и Слабость I на 4 сек»; зерцало: «Создаёт ледяную копию владельца на 30 с. Прочность копии: 15 HP. Перезарядка: 180 с»; сердце: «Частица силы Морозко для будущего оберега».

## HUD
- Bossbar `Морозко` с 1000 HP и фазами без дёрганья шкалы; у копий отдельные overhead HP/health через существующий vanilla UI, без 3 новых полноразмерных bossbars.
- Маленькая шкала `Стужа` 0–100 у игрока (см. `05_BOSS_STATES_AND_FROST_AURA.md`); убрать вне боя после спадания. Не перекрывать нижний правый HUD классов/навыков.
- `Посох Морозко`: аккуратные 2 иконки cooldown для G и V (или использовать существующий UI активных навыков), плюс маленький прогресс/подсказка канала ПКМ; не перекрывать здоровье и еду. Отображение не обязано создавать новый большой экран.
- `Морозное зерцало`: небольшой значок с обратным отсчётом 180 с/отображением существующего мира, отсутствует если амулет снят; успешный summon cooldown хранится независимо от GUI.

## Книга сказаний / lore
- Добавить *новую запись* «Испытание Морозко» в существующей книге (если в текущем проекте книга теперь появляется при первом входе, не выдавать её повторно при добавлении главы). Пример содержания: «Холод Морозко проверяет силу и терпение. Его можно призвать через оберег, полученный у Бабы-яги или Кота Баюна. Убивать зимнего старца не нужно: выдержи испытание, пока он не признает твою стойкость».
- До успеха скрыть точные случайные rewards или показывать общие: «руны, кристаллы и редкое оружие»; после успеха открыть страницу с механиками всех четырёх наград и цель будущего оберега.
- Новое достижение «Выдержавший стужу»: success event при 5%, не за убийство. Не генерировать одно достижение на каждое падение снежинки.

- Не ломать конфигурацию путей Дружинник/Ведун/Разбойник и других уже добавленных классов, не связывать переменную Зерцала с class-selection. Переназначение G и V через существующий Controls; будущий отдельный экран редактирования умений/ключей оставлен за следующим патчем по решению пользователя.
