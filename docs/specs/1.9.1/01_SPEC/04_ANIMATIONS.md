# Полноценные анимации (НЕ заменять одним поворотом головы)

## Морозко — обязательные наборы
| ID условный | Длительность | Позы/движение/сигналы |
|---|---:|---|
| `idle` | цикл 4.0 с | дыхание торса ±0.5°, слабое покачивание меха/бороды/нижних краёв кафтана, мерцание кристалла посоха; без невротичной тряски. |
| `walk` | цикл по скорости шага ~1.1 с | тяжёлые широкие шаги, руки двигаются умеренно, посох служит опорой; при каждом шаге снежные частицы у сапога. |
| `staff_melee` | 0.9 с | разворот торса, размах посохом справа налево на горизонтальной дуге, 1 точный hit-frame в 0.52 с, короткая остановка после; физический урон ТОЛЬКО в этот момент. |
| `ice_bolt` | 1.05 с | левую ладонь вперёд, навершие светится, пучок льда уходит в цель в 0.64 с, потом возврат. |
| `blizzard_cast` | 2.5 с | медленно поднимает обе руки/посох над головой, взгляд вверх, кристаллы нарастают по свечению; в 2.5 с начинается метель. |
| `spikes_cast` | 1.15 с | резкий удар основанием посоха в землю, круговая вспышка и появление меток, на 0.9 с после меток растут пики. |
| `breath_cast` | 0.8 + 2.0 с | запрокидывает голову/вдыхает (0.8), наклон вперёд и конус снежных кристаллов от лица (2), затем останавливается 0.35 с. |
| `cold_wave` | 1.2 с | посох двумя руками, нижняя часть упирается в землю, тёплый белый блеск конвертируется в синее кольцо; волна распространяется от ног. |
| `clone_summon` | 2.0 с | Морозко разводит руки, посох вертикально зависает визуально у него (не выбрасывать item), 3 ледяные статуи собираются от ступней к голове, затем оживают. |
| `final_storm` | 2.4 с + 8 с эффекта | яркая ледяная вспышка, усиленная поза, потом обычные атаки поверх погодного эффекта. |
| `hurt` | 0.24 с | короткая реакция торса/головы и минимальный скол инея, без частого спама при десятках ударов. |
| `defeat_yield` | 5–6 с, **не death** | на 5% здоровья останавливается, опирается на посох, опускает голову, поднимает кристалл Сердца вечной стужи; нет death fall, нет обычного дропа/опыта. |
| `despawn_trial` | 1.3 с | распад зимней дымкой и частицами после диалога/выдачи наград; мир без изменённых блоков. |

## Двойник Морозко
Реиспользует базовые `idle`, `walk`, `staff_melee`, `ice_bolt`, `hurt`, `shatter_death` (0.55 с: 8–15 ледяных кубических осколков расходятся и исчезают). Обязательная **визуальная прозрачность в каждом кадре**. Не запускать `blizzard_cast`/`final_storm` для копии; уникальный бафф ауры ей запрещён.

## Ледяная копия игрока
- За основу взять реальное состояние поз игрока (голова/торс/ноги/руки) и сохранённые gestures: бег, ходьба, крадущаяся ходьба, прыжок, падение, замах, натяжение лука/арбалета/щита.
- Следует сбоку на смещении ~2 блока; повторяет движение с малой задержкой 0.1–0.2 с, но использует собственную безопасную навигацию (см. файл копии). Нельзя делать T-pose при движении.
- Во время удара копии **анимация повёрнута к выбранному реальному target**, даже если она слева/справа от игрока. Не атаковать невидимую точку параллельно игроку.
- `player_clone_spawn` 0.65 с — сборка из прозрачных ледяных квадратиков снизу вверх; `player_clone_break` 0.45–0.6 с — раскол тела на лёд без обычной анимации смерти Steve.

## Посох предмет/игрок
- ЛКМ: animation swing + кристаллический всплеск у навершия синхронно с реальным выстрелом.
- ПКМ: обе руки/основная рука на посохе, циклическое удержание потока, particles только во время channel.
- Клавиша G: поднятие посоха на 0.8 с, затем 5 отдельных вспышек синхронно сосулькам.
- Клавиша V: опора на посох 0.35 с, расходящееся кольцо.
- Все key input обрабатывает клиент и отправляет валидируемую команду на сервер; анимация запускается только после серверного принятия (допускается ограниченный predicted feedback, без двойного урона).

## Критерий
При проверке блоковых состояний видно, откуда появился снаряд/снежная буря/кольцо и какой кадр нанес урон. Анимации корректно синхронизированы у двух клиентов, не застревают после смерти/отхода за 40 блоков/смены измерения.
