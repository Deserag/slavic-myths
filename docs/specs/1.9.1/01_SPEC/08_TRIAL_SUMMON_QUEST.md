# Испытание: предмет призыва, доступ через Бабу-ягу ИЛИ Кота Баюна

## Названия/логика
- Предмет: **«Ледяной тотем призыва Морозко»** (рабочий registry id `morozko_trial_totem`), переносной многоразовый артефакт по `items_06_trial_summon_reference.png`. Одна и та же функциональная вещь от обоих NPC; две версии с разными ID не создавать.
- Испытание — добровольный вызов Морозко, **не заражённого**, который проверяет игрока на стойкость; не требовать принесения Горыныча/заражённых предметов. Герои/богатыри игрока допустимы.

## Два существующих пути получения (оба обязательны)
**Путь A — Баба-яга:** в её действующем диалоге/квестах при достигнутом доверии II добавить ветку «Испытание Морозко». Условия вручения: доступ к доверительной ветке II и одно простое подношение 8 снеговых блоков + 1 синий лёд (`blue_ice`). Проверить наличие/потребление через существующую квестовую API, не городить новый квестовый движок. Если такого уровня доверия в текущей ветке нет — адаптировать к ближайшему реальному признаку завершения основного начального квеста Яги, явно отразив в status-файле.
**Путь B — Кот Баюн:** после исполнения его первых «кошачьих желаний» (в существующем контенте упомянуты 10 сырой рыбы и молоко; распознать фактическую текущую квестовую запись), добавить отдельную опцию получения тотема за 8 снеговых блоков + 1 синий лёд. Это АЛЬТЕРНАТИВНЫЙ путь, Яга не должна быть дополнительным обязательным NPC. Не требовать отдельный предмет, которого нельзя достать без Морозко.
- Если у игрока уже есть permanent unlock, при повторном разговоре соответствующий NPC может **восстановить утраченный тотем** без повторной сюжетной награды; сохранить флаг. Не давать бесплатный тотем всем игрокам при входе в мир.
- Квестовая ветка/награда у существующих NPC должна присутствовать на сервере и действительно выдавать item. Перезапуск мира не сбрасывает unlocked flag.

## Вызов в Overworld
- `use` тотема по поверхности обычного твёрдого блока в Overworld; без нового WorldGen, без изменения настоящих блоков, без отдельного подземелья/арены. В момент применения — проекция ледяного тотема/снежная сигила 3 c, затем Морозко появляется в найденном свободном пространстве примерно в 6–10 блоках перед призывателем.
- Перед вызовом сервер проверяет: есть действующий выданный unlock, нет другой активной `MorozkoTrialSession` в радиусе 80 блоков, место не в запрещённом измерении/жидкости/опасной тесной пещере, хватает высоты ≥4 блока, призыв не пересекает чужие защищённые структуры. При ошибке предмет не расходуется, на русском показать короткую причину.
- Вокруг ритуала радиус участия 40 блоков от якоря; мягкая визуальная снежная граница по необходимости, **не строить стену**. Босс преследует участников только внутри; если никого нет внутри >30 c — исчезает без награды.
- Тотем **не расходуется**, но собственный player cooldown 120 с после начала испытания; при успешном завершении заново можно призвать после 180 с (если нет новой активной сессии). Эти значения удобнее хранить в server config, не в lore.
- Не создавать нового постоянно заснеженного биома, не спавнить Морозко естественно и не вредить ванильным постройкам.

## Регистрация участников и выдача наград
- На момент успешного завершения участником является игрок, находившийся в радиусе 40 в ходе боя и внёсший **не менее 1 HP учитываемого урона по боссу/двойнику** или был атакован Морозко/двойником при не менее 15 с активного участия. Урон собственных богатырей засчитывается их владельцу.
- Участники, временно умершие/отошедшие и вернувшиеся в сессию до 5%, сохраняют право, если выполняли вклад; не выдавать лут случайному AFK прохожему.
- Награду каждому считать независимо с уникальным `sessionId + playerUUID` и подтверждением «rewarded». Если инвентарь полон, безопасно выдать в существующую надёжную mail/claim-систему при её наличии или создать персональный безопасный предметный drop с owner-lock, а не терять награду или бросать один общий стак на всех.

## Финал испытания
- На 5% Морозко опускает посох, прекращает агрессию и говорит (локализованной репликой) что-то вроде: «Стужу мою выдержал. Силу и терпение доказал». Без смерти, опыта за убийство, превращения в infected mobs.
- Выдача: зерцало при первом успехе; 1 из 2 рун; 15% посох; 100% сердце (см. файл наград). Сохранить для будущего 1.9.3 `morozkoTrialCompleted=true` и число побед; не создавать сейчас неработающий вызов союзника.
