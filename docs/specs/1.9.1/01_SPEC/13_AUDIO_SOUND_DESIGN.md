# Звуковой дизайн — НЕ забыть регистрацию/сами ресурсы

Задача не считается выполненной, если зарегистрированы `SoundEvent`, но отсутствуют проигрываемые `.ogg` / файл `sounds.json`. Использовать оригинальные подготовленные SFX (если они есть в проекте) либо синтезировать/собрать новые небольшие собственные звуки с корректным OGG encode без нарушения авторских прав. Ванильные звуки допустимы **только как дополнительный слой**, не вместо специфичных главных эффектов. Длительность и динамику можно подстроить под фактическую анимацию.

## Практические требования
- Подключить SoundEvent на сервере и корректно проигрывать клиентам в пределах радиуса; `sounds.json` соответствует действительным путям. Не дублировать звуки у всех клиентов при одной атаке.
- Тихие игровые звуки не должны перекрывать шаги, удар, предупреждение ауры и кастов; отдельный общий volume budget (до 0.9 субъективно для boss spells, ambient до 0.4).
- Для больших способностей читаемый предупредительный звук **раньше**, чем наносится урон.
- Если библиотека Sound API не позволяет авторский synth, допускается смешивание уже имеющихся в проекте кристаллических звуков с фильтрацией/вариацией pitch только если оно создаёт различимые касты; не регистрировать несуществующие ogg.
- Для копий player's equipment использовать hit звуки текущего оружия с дополнительным тихим ледяным crackle, а не выдавать обычную жизнь/голос Steve.
