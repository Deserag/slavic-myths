# 1.9.7 — Визуальный стиль и поведение

## Стиль обязателен
Minecraft **pixel-art / voxel**, стилистически совместимый с уже существующими предметами мода. Читаемый контур, ограниченная палитра, чёткие границы пикселей, **без** мягкого рендера, реалистичной металлической поверхности, постобработки, шума, встроенных надписей, тяжёлых шейдеров и избыточных частиц.

**Приоритет референсов:** `references/03_pixel_sprite_study.png` и исходные 32×32 спрайты — ориентир для точных пикселей; `references/01_overview_modes_crafting.png`, `references/02_artifact_abilities_and_nether.png` — ориентир по форме и атмосфере. Надписи и декоративные цифры на плакатах **не являются ТЗ**.

## Медальон: фронт / бок / верх
- **Спереди:** небольшой плоский симметричный подвесной медальон (высота ~1.2 ширины), тёмно-серебряный восьмиугольный каркас, 4–6 угловатых заклёпок, маленькое кольцо сверху, острый короткий нижний наконечник. Центральный кристалл разделён **вертикально** на две узнаваемые половины: **слева** лазурно-голубая грань Морозко с белым ледяным бликом, **справа** темно-фиолетовая грань Карачуна с чёрными трещинами. Грани кристалла угловатые, не круглые и не гладкие.
- **Сбоку:** медальон почти плоский: чёткая 2–3-пиксельная металлическая окантовка, слегка выступающий кристалл; не делать объёмным шаром. Кольцо расположено вверху по оси, один короткий подвес.
- **Сверху:** узкий овальный металлический обод, невысокое кольцо; верхняя геометрия не заслоняет грани кристалла.
- **В инвентаре:** прозрачный фон PNG, рекомендован 32×32 с проверкой читаемости в обычном 16×16 интерфейсном масштабе. Нельзя превращать оберег в крупный фотореалистичный рендер. В руке использовать естественный ванильный наклон и габариты стандартного предмета.

## Состояния визуала
1. **Базовый предмет:** обе половины контрастны и одинаково узнаваемы.
2. **Морозко:** яркий ледяной голубой акцент слева, правая половина приглушена. При переключении краткая вспышка 0.25–0.4 с, 3–6 снежинок; при активации — тонкий гранёный голубой щит, не закрывающий обзор, угловатый пиксельный блеск. При исчерпании щита несколько кратких осколков.
3. **Карачун:** яркий фиолетовый акцент справа, левая половина приглушена. Краткий тёмно-фиолетовый импульс и несколько частиц. Активация — одно расширяющееся кольцо темного холода радиусом 5 блоков, ~0.5 с, затем исчезает.
4. **Адская аура:** 1–3 редких тёмно-красных пиксельных частицы, краткие уведомления при входе и изменении стадии, без эффекта сплошного красного экрана.

## Текст и HUD
- Русское имя: **«Оберег двух зим»**. Подсказки в игре: текущий режим, Shift+ПКМ — переключение, ПКМ — активная способность, оставшееся время кулдауна **по запросу**.
- Не открывать новый GUI; достаточны обычный tooltip и короткий actionbar при управлении/смене стадии. Учесть присутствующие языковые файлы проекта.
- Названия умений: **«Ледяной покров»** и **«Объятия Карачуна»**.

## Звуковая постановка
| Событие | Звук | Частота |
|---|---|---|
| Переключение на Морозко | Короткий звон льда | Один раз на переключение |
| Переключение на Карачуна | Низкий хрустящий гул | Один раз на переключение |
| Активация щита | Тонкий ледяной удар, затухание | Один раз на активацию |
| Активация волны | Низкая морозная волна / ветер | Один раз на активацию |
| Изменение стадии ауры | Глухой предупреждающий пульс | Только при входе/смене стадии |
| Поглощение/разрушение щита | Короткий треск стекла | Без спама на каждый тик |

Если оригинальных лицензированных OGG в проекте нет, допустимы подходящие **ванильные** звуки Minecraft с небольшим изменением pitch/volume. Случайные ресурсы с неизвестной лицензией не использовать.
