# Slavic Myths 1.9.7 — «Подготовка к Аду»
## Цель микропатча
Добавить один артефакт **«Оберег двух зим»**, получаемый через награды уже существующих Морозко и Карачуна. Оберег объединяет два переключаемых режима — защитный Морозко и атакующий Карачуна, нейтрализует новую персональную опасную ауру Нижнего мира и может копироваться с помощью нерасходуемого **оригинала-шаблона**.

## Что реализовать
1. Новый предмет с двумя состояниями, серверной логикой и локализацией.
2. Первый рецепт из наград двух боссов; второй рецепт копирования из расходных ресурсов с сохранением оригинала.
3. Пассивные и активные свойства обоих режимов; общая перезарядка.
4. Поэтапная адская аура без оберега; вход в Нижний мир **не блокировать**.
5. Пиксельные ресурсы, умеренные эффекты, короткие звуки, подсказки управления.
6. Тесты из `04_ACCEPTANCE.md`.

## Приоритет при расхождениях
Числа/правила: `01_IMPLEMENTATION.md`; визуал: `02_VISUAL.md`, `03_ASSETS.md`; изображения в `references/` — только художественные ориентиры (надписи на плакатах могут быть неточными). Реальную организацию кода, версии API и IDs определить из существующего проекта, не угадывать.

## Границы
**Не менять** существующие механики Морозко, Карачуна и их выпадение наград; не переделывать баланс остальных боссов, старые руны, портал, миры, общие эффекты, инвентарь и GUI. Использовать фактические игровые предметы и материалы проекта, не регистрировать их дублей. При отсутствии предполагаемых наград с указанными русскими именами определить реальные уже существующие награды соответствующих боссов и адаптировать ингредиенты к ним — не придумывать отдельные дубль-предметы.

**Не входит в 1.9.7:** новые боссы, биомы, структуры, портальная блокировка, дополнительные измерения, сюжетные квесты, полная оптимизация мода, переработка старых текстур, масштабный интерфейс. Это завершающий **микропатч**, а не ревизия 1.9.8+.

Общие постоянные правила работы Codex уже выданы отдельно в чате «Требования»: **не повторять и не переосмысливать их в этом ТЗ**.
