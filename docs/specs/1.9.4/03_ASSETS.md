# 1.9.4 — РЕСУРСЫ: модели, текстуры, анимации, частицы и звуки

Цель: **реальные игровые ресурсы**, а не пустая регистрация с ванильным силуэтом или одним звуком на все события. Выбрать фактическую используемую в проекте систему GeckoLib/Blockbench/renderer и правильный для неё экспорт; не добавлять новый движок анимаций без необходимости. Ниже — логические resource ID, допустима адаптация к уже принятому naming мода с сохранением однозначного соответствия.

### Логическое размещение
- Entity textures: `assets/slavicmyths/textures/entity/<id>_corrupted.png`, `<id>_cleansed.png` (или текущий формат атласа проекта).
- Entity animation/model resources: каталог модели/анимации, который реально используется текущими существами мода (`geo/*.geo.json`, `animations/*.animation.json` только если существующий loader именно таков). Не требовать синтаксиса новых версий Minecraft.
- Предметы: `assets/slavicmyths/textures/item/mor_fire_amulet_fragment.png`, `.../mor_water_amulet_fragment.png` и соответствующие `models/item/*.json`.
- Звуки: `assets/slavicmyths/sounds/guardians/*.ogg`, события в `assets/slavicmyths/sounds.json`, ключи локализации `lang/ru_ru.json` и `lang/en_us.json`.
- При кастомных particles: задать зарегистрированные типы, корректные материалы/texture sprites и их синхронизацию на клиент. Проверить производительность при нескольких клиентах.
- При `fabric` или API Minecraft 1.19+ предложениях **не менять** существующий 1.16.5 Forge-пайплайн.

## 2. Анимации — обязательные клипы/состояния

### Страж
`idle_embers`, `awakening`, `walk_heavy`, `melee_left`, `melee_right`, `fire_pulse_charge`, `fire_pulse_release`, `lockdown_begin`, `lockdown_hold`, `lockdown_end_exhausted`, `ground_slam_charge`, `ground_slam_impact`, `hurt_react`, `purify_kneel`, `purify_glow`, `cleansed_idle`.

Отдельно воспроизвести: перемещение рук/торса в самом клипе, точный контакт ладоней с поверхностью и паузу при огненном щите. Синхронизировать момент серверного урона с моментом визуального удара, а не с началом телеграфа. Пульсация «сердца» может быть отдельной текстурной анимацией и не должна рассинхронизировать основной скелет.

### Хранительница
`idle_water`, `emerge_from_spring`, `walk_glide_blocky`, `whip_windup`, `whip_strike_left`, `whip_strike_right`, `whirlpool_cast`, `prison_cast`, `flood_cast`, `heal_begin`, `heal_loop`, `heal_interrupt`, `hurt_react`, `desperation`, `purify_water`, `cleansed_idle`.

Плети — **несколько связных rectangular model bones** или подходящие модовые анимируемые сегменты с отдельной hit detection на сервере; не одиночный ray без визуальной связи и не сплошная полупрозрачная ширма. Водяные полосы волос остаются пиксельно-блочными даже на ближнем расстоянии.

### Арена / интерактивные элементы
`fire_tile_warning`, `fire_tile_active`, `fire_tile_fade`, `fire_shield_active`, `valve_open`, `valve_closed`, `water_heal_stream`, `water_level_rise`, `water_level_fall`, `water_prison_crack`, `purification_fire`, `purification_spring`.

Если звук дублируется с качественным оригинальным ресурсом мода, допустимо использовать существующий asset только если он подходит по характеру и это видно в файле/конфиге.

### Управление громкостью
- События разбиты на категории entity/blocks/ambient в соответствии с реально существующим `sounds.json`/API; звуки опасного предупреждения слышимы на территории **своего** зала и не слышны всему миру за сотни блоков.
- Idle редко и тише атак; громкий burst ограничен, overlapping loops выключаются при смене state/death/unload; обязательная обработка spatialization, чтобы несколько игроков слышали одно событие, а не N дублей из каждого клиента.
- Две сущности не должны звучать одинаково; Страж деревянно-огненный, Хранительница водно-каменная.

## 4. Текстуры и визуальная целостность
- Формат PNG с nearest filtering и без фотореалистичных высотных карт; рекомендованная кратность пиксельной сетки 16/32/64 на модельную UV-панель. Не раздувать texture atlas только ради микродеталей, не выдумывать сложный shader dependency.
- Каждая заражённая модель имеет минимум две выразительно разные зоны: оригинальный материал + багровое заражение; очищенная версия — **тот же skeleton/UV**, другой palette/state, без потери лица/узоров.
- Иконки фрагментов соответствуют друг другу формой и изображают части **одного** древнего оберега. Визуально проверять рядом на экране обычного инвентаря Minecraft.
- Оценить нагрузку: объём частиц при 2–4 игроках, локальные decals вместо реальных обновлений сотен блоков, audio loops без многократного запуска.
