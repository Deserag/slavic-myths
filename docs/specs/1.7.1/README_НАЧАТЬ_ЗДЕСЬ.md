**ЭТО ПРЯМОЙ ПРОМПТ ДЛЯ CODEX, И ОН ОДНОВРЕМЕННО ЯВЛЯЕТСЯ ИСЧЕРПЫВАЮЩИМ ТЕХНИЧЕСКИМ ЗАДАНИЕМ. НЕ ПЕРЕПИСЫВАЙ ЕГО В НОВЫЙ ПЛАН. ПЕРЕХОДИ К РЕАЛИЗАЦИИ.**

Реализуй в существующем моде Slavic Myths для текущей рабочей ветки **ровно релиз 1.7.1**: (1) призываемого союзника Илью Муромца, (2) босса Идолище Поганое, (3) их уникальные взаимодействия, (4) звуки, анимации, локализацию, настройки, сохранение прогресса и проверяемые тесты. Используй файлы архива как обязательную спецификацию; изображения в `04_Референсы` — реальные приложенные визуальные материалы, а `05_Звуки` — пригодные к подключению оригинальные OGG. Внешний вид утверждённой концепции сохранить; новые ракурсы нужны для технической реконструкции блочной модели.

## Порядок чтения
1. `00_ОБЯЗАТЕЛЬНО_ПРОЧИТАТЬ/00_Правила_границы_запреты.md` — обязательное, имеет высший приоритет.

5. Общие системы и проверки. Ресурсы из `04_Референсы` / `05_Звуки` подключить к соответствующим реестрам.

## Одна таблица неизменяемых чисел
| Параметр | Значение |
|---|---:|
| Рост Ильи | 2.5 блока |
| Илья: max HP | 280 единиц здоровья |
| Илья: снижение физического урона | 25%, до других временных усилений |
| «Несокрушимый» | автоматически при <=30% HP, 1 раз за бой |
| «Последний рубеж» | при <=15% HP (42 HP), отступление на лечение |
| Рост Идолища | 9 блоков |
| Идолище: max HP | 900 единиц здоровья |
| «Ярость Идолища» | при <=35% HP, однажды за бой |
| Баланс игрока для тестов | 12 сердец = 24 единицы здоровья, полная алмазная броня |
| Целевой урон сильного попадания босса | минимум 6 HP (= 3 сердца) по указанному игроку БЕЗ дополнительных бафов, чар и блока |
| Награды/трофеи | **Не добавлять в 1.7.1; запланированы в 1.7.6** |

**Важно о единицах:** Minecraft по умолчанию имеет **20 единиц HP, то есть 10 сердец**. Поэтому целевой персонаж с 12 сердцами — это 24 HP. Не путать эти два измерения.
