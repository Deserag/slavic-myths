# Илья Муромец — звуки, реплики, аудио-события

## Ограничения авторского права
Ориентир **по характеру** — мощный, низкий, сдержанный голос былинного богатыря; нельзя скачивать/нарезать и распространять звуковую дорожку анимационного фильма «Илья Муромец и Соловей Разбойник» без подтверждённых прав. Нельзя имитировать голос конкретного актёра. Все 15 OGG в `05_Звуки/ilya_muromets/` — **оригинально синтезированные невербальные эффекты, которые можно подключать немедленно**. Они НЕ являются полноценной человеческой дикторской записью. Для игровых русских фраз ниже требуется оригинальная запись актёром/пользователем либо согласованная TTS-модель с разрешением на использование. Не ставить текст субтитра, утверждающего дословную фонограмму, если озвучка только невербальная.

## Манера речи
Глубокий грудной бас, простые короткие фразы (1.2–2.5 sec), без подросткового крика и комедийного переигрывания. Микрофон сухой; лёгкая комната, без музыки. Экспорт моно OGG Vorbis 22050 Hz 16-bit ingest, динамика звука max -3 dBFS; реверберация не более 0.2 sec. Минимум 3 варианта часто повторяемых short pain/taunt in production; пакет даёт 2 боли и 1 taunt synth, недостающий актёрский материал — отдельный слот для будущего контента.

## Дополнительные оригинальные voice lines
`on_summon`: «Станем рядом, друг!»; `on_protect`: «За мной стой!»; `on_intercept`: «Не тронь!»; `on_boss_intro`: «Ишь, какое чудище землю русскую терзает!»; `on_boss_defeat`: «Вот и одолели нечисть!»; `no_path`: **без реплики**, не раздражать игрока повторением. Каждую реплику синхронизировать с анимацией; пока файла голоса нет, дать subtitle message лишь для `intro / taunt / retreat / victory` и оригинальный nonverbal effect.

## Registry / интеграция
Разместить в реальном Minecraft `assets/slavicmyths/sounds/entity/ilya_muromets/*.ogg`; JSON `assets/slavicmyths/sounds.json` с sound event именами `entity.ilya_muromets.taunt`, `entity.ilya_muromets.shield.raise`, `entity.ilya_muromets.shield.block`, `entity.ilya_muromets.mace.swing`, `.mace.hit`, `.hurt`, `.footstep`, `.drink`, `.recover`, `.return`; остальные индивидуально по manifest. Одновременно все события **не** запускать во время одной атаки; draw distance 24–32 blocks для речи, 40 для металлических clash. Pitch jitter ±0.04 для кратких повторов, случайный выбор нескольких файлов, ограничение gain max 1.0.

## Атрибуция
Читать `05_Звуки/manifest.json` и `08_Источники_звука/ПРАВА_И_ПРОИСХОЖДЕНИЕ.md`. Не объявлять процедурный sound «нарезкой из кино». Проверить действительное звучание в игре; генератор воспроизводимых исходников включён в архив.
