# Resource inventory, имена файлов и нужные реестры

В именах registry использовать **латиницу в lower_snake_case**, русские имена только в локализации. Учитывать фактическую Java package/loader naming текущей ветки; нижеприведённое — префиксы и обязательные факты, не предписание добавить параллельную систему.

## Entity/resource identifiers
`slavicmyths:ilya_muromets`, `slavicmyths:idolishche_poganoe`, `slavicmyths:idolishche_minion_marker` (data tag на vanilla zombie, НЕ третья новая сущность). Ожидаемые files: entity renderer/model and state machine, entity attributes/registry, 2 texture atlases, 1 sounds.json with sound events, keys ru_ru/en_us, boss encounter attach data, HUD, 2 model animation mappings.

## Обязательные ресурсы изображений
`textures/entity/ilya_muromets.png` 128×128 minimum, `textures/entity/idolishche_poganoe.png` 256×256 minimum, **фактически вручную выполненные** UV текстуры, не используйте целую приложенную картину как UV текстуру. `textures/gui/boss/idolishche_bar.png` 256×32 или equivalent procedural existing bossbar skin; `textures/gui/companion/ilya_status.png` 256×64 или equivalent existing companion HUD. VFX трёх кругов можно реализовать meshes/particles без файлов, но материалы должны быть три оттенка и три узора.

## Аудио assets
Физически скопировать 15 original `.ogg` из `05_Звуки/ilya_muromets` и 18 из `05_Звуки/idolishche_poganoe` в `assets/slavicmyths/sounds/entity/<character>/`. **Подключить каждое нужное имя** в existing sounds.json; JSON должен соответствовать формату именно установленной версии. Работоспособность OGG проверить `ffprobe`/real game event, а не считать наличие файла достаточным.

## Качество JSON и data pack
- У всех resource identifiers не должно быть пробелов и кириллицы.
- Проверить `UTF-8` и валидность JSON; отсутствие missing texture pink-black или звуков Missing sound event.
- Если мод имеет GeckoLib/Blockbench animation exports, использовать existing integration, не подключать вторую несовместимую анимационную библиотеку ради пары entity.
- Ни в одном рецепте нет новых материалов/наград, достижений, выпадающих артефактов.
