# Появление и организация схватки

## Границы релиза
Для 1.7.1 не строить масштабный сюжетный город или полноценное новое измерение. Обеспечить один честный воспроизводимый бой и возможность вызвать помощь Ильи в уже установленной системе призыва. Не добавлять новых дорогих уникальных артефактов ради вызова.

## Босс
- По умолчанию **не появляется обычным естественным спауном**. Внешний вид напоминает кошмарного огромного людоеда у старого укреплённого логова. Реализацию боя и тестирования обеспечить debug summon; если в проекте есть текущая система призыва боссов/специальных арен — **точечно** подключить туда Идолище через новый encounter identifier.
- При отсутствии такой готовой системы создать **безлутовую** точку схватки `Двор Идолища`: руины из ванильных камня/андезита/дуба/железных прутьев, внешний радиус 30 блоков, полезная площадка диаметром 44 блока, минимальная очистка под 9-блочную сущность — 13 блоков по высоте и по 6 блоков между препятствиями. Не заменять ландшафт вокруг по площади более чем 64×64. Предпочтение — выделенная безопасная staging arena только по специальному вызову/команде; **не генерировать автоматически по worldgen** в 1.7.1.
- Доступная для обоих бойцов зона: диск радиуса 26 вокруг `arenaOrigin` и периметр 2 блока из нерушимых на время боя визуальных маркеров, без невидимого убийства игрока; уход из зоны -> предупреждение 5 секунд -> encounter disengage/reset.
- Boss wander только внутри радиуса 23. Посередине не создавать столбы под потолком, в которых голова 9-блочного босса постоянно застревает.

## Призыв Ильи
В этой версии ввести первый hero-call controller с интерфейсом, пригодным для будущих трёх богатырей, **не реализуя их**. Если уже существует система — интегрироваться с ней. До начала битвы игрок может призвать Илью из доступного UI/предмета действующей механики (не вводить новый loot); контроллер хранит максимум двух summoned hero slots для будущего. Из уже существующих сейчас типов доступен **только Илья**, без разрешения клонировать его в два слота.
- В радиусе 6 блоков безопасная точка появления, проверка 2.5 блока клиренса и твёрдой опоры. Илья привязан к owner UUID и dimension.
- Во время активной встречи с боссом **запрещён любой новый вызов или замена богатыря**; ранее призванный Илья участвует.
- Если Илья не был призван заранее, босс проходим соло при высоком навыке и подходящем снаряжении, но заведомо значительно сложнее.
- Следование вне боя: 3–8 блоков, телепорт при >28 блоках и отсутствии прямого path, только вне arena и не сквозь стены с безопасным поиском.
- Покинувший поле боя на лечение Илья не освобождает слот для другого богатыря до окончания встречи.

## Масштаб противника
Hitbox Идолища ~4.2 блока в ширину, ~8.8 блока в высоту; render mesh top at 9.0. Порог дистанции melee измерять до края bounding box, не до центра его огромного тела; иначе игрок не достанет босса. Снаряды/удары должны корректно попадать в ноги, торс и руки. Bounding box разрешено разделять на сегменты только если основной контур корректно регистрирует любые попадания и не допускает двойного урона.
