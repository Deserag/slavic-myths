# SOUND & IMAGE RIGHTS MANIFEST — Slavic Myths 1.7.1

## Приложенные звуки
`05_Звуки/manifest.json` включает 33 файлам полное соответствие event file/name. Все аудио в этом архиве **оригинально сгенерированы локальным скриптом `08_Источники_звука/build_audio.py`** (детерминированные шумовые/тоновые компоненты и физический envelope; не использованы записи или звуковые дорожки фильмов). Отдельные короткие low-pitch звуки — **эффекты, не озвученные реплики**. Разрешена адаптация и использование этих оригинальных процедурных эффектов в моде, в том числе публикация, как часть данного проекта. Код производства тоже прилагается для пересборки.

## Нельзя автоматически допускать
Мультфильмы о богатырях, музыкальные фонограммы и голосовые партии могут охраняться авторскими и смежными правами; **не использовать фрагменты из фильмов «Мельницы» по неподтверждённому утверждению, что права отсутствуют**. Даже если интернет-ролик свободно просматривается, это не лицензия на распространение озвучки как части jar. Codex не должен скачивать/repack без документированной лицензии / разрешения правообладателя.

## Голосовые дорожки (ПОКА НЕТ В АРХИВЕ)
Список всех фраз, event cues и требования по голосу находятся в `01_Илья_Муромец/04_Звуки_реплики_триггеры.md` и `02_Идолище_Поганое/04_Звуки_рёв_шаги_эффекты.md`. Для производства им требуется оригинальная актёрская запись/законная TTS генерация без имитации узнаваемого актёра. Пока файла нет, НЕ ссылаться на несуществующие OGG; запустить невербальный слот + игровую subtitle строку.

## Приложенные референсы
PNG созданы генерацией для данного проекта, а не скопированы из кадра чужого мультфильма. Они предназначены для реконструкции **оригинальных** Minecraft-моделей; допускается художественная адаптация в рамках проекта. Два старых approved concept images и два новых обзорных листа включены, а отдельные 4-view sheets/палитры получены технической обработкой этих концептов. Вспомогательные overview pictures содержат OCR-like генеративные надписи и **не являются нормативным текстом**.
