# UI, Книга сказаний, достижения, лор

## UI
- Собственный босс-бар «Карачун» + стадия испытания, HP до 5%. При yield = «Испытание пройдено», не «Карачун убит».
- Два компактных индикатора на уровне экрана: шкала страха (фиолетовая иконка глаза) и угасания (тёмный морозный ромб с I/II/III); отключаемые/уменьшенные визуальные искажения, без полноэкранной постоянно вращающейся камеры.
- Значения КД на активных предметах (коса/амулет) показывать через существующие cooldown overlay/tooltip; настроить controls как уже в проекте, клавиши можно переназначать.
- На русском локализовать все предметы, имена boss attacks, статусы, квестовую цель, надписи «ещё не восстановился», сообщения о невозможности призвать второго boss, награды.
- Book of Tales: Карачун — один из фольклорно вдохновлённых образов зимы/смерти, артефакт из испытания понадобится в дальнейшем. Не утверждать как исторический факт, что все вороны и коса обязательные атрибуты исторического Карачуна. Не раскрывать заранее рецепт будущего Ада.
