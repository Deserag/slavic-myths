# Новое существо «Ворон Карачуна» — геометрия, AI, анимации

**Визуал:** `KARACHUN_RAVENS_APPROVED.png` + `raven_*` crops. Ворон — новая модель, не простая замена текстуры летучей мыши. Впечатление Minecraft raven: короткая блочная шея, угловатая голова, чёрный клиновидный клюв, **синие/холодно-фиолетовые глаза**, грудь из маленьких кубических перьев, широкие слоёные крылья из чернильно-чёрных/серых ступенчатых сегментов, слабая изморозь на кончиках перьев, компактные когти и хвост-веер.

**Виды:** полный FRONT, SIDE, BACK, лицо вблизи, сложенные/раскрытые крылья и масштаб рядом с игроком. Рекомендуемый размах раскрытых крыльев ~1.25–1.6 блока, размер тела ~0.45–0.65 блока (не утверждён, вписать в карту реальных хитбоксов).

**Анимации:** взлёт → wing flap при движении → редкий glide → круговое патрулирование → пикировании с прижатыми крыльями → раскрытие крыльев при торможении → удар клювом/когтями → отлёт на безопасную высоту → рассевание чёрно-синими перьями при отзыве/смерти. В посадке — сложить крылья; не телепортироваться рывками при обычном движении.

**AI:** в начале боя сервер создаёт 4 ворона по 20 HP каждый (проектный default, конфиг). Вороны *физические* hostile summons Карачуна: выбирают участника, кружат на высоте ~4–8 блоков (корректировать при потолке/деревьях), по очереди пикируют, атакуют реальным collision hit (по умолчанию 2–3 HP, CD между пикированием >=4–6 сек.), выходят из пикирования, снова кружат. Урон ТОЛЬКО при успешном серверном столкновении с допустимой целью. Не спамить одновременно всеми четырьмя одну цель без пауз.

**Повторные вызовы:** если уничтожены и перезарядка истекла, Карачун может довызывать до лимита 4 активных (предложение 35 секунд); не создавать ворон бесконечно каждым тиком. Хозяин по UUID/sessionId. Ворон Карачуна не бьют его, союзных ему summon-юнитов и защищённых NPC. Могут атаковать богатырей по общей системе hostile targeting, с читабельной агрологикой. Никаких обычных яиц/спавна в мире без отдельного разрешения.

**Союзные вороны «Чёрного крыла»:** та же отдельная модель и flying AI, **другой режим Faction/Owner**; ровно 2, на 20 сек, приоритет: цель владельца/защита владельца, без friendly fire и farm/exploits, не атакуют NPC/домашних/игроков из собственной команды. Визуально союзников можно отличать маленьким знаком под крылом/глазами, но сохранить базовый силуэт референса.

**Галлюцинации** — отдельная система; ворон-обманка как необязательный visual subtype, но основной страх может показывать фантомы привычных мобов. **Не выдавать фантомов за настоящих attack entities.**
