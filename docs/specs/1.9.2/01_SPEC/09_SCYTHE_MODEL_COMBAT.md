# Коса Карачуна — конструкция, боевое управление, хитбоксы, анимации

**Визуалы:** `KARACHUN_SCYTHE_COMBAT_APPROVED.png`, `KARACHUN_REWARDS_APPROVED.png` + `scythe_*` crops. Длинное тёмно-коричнево-чёрное древко с обмоткой, поперечными кольцами, резными костяными украшениями и висящей цепочкой с синим кристаллом. Широкий боковой клинок-полумесяц из почти чёрного металла, острые ледяные зубцы вдоль нижней стороны, прерывистая фиолетовая светящаяся кромка, тёмный обух. **Форма настоящей косы, НЕ серп, НЕ меч, НЕ топор.** Все углы front/side/back и lower-grip показывать одним согласованным мешем и разверткой. Отдельная 3D/voxel модель для предмета в руке/на земле и подходящие 2D inventory sprites. Руки держат древко двумя руками, соблюдая arm handedness.

## Обычная атака и комбо
- Выполняет 3 чередующихся движений: diagonal справа-налево, reverse слева-направо, верхний мощный финальный удар; окно серии, например 1.25 сек, затем reset combo.
- Не простой `swordDamage + freeze`. У атаки действительная область: дуга перед игроком радиус ~3–3.5 блока, сектор примерно 110–150 градусов для базового combo; не поражать врагов позади игрока при обычном swing. На одну атаку каждую цель можно ударить **только один раз** даже при пересечении нескольких tick hit frames. Реальный серверный cone/LOS/raycast и aim validation, не урезать wall collision.
- Базовые параметры оружия — balance defaults: 11–12 attack damage до enchantment/bonuses, тяжёлый attack speed ~-3.0. Учесть существующие сильные награды Полоза: балансируем в контексте модовой прогрессии, не придумывать в обход текущей системы.

## Пассивные способности
### «Жатва душ»
**Каждый третий успешный удар по одной и той же цели** накапливаемой цепочки накладывает Иссушение I на 4 секунды. Счётчик независимый для каждой цели UUID и конкретной косы/владельца, сброс после 8 сек без попадания (config). Промах и удар воздухом не увеличивают счётчик. Никакой заменённой по согласованию «Метки Карачуна».

### «Пожиратель жизни» — ПЕРВЫЙ В МОДЕ ВАМПИРИЗМ
**Реальный успешный удар** восстанавливает владельцу **2 HP (1 сердце)**, не чаще одного раза за **5 секунд** для владельца/оружия (server-side). Нельзя лечиться от бессмертных NPC, собственной птицы, бессмертных двойников, armor stands, нулевого урона, спама client packets, игроков из собственной команды; лечить <= реально нанесённого пост-митигационного урона, нельзя превысить max health. Красно-фиолетовые частицы перетекают от цели к игроку и дают короткий sound cue. Не стакается в одной атаке по пяти целям пятью срабатываниями.

### «Гроза нежити» — **вариант A**
Коса имеет +25% базового damage (дефолт) **по нежити** согласно корректным game tags/типам мобов, включая существующую модовую нежить, если она категоризована так в проекте. За **фактическое убийство** нежити косой (включая законно credited DoT, если учитывается владельцу) владелец получает **дополнительно 3 HP**. Проверять claim kill один раз по death entity ID, никаких XP/farm для fake summons. Дополнительные +3 HP поверх «Пожирателя жизни» допускаются, но за одно убийство — только один бонус. Не превращать «Грозу нежити» в накопительный заряд/Силу I: это не выбранные варианты.

## Активные способности — строго 2
### «Последний вздох»
CD **18 секунд** (default). Полный тяжёлый разворот с огромной горизонтальной дугой косы, **AoE radius 4 blocks**, линия видимости/закрытие стенами; удары по допустимым врагам, без friendly fire; урон примерно 1.4× weapon base при типовом 10 tick windup, телеграф ледяным кругом, тёмно-фиолетовый trail. Начало recovery не освобождает героя мгновенно для спама.
### «Чёрная жатва»
CD **22 секунды** (default). Игрок направляет косу и запускает **три полупрозрачных серповидных лезвия** по трём слегка расходящимся траекториям на дальность, например 8–10 блоков. Снаряды реальные **серверные** hitboxes, не только particle, не искривляются в homing аимбот. Твёрдые блоки их останавливают. Одну цель нельзя повредить три раза одним выстрелом без отдельного balancing cap; рекомендуем единый per-cast hit ledger. Появление звука и flash перед вылетом + fading trail. Не создавать «Проклятый размах» как ещё одну активную кнопку.

## Управление и интеграция
- ЛКМ = стандартный цикл ударов/3-комбо; alt skills через уже существующую систему спецспособностей/привязок. Имена клавиш в программе должны быть **переназначаемы** через текущий Minecraft Controls / существующий mod keymapping; не хардкодить `G`/`V` как единственный способ, если занято. По умолчанию выбирать свободные bindings исходя из фактической схемы проекта.
- Не создавать целый новый экран управления ради 1.9.2; отдельный раздел настроек управления обсуждался на поздний патч.
- Левую руку не использовать для обычного двойного wield при heavy scythe, если требуется полнота визуальной двуручной анимации; физически не удалять/перемещать offhand item. Поведение shield/offhand совместить с текущей системной механикой и «Угасанием».
- Для каждой способности отдельные effects, sounds, weapon animations и tooltip, а не пустые registry items.

## Реалистичность игрового результата
В hand/camera обе модели костей двигаются вместе; model item не выворачивается при замахах. Клип не застревает после weapon-switch/teleport/death. Сектор урона совпадает с прорисованной дугой. Соедини с существующим damage/runes/enchants и не сломай NBT/repair.
