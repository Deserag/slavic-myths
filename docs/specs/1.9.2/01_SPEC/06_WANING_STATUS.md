# Новый эффект «Угасание» и аура тёмного мороза

**Угасание** — НОВАЯ механика, не переименование старого зелья. Отображать 0..100 (server authoritative) и уровни I/II/III. Убрать отрицательные эффекты после завершения/выхода из испытания. Система пригодна для повторного использования в будущих патчах, но сейчас интегрируется только по 1.9.2.

| Накопление | Уровень | Реальные последствия |
|---|---|---|
| 0–24 | 0 | единичный тёмный иней, движения без штрафа |
| 25–49 | I | замедление движения примерно 15% (не стэкается до полного обездвиживания) |
| 50–74 | II | эффекты I + **короткие периодические** волны тошноты/головокружения, легкое camera wobble (без болезненной постоянной качки) |
| 75–100 | III | эффекты I/II + **левая / второстепенная рука** временно недоступна для обычного использования предметов и щита; содержимое инвентарного offhand слота не пропадает |

Приоритет оффхэнда: **сохранить ванильную работу Totem of Undying в offhand при lethal damage** — безопасность не должна ломаться скрытой блокировкой, запрет относится к активному использованию предмета/щита. На III уровне опустить визуальную левую руку вниз, на ней тёмный иней, попытка применить предмет даёт мягкий звук отказа и русское краткое уведомление, без постоянного чата. Если игрок левша/основная рука настроена другой, блокировать именно логический **offhand slot**, не фиксировать жестко левую клавишу/animation arm.

**Аура Карачуна:** radius 10 blocks (default). Внутри: near <4 block +8 ед./сек, middle 4–7 +5 ед./сек, outer 7–10 +2 ед./сек; значения defaults to tune. Вне ауры: небольшой grace 2 сек, затем -6 ед./сек; величины должны быть config. При дистанцировании эффект заметно падает; 3-й уровень не держится после очистки шкалы. Аура не наносит прямой DOT урон по умолчанию — её ядро потеря функций, не копирование смертельной морозной ауры Морозко.

«Прикосновение мороза» добавляет +20–25 единиц Угасания, «Прикосновение смерти» +8–12 если баланс позволяет, «Чёрный мороз» во время тьмы ускоряет накопление, но нет скрытого вторичного дебафа, который незаметно превращает победу в невозможную.

**Враги/богатыри:** эффект — для игроков, на боссов/обычных существ адаптировать без попытки блокировать несуществующие offhand/inventory API. Для мобов III — заметное замедление частоты атак/ослабление урона (на боссах — ослабленный статус), не отключать server AI навсегда. Богатыри сопротивляются быстрее и восстанавливаются (предложение 50% уменьшение скорости накапливания), но не игнорируют ауру полностью.

**UI:** компактный значок «Угасание» с I/II/III и маленькой полосой. Никаких fullscreen неотключаемых shader FX. Русское название, локализация/подсказки.
