# Страх, ложные мобы и «Долгая ночь»

## Страх
Отдельная шкала 0..100, **независимая от Угасания**. Возрастает от ночи, угроз/попаданий, атаки ворон и spell «Первобытный страх». По умолчанию thresholds: 0–24 без помех, 25–49 шорохи/периферийные тени, 50–74 до 2 индивидуальных фантомов, 75–100 до 3 индивидуальных фантомов + редкие ложные звуки (никаких постоянных фальшивых HUD-ударов). Вне испытания -8/сек после grace. Попадания по Карачуну могут немного снижать страх (например -6 при реальном успешном попадании, cooldown 2 sec).

## Фантомы — ДВА ТИПА РЕАЛЬНОСТИ
- Реальные вороны имеют UUID, server AI, hitbox/damage/health, существуют для **всех** клиентов сессии.
- Фантомы — **индивидуальные клиентские галлюцинации** конкретного игрока; внешне походят на уже существующих мобов Minecraft/Slavic Myths, но могут иметь лёгкий дрожащий тёмно-голубой контур при близком рассмотрении. Они **не серверные сущности**, не занимают мир и не получают drops/aggro и не должны восприниматься богатырями.
- При попытке ударить фантома — он сразу исчезает с мягким эффектом тёмного рассыпания (один локальный hit-test для виртуальной фигуры). Всплывающие движения/удары фантома не причиняют HP-урон, не меняют armor durability и не вызывают server-side события урона.
- Не перехватывать реальные атаки через entity spoofing, не регистрировать фантомов в серверном entity list, не отправлять клиенту fake server entity id, который ломает hit packets. Отрисовывать в клиентском менеджере сцены (уровень/камеру/математику луча определить по стеку). Если виртуальный фантом стоит между настоящим врагом и crosshair: приоритет настоящей server target, чтобы иллюзии не ломали боевую механику, затем локальное «исчезновение» phantom при атаке без реальной цели.
- Классика: пара зомби рядом; один настоящая сущность, один фантом. Ворон атакует сверху, пока игрок разбирается с иллюзией. **Ложные фантомы не обязаны быть только птицами**: reuse модель обычных зомби/скелета и 1–2 модовых существ без копирования их entity AI.
- При выходе, смерти, телепорте, завершении испытания, смене мира, disconnect и unload — подчистить client phantom manager, перестать рисовать overlay и воспроизводить ложные звуки.

## «Долгая ночь»
- Срабатывает на Карачуне; `windup=1.2 sec`, ночь вокруг **только арены/участников**, duration 15 sec defaults, CD 35 sec.
- Визуал: локальный тёмно-фиолетовый туман, редкий снег из чёрного льда, синеватый лунный круг, сокращённая дальность видимости; реальное мировое время/погоду/освещение у других игроков не менять. Не зашторивать HUD полностью.
- Пока активна: +30–50% набор страха, вороны становятся труднее заметны, но **обязательно остаются визуально читаемые глаза и предупредительные звуки пикирования**.
- Option `reducedEffects`: слабее туман, disable camera bob/nausea, без пульсирующего экрана, gameplay impact тот же.
