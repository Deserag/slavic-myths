# Обязательная реализация референсов как voxel-моделей и pixel textures

Плакат нельзя просто отрендерить целиком как одну огромную quad texture; требуются самостоятельные assets Minecraft. Ниже — измеримый ориентир для model review, координаты подогнать к текущей системе model units.

## Карачун
- В сравнении со Steve (2 блока) — почти двукратная высота, стройнее и **темнее**, плечи шире торса (примерно 1.7–2.0 ширины головы), мощная меховая рама и узкий низ рваного подола.
- Лицо не full-white snowman: нижняя часть серо-палевая, глубокие затемнения около глаз и впалых щёк; голубое свечение только в глазах.
- Отдельные кости/сегменты: костяные подвески справа/слева, серые пряди, наружный рваный край плаща, ледяные шипы, цепи с подвесками, ворот. Двигаться с animate bones, а не залипать.
- Текстура в насыщенных тёмных сегментах, не сливаться в одну чёрную массу: мех/подол/кожа/металл/костяшки должны различаться по value contrast, в ярком дне и ночи.

## Косы и предметы
- Коса должна иметь изогнутый длинный blade sweep и *физическую толщину*, чтобы профиль был отличим от 2D плоскости, в инвентаре отдельная иконка.
- Руна угасания с узким **фиолетовым ромбом со штрихом** в центре, тёмно-серая плита с голубыми обледеневшими углами. Нельзя копировать snowflake rune Морозко.
- Чёрное крыло: плечики пера/крыла симметрично окаймляют каплевидный светящийся кристалл. Инвентарь 16–32px должен легко узнать два крыла.
- Осколок: вертикальная, неровная тёмная кристаллическая форма, violet inner slit; не синий круг или сердце.
- Тотем: миниатюрная ритуальная фигура с выступами, синим светящимся знаком; если можно поставить, убедиться, что placed block и item icon визуально соответствуют.

## Ворон
- Клюв клином, голова angular; крылья из 3–5 крупных ступенчатых перьевых секций на каждой стороне + 2–3 нижних кончика; внутренние кисти пера тёмные, слегка иней только на краях.
- При раскладке крылья должны заметно раскрываться в два раза по ширине, перья не проскальзывают сквозь грудь; in-flight silhouette читается на фоне ночи.
- Тёмные глаза не скрывать, допустимый холодно-фиолетовый glow 1–2 пикселя в texture.

## Проверка ассетов
Для каждого объекта — визуал референса front/side/back, перечисление model resource / texture path / registered renderer / optional animator; actual asset exists и файл валиден; `Missing texture` и invisible entities недопустимы. Экспертная оценка '1:1' невозможна без визуального QA пользователя: честно перечислить технические отклонения от плаката.
