# Единственная выбранная руна 1.9.2 — «Руна угасания»

**Важное решение:** пользователь выбрал именно **эту руну**; не генерировать автоматически 50/50 две руны по схеме Морозко. Руна гарантирована **одна на каждое успешное испытание**, если игрок eligible. Не создавать в 1.9.2 «Руну несокрушимого духа», «Руну последнего часа» или «Руну мёртвой ночи» как дополнительные награды.

## Внешность
`KARACHUN_REWARDS_APPROVED.png`, `items_rune_waning.png`: крупная продолговатая неровная руна из тёмного обсидианово-серого камня, по кромке **угловатые светло-синие ледяные наплывы**; в центре яркий узкий лилово-фиолетовый значок, геометрический вертикальный ромб с осевым штрихом, не снежинка Морозко. Нужны inventory icon, dropped item model и rune socket icon — одинаковый символ. Пиксельный UV, без blur/слишком тонкого нечитаемого текстового глифа.

## Механика
- Вставка **в оружие** через существующую систему рун и её требования, не отдельный самодельный forge UI.
- Каждый **успешный hit** даёт **20% шанс** наложить/увеличить серверную шкалу «Угасание» на цели на +25 единиц (config), ICD на уникальную цель ~1 сек для предотвращения AOE instant-III.
- Для игрока-получателя эффекты I/II/III такие, как в `06_WANING_STATUS.md`; не отключать обычную верхнюю руку или Totem-of-Undying.
- Для обычных мобов без offhand: I замедление, II слабость/снижение скорости атак, III кратковременный тяжёлый combat debuff без полного AI freeze; на больших боссах — пониженная длительность/эффективность и cap level II, если совместимость требует. Стек должен быть полезен, но не бесконечно станить боссов.
- Прок прокатывается на **сервере**, не на визуальном ударе без damage. Runes + enchanted weapon + AoE проверяют per-target ICD; не обходить rune socket limit, не ломать NBT при перековке.
- Tooltip на русском описывает proc, шкалу, ограничения; icon в действующем руническом меню. Если у игрока уже открыт слот руны другой версии — конвертация/сохранение безопасны.
