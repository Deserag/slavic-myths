# Наградной амулет «Чёрное крыло»

**Получение:** 100% при ПЕРВОМ успешно завершённом испытании на каждого игрока. Повторно не дюпать автоматически; если утратил амулет — не давать незаслуженный дубль через спам, реализовать восстановление только согласованным/имеющимся механизмом, либо чётко документировать.

**Внешний вид:** `KARACHUN_REWARDS_APPROVED.png`, `items_black_wing_amulet.png`: тяжёлая тёмно-стальная цепочка, центральная каплевидная светло-голубая грань, по краям веером **два миниатюрных чёрных крыла из ступенчатых перьев**, внизу короткие острые ледяные подвески; крупный pendant, но inventory icon читабелен на 16–32px. Не использовать иконку Морозного зерцала, не делать просто один чёрный амулет с текстом.

**Аксессуар:** установить в уже существующий слот аксессуаров (проверить ограничения: если свободный амулетный слот занят, подсказать текущую UI-логику; не создавать новое окно). Активное действие по существующему keybind/reassignable controls. Нельзя применить в инвентаре без корректной активации, нельзя использовать пассивно из рюкзака, если мод требует активный slot.

**Способность:** однократный вызов **ровно 2 физических союзных ворон** при нажатии, duration **20 sec** или до 0 HP, global owner cooldown **150 sec** (server defaults), детальный визуал/модель как у призываемой Карачуном птицы. Призывать в непосредственной допустимой близости от хозяина, не внутри блока и не за стеной. Сигнал тонкого карканья, чёрно-фиолетовый вихрь перьев. Вороны летают, атакуют выбранную владельцем законную цель или защиту игрока, не бьют его, его союзников/богатырей, Кота Баюна, Бабу-ягу и мирных NPC. Нет лута/XP за искусственно удалённую птицу. Не клонировать бесконечно через re-equip, death, disconnect, dimension switch; owner UUID и завершение на server.

**Сравнение с другим амулетом:** Морозное зерцало создаёт копию игрока; «Чёрное крыло» призывает **двух самостоятельных летающих ворон**. Механики не заменяют друг друга. Если обе способности включены, не создавать лишний регистр слотов; применять существующие правила одновременных аксессуаров.
