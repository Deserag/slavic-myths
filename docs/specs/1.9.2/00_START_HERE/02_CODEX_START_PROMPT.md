# ГЛАВНЫЙ ПРОМПТ ДЛЯ CODEX — Slavic Myths 1.9.2 «Испытание Карачуна»

Реализуй **полностью работающий патч 1.9.2** в текущем проекте Slavic Myths; это не brainstorming и не прототип. Сначала прочитай весь пакет `00_START_HERE`, `01_SPEC`, `03_IMPLEMENTATION`, `04_QA`, и только потом приступай к точечному осмотру кода по `03_IMPLEMENTATION/01_TARGETED_INTEGRATION.md`. Не сканируй повторно весь проект, не запускай Minecraft/PolyMC/игру. Исходные версии и API бери из текущего build config.

**Карачун:** НЕ заражён. Это отдельное тяжёлое испытание через ритуальный предмет, который игрок реально получает у Бабы-яги **либо** Кота Баюна (согласно действующим отношениям/прохождению). Внешность строго по `02_REFERENCES/approved_full/KARACHUN_DARK_BOSS_APPROVED.png`: тёмный рваный плащ, чёрный мех, черепообразное лицо, седина, костяные и ледяные подвески, фиолетово-синий тёмный лёд, гигантская коса. Он должен быть заметно темнее и отличимее от Морозко. Виды **спереди/сбоку/сзади**, самостоятельная геометрия, отдельные анимации, 3D оружие, не recolor. При вызове создаёт **четырёх реальных ворон по 20 HP** (дефолт); визуал и полёт по `KARACHUN_RAVENS_APPROVED.png`. Богатырей призывать можно.

**Бой:** постоянная аура «тёмный мороз» накапливает уникальное **«Угасание»**: I — замедление, II — плюс кратковременная тошнота/головокружение, III — плюс временная блокировка **только offhand** (с безопасностью тотема); при дистанцировании статус ослабевает. Отдельная шкала **«Страх»** вызывает локальные индивидуальные клиентские фантомы существ — они не наносят реального урона и исчезают при одном попадании, при этом **настоящие вороны продолжают наносить настоящий урон**. Локальная «Долгая ночь» (не глобальная смена времени) и атаки «Прикосновение голода» (быстро тратит сытость, не HP), «Прикосновение мороза», «Прикосновение смерти», «Погребальный взмах», «Последний час» (предсказуемая и уклоняемая) и финальная фаза. Никакого инфекционного Мора.

**Победа:** ориентир HP 1200 (конфиг), при снижении до **5% максимального HP** без смертельного удара переходит в YIELD/FINISH: отменить урон, снять локальную тьму, отозвать ворон, удалить фантомы и дебафы участников, завершить один раз, выдать каждому честному участнику серверные персональные награды.

**Награды:** в первый успешный раз **амулет «Чёрное крыло»**, который призывает ровно двух реальных союзных ворон на ограниченное время; **одна Руна угасания** при каждом успешном прохождении (другой руны не добавлять!); **коса Карачуна** независимый roll предложенные 15% за прохождение; **Осколок последней ночи** — гарантированно каждому после каждого прохождения. Возможность дальнейшего союзного призыва самого Карачуна, если предусмотрена общей дорожной картой, относится к 1.9.3 — не реализовать её в 1.9.2 без прямого требования (можно сохранить флаг `karachunTrialCompleted`).

**Коса:** самостоятельная 3D-модель и корректные анимации в 1-м/3-м лице по `KARACHUN_SCYTHE_COMBAT_APPROVED.png`; комбо из трёх широких двухручных ударов; **Жатва душ** (каждый 3-й успешный удар по одной цели — краткое иссушение), **Пожиратель жизни** (первый в моде эффект вампиризма: лечение только от корректного попадания, 2 HP/5 сек.), активные **Последний вздох** (круговой AoE, CD 18 сек.) и **Чёрная жатва** (3 призрачных лезвия, CD 22 сек.), **Гроза нежити вариант А** (+25% базового урона против нежити и лечение 3 HP за убийство нежити). Не создавать «Метку Карачуна», не добавлять «Проклятый размах» как дополнительный навык. Не следовать ошибочной подписи про «метку» с картинки косы: картинка задаёт визуал, а этот текст — механику.

**Звуки:** настоящие зарегистрированные собственные `.ogg`/sounds.json по звуковому сценарию; динамика «Долгой ночи», карканье, трепет крыльев, страх, коса/попадания, угасание, завершение испытания. Проверить, что нет отсутствующих файлов. Полные русские тексты.

Критерии приёмки и чеклист — в `04_QA`. Подготовить сборку и отчёт без запуска клиента/игры; при частичной готовности отмечать частичную, не выдавать за законченную. Работать только с реальными APIs текущего проекта. Не начинать 1.9.3, Змеиную гору, Ад, рефактор всего дерева рун.
