# 03_ASSETS — материалы, звуки, ресурсы

## 1. Техническая совместимость ресурсов
Ориентир проекта: **Minecraft 1.16.5 / Forge 36.2.42 / Java 8 / modid `slavicmyths`**. Привязать ресурсы к действительной структуре проекта (`assets/slavicmyths/...`); НЕ создавать дубликаты зарегистрированных предметов 1.8–1.9 и не заменять модовые ID без миграции.

| Группа | Требуемые ресурсы | Требования |
|---|---|---|
| Gorynych | модель тела, 3 шеи/головы, 4 лапы, хвост, отдельные 2 крыла | модель с частями для независимых animations, сегменты блоковые |

| Boss animations | idle, patrol/walk/turn, 3 головы windup/attack/recover, bite/grab/release, tail sweep, ground spikes, morph, flight, dive, wing gust, land, exhausted, three cleanses, purified | отдельные keyframes и события урона, 1st/3rd person only where applicable |

## 5. Форматы
- Пиксельные текстуры PNG, без реалистичной фотографии/фильтрованных фотографических материалов; не применять smooth sampling там, где текстура Minecraft должна быть пиксельной.
- Звуки OGG; `sounds.json` должен содержать реальную регистрацию и проверенную ссылку.
- Данные рецептов/лут-таблиц JSON с правильными namespace/path для Minecraft 1.16.5; для NBT-сохраняющих апгрейдов — локальный custom recipe в существующей архитектуре.
- Модели: придерживаться фактически используемого в проекте формата моделирования, без добавления тяжелого нового рендер-движка ради одного босса.
