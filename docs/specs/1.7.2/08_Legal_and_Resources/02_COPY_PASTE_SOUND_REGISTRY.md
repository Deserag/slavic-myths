# Ready-to-integrate audio templates

`08_Legal_and_Resources/sounds_json_TEMPLATE.json` enumerates **all 39 real OGG assets** in Minecraft `sounds.json` syntax. Copy this content into `assets/slavicmyths/sounds.json` if the current project uses mod ID `slavicmyths`, or merge its entries into the existing file (NEVER replace unrelated sound events). Place OGGs in corresponding `assets/slavicmyths/sounds/{dobrynya|marinka|arena}/...ogg` paths. Template sound key `dobrynya.spear_parry_01` names path `slavicmyths:dobrynya/spear_parry_01` and links subtitle key `subtitles.slavicmyths.dobrynya.spear_parry_01`.

`08_Legal_and_Resources/sound_subtitles_{ru_ru,en_us}_TEMPLATE.json` are complete 39-event human-legible fallback sound-description entries, not substitutes for the story/dialogue localization in `09_Localization`. Merge with actual existing language JSONs and refine subtitle text as needed. Do not assume all 39 must sound each frame; event descriptions/timing and priorities in the 4 audio documents control scheduling. If namespace differs, replace namespace systematically before adding entries. Use configured sound registry; static JSON is not proof Java sound event registries were properly implemented, so compile and run checks are mandatory.
