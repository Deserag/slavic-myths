## 1. Фиксированный список новых предметов для броневой части

**Два комплекта — 8 носимых предметов.** Рабочие ID приводятся в ART_IMPLEMENTATION_LOCK; перед регистрацией проверить дубликаты на HEAD `hell`, сохранить идентификаторы после утверждения.

**Промежуточные ресурсы (не часть worldgen):**
| RU название | Предлагаемый item ID | Форма маленькой иконки 16×16/32×32 | Палитра/контраст |
|---|---|---|---|

Для всех 7 сделать настоящий PNG пиксель-арт с прозрачной подложкой, отдельные ItemModel JSON (или корректная версия модели для 1.21.1), RU/EN title, tooltip, creative grouping; исключить `missingno`. Ключевая проверка: в инвентарной ячейке при 1× видны разные силуэты; 7 перекрасок одной геометрии = FAIL_ART. Первые два ингредиента относятся к первой броне; остальные пять используются в рецептах боссовой (в т.ч. уголь как mob drop).

## 2. Предложения как конкретные исполнительские значения (не путать с пользовательскими прямыми решениями)

- **Первый комплект:** armor values как у алмазной 3/8/6/3, `toughness=3.0`, `knockbackResistance=0.05`; durability = ceil(diamond×1.15), repair ingredient **Алатырский слиток**. HP-бонус первой комплектации по #326: шлем +1 HP, кираса +2 HP, поножи +1 HP, сапоги +1 HP (= +2.5 сердца вместе). Если у мода есть обычные адские усиления, не удваивать эти бонусы через set trigger.
- **Второй комплект:** armor values стартовая таблица 4/10/8/4, `toughness=4`, durability ceil(diamond×1.5), repair ingredient **Алатырский слиток**, `knockbackResistance` как дополнительный +0.25 только для полного набора, не за каждую деталь. **Итоговая защита должна считаться сервером и тестироваться на 20 разных типах повреждения**: vanilla armor cap не считать гарантирующим работу неограниченного armor value. Бонусы +HP и эффекты — строго #326/основной контракт.
- **Шлем:** bonus +3 HP и +20% урона игрока (допустимые прямые атаки), не поражает само себя в цикле; **кираса:** +6 HP, −25% обычного полученного урона; **поножи:** +4 HP и 15% к движению; **сапоги:** +2 HP, прыжок выше и Slow Falling; **полный сет:** 20% скорости суммарно, защита от огня/лавы только в Нижнем мире и +0.25 knockback resistance. Это owner-релевантные значения с конкретным anti-stack соглашением.
- **Руны:** первая броня 2/3/3/2, вторая 3/3/3/3. Использовать имеющуюся запись `ItemState.runes`, no new NBT. Не выдавать все socket slots открытыми. Для первой кирасы/поножей важна кастомная ID ветка перед `armorCapacity`, потому что material-based доработки иначе присвоят всем четырём 3.
- **Эффекты на персонаже, не при нахождении в сумке.** Снятие, смерть, измерение, restart и switch между комплектами снимают модификаторы без остатка. RuneRuntime меняет transient attributes; обновление не должно удалять чужие modifiers.
- **Исключить новые звуки и обязательную установку дополнительных библиотек без согласования**. Для эмиссивной маски и 3D плаща рассмотреть собственный NeoForge client renderer/model layer совместимый с текущим проектом, не заменять плоским vanilla layer из-за желания избежать кода.
- **Блоки-станции** и «Адский уголь» не входят в эту броневую подзадачу #326; это родитель #325.

## 3. Структура рецептов и возможность крафта без OP

**Шаблон, результат 4:**
~~~text
[Кварц Незера] [Незерский кирпич] [Кварц Незера]
[Бумага]        [Обожжённый пекельный осколок] [Бумага]
[Бумага]        [Сера]           [Бумага]
~~~
Порядок компоновки задаёт ориентацию template, способ получения — ванильный верстак; тест с `minecraft:nether_brick` ITEM, а не `nether_bricks` BLOCK.

**Жаровая пластина, результат 1:**
~~~text
[Живокамень обожж.] [Пекельный осколок обожж.] [Живокамень обожж.]
[Пекельный осколок обожж.] [Алатырский слиток] [Пекельный осколок обожж.]
[пусто] [Золотой слиток] [пусто]
~~~

**Боссовые катализаторы, результат 1** — точные слоты в #326, без случайных альтернативных наборов. Каждый содержит **Алатырский слиток** в центре и соответствующие боссовый/обычный дропы. У Posten 4-ликовый венец, у Magma Lord Сердцевина, у Grove Guardian Плетение, у Жареницы Печать поступи. Перед изготовлением каждого надетого предмета требуется ещё алмазная основа и шаблон (smithing table). Шаблон при smithing расходуется ровно 1, catalyst ровно 1, исходная diamond-часть ровно 1, output ровно 1.

## 4. Конкретные negative/compatibility gates для 7 промежуточных предметов

| Тест | PASS только если |
|---|---|
| Нет босса — нет части | Из одного только обожжённого сырья невозможно изготовить боссовую броню |
| Трофейная голова | Случайно не расходуется и не считается заменой уникального сердечного/печатного материала |
| Тлеющий уголёк | Дополнительный честный loot Пекельника, не выдаётся дважды через entity drop + event |
| Алмазная основа | Замена на iron/netherite/другую diamond-часть рецепта НЕ проходит |
| Износ / enchants / custom name | После апгрейда сохранены, процент повреждения соответствует исходнику |
| Trims и нестандартные компоненты | Нет удаления других data components (кроме тех, которые технически нельзя переносить — обосновать) |
| Переполненный инвентарь и shift-click | Ничего не теряется/не дублируется, накрафтить 64 из 1 катализатора нельзя |
| Recipe book / RU / EN | Все реальные названия и значки совпадают и доступны без OP |
| Свободные места | Иконки маленькие, узнаваемые, нет пиксельного мусора/текстур из другого мода |

**Окончательный gameplay contract:** `#326`; окончательный art contract: `ART_IMPLEMENTATION_LOCK_2.0.X.md`. При отсутствии реальных бинарных оригиналов в GitHub художественная задача остаётся `BLOCKED_REFERENCE` независимо от качества письменной документации.
