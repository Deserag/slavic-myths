# Строгое ТЗ: ТРИ НОВЫЕ ТРОФЕЙНЫЕ ГОЛОВЫ НОВЫХ БИОМНЫХ БОССОВ (2.0.2/2.0.3/2.0.4)

**Прямое решение владельца, 27.10.2026.** Три **отдельных настоящих Minecraft размещаемых головы**: Сторож чащи (биом 2.0.2), Жареница (2.0.3), Постень (2.0.4). Это **НОВАЯ микрозадача поверх уже существующей общей [#140](https://github.com/Deserag/slavic-myths/issues/140)** (старые головы Тугарина/Скима/Волколака/Лиха/Крупного Подземника и т. п.). **НЕ переделывать старые головы #140, не создавать новую общую дублирующую подсистему.** После создания отдельной Issue её номер закрепить в этом документе.

## 1. Единый технический контракт

- Каждый из 3 боссов **гарантированно отдаёт ровно 1 свою голову** после настоящей единственной победы, независимо от Looting/difficulty. Дроп одновременно с другими гарантированными уникальными наградами, **НИ ОДИН** из обычных/теневых мини-клонов босса не дропает вторую. Существующая kill/death/drop pipeline одна серверная; не добавлять head и loot table, и второй LivingDropsEvent одновременно.
- Для каждой головы: **один стабильный Item ID** (примерная схема `slavicmyths:guardian_grove_head`, `slavicmyths:zharenitsa_head`, `slavicmyths:posten_head` — точные ID сверить с текущими registry до регистрации); сопутствующий `Block/BlockEntityType` по архитектуре текущих `TrophyHeads` и `TrophyHeadsClient`, уникальные `ModelPart`/UV/текстуры. Если единая система регистрирует головные варианты под одним block ID через Kind, использовать её, не делать параллельную incompatible регистрацию.
- Размещение на **полу и стенах**, orientation по направлению взгляда (4 горизонтальных направления + wall face), добыча соответствующей head при разрушении, pickup/re-place без потери имени/варианта, creative catalog/локализация RU/EN/tooltip, correct sound, не `minecraft:player_head` с generic skin, не 2D плоский квадрат.
- Физические размеры **обычного трофея**, ориентир `~0.65–0.85` полного блока высоты/ширины на пьедестале, не 3–5 блоков как исходный босс. Все 3 должны адекватно стоять рядом на витрине; collision и block outline привязаны к неподвижной опоре, **анимации не меняют физический block shape каждый тик**.
- Небольшие **индивидуальные** клиентские эффекты только для видимой установленной головы (item icon/render статический, чтобы не прыгать на курсоре). Границы производительности: **никаких обязательных server tick BE для косметики**, не сканировать все BlockEntities мира каждый tick, не спавнить бесконечные постоянные частицы. В unloaded/non-rendered чанках нет эффектов, статусы и инвентарь не изменяются.
- Если есть приближающийся игрок: **не трогать его HP, potion effects, aggression/AI, inventory, sneak и HUD**. Все эффекты строго косметические.
- Текстуры Minecraft pixel art, геометрия 3D, исходные авторские модели/UV. **НЕ выдумывать голову вместо отсутствующего оригинального арт-референса**: подтверждение SOURCE SHA для каждого исходного концепта от владельца, отдельные front/left/right/back/top для готовой новой trophy model. Поскольку artwork босса ≠ trophy geometry, уменьшить оригинальные элементы разумно, сохраняя silhouette/eyes/face.

## 2. Голова Сторожа чащи (700 HP boss, биом «Навья роща»)

**Вид:** тёмный грубо вытесанный сучковатый деревянно-костяной череп с двумя асимметричными выступами ветвей, корнеобразной «челюстью», сохраняющей исходный образ многоярусного Стража, не generic zombie/creeper head. Ранее утверждённый финальный **тёмный** облик Сторожа приоритетнее светлых ранних генераций. Текстурная сетка грубая, видны сучки, чёрные корни, бледные костяные вставки. От boss 700 HP **100% ×1**, не заменять Сердцевину чащи/Ветви.

**FX:** лёгкое шевеление 2–3 внешних веток, очень медленная ритмическая пульсация глаз/сучков, **едва видимые** частицы листового пепла/корешка не чаще **1 частица / 50–70 видимых клиентских тиков** для близкой головой (инженерная частота, подстроить при тесте). Не выращивать блоки корней вокруг, не разрушать основание, не менять цвет всего экрана.

## 3. Голова Жареницы (750 HP boss, биом «Чёрная гарь»)

**Вид:** **женская** угольно-тёмная маска/голова с пепельной короной/венцом, огненными трещинами, раздельными выразительными оранжевыми глазами и рваной гривой дымных прядей, никакой обычной головы скелета, не калька Зимней ведьмы. Нет полноразмерного тела/плаща трофея. При победе **100% ×1** поверх всех печатей брони/руны/души.

**FX:** поочерёдное притухание/разгорание **локальной** линии глаз/трещин на исходной голове, едва заметное движение двух пепельных прядей/венца и редкие искры (не больше 1 на ~40–60 видимых client ticks). **НЕ поджигать мир**, не ставить огонь, лаву, не делать динамически меняющийся block light с постоянными neighbor updates. Цвет черепа остаётся узнаваемым без emissive render.

## 4. Голова Постеня (650 HP boss, «Чертоги заблудших»): интерактивная трофейная масочная конструкция

**Основной уникальный запрос владельца:** **при подходе игрока голова ПОВОРАЧИВАЕТСЯ**, маски и глаза тоже меняют состояние. Это настоящая анимация модели на placed block, не частицы вращающегося предмета и не глобальное изменение BlockState каждой секунды.

**Форма:** тёмная голова духа со скошенным кольцом и четырьмя независимыми **геометрическими** выразительными масками как у оригинального босса, в уменьшенном масштабе; `face_sorrow` бледно-голубая скорбь, `face_anger` красное сердитое лицо, `face_decay` тёмно-зелёное истление, `face_silence` фиолетовая пустота. Глаза меняются в зависимости от повернутой маски. Единая подставка остаётся закреплена.

**Детерминированная схема визуальной реакции (baseline для QA):**
1. Когда ближайший **реальный** игрок в пределах **6 блоков** до поставленной головы (3D дистанция, можно выбрать ближайшего при нескольких), и чанк открыт/видим, модель просыпается: лёгкая пауза 0.3–0.5 с; кольцо **медленно поворачивается на 90°** к следующей маске за **0.6–1.0 с**, easing с непрерывным интерполированным рендером, не snapping текстуры.
2. При длительном нахождении игрока рядом цикл идёт **один шаг примерно каждые 2.0–2.5 секунды**, маски в фиксированном порядке: Скорбь → Гнев → Тление → Безмолвие → Скорбь. На каждом шаге **моргание/переход свечения глаз** к оттенку соответствующей маски. Не применять эффекты Poison/Wither — это выставочный трофей, не ловушка.
3. Дополнительно основная узкая часть черепа **мягко поворачивается** по горизонтали к ближайшему игроку максимум на ±20° **относительно направления установки**, не прокручивается на 360° вслед за его спиной; это не заменяет реального кругового поворота масок. Глаза не остаются неподвижными на мёртвой исходной face после смены.
4. При отходе за **8 блоков** анимация спокойно прекращает цикл (гистерезис 6→8 предотвращает дрожание границы); голова остаётся в текущем лице либо возвращается мягко в исходную позу без snapping; **настройка не должна перегенерировать ItemStack/NBT или головной loot**.
5. Клиентский `BlockEntityRenderer`/render animation на основе уровня времени (client tick + partial tick), без **обязательного серверного scan** голов и без объявления server authoritative gameplay. Каждый наблюдатель может видеть немного отличающуюся косметическую фазу; если дизайн требует одинаковой маски для двух игроков, использовать только минимальную sync переменную по событию/изменению, а не постоянные блок-обновления.
6. Все четыре **реальные геометрические маски** остаются видимыми/различимыми в скриншотах при снятой эмиссии, а поворот на 90° сохраняет их правильное лицевое направление. Не делать трюк с одной квадратной головой и меняющейся palette-текстурой. Не замораживать rotating ring при сохранении/перезаходе.

**QA:** установить **10 экземпляров** голов в 4 ориентациях и на стену/пол, проверить 0, 5.9, 6.1, 7.9, 8.1 блока, подход с разных сторон, два игрока, spectator/view frustum, камера от предмета, `relog`, `unload/reload`, FPS/particle count. Кадры `idle` → `mask 1` → `rotation mid` → `mask 2/3/4` → `idle far`, и медленное eye blink. Голова **не наносит урон**, эффекты не копируют боевые заклинания.
