## 2. Точные размеры, позиционирование, помещения
- **Фиксированный участок военного района:** городские X=12..39, Z=75..99 (**28×25**). Важно: `Xcity=12+Xlocal`, `Zcity=75+Zlocal`, `Yworld=Yplatform+Ylocal`.
- **Комплекс:** полный bbox Xlocal=0..27, Zlocal=0..24, Ylocal=0..17; итоговая высота 18 уровней.
- **Главный двухэтажный корпус:** Xlocal=2..25 (24 блока) / Zlocal=1..11 (11 блоков); фронт в северную сторону, кровля Xlocal=1..26 / Zlocal=0..12. I этаж — пол Y0, стены Y1..5; II — пол Y6, стены Y7..11; скатная кровля Y12..17.
- **Ратный плац:** Xlocal=1..26, Zlocal=13..23 (ширина 26, длина 11), ограждения и тренировочная зона. Мишени из `minecraft:target` на опорах, деревянные тренировочные чучела из `crimson_fence` + `carved_pumpkin`; не вводить новых сущностей или специального манекена.
- Вход в корпус с северного городского прохода, второй выход во двор с юга; в заборе двора есть проходы на городские дорожки. Основная центральная зона коридора Xlocal=11..17 и двухблочная лестница Xlocal=11..12 (Zlocal9→4, Y1→6); физически проверять переход на II этаж.
- **В общей картинке больше башен**, но участок мал: не добавлять огромных внешних башен, перекрывающих квартал. Дозорная позиция/подвесы возможны только по проверяемому R2 в рамках bbox и после приёмки.

### 4.4 Главный сундук сотника — НЕЗЕРИТОВАЯ БРОНЯ ОБЯЗАТЕЛЬНА
`nether_druzhina_captain.json`:

2. **НЕЗАВИСИМЫЙ ШАНС 20%**: **ещё одна** из этих четырёх частей с теми же весами. Итого **80% шанс ровно одной части, 20% шанс ровно двух**. **Максимум две части, полный комплект из четырёх невозможен в одном комплексе.** Две части **могут совпасть** — в чистых двух ванильных JSON-пулах исключение дубликата не предусмотрено. Не заявлять о гарантии двух разных частей без отдельной серверной логики/уточнения владельца.
3. **Обычный трофейный пул:** 2–3 выбора из `minecraft:gold_ingot` (вес 4,1–2), `minecraft:gold_nugget` (8,2–7), `minecraft:iron_ingot` (5,1–3), `minecraft:book` (3,1–2), `minecraft:arrow` (4,4–12).
4. **70% независимый шанс** на **1–4 `slavicmyths:ancient_coin`** (не более четырёх монет в этом сундуке), уже существующий предмет.
5. **25% независимый шанс** ещё одного оружия: `minecraft:diamond_sword` (вес 35), `minecraft:diamond_axe` (25), `minecraft:crossbow` (20), `minecraft:bow` (20). **Незеритовое оружие пока не добавляем**, чтобы сохранить роль брони. В будущем после теста можно обсудить зачарованные версии, но сейчас **нет придуманного enchantment NBT**.
6. Ни один другой сундук комплекса не содержит незерита; не допускать копирования этого пула в обычные дома/казармы/кладовые.

Подсчёт `2–4 выборки` означает взвешенные roll, а не ровно N гарантированно разных слотов. Одинаковые предметы могут складываться.
