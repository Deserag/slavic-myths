# Slavic Myths 2.2.7 — «Зелейная изба», вариант Б

Одноэтажная изба с высокой кровлей и клетью, сушильным навесом, двором и грядками. **Статус: архитектурное ТЗ и машинная блочная модель, не игровая реализация.**

- Город: 113×113; зарезервированный участок **X76..100/Z44..69** (25×26).
- Основное здание **X78..92/Z46..60** (15×15); отдельная клеть **X94..99/Z47..55** (6×9); навес **X94..99/Z56..60** (6×5), двор **X78..92/Z62..68**, огород **X93..99/Z62..68**.
- Машинная модель: [MODEL_R1.json](./MODEL_R1.json) — **1599 non-air блоков**, Y0..10, block ID + state.
- [Этаж](./FIRST_FLOOR.svg), [кровля](./ROOF.svg), [13 послойных SVG](./layers), [4 фасада](./facades), [разрезы](./SECTION_HALL.svg), [6 комнат](./rooms), [валидация](./VALIDATION_R1.json).
- Пять серверных loot table JSON для 5 сундуков — каталог [loot_drafts](./loot_drafts); в 2.2.7 не вводятся новые предметы, блоки, рецепты, NPC и GUI.
- Помещения: зельеварная 5×6, подготовка 5×6, сушилка 4×6, кладовая 4×6, сени 2×13, отдельная клеть внутри 4×7. Функциональные размеры уточнены по реальным стенам.
- В огороде nether wart на soul sand и багровые корни/грибы на nylium. Вода и vanilla bed запрещены.

**Важные ограничения:** исходные художественные PNG доступны владельцу в предыдущем чате, но их полноразмерные копии пока не опубликованы в GitHub. SVG — только геометрические изображения. Нет выполненных NBT, WorldGen, загрузки в игру и Minecraft QA. Переиспользовать материалы только из существующего registry.
