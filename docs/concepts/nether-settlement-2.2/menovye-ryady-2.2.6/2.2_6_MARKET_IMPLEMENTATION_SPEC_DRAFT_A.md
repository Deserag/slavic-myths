# Slavic Myths 2.2.6 — «Меновые ряды» / подробный технический проект DRAFT A

**Статус: проект DRAFT A одобрен владельцем для оформления реализационной задачи 29.10.2026.** По просьбе владельца создано самостоятельное GitHub Issue для 2.2.6; состав: вариант А, 8 ресурсных сундуков, 20% независимый шанс 1–2 древних монет в купеческом тайнике. **Не является разрешением самостоятельно запускать программную реализацию** — необходима отдельная команда. Изображения и блочные чертежи служат проектом, не результатом Minecraft QA.

## Источники ограничений
- Принятый город 113×113 и статические кварталы, карта `2.2_POSAD_MASTER_PLAN_R1.svg`, вопросы #343, #346, #347, #348, #350 и #351 ветки `hell`.
- ROADMAP_2.2_MICROPATCHES_2026-10-29.md: микропатч 2.2.6, **строго X=75..101,Z=75..99**, 27×25. Старую черновую зону Z73..99 не брать.
- Предыдущий художественный комплект: 4 лавки, 2 склада, сквозная центральная ось, поперечные проходы, древнерусские кровли с палитрой Незера. Изображения — концепты, а не игровые скриншоты.

## Координатная система, здание и смежные зоны
Все записи в `2.2_6_MARKET_VOXELS_DRAFT_A.json` имеют локальные `u, y, v` и канонический `minecraft:<block_id>[blockstates]` (или ванильные IDs без states). Соответствие `Xгород=75+u`, `Zгород=75+v`, `Yмир=Yплощадки+y`; север — к уменьшению v. Участок 27×25: u0..26, v0..24; Y0..11. Отступы по краям. **Нельзя перемещать постройки случайно** или поворачивать их независимо от города.

| Название | Функция | Локальное размещение | Размер |
|---|---|---|---|
| M01 | Рудная лавка | u2..10, v2..8 | 9×7 | 1-й этаж, отдельная лавка |
| M02 | Лавка припасов | u16..24, v2..8 | 9×7 | 1-й этаж, отдельная лавка |
| M03 | Ремесленная лавка | u2..10, v11..16 | 9×6 | 1-й этаж, отдельная лавка |
| M04 | Лавка повседневных товаров | u16..24, v11..16 | 9×6 | 1-й этаж, отдельная лавка |
| W01 | Кладовая сырья | u2..10, v19..23 | 9×5 | 1-й этаж, склад |
| W02 | Купеческая кладовая | u16..24, v19..23 | 9×5 | 1-й этаж, склад |

Центральная ось u11..15,v0..24 свободна при Y1/Y2 (5 блоков). Поперечные переходы v9..10 и v17..18, ширина 2; соединяют периферийные обслуживающие коридоры и основной проход. Входы продавцов — тыльные двери с восточной/западной стороны, покупательские фасады открыты к центру. Отдельную ограду сейчас не добавлять без согласования изменения архитектуры. В этом проекте **сплошной забор не ставится**, чтобы не блокировать соседние дороги.

### Все помещения и функциональные зоны
- **M01 Рудная лавка (9×7)**: u2..10/v2..8, вход персонала u2/v5; торговый прилавок u10/v3..7. За прилавком: бочка (5,1,4), верстак (7,1,7), сундук `metal` (4,1,3). Пол багровые доски, каменные колонны/стены, багровая кровля и фонарь.
- **M02 Лавка припасов (9×7)**: u16..24/v2..8, дверь u24/v5; прилавок u16/v3..7. Бочка (21,1,4), компостер (19,1,7), сундук `food` (22,1,3), фонарь.
- **M03 Ремесленная лавка (9×6)**: u2..10/v11..16, задняя дверь u2/v13; прилавок u10/v12..15; бочка (5,1,15), верстак (7,1,12), сундук `craft` (4,1,12), фонарь.
- **M04 Лавка повседневных товаров (9×6)**: u16..24/v11..16, задняя дверь u24/v13; прилавок u16/v12..15; бочка (21,1,15), стол картографа (19,1,12), сундук `general` (22,1,12), фонарь.
- **W01 Кладовая сырья (9×5)**: u2..10/v19..23, пол багровые доски, каменные стены; вход u10/v21; две бочки u5/u7,v22; сундуки `raw_goods` (4,1,20) и `building_goods` (7,1,20). Два железных решётчатых окна на северной стороне, фонарь (6,3,21) с цепью до крыши.
- **W02 Купеческая кладовая (9×5)**: u16..24/v19..23, те же материалы; вход u16/v21; две бочки u19/u21,v22; сундуки `merchant_goods` (19,1,20) и `merchant_cache` (22,1,20). Окна, фонарь (20,3,21) с цепью до крыши, складская зона с реальными проходами.

**Пространство над головой:** одноэтажные постройки, нет ложных лестниц и этажей, рабочие поверхности не блокируют открывание контейнеров. Высоты фронтальных стен 4 блока, кладовых 5; крыши в JSON. Все проходы проверяются в survival, без веры только визуальному PNG.

Всего **8**, по одному в каждой торговой лавке и по два в каждой кладовой.

| merchant_cache | W02 | (22,1,20) | (97,1,95) | `slavicmyths:chests/nether_market_merchant_cache` |

Точные JSON drafts расположены в `loot_drafts/nether_market_*.json`: 8 независимых таблиц с предметными ID, весами, min/max. В товарных лавках ориентир 2–4 weighted rolls, в складах 2–4, в последнем сундуке 2–3 + редкая монета. **Баланс:** лишь в `merchant_cache` есть 20% независимый шанс 1–2 `slavicmyths:ancient_coin`, 80% шанс ноль; **максимум две древние монеты на весь рынок**. Существующие ID из ветки `hell`: `slavicmyths:ancient_coin`, `slavicmyths:silver_nugget`, `slavicmyths:iron_rings`; остальные — vanillla Minecraft 1.21.1. Незерит и алмазы исключены. В проект не входит новый GUI, продажа или NPC: это future 2.2.12.

Бонусный сундук `merchant_cache` содержит только обычные редкие торговые припасы и низкую вероятность монет; **согласовано владельцем для постановки задачи на реализацию**. Все сундуки после реализации должны использовать реальные server-side data pack loot tables, формат MC 1.21.1: `src/main/resources/data/slavicmyths/loot_table/chests/nether_market_*.json`, сохраняемые после открытия и перезапусков без повторного получения предметов. Технические JSON в пакете — исходники для будущей задачи, но не зарегистрированные сейчас runtime tables.

## Что включено в комплект
- `art/`: **четыре полноразмерных оригинальных художественных PNG и предварительная согласовательная планировка в локальном ZIP-архиве беседы**, показанные владельцу ранее. Оригинальные большие PNG находятся в архиве чата; технический PNG и SVG публикуются в GitHub отдельно. До финальной художественной приёмки нужно загрузить исходники полноразмерно, если это ещё не сделано.
- `source/build_market_226_draft.py`: исходный Python-генератор в локальном ZIP-архиве, для пересборки потребуется перенести этот файл в репозиторий; SVG и JSON уже доступны как реальные файлы. Использует Pillow/CairoSVG для PNG.
- `2.2_6_MARKET_PLAN_Y1_DRAFT_A.svg` + `.png`: внешний участок и оборудование на уровне Y1;
- `2.2_6_MARKET_ROOF_DRAFT_A.svg`: крыша по верхнему видимому слою;
- `2.2_6_MARKET_FOUR_FACADES_DRAFT_A.svg`: четыре фасада всего комплекса;
- `2.2_6_MARKET_SECTIONS_DRAFT_A.svg`: разрезы 3 поперечных и 1 продольный;
- `2.2_6_MARKET_ROOMS_DRAFT_A.svg`: отдельные планы всех шести внутренних помещений;
- `2.2_6_MARKET_ALL_Y_LAYERS_DRAFT_A.svg`: послойная кладка Y0..11;
- `2.2_6_MARKET_VOXELS_DRAFT_A.json`: точная цифровая модель всех блоков со states;
- `2.2_6_MARKET_VOXEL_ISOMETRIC_DRAFT_A.png`: машинная аксонометрическая визуализация (не игровой скриншот);
- `loot_drafts/`: 8 плановых серверных JSON.
