**Статус:** художественный облик одобрен владельцем 29.10.2026; реализационная постановка подготовлена, реализация отдельно не запускалась. Ветка hell, main не изменять.

**Основной машинный источник:** [2.2_VECHE_HALL_VOXELS_R1.py](./2.2_VECHE_HALL_VOXELS_R1.py). Он однозначно восстанавливает весь массив 3598 занятых блоковых координат из исходного VOXELS_R1.json, с полным blockstate и SHA256. Команда: python3 2.2_VECHE_HALL_VOXELS_R1.py > /tmp/veche_voxels.json. Команда с --count выводит количества блоков.

## Референсы R1: что реально доступно
- В GitHub доступна полная машинная модель [VOXELS_R1.py](./2.2_VECHE_HALL_VOXELS_R1.py) с координатами всех 3598 занятых блоков.
- Художественные референсы фасадов, основного зала, кабинета старейшины и верхней совещательной палаты владелец одобрил в чате ChatGPT 29.10.2026. **Оригинальные PNG физически в GitHub пока НЕ загружены**. Кодекс не должен считать чат-картинки локальными файлами. Необходимо прикрепить PNG или согласовать адаптированный векторный/растр reference pack до визуальной приёмки.
- Декоративная подсистема из рендеров (баннеры, фонари/цепи, нарядные окна и подиумы) **не включена в исходные 3598 блоков**. Любые добавления делаются отдельно с точным списком ID + координатами; не маскировать увеличение ведомости.
- Главный зал в R1 внутренне **13×8**, а художественный концепт визуально просторнее; если он сильно отличается от конечного R1, сначала зафиксировать несоответствие для владельца. Не масштабировать произвольно корпус, так как его внешний участок жёстко резервирован городским генпланом.
