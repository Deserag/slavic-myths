## 2. НОВЫЕ культуры Верхнего мира (5 видов, age=0..3)
| Культура / registry IDs (проектные) | Посадочный item → субстрат | Четыре стадии | Зрелый урожай без Fortune |
|---|---|---|---|
| `garlic` + `garlic_clove` + `garlic_crop` | Зубчик чеснока на `minecraft:farmland` | тонкий росток → 2 листа → пучок → белое основание и зелень | 1–2 головки и посадочные зубчики (см. ниже) |
| `horseradish` + `horseradish_cutting` + `horseradish_crop` | корневой черенок на farmland | всход → 2 листа → широкая листва → мощная розетка | 1–2 корня, черенок через безубыточный рецепт |
| `black_radish` + `black_radish_seeds` + `black_radish_crop` | семена на farmland | всход → раскрытые листья → розетка → тёмный корень | 1–2 редьки и 1–2 семени |
| `mustard_seeds` + `mustard_crop` | семена горчицы на farmland | листья → высокий росток → жёлтые цветы → сухие стручки | 2–4 семени, по желанию цветочный пучок без нового ID |
| `onion` + `onion_set` + `onion_crop` | севок на farmland | росток → 2 пера → пучок → луковица | 1–2 луковицы и посадочный севок |

- Прямой нормальный цикл: первый посадочный материал из ферм/хозяйственных сундуков, торговли или травы (где подходит); после полного созревания игрок **гарантированно** может получить посадку на следующий цикл. Пример: `garlic` → `garlic_clove` из головки; `horseradish` → `horseradish_cutting` из корня; `onion` → `onion_set`, рецепты 1:1 с разумным выходом. Нельзя сделать одноразовые семена или растение только для creative.
- Успешная посадка требует достаточного освещения по ванильной логике; рост random tick сопоставим с базовыми культурами. Следовать `FarmingCrop`: CropBlock (а не самостоятельный непригодный BonemealableBlock), `age=0..3`, отдельные blockstates/models, drops via loot tables, loot подчиняется `doTileDrops`.
- Дроп из зрелой стадии, ранняя ломка возвращает посадочный материал без урожая; Silk Touch и Fortune не создают бесконечных ресурсов. Ограниченный Fortune <= ванильных подходов, без дюпа.
- `garlic`, `horseradish`, `black_radish` и `onion` — съедобные сырыми обычные продукты; `mustard_seeds` используются как семена/специя (нет обязательного съедания горчицы). `black_pepper` и `ground_black_pepper` — торговая пряность, **не культурный crop**, рецепт измельчения горошин 1→1.

## 4. БОНЕМЯЛ — ОБЯЗАТЕЛЬНЫЙ БЛОКИРУЮЩИЙ ТЕСТ (owner P0)
- **Каждая выращиваемая культура и куст**, включая 5 новых обычных, `heat_berry_bush`, `sernica_crop`, **`crimson_pepper` из #363** (совместимость, без дублирования реализации), `coal_plum_sapling` — должна реагировать на обычную `minecraft:bone_meal`. Никакого custom fertilizer вместо обязательной костной муки.
- На `age<3` `isValidBonemealTarget` возвращает true при корректном субстрате; `performBonemeal` на сервере реально повышает `age` не менее чем на одну стадию за успешное применение (можно 1 гарантированную). При `age=3` цель false; no consumption/no fake success, никаких infinite loops.

- `CropBlock` / `BonemealableBlock`, серверная синхронизация и loot; не ломать vanilla bonemeal. Суспендировать эффект без подходящего субстрата/света/площади. Нельзя списать костную муку, оставить age прежним и отчитаться PASS.
- **Фактический GameTest + Minecraft test:** поставить 0-stage растение, `/give ... bone_meal 64`, применить на всех стадиях, проверить реально видимый переход и расход кости, собрать урожай; отдельно заверить до/после save/relog, dedicated server и два игрока. Для уже зрелого растения подтверждён отказ/нет расхода. Те же сценарии на ростках #363, с документированным результатом.
- Рост при обычных random ticks, нулевая зависимость от воды в Nether, отсутствие double drops; не считать статический тест изменения возраста реальным применением bone meal.

## 7. Поведение всех новых пищевых предметов: СТРОГО ВАНИЛЬНЫЙ MINECRAFT
**Owner P0:** пища работает так же, как обычная Minecraft еда, не «сырьё с иконкой»:
- Все съедобные овощи/плоды/блюда имеют `FoodProperties`, действительную nutrition/saturation. Непосредственные специи (`black_pepper`, `ground_...`, `sernica` как сырьё) не обязаны быть съедобными. Для `#363` уже согласованы съедобные 5 адских культур — оставить как есть.
- `UseAnim.EAT`, стандартная vanilla анимация поднесения к лицу в обеих руках, `getUseDuration=32 ticks` и **стандартный Minecraft звук еды** (без custom OGG / собственного SoundEvent). Предмет съедается **только при неполном голоде** по обычному vanilla правилу, если специально не указано vanilla-подобное исключение.
- Для жидкостей `UseAnim.DRINK`, 32 ticks, стандартный звук питья; никакой анимации «поедания кружки». У `BeverageItem` уже есть свой `finishUsingItem`: убедиться, что пища/насыщение, статистика, sound и `remainder` работают при полном питье. Напитки можно оставить в рамках уже существующей напиточной логики, но визуальное/звуковое поведение — vanilla.
- Эффекты блюд применяются только при завершённом съедании, не в момент начала анимации и не при её прерывании. Пустая миска возвращается, тара после питья возвращается, творческий режим не дюпает расходники. Отсутствие повторной выдачи через обе руки, logout/relog/server restart/2 player.
- В `inventory` stack: сырые овощи и нескоропортящиеся ингредиенты 64, выпечка до 16 (в рамках аналогов), порционные миски 1, кружки согласно `Brewing` и существующим правилам. Не изобретать голод для затравленных служебных (seeds/mash/wort) item-ов.
- Без самостоятельных частиц, громких звуков, новых splash/посадочных анимаций и без спецэффектов для `bonemeal` сверх обычной Minecraft визуализации.
