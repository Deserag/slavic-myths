# Slavic Myths 2.2 — Пекельный посад: листы чертежей (ревизия R1)
Дата: 2026-10-29. Статус: OWNER_REVIEW, IMPLEMENTATION_NOT_AUTHORIZED.

## Состав
- `2.2_POSAD_MASTER_PLAN_R1.svg` — точный блоковый план расположения стен, ворот и фиксированных районов, X/Z=0..112.
- `2.2_POSAD_GATE_ELEVATIONS_R1.svg` — южный/северный/западный/восточный фасады привратного узла и разрез стены.
- `2.2_POSAD_GATE_LAYERS_R1.svg` — восемь контрольных слоёв Y=0,1,6,7,8,9,10,16.
- `2.2_POSAD_GATE_ALL_18_LAYERS_R1.svg` — полный отдельный чертёж **всех 18 слоёв Y=0..17** привратного узла. Проектное кодирование блока для разметки всё ещё требует точных blockstates при реализации.

## Статус и ограничения
Эти SVG — **читаемые инженерные эскизы с едиными координатами**, а не готовый NBT и не финальное разрешённое ТЗ. Основой является проектная палитра и диапазоны из [2.2_POSAD_FORTIFICATION_SPEC_DRAFT.md](./2.2_POSAD_FORTIFICATION_SPEC_DRAFT.md). Часть параметров там ещё на утверждении. Предыдущий черновой SVG следует считать устаревшей компоновкой; ревизия R1 используется для визуальной оценки.

### Важные оговорки R1
- Город 113×113; периметр толщиной 5; южные ворота 29×11; проезд шириной 7, высотой 6, длиной 5 блоков.
- Графика строится по одной координатной модели для всех контрольных проекций. Возможна адаптация общего поворота и основания под все биомы Незера и лавовые моря; расположение зданий внутри города не рандомизируется.
- Высокие реальные открываемые ворота пока **не запроектированы**. На текущей стадии проезд открыт; создание механизма подвижных створок нуждается в отдельном обсуждении. Не размещать стены в семи свободных колоннах X=53..59 на Y=1..6.
- Помещения башен и вертикальные подъёмы показаны условным местом для лестниц; необходим подробный фасад/разрез внутренних лестниц с достоверными blockstates и игровым проходом.
- На этих листах показаны **крепостной контур и фиксированные зоны**, но нет точной кладки жилых зданий, палат, ферм и пр. Для каждого здания потребуется отдельный строительный комплект.
- Проектировать итоговые полные послойные размещения, blockstates, шаблоны 0°/90°/180°/270°, преграды, фундамент/мост и actual in-game preflight/QA до выдачи задания Codex.

### Правка геометрии R1
В пределах привратного footprint X=42..70, Z=102..112 **уровень Y=0 представляет сплошной пол/фундамент** без воздушных просветов. Техническая визуализация (местный предпросмотр и SVG ревизии R1) обновлена на ту же координатную систему.
