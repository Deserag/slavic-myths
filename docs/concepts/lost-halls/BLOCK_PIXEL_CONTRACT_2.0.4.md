**Различимость:** main stone №3 не должен выглядеть как `minecraft:polished_basalt`, `blackstone`, `deepslate` или `nether_bricks` при Minecraft 16×16. При совпадении крупной структуры пикселей и силуэта шва — **FAIL_ART**, даже если перекрашен оттенок. Все новые материалы сохраняют согласованную холодную гамму.

## Детализация каждого семейства

### КБ-01 Основной камень (`lost_hall_stone` — предварительный ID)
- Полноразмерный куб 16×16×16 модельных единиц; продуманные tileable top, bottom и side. Боковая плитка **слоистая, но НЕ строго регулярные горизонтальные полосы** из отвергнутого варианта №2. Нет ровной сетки каменных кирпичей.
- Мелкие пиксельные камни и впадины могут давать естественную гранулярность без «шумового телевизора»: в 16×16 различаются хотя бы несколько крупных областей.
- Ступени/плиты/стены наследуют материал, UV не растягивается на полтора блока. Нужны item models, valid stairs rotation, mirror, slab double states, walls shape connections, no `missingno`.
- **Полированный камень** — более гладкий, но **не новый «пятый основной природный материал»**; рецепт полировки должен быть обычным и указан в recipe book. Основной камень и полированный используются в строительных формах без огромного числа копий.

### КБ-02 Треснувший камень (`cracked_lost_hall_stone`)
- Внешне сохраняет породу основы, добавляя 1–3 крупных неровных тёмных разлома на видимых гранях; не превращать в железную решётку, малую плитку керамики или lava magma.
- Поверхностный pattern каждый блок не должен быть абсолютно одинаковой 4×4 сеткой; при необходимости допустимо 2–3 согласованных variants только как `BlockState` с одинаковой физикой.
- Не наносит автоматически урон от огня; механика обвалов или падения — **не утверждена**, не добавлять.
- Естественно формируется рядом с пропастями, старшими каменными арками и местами обвалов, но не заменяет весь основной камень.

### КБ-03 Светожильный камень (`luminous_vein_stone`)
- Яркие голубые/бирюзовые сегментированные жилы внутри тёмного камня, **разные от обычной руды**. Суммарно темно-серый фон должен занимать большую часть грани; голубое свечение — акцент.
- В vanilla Minecraft блоковый свет `lightEmission` — число от 0 до 15, **цвет общего света не голубой**. **Рекомендуемая начальная точка 10**, диапазон проверки 8–12; это инженерная настройка, не утверждённый пользователем точный уровень. При необходимости дальняя подсветка через пылевые/световые частицы с жёстким количеством, без глобального tick loop.
- Коллизия полный куб, без невидимых неровностей; безопасен для ходьбы, не налагает яд/огонь/Wither. При добыче отдаёт себя по Silk Touch, обычную добычу/преобразования определить в блоковом луте без введения руды нового типа. **Новый кристальный отдельный предмет пока не утверждён**.
- Группы в стенах/потолках локально редки, гроты могут иметь более плотные скопления, но без освещения каждой развилки.

### КБ-04 Пещерный налёт (`cave_coating`)
- Это **тонкая видимая текстура на примыкающей грани**, как у Glow Lichen, а не непрозрачный полноразмерный куб. По возможности 1–6 face states, поддерживаемых блоками; в противном случае форма, действительно сохраняющая проходимость/коллизию.
- Полупрозрачная/вырезанная пиксельная текстура, правильная alpha cutout/render layer; тёмно-серо-зелёная масса и очень ограниченные холодные точки. Не должен оставлять чёрный или пурпурный `missing texture` box.
- Природный spawn только на видимых гранях камня/стен/встречных навесов с предикатом support, не на воздухе, не на жидких блоках; не закрывать игроку проход и exit marker. Проверить ориентации UP/DOWN/N/E/S/W, разрушение support и loot/item pickup.

## Какие vanilla блоки РАЗРЕШЕНЫ как часть среды
`minecraft:blackstone`, `minecraft:basalt`, `minecraft:polished_basalt`, `minecraft:netherrack`, `minecraft:nether_bricks`, `minecraft:red_nether_bricks`, `minecraft:polished_blackstone_bricks`, `minecraft:magma_block`, `minecraft:glowstone`, `minecraft:shroomlight`, `minecraft:warped_nylium`, `minecraft:crimson_nylium`, `minecraft:warped_fungus`, `minecraft:crimson_fungus`, `minecraft:weeping_vines`, `minecraft:twisting_vines`, `minecraft:warped_roots`, `minecraft:crimson_roots`. Проверить реальные ID при регистрации на 1.21.1. НЕТ новой древесины, деревьев нового вида, ещё одного гриба с полным набором досок, автоматических redstone ore в Незере.

**Распределение**: основная масса природных стен из КБ-01, КБ-02 отдельные зоны повреждений, КБ-03 редкие ориентиры/концентрации в гротах, КБ-04 внутри больших комнат. Vanillla нетерский и красный кирпич — **редкие фрагменты исторической архитектуры**, не основная регулярная решётка лабиринта. Нельзя использовать старый багровый кирпич вместо нового основного камня по всему биому.

## Обязательные артефакты и QA

- `source_inventory.tsv`: registry ID / file path / original PNG cell reference / model type / loot / creative group / mining tier / recipe / light / shape.
- `block_contact_sheet.png`: 4 основные породы и строительные формы **в Minecraft**, 3 ракурса top/front/side; сделать отдельный `approved_vs_actual.png` в одинаковом масштабе, **отобразить отвергнутый №1 как запрет**, а не как допущенный вариант.
- `models`, `blockstates`, `textures`, `items`, `loot_tables`, `recipes`, `lang` file completeness: только существующие реальные пути из рабочей сборки; validate all references, 0 missing, 0 duplicated registry.
- Unit/data тест: `place → break → recover`, shears/silk touch как у выбранного стандарта, slab double, stair rotation, walls connect, coating on 6 sides, drops independent of Fortune если не выбран новый редкий дроп.
- Runtime QA: ванильный renderer без шейдеров, day/night/nether/темнота, дальняя читабельность 4–16 блоков, texture atlas no crashes, light emission measured not assumed. Неполнота = `FAIL`/`NOT_RUN`.
- **Без** реального reference PNG / сравнительного листа и 16×16 ассетов для варианта №3 = `BLOCKED_REFERENCE` / `FAIL_ART`, не релиз.
