## 4. Текущий статус доступа, проверки и прикрепления

1. **LIBRARY_FOUND:** все четыре ZIP зарегистрированы в личной библиотеке ChatGPT по указанным именам и размерам, а отдельные PNG видны для визуального просмотра.
2. **GITHUB_LINKED_SPEC:** настоящие текстовые спецификации/технические SVG находятся в GitHub; этот индекс и ссылки в Issues обеспечивают исполнителю однозначную карту референсов.
3. **BINARY_NOT_ATTACHED:** ZIP и пять подтверждённых оригинальных PNG **не найдены как бинарные файлы ветки `hell`**. Прямых GitHub asset URL для них нет; не выдавать этот индекс за «файлы прикреплены».
4. **SHA_NOT_VERIFIED / BLOCKED_REFERENCE для art gate:** при попытке получить raw ZIP из библиотеки среда вернула `This Project file does not have an authorized raw-byte materialization path`. Пока побайтовый доступ не появился и совпадение пяти SHA не проверено, **никакого ART_PASS**.
5. **NEXT EXECUTOR ACTION:** сначала попытаться получить raw bytes конкретных архивов из уже существующей библиотеки или реального вложения/репозиторного файла (не просить владельца заново выбирать арт). Запустить существующий валидатор по всем пяти SHA, записать фактические пути и размеры, затем строить модель/UV/текстуры. По-прежнему проверять без OP, сохранение, MP и игру согласно `AGENTS.md`; `NOT_RUN` не равно `PASS`.

**Все Issues сохраняются открытыми до ручного решения владельца.** Размещение ссылок на эталоны не означает завершения реализации или сдачи биома.
