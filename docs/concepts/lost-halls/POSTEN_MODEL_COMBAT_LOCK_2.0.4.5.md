## 1. Модель, жёсткие визуальные признаки

**Minecraft 1.21.1 NeoForge Java 21, объёмные кубические ModelParts/Blockbench, не flat entity billboard, не recolor Evoker/Warden/Wither/Skeleton.** Высота модели **~4.5 блока** как на эталоне; baseline hitbox `1.45×3.9` блока (инженерное значение: обзорное тело шире узкой конечности, высота не включает весь шлейф частиц). Изменение только при документированном столкновении с реальной геометрией арены; 650 HP неизменно. Проверить серверную hitbox/eyeHeight / player reach: парящий босс не должен становиться неуязвимым для ближнего боя из-за физически недостижимой высоты.

### 1.2. Чертежи/кадры, обязательные исходники

Экспортировать реальный модельный исходник `.bbmodel` либо документированные `ModelPart.Builder` + pivot map; текстуры PNG/UV sheet, `front.png`, `left.png`, `right.png`, `back.png`, `top.png`, `three_quarter.png` одинакового масштаба; отдельные крупные виды **каждой из 4 реальных масок** и **кадр поворота 0°/45°/90°**. ## 2. Идентичность, здоровье и конечный автомат фаз

- **Boss max health = 650 HP**, bossbar одна на encounter, название «Постень — Хозяин Чертогов» RU / EN; здоровье хранится на сервере. Разделение **ОДИН раз** при достижении **260 HP**: старт Phase1 650, урон в фазе I суммарно **390**, Phase2 пул **260**.
- **Ровно ЧЕТЫРЕ копии** по **65 HP** каждая. Копии 1→4 соответствуют Скорби/Гневу/Тлению/Безмолвию, имеют разные соответствующие способности и **не дублируют все четыре атаки в одной копии**. Одна и только одна активная общая полоска `sharedBossHealth = sum(currentHpOfAliveClones)` в каждом тике. Никаких дополнительных скрытых HP тела, никаких самостоятельных 650 HP у каждой копии.
- При пограничном ударе, который снижает фазу I с >260 ниже 260: **отсечь значение на 260**, запустить split ровно один раз, не причинять копиям «отрицательный» HP; в отчёте указать принятое правило переноса остаточного урона (допустим перенос на одну выбранную копию, если ограничен и не меняет предельный общий 650 HP). При уроне копии используем `effectiveDamage=min(incomingValidated,cloneHP)`, единый акт уменьшения её HP; общий пул **вычисляется** из всех оставшихся HP, а не уменьшается второй раз. При смерти 4-й копии = одна общая death state + один batch loot.
- Копии **не выбрасывают** отдельного XP/душ/сердец/голов/руны, не создают recursive split и не возрождаются через reload. Boss entity/arena SavedData либо эквивалентная **persisted encounter state** хранит phase=II, stable encounter UUID, четыре stable clone IDs, HP каждого, defeated flag; при выгрузке/рестарте восстановление без двойной четвёрки. При случайном despawn или исчезнувшем ID — reconciliation только для отсутствующего клона и только пока `defeated=false`, без наград/эксплойта.
- Смерть босса и награды запускаются **один раз** серверной транзакцией состояния; никаких наград каждый раз при клике на активатор/перезаходе.

## 3. Четыре маски: одна читаемая атака на маску

| Маска | Боевая роль | Визуальный windup | Эффект | Как уклониться |
|---|---|---|---|---|
| Скорбь (голубая) | Контроль | 1.2 с, яркий голубой контур/вытягивание рук | Краткая теневая волна, **Slowness** на валидных целях; без длительного оглушения | Укрытие за колонной или боковой отход |
| Гнев (красная) | Ranged / огонь | 1.0 с, красная маска, поднята рука | 2–3 направленных **огненных** projectile, проверять LOS; не ставить fire blocks на арену | Заметная траектория, боковое движение |
| Тление (зелёная) | Area denial | 1.4 с, зеленоватые пятна на полу | Малая локальная облачная зона **Poison**, быстро исчезает, не заполняет всю арену | Выход из размеченного участка |
| Безмолвие (фиолетовая) | Направленный магический урон | 1.4 с, фиолетовые геометрические полосы | Краткая фронтальная волна, умеренный damage+**Wither**, без удара через непрозрачную стену | Линия видимости/укрытие |

**Точные damage, длительность статусов, cooldown — инженерный старт для реального combat QA**, не устанавливать экстремальные эффекты без counterplay. Ни одна атака не наносит урон «в спину через десять стен» или при недоступном target. В Phase1 `mask_ring` видимо вращается до появления соответствующего лица, ограничение стрельбы на время поворота; UI/звук у каждой маски свой. В Phase2 копии используют только `theirMask`, остаются узнаваемыми без визуальных хитростей.

## 4. Перемещение между стенами (не путать с noclip)

- Из **уже созданных** безопасных `ArenaWallAnchor` выбирать не менее 2 достаточно далёких друг от друга anchors на стенах/колоннах (активная область только `alreadyLoaded`), валидировать целевой **final** hitbox, ширину пола, отсутствие solid blocks, лавы, bedrock и падения с края. Не принимать непроверенную позицию из старого/исходного footprint.
- 0.6–1.0 с видимого растворения на стене, пауза, 0.6–1.0 с появления на другой; в transit нельзя наносить скрытый урон игроку, bossbar не исчезает, все следы атаки прекращаются. Максимальная дистанция и частота подбираются по арене; отсутствие подходящего anchor приводит к **отмене перемещения, НЕ к телепорту на (0,0,0)**.
- Никогда не генерировать/подгружать чанки в AI тик и не делать `getChunk(FULL)` для далёкого anchor. Достижимость boss arena и walls QA из #294, искусственно крошечная арена => FAIL_WORLDGEN.

## 5. Общее взаимодействие с игроком и награды

- Голова Постеня: отдельная микрозадача трёх новых Nether heads; **×1 100%**, динамическое вращение четырёх масок при подходе игрока. Не регистрировать дублирующий head Item/Block в двух подсистемах; передать создание registry в microtask, boss здесь подключает единственный гарантированный drop.
- **Сердце Постеня ×1 (100%)**, тёмное призрачное ало-фиолетовое сердце с неровными трещинами и тёмной тлеющей серединой как на утверждённом постере. Не подменять кожей: основной согласованный трофей — сердце.
- **Руна Теневого лика ×1 (100%)**, действующая. Точный runtime эффекта — отдельная rune microtask, которая читает [RuneFoundation.java](../../../../src/main/java/org/slavicmyths/rpg/RuneFoundation.java) и существующее назначение клавиш; запрет регистрации двух одноимённых рун. Когда [#303](https://github.com/Deserag/slavic-myths/issues/303) не готова, boss loot нельзя признавать конечным.
- **Одна уже зарегистрированная `slavicmyths:soul` ×1 (100%)**, без пятой дублирующей soul ID. **НЕ выполнять lore про «среднюю заражённую» без отдельной пользовательской конкретизации**.
- Награда только после смерти всех 4 копий, независимо от способа победы, серверно один раз на encounter; zero chance of absence у любого из четырёх уникальных трофеев.
- **Точно четыре типа наград:** сердце + руна + душа + голова, не добавлять «Кожу Постеня» как пятую конкурирующую сущность и не копировать награды другого босса.
- По одному гарантированному размещению арены в **каждой полноценной связной области** биома; алгоритм worldgen/locate только #294, **не выдавать spawn egg за подтверждение natural spawn**.
