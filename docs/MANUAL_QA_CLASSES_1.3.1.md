# Ручная проверка классов 1.3.1

Клиент автоматически не запускался. Этот список — оставшаяся визуальная и пользовательская проверка; headless результаты её не заменяют. Использовать отдельный тестовый мир или копию, без перезаписи существующих сохранений.

1. Открыть классы клавишей K или камнем пути. Проверить три карточки и подтверждение постоянного выбора. Руническая наковальня должна открывать свой прежний экран.
2. Проверить дерево, связи требований, ранги, численные текущие/следующие параметры, прокрутку описаний, развитие на 10/25 уровнях и эволюции. Выбрать три разных активных навыка и один пассивный; кнопки текущих слотов снимают навык.
3. Проверить HUD справа снизу с GUI Scale 1/2/3/4/Auto, в 16:9 и узком окне, со щитом. F1 скрывает HUD; настройка HUD сохраняется. Изменить G/H/J в настройках: подписи должны измениться, конфликт подсвечивается красным, мышиные назначения работают.
4. Проверить все навыки в реальном бою: обычный моб, тяжёлая цель, игрок, союзник, стена, пустая цель, неверное оружие, повторное нажатие до конца КД. Частицы и звуки должны быть умеренными и видны соседнему игроку.
5. Проверить воздушный удар при снижении и приземлении, отсутствие постоянного иммунитета к падению; Сеча ускоряет атаки без сброса hurt cooldown цели. Сеть не пролетает бесконечно; Зоркий глаз не становится самонаводящейся ракетой.
6. Умереть, возродиться, выполнить `/kill`, выйти в меню и реально зайти снова, затем перезапустить сервер. Класс, ветви, уровень, опыт, очки, ранги, слоты, HUD и КД сохраняются; пассивные атрибуты не удваиваются.

Администратор: `/smclass <player> choose|force <class>`, `xp <amount>`, `level <value>`, `points <value>`, `add_points <value>`, `learn|forget <skill>`, `cooldown_reset`, `state`. Права — permission level 2. Class XP пока выдаётся через этот API/debug, без добавления новых массовых источников опыта.
