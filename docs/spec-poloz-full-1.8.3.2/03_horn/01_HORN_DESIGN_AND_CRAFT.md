# Моровой рог — дизайн и крафт

## Референс
Использовать `refs/morovoy_horn_reference.png`.

## Внешний вид
- Основа: изогнутый древний рог.
- Внутри и по швам — моровые красные трещины.
- Общая гамма: тёмное древнее дерево/кость/рог + красное свечение.
- Предмет должен выглядеть как древний опасный ритуальный артефакт.

## Логика
- Это основной инструмент призыва Великого Полоза.
- Предмет **не расходуется** при первом использовании как базовый артефакт.
- Для повторных призывов может требоваться дополнительный расход Морового праха (если это уже обсуждалось и есть соответствующая удобная реализация).

## Рецепт
В центре рецепта — **ванильный козий рог**.
Остальные обязательные компоненты:
- Око мора
- Пепельное сердце
- Моровой прах x5
- Золотой слиток

Разместить рецепт согласно утверждённому референсу.

## Иконка
Повторять силуэт референса, не упрощая его до безликого цилиндра.
