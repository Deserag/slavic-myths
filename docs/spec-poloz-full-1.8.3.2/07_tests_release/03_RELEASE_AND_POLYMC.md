# Сборка, релиз и PolyMC

## В конце выполнения
1. Собрать итоговый JAR.
2. Проверить, что сборка прошла успешно.
3. Обновить модовый JAR в тестовом профиле PolyMC.
4. Не запускать Minecraft.
5. В отчёте показать:
   - список ключевых изменённых файлов;
   - путь к собранному JAR;
   - подтверждение замены JAR в PolyMC.
