# Definition of Done

Работа считается завершённой, если:
1. Реализованы заражённые блоки 1.8.3.1.
2. Реализован Моровой рог.
3. Реализован мировой босс Великий Полоз.
4. Реализованы его фазы, уязвимые зоны, звук, анимации и поведение.
5. Босс корректно действует в обычном мире без арены.
6. Босс может появиться в воде и продолжать бой.
7. Реализованы награды: Голова, Сердце, Чешуя, Плеть, броня, Руна IV.
8. Дизайн максимально близок к приложенным референсам.
9. RU-локализация заполнена.
10. Проект собирается.
11. Обновлён PolyMC без запуска Minecraft.
12. Подготовлен краткий отчёт об изменённых файлах.
