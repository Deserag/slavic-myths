# 1.8.3.1 — заражённые блоки

## Главный принцип
**Оригинальные ванильные блоки не перерабатываются глобально.**
Создаются локальные заражённые аналоги, появляющиеся:
- при проходе Великого Полоза;
- при моровых мировых эффектах, если это требуется логикой.

## Список базовых заражённых блоков
Минимальный обязательный набор:
1. Заражённая трава
2. Заражённая земля
3. Заражённый камень
4. Заражённый булыжник
5. Заражённый песок
6. Заражённый гравий
7. Заражённые дубовые брёвна / древесина (базово можно сделать общий заражённый древесный вариант)
8. Заражённые доски (общий вариант)
9. Заражённая листва
10. Заражённый мох / растительность, если есть смысл для биомов
11. Заражённый каменный кирпич / строительный камень (для разрушенных построек)
12. Моровые шипы / наросты как атмосферный вспомогательный блок / декор

## Визуальный стиль
Обязательно использовать `refs/blocks_infected_reference.png`.
Основные признаки:
- чёрно-тёмная база;
- багрово-красные трещины;
- эффект внутреннего морового свечения;
- пепельная, мёртвая, испорченная фактура.

## Геймплейные эффекты
### Общие правила
- Эффекты действуют рядом с блоком или при контакте с ним.
- Эффекты не должны стекаться бесконечно до абсурда.
- Эффекты не должны перманентно убивать игрока за один шаг.

### Предлагаемое распределение
- Заражённая трава / земля: `Slowness I` после короткого контакта.
- Заражённый камень / булыжник: `Weakness I` поблизости/при долгом нахождении.
- Заражённый песок / гравий: `Slowness I` и визуальный дискомфорт.
- Заражённая листва / древесина: слабый периодический урон при долгом контакте.
- Моровые шипы / наросты: прямой контактный урон.

## Поведение после смерти босса
Заражённые блоки, оставленные Полозом, не исчезают автоматически сразу. Они остаются следом события.

## Техническое замечание
Если полная реализация множества заражённых вариантов всех древесных/каменных семейств слишком тяжела, делать в этой версии ограниченный, но законченный набор общих моровых блоков, которые хорошо покрывают основные сценарии разрушения.
