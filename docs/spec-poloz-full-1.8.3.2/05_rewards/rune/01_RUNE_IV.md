# Руна Земного Владыки IV

## Референс
- `refs/rune_iv_blueprint.png`

## Роль
Очень редкая высшая руна, связанная с силой Полоза.

## Внешний вид
- Тёмный рунный камень / пластина.
- Багровое сияние, напоминающее шрамы Полоза.
- Визуальная связь с заражённой землёй и глубинной силой.

## Эффект
После каждого **4-го успешного удара** по цели срабатывает **земляной разлом**:
- дополнительный урон;
- короткая визуальная вспышка трещин под врагом;
- перезарядка **20 секунд**.

## Ограничения
- Массовые удары по толпе не должны ломать баланс и бесконечно множить проки.
- Эффект должен быть мощным, но редким.
