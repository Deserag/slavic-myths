# Плеть Полоза — анимации, поведение и характеристики

## Характеристики
- Урон: **13**.
- Дальность базового удара: **6 блоков**.
- Это должно быть самое сильное оружие данной стадии прогрессии.

## Поведение
### Базовая атака
- Дальний взмах плетью.
- Может задевать несколько целей по ширине траектории.

### Особая атака
- Удар в землю.
- Создаёт **3 каменных шипа** впереди/по линии.
- Особая атака имеет перезарядку примерно **18 секунд**.

## Ограничения
- Не должна разрушать постройки игрока как босс.
- Не должна быть бесконечной мясорубкой без пауз; скорость атаки ниже меча.

## Анимации
1. `idle_in_hand`
2. `swing_basic`
3. `swing_wide`
4. `special_ground_strike`
5. `item_use_cooldown_feedback`

## Звуки
- свист сегментов;
- тяжёлый резкий удар;
- при особой атаке — всплеск камня/земли.
