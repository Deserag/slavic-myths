# Великий Полоз — анимации

## Общий стиль анимации
- Тяжёлое, живое, змееподобное движение.
- Не механическое дёрганье.
- Чувство массы и длины.
- Плавная волна по сегментам.

## Обязательные анимации
1. `idle_ground`
   - тело слегка шевелится;
   - голова медленно осматривается;
   - трещины пульсируют.
2. `move_ground`
   - длинная волнообразная походка/ползучее движение.
3. `emerge_from_water`
   - выползание из воды, подъём головы, стекание воды.
4. `burrow`
   - уход под землю.
5. `emerge_attack`
   - вырыв из земли под целью.
6. `roar`
   - распахивание пасти, сильный рев, вибрация головы/шеи.
7. `head_strike / bite`
   - атакующее движение головой / укус.
8. `tail_slam`
   - тяжёлый удар хвостом.
9. `earthquake_body_slam`
   - удар телом/сегментом о землю.
10. `ring_of_doom`
   - тело собирается в кольцо/полукольцо вокруг врагов.
11. `phase_transition_1_to_2`
   - активируются дополнительные шрамы, усиливается свечение.
12. `phase_transition_2_to_3`
   - более яркая вспышка, максимальная агрессия.
13. `hurt_on_weakpoint`
   - заметная реакция только при попадании по уязвимой зоне.
14. `hurt_on_armored_part`
   - минимальная или почти отсутствующая реакция.
15. `death`
   - долгое тяжелое затухание, падение, угасание трещин.

## Важная логика
Уязвимые зоны должны визуально читаться во время движения. Игрок должен видеть, куда действительно имеет смысл бить.
