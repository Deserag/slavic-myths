# 1.2.5 — городище и исправления домов / мешка

Реализовано 2026-10-08 по пакету Slavic_Myths_1.2.5 и прямым замечаниям пользователя. Minecraft 1.21.1, NeoForge 21.1.255, Java 21; существующие registry ID сохранены. PolyMC в этой итерации не обновлялся, клиент не запускался, commit не создавался.

## Исправления

- Опоры наблюдательной площадки казармы продолжены до крыши. Нижние опоры домов заполняют пустоту тем же материалом, с ограничением восемь блоков: берётся нижний несущий блок столбца, а не верхнее бревно. Авторские сплошные блоки, bedrock и block entities не подменяются. Старые уже поставленные дома автоматически не перестраиваются.
- Мешок имеет собственную объёмную тканевую форму: расширяющееся основание, плечи, собранную горловину, верёвку и узел. Открывается интерфейс с пятью слотами по 64 предмета; Shift-перенос работает целыми стаками. Только продукция из тега sack_items, включая ванильные семена, урожай и ряд растительных продуктов; инструменты не принимаются. Уровень формы равен min(5, floor(общего количества / 64)): 63 предмета — уровень 0, 64 — 1, 320 — 5. Частичные стаки сохраняются, делимость не является условием помещения предмета.
- При загрузке обычных мешков сохраняются позиции слотов. Старые четыре стака по 99 перераспределяются: 320 помещаются внутрь, 76 сохраняются в SackOverflow и выпадают при загрузке блока. Проверено отсутствие потери предметов. Существующая механика выпадения содержимого сохранена.
- Все восемь сортов пива, квас и морс имеют настоящие cuboid-модели кружки / бутылки: ручка, клёпки и обручи, напиток / пена; у бутылки плечики, горлышко и пробка. Сохранены ID и существующий bottled override. Генераторы ресурсов воспроизводят новые модели.

## Городище

Нативная структура `slavicmyths:gorodishche`, отдельный StructureSet: spacing 128, separation 96 чанков, salt 125176, исключение рядом с vanilla village 12 чанков. Это диапазон размещения кандидатов примерно 1536–2048 блоков, а не обещанная частота готовых городов: строгие ограничения рельефа делают их существенно реже. Биомы: равнины, лес / берёзовый лес, тайга, снежные равнины / тайга и саванна.

Два детерминированных master layout: axial и cross_axis. Сначала создаётся граф улиц, затем участки с обязательным фасадом к улице и красной линией. Главные улицы 7 блоков, второстепенные 5, служебные и обход стены 3; подходы к зданиям связываются с дорогой, перепады оформляются ступенями. Размер участка и поворот проверяются без масштабирования шаблонов. Варианты крыши и материала выбираются с ограничением повторов соседей.

Каталог содержит 240 реальных NBT, 80 на каждый климат temperate / cold / warm. Четыре сочетания древесины и камня, климатические поправки; дуб, ель, тёмный дуб, берёза, каменный кирпич, андезит, туф. Есть богатые одно- и двухэтажные избы, узкие городские дома, дом дружинника, городские дома ткача / пивовара, повара, летописца, травника и трёх кузнецов. Варианты различаются планировкой / объёмом / крышей, имеют действующие двери, лестницы, кровати и POI.

Принудительный axial showcase: 22 внутренних объекта, включая 8 жилых и 6 отдельных рабочих домов, 39 кроватей; 40 сегментов каменной стены, четыре угловые башни и главные ворота. При размещении появляются 19 профессиональных жителей, включая восемь дружинников; дополнительные кровати оставлены для обычного ванильного размножения. Нативный план допускает дополнительные жилые участки в пределах лимита кроватей.

Жители используют существующие профессии и ванильные Brain / расписание / владение POI, без принудительной установки JOB_SITE. Дружина и нападения используют уже действующую военную систему. Только при начале нападения определяется городище; разбойники появляются снаружи перед воротами и идут к внутренней цели. Поиск использует загруженные references / ручные записи; чанки ради AI не грузятся. Новых глобальных обходов каждого тика нет.

Рельеф: ограниченная сетка 121 точки на кандидата, общий перепад поверхности максимум 16, локальная коррекция участка максимум шесть; отвергаются глубокая вода, чрезмерный уклон и пересечения структур. Девять ограниченных локальных смещений кандидата; высоты кэшируются только внутри одной попытки. Фундаменты используют существующий `LandFoundationPiece`, выбор земли — `LandTerrain`, контроль пересечений — `StructureCandidates`, ручные записи — `ManualStructureRecords`: это общие helpers действующей системы лагерей. Размещение повторяет её проверенный порядок подготовки / валидации / chunk-clipped placement / освобождения tickets; оно не вызывает camp-команду и не подменяет город лагерем.

## Команды

Нужны права оператора уровня 2. В отдельном тестовом мире на свободном месте:

```text
/sm test gorodishche_showcase
/sm test gorodishche_showcase temperate
/sm test gorodishche_showcase cold
/sm test gorodishche_showcase warm
/sm debug gorodishche
/locate structure slavicmyths:gorodishche
```

Showcase создаёт весь город 176×176, начиная со смещения +8 / +8 от позиции команды, на высоте поверхности; без аргумента климат выбирается по биому. Обходит естественную редкость и фильтр биома. До первой правки проверяет реальные NBT / blockstates / loot / профессии, высоту, границу мира и существующие block entities; готовит все чанки, после завершения освобождает временные tickets. Предварительный отказ не оставляет частично построенный город. Произвольный сбой после начала размещения не является транзакционным rollback. Ответ и диагностика русские, с числом построек, стен, жителей, дружинников, кроватей и координатами.

Команда для прежней выставки всех домов 1.2.4: `/sm test village_showcase [temperate|cold|warm]`. Команда locate ищет естественный StructureStart; ручная выставка хранится отдельно и не становится нативным результатом locate.

- Все 55 попавших в финальную выборку работников самостоятельно получили JOB_SITE; без shortcut памяти. Девять торговцев действительно получили оплату и автоматически восстановили использованные предложения. Команда зарегистрировала 19 успешно созданных NPC / восемь дружинников на город; немедленная AABB-выборка у границы структуры может видеть меньше.
- Город распознан Minecraft как village; семь разбойников существующей системы пересекли ворота, трое взаимодействовали с дружиной. Нативный маршрут проверен в обе стороны. Записи городища переживают NBT roundtrip.
