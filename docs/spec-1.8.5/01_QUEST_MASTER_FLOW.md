# 1.8.5 — конечная последовательность и отношения

## Главная идея
Баба-яга созывает известных игроку союзников к порогу своей избы: «Мор не наш, даже здешняя нечисть его отвергает». Игрок по желанию расследует происхождение мора, изучает трофеи, узнаёт рецепт рога, получает предупреждение о мировом событии, после победы учится очищать испорченные участки мира.

## Начальное условие
После первого **успешного убийства игроком** любого морового существа из 1.8.1 (Леший, Полудница, Кикимора, Огненный змей) / высшего морового из 1.8.2, если игрок ранее разговаривал хотя бы с Ягой или Баюном — единожды предложить помощь в чате. При встрече без убийства записать «первый след мора» в книге, но не форсировать телепорт. Если ранее уже убил — при загрузке 1.8.5 можно предложить отложенный квест по сохранённому флагу. Если убил, но никого не знает — только книга и возможность вручную найти Ягу и начать.

## Куда попадает игрок
**Всегда к избе Бабы-яги.** Если инициатор сообщения Баюн — он направляет к Яге. «Последний собеседник» выбирает инициатора при знакомстве с обоими (детерминированно по persisted timestamp), не меняет места встречи.

## Состав сцены
- Баба-яга — обязательная хозяйка/ведущая, даже если её trust < II: при доверии < II краткая настороженная реплика, без скидок/дополнительных услуг.
- Кот Баюн — дополнительный участник при `met && trust >= II`.
- Серый Волк — дополнительный участник при `met && trust >= II`.
- Если все три отношения >= II, все трое разговаривают вместе на крыльце.
- Если условие не выполнено — нет реплик и актёра участника; вся история полностью проходима с Ягой.

## Альтернативный путь
Все флаги последовательности можно выполнить в другом порядке и позже засчитать; ступени выдаются по порядку, но они не должны требовать повторных убийств уже убитых боссов или второй крафт рога. Если для старой версии события нет сохранённых доказательств — принимать уже имеющиеся нерасходуемые ключевые предметы, статистику / advancement / loot-proof события; нельзя «досочинять» факт убийства из обычной случайной чешуи.

## Дополнительные задания Волка
`wolf_tracks` «Чужой след» → `wolf_fear` «Звериный страх» → `wolf_loyalty` «Верность до конца»; см. отдельный раздел. Начать можно если Волк присутствует во встрече (`trust>=II`) либо позднее у него лично. Не блокируют основной квест.

## Как трактовать предмет «Знание очищения»
Это **новая вкладка/глава той же Книги сказаний**, с рисунком-пиктограммой книжечки по утверждённому референсу, не второй обязательный предмет, который мог бы исчезнуть после смерти.
