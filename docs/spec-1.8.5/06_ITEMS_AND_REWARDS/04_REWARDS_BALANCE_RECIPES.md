# Свод рецептов/лутов/баланса 1.8.5

1.8.3.2 уже добавил «Плеть Полоза», «Сердце Полоза», «Чешуя Полоза», «Голова Полоза», Руна IV/броня. Эти награды НЕ являются наградами за Q1–Q5. 1.8.5 выдаёт лишь квестовые утилитарные вещи.

## Точные рецепты
**Оберег** (shapeless): 1 copper ingot + 1 string + 1 gold nugget + 1 morovoy dust -> 1.
**Чутьё следопыта** (shaped): строка1 `. iron_nugget .`; строка2 `redstone lantern redstone`; строка3 `. morovoy_dust .` -> 1.
**Очищающий порошок** (shapeless): **2 bone_meal + 1 glowstone_dust + 1 morovoy_dust -> 4**. Изображение рецепта на визуальном референсе — стилизованное, фактические количества и ID брать из настоящих регистров игры по этому тексту.
**Волчий зов**: отсутствует рецепт, только W3.

## Какие предметы берутся из существующей версии
Моровой прах — дроп из 1.8.1, Око мора и Пепельное сердце — 1.8.2, Моровой рог — 1.8.3.2, заражённые блоки — 1.8.3.1. Не создавать дубли, не ломать рецепты:
```
Око мора   Золотой слиток  Пепельное сердце
Прах       Козий рог       Прах
Прах       Прах            Прах
```
Схема рога приведена здесь только ради совместимости; сам рецепт остаётся тем, что уже реализовано и утверждено ранее.

## Соглашение о выдаче
Задания Q1/Q3/W2 могут выдавать похожие «Обереги от мора». Это разрешено: один — за основной этап, один — за дополнительный. Награды проверять и выдавать once-per-stage, а не по числу открытий меню.

## Свод XP
Q1=150, Q2=200, Q3=350, Q4=250, Q5=300, Q6=800; W1=100, W2=175, W3=300. Все XP — ванильный опыт, серверный grant при claiming once.
