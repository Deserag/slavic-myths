# Нелинейность, отказ, повторный визит, уже пройденные события

## События, которые обязательно слушать
- мор: encounter+kill type
- высшее Лихо: verified defeat flag
- высший Овинник: verified defeat flag
- Моровой рог: successfully crafted / possessed / used flag
- мировой босс Полоз: event participation + actual boss death
- актуальное доверие и прежние выполненные квесты Яги, Баюна и Волка
- последний значимый разговор с Ягой/Баюном

## Счётчики и дата первого контакта
Хранить `firstMorEncounterAt`/`firstMorKillAt` и набор типов, а не «заменить все» при принятии. При интеграции с уже существующим save/advancement — не дублировать параллельные противоречивые счётчики. Если нет старого лога, safe fallback: инвентарь или UUID зарегистрированного рога; не выдавать победу по одному праху без источника.

## Порядок подачи
1. `chapter_intro` вручную или через приглашение.
2. Игрок может в любом порядке добывать материалы, выполнять старые квесты Волка, убить Лихо/Овинника, создать рог.
3. По диалогу с Ягой задания завершаются по очереди, когда доказательства есть.
4. Если Полоз уже побеждён, после Q5 автоматически появляется «Я уже победил Полоза» с выходом в Q6.
5. Победа над Полозом **не требует**, чтобы Яга объявила Q6 заранее.

## Зачем фиксировать флаги именно отдельно
Не связывать quest state с физическим наличием предмета: игрок может потратить Око/Сердце на рог, потерять рог после смерти или забрать лут, а босс уже побеждён. Не заставлять игрока заново устраивать катастрофу ради книги.

## Квестовые диалоги и доверие
Участие Баюна/Волка в сцене определяется trust на момент **каждого** начала сцены. Если игрок позже улучшил отношения, при повторном визите Яги их реплики/участие можно увидеть в разделе «Что думают друзья?» без сброса сюжетных стадий. Нельзя навязывать чужую NPC-линию как обязательную.
