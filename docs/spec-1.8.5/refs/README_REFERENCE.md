- Репликам и игровым условиям отдавать приоритет текстовым файлам из ZIP.

- Каждый новый предмет должен получить отдельный Minecraft-совместимый PNG / модель, а не обрезок постера.
- Баба-яга, Баюн и Волк сохраняют существующие игровые модели.
