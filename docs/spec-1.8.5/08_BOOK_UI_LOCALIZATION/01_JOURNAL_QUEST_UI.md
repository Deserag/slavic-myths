# Журнал/Книга сказаний/интерфейс прохождения

## База
Использовать имеющийся GUI Книги сказаний. Не создавать ещё одну обязательную квестовую книгу или новую независимую систему разметки, если существующий journal поддерживает необходимое.

## Интерфейс
- Вкладка «Хворь другого мира» → подраздел «Предвестники бедствия».
- На экране отслеживаемого квеста: название, короткое описание, progress counters, ближайшая цель и кнопка/подсказка визита к Яге.
- Главный квест (6 этапов) отдельно от «Помощь Серого Волка» (3 этапа), всё не больше одной страницы при стандартном GUI масштабе.
- У этапа статусы: `Не начато`, `В процессе`, `Можно сдать`, `Завершено`.
- Напоминание о телепортации только когда invitation уже показан и intro ещё не завершён; добровольная кнопка «К избе Яги» при доступной известной точке и при соблюдении правил безопасного телепорта.

## Читаемость
- Цветовая тема: старая бумага #D8C5A1, тёмная краска #3D3023, мор #8E2634 только как символы/рамки, не огромные красные панели.
- Заголовки размера как в уже существующих разделах, не новый full-screen presentation.
- Предметы показываются **живыми зарегистрированными item icon renderers**, не обрезанными фотографиями с референса.
- Допустимое описание одной цели до 2–3 строк, дальше отдельная «Подробнее».

## Список кратких подсказок
«Вернуться к Бабе-яге»;
«Победить моровых существ: {count}/3»;
«Принести Моровой прах: {available}/3»;
«Высшее моровое Лихо: {done}»;
«Высший моровой Овинник: {done}»;
«Предъявить Око мора и Пепельное сердце»;
«Создать или предъявить Моровой рог»;
«Выслушать предостережение»;
«Остановить Великого Полоза»;
«Вернуться к Яге для очищения».

## Взаимодействие
После нажатия «Сдать» сервер повторно проверяет выполненные условия и выдаёт ответ/награду; клиент не может просто сменить статус на complete. Переключение вкладок не должно стирать прогресс.
