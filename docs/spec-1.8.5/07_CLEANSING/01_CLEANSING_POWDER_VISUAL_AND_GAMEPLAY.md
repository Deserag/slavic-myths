# «Очищающий порошок» — внешний вид и точная механика

## Референс
`refs/01_APPROVED_1_8_5_QUEST_REWARDS_AND_DIALOG.png`, средний левый блок, нижние кадры «Пример очищения блоков».

## Предмет
Небольшой мешочек из холщовой светло-серой ткани (#A69A84), сверху шнур коричневого цвета, на передней стороне крупная тёмно-красная ромбическая руна, вокруг рассыпаны почти белые крупинки (#E8E1D2). Иконка 16x16 readable: мешочек занимает 11x12 пикселей; 1–3 группы белых порошинок. Не делать аптечную колбу или алхимическое зелёное зелье.

## Получение
- За Q6 ×12 предметов.
- После Q6 **shapeless** крафт `2 bone_meal + 1 glowstone_dust + 1 morovoy_dust = 4 очищающих порошка` (все ингредиенты реально добываемы), открывается в книге рецептов/секции после квеста.
- До Q6 можно хранить порошок (Creative/админ), но в Survival рецепт заблокирован; ранее выданные стеки на test/dev можно использовать без аварий.

## Взаимодействие ПКМ
- Только по заражённому блоку из 1.8.3.1. Нет заражённого блока/нет прав на изменение — звук мягкого отказа и сообщение «Здесь нечего очищать», предмет не расходуется.
- При попадании начинается локальная обработка **3×3 блока по плоскости выбранной грани** (9 целевых позиций максимум), включая центр. Для пола/потолка плоскость XZ; для стены — соответствующая XY или YZ. Обрабатывать только реально заражённые блоки, а не соседние обычные.
- Расходуется **ровно 1 порошок** при запуске, если хотя бы 1 реально заражённая и разрешённая позиция; порошок очищает до 9 блоков. Если все заняты другими задачами/claim запрет — не расходуется.
- Обработка по **1 блоку каждые 4 server ticks**, в пределах 36 тиков + небольшая стартовая анимация 10 тиков. Не делать chain reaction, который чистит весь лес одним предметом.
- Если игрок умер/вышел после расхода — уже начатая серверная операция очищения завершается для выбранных позиций без повторного расхода и без бесконечного queue. При остановке сервера последовательность хранить в saved task state либо атомарно завершить все допустимые блоки при следующей загрузке, но НИКОГДА не возвращать item и одновременно очищать.

## Визуал / этапы
- 0.0–0.25 c: у выбранного блока мягкие бело-золотые частицы, потрескивание мора начинает спадать.
- 0.25–1.6 c: линии багровых трещин уходят от края к центру, кусочки тёмной корки осыпаются маленькими частицами.
- По каждому завершённому блоку 2–5 белых пиксельных искр; новая исходная текстура не рендерится поверх заражённой как полупрозрачная «картинка» — сервер реально заменяет состояние блока на прежнее.
- Звук 0.9–1.4c: сухой мягкий шорох порошка, короткий чистый звон в конце без синтезаторных басов. Радиус слышимости 12 блоков, громкость ≈0.6.

## Что НЕ делает порошок
- Не восстанавливает разрушенный Полозом дом/дерево. Он только очищает **оставшиеся заражённые блоки**.
- Не наносит урон моровым существам и не отменяет эффект Мора на мобах.
- Не очищает заражённую землю на всей карте, не влияет на отдельное измерение Ада.
- Не может превратить чужую заражённую серверную запись в произвольный блок по выбору игрока.
