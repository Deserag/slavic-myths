# Definition of Done

Работа считается завершённой, если:
1. Реализовано **Высшее моровое Лихо Одноглазое**.
2. Реализован **Высший моровой Овинник**.
3. Оба используют внешний вид, близкий к приложенным Minecraft-референсам.
4. Оба получили новые/обновлённые звуки, анимации и поведение.
5. Работает система временной поражённой земли.
6. Работает система «Отторжение мора».
7. Обычные формы мобов не сломаны.
8. RU локализация в порядке.
9. Проект успешно собирается.
10. Новый JAR положен в тестовый профиль PolyMC без запуска игры.
11. Подготовлен краткий итоговый отчёт по внесённым изменениям.
