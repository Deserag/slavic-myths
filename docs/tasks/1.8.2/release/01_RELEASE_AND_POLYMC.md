# Сборка, версия, PolyMC

## Версия
Оформить патч как **1.8.2**.

Если в проекте есть место с номером текущей версии / display version / changelog / metadata — обновить его согласованно и аккуратно.

## Что сделать в конце
1. Собрать мод в production/test JAR.
2. Убедиться, что собран именно актуальный JAR.
3. Обновить тестовый профиль **PolyMC**:
   - найти папку `mods` нужного инстанса;
   - заменить старый JAR на новый;
   - не запускать Minecraft.
4. В итоговом отчёте кратко перечислить:
   - какие файлы изменены;
   - где лежит JAR;
   - что именно обновлено в PolyMC.

## Чего не делать
- Не запускать PolyMC.
- Не запускать игру.
- Не пытаться проходить бой автоматически.
