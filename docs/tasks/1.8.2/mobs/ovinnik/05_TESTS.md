# Высший моровой Овинник — тесты

Проверить:
1. Спавн / призыв формы.
2. Корректный увеличенный размер и хитбокс.
3. Заражение земли вокруг моба.
4. Разницу визуального языка заражения по сравнению с Лихом.
5. 3 снаряда «Моровых углей».
6. Зольную завесу.
7. Переход во вторую фазу на 50% HP.
8. Учащение заражения земли во второй фазе.
9. Корректную работу «Отторжения мора».
10. Отсутствие permanent damage миру.
