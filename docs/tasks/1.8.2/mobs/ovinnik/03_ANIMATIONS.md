# Высший моровой Овинник — анимации

## Обязательные анимации
1. `idle`
   - тяжёлое дыхание, подрагивание корпуса, дым из спины.
2. `walk`
   - тяжёлая мощная походка.
3. `claw_attack`
   - резкий удар когтями.
4. `ember_shot`
   - корпус собирается, из рук/пасти/груди вылетают 3 сгустка.
5. `ash_cloud_cast`
   - выброс зольной завесы вокруг.
6. `phase2_rage`
   - вспышка трещин и дыма.
7. `hurt`
8. `death`

## Важное
Овинник должен читаться как тяжёлый заражающий хозяин территории, а не быстрый акробат.
