# Высшее моровое Лихо Одноглазое — тесты

Проверить:
1. Спавн / призыв высшей моровой формы для отладки.
2. Увеличенный размер и корректный хитбокс.
3. Корректную работу заражённой земли.
4. Срабатывание негативных эффектов у игрока.
5. Заряд и выпуск глазной атаки.
6. Переход во вторую фазу на 50% HP.
7. Появление читаемого облака Хвори.
8. Более частое сближение после начала второй фазы.
9. Отсутствие permanent griefing мира.
10. Совместимость с системой «Отторжение мора».
