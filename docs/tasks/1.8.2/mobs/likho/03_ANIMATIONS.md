# Высшее моровое Лихо Одноглазое — анимации

## Обязательные анимации
1. `idle`
   - медленное покачивание;
   - лёгкое дрожание рук;
   - глаз живёт отдельно, едва пульсирует.
2. `walk`
   - тяжёлая, но резкая походка, с длинным шагом.
3. `melee_attack`
   - широкий тяжёлый взмах рукой.
4. `eye_beam_prepare`
   - Лихо замирает, чуть поднимает корпус, глаз ярко заряжается.
5. `eye_beam_release`
   - короткий мощный выброс из глаза.
6. `phase2_cloud_cast`
   - рывок корпуса/раскрытие плеч/выброс миазма вокруг.
7. `hurt`
   - заметная реакция, но без долгого stun-lock.
8. `death`
   - потеря устойчивости, затухание глаза, осыпание морового свечения.

## Важное
Анимации должны делать вторую фазу визуально понятной.
