# Правила, запреты и рамки работ

## Общие ограничения
- Работать только в актуальной ветке `main`.
- Не проводить полный аудит проекта.
- Не делать посторонние рефакторы.
- Не менять unrelated content.
- Не трогать другие версии 1.8.x, кроме задач данного патча.
- Не добавлять новые яйца призыва для высших моровых.
- Не ломать существующие спавны, квесты и старые формы мобов.

## Как искать код
Разрешён только точечный поиск по уже существующим реализациям:
- Лихо Одноглазое;
- Овинник;
- существующие hostile/neutral AI паттерны;
- существующие анимации, рендеры, звуки и entity registrations;
- похожие системы временных опасных зон / эффектов / projectiles / облаков / ground effects.

## Стиль реализации
- Использовать существующую архитектуру мода.
- Повторно использовать уже имеющиеся подходы и утилиты.
- Предпочитать простую и читаемую реализацию без избыточных абстракций.
- Если можно реализовать через состояние сущности и уже существующие ticking/goal/mechanics — делать так.
- Новые данные синхронизировать ровно в том объёме, который нужен клиенту.

## Обязательные требования по локализации
- Проверить и добавить RU локализацию для всех новых имён, подсказок, сообщений, предметов/эффектов, если они нужны.
- Если добавляется EN локализация — она вторична, но RU обязательна.

## Ограничения по запуску
- Не запускать Minecraft клиент автоматически.
- Не выполнять `runClient` и любые UI walkthrough.
- В конце разрешено только:
  1. собрать JAR;
  2. обновить тестовый профиль PolyMC, подменив модовый JAR;
  3. подготовить результат для ручной проверки пользователем.

## Модель / режим исполнения
Ориентироваться на режим работы уровня **6.1 Sol**: минимум лишних действий, точечное изменение файлов, конкретный результат.
