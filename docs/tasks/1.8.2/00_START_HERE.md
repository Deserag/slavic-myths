# Slavic Myths 1.8.2 — ТЗ для Codex

## Задача
Реализовать патч **1.8.2 «Высшие моровые»** для мода **Slavic Myths** на актуальной ветке `main`.

Патч включает:
1. **Высшее моровое Лихо Одноглазое** — усиленная мини-босс / босс-форма существующего Лиха.
2. **Высший моровой Овинник** — усиленная мини-босс-форма существующего Овинника.
3. Общую систему:
   - временная **поражённая земля** вокруг высших моровых;
   - общее правило **«Отторжение мора»**: обычные нейтральные мобы избегают моровых, обычные враждебные мобы атакуют моровых;
   - корректная интеграция в текущий мод без ломки существующих систем.
4. Русская локализация.
5. Сборка итогового JAR и обновление тестового профиля **PolyMC** без запуска Minecraft.

## Важные референсы
Использовать приложенные изображения как обязательную основу и **повторять внешний облик максимально близко**, адаптируя его под текущие ограничения Minecraft-модели и текущий стиль мода:
- `refs/ref_likho_vysshee_morovoe.png`
- `refs/ref_ovinnik_vysshiy_morovoy.png`

Если текущая игровая модель уже существует, нужно **сохранить узнаваемый базовый образ моба из мода** и довести его до вида с референса, а не заменить на другое существо.
