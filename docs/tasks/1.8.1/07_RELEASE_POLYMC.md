# Финал: версия, build gates, тестовый PolyMC — БЕЗ ЗАПУСКА

1. **Версия:** после всех модификаций установить `mod_version=1.8.1` в реальных gradle/version/meta файлах (если исходная версия ниже/равна 1.8.1), сверить generated `neoforge.mods.toml` и имя JAR. Текущий `main` мог уже иметь другую версию; перед правкой проверить фактическую (на момент проектирования было замечено `gradle.properties mod_version=1.6.8`, но это НЕ гарантия рабочей копии). Если рабочая версия >1.8.1 — не откатывать, явно доложить конфликт вместо опасной замены.
2. **Environment:** Java21, NeoForge21.1.255, MC1.21.1, Curios текущая рабочая зависимость. Не добавлять новых зависимостей. На Windows корректный локальный `JAVA_HOME` для команды, не переписывать persistent env vars.
3. **Build:** `gradlew.bat clean build` (Windows) или `./gradlew clean build` (Linux), исполнить ограниченные существующие проверки ресурсов/native model/production JAR с явным log результата. Если есть компиляционная ошибка из нового кода, исправить адресно и пересобрать; не запускать игру. Не запускать тесты игры, влекущие автоматический Minecraft client. Headless GameTests/server только при наличии существующего безопасного механизма запуска, иначе unit/static/production JAR и честный NOT_RUN.
4. **Verify JAR:** `build/libs/slavicmyths-1.8.1.jar` либо фактически произведённое имя; проверить contains `META-INF/neoforge.mods.toml`, новые assets, 4 mor textures, audio resources если новые, ru_ru/en_us, item model и нет test/debug bundles. Записать SHA256 и size.
5. **PolyMC обязателен к действию после PASS:** найти **существующий** тестовый профиль `Slavic-Myths-1.21.1-Testing` (не выдумывать и не создавать другой; реальный путь обнаружить из конфигурации системы/рабочих docs). MC1.21.1, NeoForge21.1.255. Профиль не должен быть запущен. Сохранить backup ПРЕЖНЕГО `slavicmyths-*.jar` в скрытый `.slavicmyths-backups/pre-1.8.1-YYYYMMDD-HHMMSS/`. Не удалять остальные JAR, worlds, saves, configurations, configs/servers, shaderpacks, resource packs и файлы пользователя. Если тестовый профиль отсутствует/невидим, остановить установку и зафиксировать причину/путь собранного JAR.
6. Копировать **один** проверенный production JAR в `<PolyMC-profile>/.minecraft/mods/`, удалить только дублирующие старые JAR именно `slavicmyths-*` ПОСЛЕ backup; не трогать сторонние моды (Curios/JEI/Xaero). Проверить установленный SHA256 = build JAR SHA256, отсутствие дублей, проверить SHA256 всех сторонних JAR до/после и по возможности `instance.cfg`/`mmc-pack.json` до/после. **Ни запуск PolyMC, ни Minecraft, ни `runClient`/GUI/screenshot не разрешены**.
7. Receipt `docs/verification/mor-1.8.1/POLYMC_INSTALLATION.md` + JSON (где profile path, old/new SHA256, backup path, result PASS/BLOCKED, unrelated files intact), и короткий отчёт итогов в `docs/PROJECT_STATUS.md`, `docs/ROADMAP.md`, `docs/ARCHITECTURE.md` **только соответствующие разделы**; `CHANGELOG.md` кратко. Не переписывать старые длинные страницы, не редактировать историю чужой работы.
8. Final answer Codex на русском, кратко: сделано (4 forms / 8+attack skills + cloned serpent / Flask / Book), build/resources tests PASS/FAIL, PolyMC PASS/BLOCKED, client/game manual NOT_RUN, ссылка/путь JAR и report. Без commit/push.

## Требования к отказоустойчивости установки
Если PolyMC открыл мир/работает — не менять файлы; нет прав — не отключать безопасность; backup не создан — не устанавливать; checksum mismatch — откатить предыдущий JAR из backup и сообщить. Повторный запуск установки должен быть идемпотентен: если JAR такого же SHA256 уже там, отчёт PASS без повторного удаления и без новой копии.
