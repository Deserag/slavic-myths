# Definition of Done — не выдавать неполную работу за готовую

## 100% обязательно
- [ ] Четыре **старые entity IDs**, четыре моровые формы, отдельных mor eggs нет; **Овинник не добавлялся**.
- [ ] 4 полноценные индивидуальные native модели/части и 4 отдельные существующие в JAR пиксельные текстуры по `references/01...04`, не просто tint+particles. Различия заметны без particles.
- [ ] Сохраняемый, клиент-синхронизируемый 3-state mor, единый server transform 50ticks и rare natural mor spawn 4% после седьмых суток вне spawn radius160.
- [ ] HP ratios и cooldown/focus/aggro только для ACTIVE; original остается нормальным, repeat Flask idempotent.
- [ ] Леший: Корни мора / Вопль; Полудница: Багровый полдень / Жатва; Кикимора: Пляска / Путы; Змей: три огненных снаряда / dive / две визуально одинаковые копии по30HP один раз на50%.
- [ ] Mini-boss bar скрыт пока живы клоны; clones не дают XP/дроп/знаний, персистентность без рекурсии и дублирования.
- [ ] Склянка мора — 16×16 vanilla-like pixel splash, Creative+OP only acquisition, нет рецептов/лутов, радиус 3, нет эффекта на игрока/случайных NPC.
- [ ] Книга сказаний: первая встреча, запись один раз, RU/EN, не новый GUI/квест.
- [ ] Звуки каждого вида реальны и соответствуют timestamps; no dummy assets. Не заимствовать чужие файлы.
- [ ] Source game mechanics не разрушает/не поджигает блоки, сервер authoritative, no global per-tick scanning/unloaded chunks/worldwide updates.
- [ ] Vanilla/старые mod assets and registry IDs не переименованы, старые миры открываются без обязательной миграции (проверки сериализации + manual пользователь).
- [ ] ru_ru/en_us все ключи, no mojibake, Item/Model/Texture/Sound resource gates и production JAR PASS.
- [ ] Параметры и игровые времена из `05_BALANCE_AND_TIMING.md` соблюдены; автоматические headless/unit tests отмечены без выдуманных запусков.
- [ ] Версия 1.8.1 (либо явное предупреждение если base впереди); production JAR SHA256 записан, предыдущий JAR в PolyMC backed up, новый установлен, hashes verified без запуска; если профиль недоступен BLOCKED с путём JAR.
- [ ] `REPORT`, `POLYMC_INSTALLATION`, `ART_AUDIO_SOURCES`, минимальные status/roadmap/changelog; никаких незакоммиченных правок пользователя не потеряно, commit/push не делался.

## Остановочные правила
Никаких «оставим анимации/звук/модель на потом»; если код API несовместим — исправить локально и собрать. Если нет инструментов, способных выполнить конкретное действие, честно пометить blocked, не утверждать COMPLETE. Полноценное визуальное/аудио тестирование клиентом оставлено пользователю по прямому запрету CodeX на запуск игры; это **не повод** оставлять текстуры и анимации неполными.
