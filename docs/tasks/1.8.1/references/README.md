# УТВЕРЖДЁННЫЕ пользователем визуальные референсы для 1.8.1
**Они физически вложены в ZIP.** CODEX ОБЯЗАН использовать именно эти четыре PNG как образец формы, геометрии, пигментов и визуального отличия от обычных сущностей. Это вторая, Minecraft-voxel серия изображений, **не** первая реалистичная серия.

- `01_MOR_LESHY.png` → Моровой Леший: угловатый мощный древесный гуманоид, мох, рога-ветви, красные трещины и глаза.
- `02_MOR_POLUDNITSA.png` → Моровая Полудница: соломенный венок, длинное белое загрязнённое платье, чёрно-красные руки, изогнутый серп; справа показаны 4 ракурса и детали.
- `03_MOR_KIKIMORA.png` → Моровая Кикимора: маленькая худая сгорбленная фигура, рваная тёмная одежда, длинные когти и алые нити; справа показаны 4 ракурса и детали.
- `04_MOR_FIRE_SERPENT.png` → Моровой Огненный змей: чёрно-алая сегментированная летающая змея с пастью, рогами, гребнями и двумя отражениями. **Во время боя настоящие клоны полностью непрозрачные и визуально идентичные**: задние красные силуэты в арте показывают сам момент призыва, а не постоянную полупрозрачность!

## Что значит «повторять точь-в-точь» в Minecraft
1. Повторить **отличительные геометрические силуэты**, расположение деталей головы, корпуса, оружия, рук/хвоста, пучков волос, рогов, яркие красные трещины/узоры по максимальной возможности native ModelPart и маленькой текстуры.
2. Не пытаться буквально повторить освещение и туман иллюстрации на GPU как шейдер/постпроцесс; использовать vanilla-like частицы. Не класть большой PNG в sprite texture atlas; построить пиксельную UV развертку.
3. Соотносить размер и базовые joints с реально существующей моделью моба: не превращать Кикимору в 2-блочного человека, а летающего змея — в Горыныча. Референсы дают дизайн моровой формы, исходный код — базовый скелет и scale.
4. Если какой-то фрагмент арта визуально похож на косу, итоговая Полудница **держит серп** — её согласованное оружие. Точный дизайн изогнутой рваной кромки оставить.
5. Ни один из этих файлов не удалять из задания после первой демонстрации; в итоговом report указать, какие Minecraft visual components реализованы на основании каждого.
