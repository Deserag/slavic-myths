# Моровая Полудница — ИНТЕГРАЦИЯ
- Найти фактические AI/renderer/оружие Полудницы. Мор не должен создавать другой entity для смены формы; стандартный animation layer/renderer переключает texture и дополнительные hair/wreath/dress/sickle parts.
- Если обычная Полудница имеет дневные ограничения, мор не убирает базовые условия естественного спавна (включая биом, day/time). В активной форме получает новый pulse damage в 5800..6600; эта разница не означает новый natural spawn ночью.
- Морфинг останавливает базовые attack goals, затем переключает target selector на атакующего игрока; обычные персонажи/поле не страдают.
- Серп является визуально частью модели/held item, если у обычной мобилки уже held weapon — переиспользовать item renderer без создания нового добываемого предмета. Не дропать новый серп и не менять существующий loot.
- Damage/Blindness/Gamerule проверять только на сервере; packet flash только видимым tracking clients, не full-screen shader.
