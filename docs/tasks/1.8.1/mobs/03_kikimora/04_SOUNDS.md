# Моровая Кикимора — ЗВУКИ
Здесь нужны высокочастотные сухие короткие звуки. Ни голоса обычной женщины, ни скример-громкости.

| Триггер | Звук | Длина / уровень |
|---|---|---|
| idle раз в 8–12s | короткий кашляющий смешок + шорох ткани | 0.3–0.5s, vol .45 |
| transform start | сухое щёлканье суставов/нить натянулась | 0.5s, vol .7 |
| transform end | хриплый один быстрый писк + стук когтей | 0.4s, vol .65 |
| Пляска t0 | три связанных щелчка/злорадный смешок, слышимый до первого прыжка | 0.65s, .75 |
| Пляска шаги | 3 очень тихих щелчка на соприкосновении с землёй | 0.15s each, .35 |
| Путы t0 | волокнистое натяжение нитки/свист короткой струны | 0.6s, .8 |
| Путы hit | глухой щелчок/сухая затяжка | .2s, .55 |
| hurt/death | короткий нечеловеческий визг и затухающий шорох | ≤0.7s, .7 |

Если делаются OGG event keys: `entity.mor_kikimora.ambient`, `.transform`, `.dance_windup`, `.dance_step`, `.threads_cast`, `.threads_hit`, `.death`; все реальные. Для fallback подойдут actual registered vanilla `entity.silverfish.ambient` pitch .8/ `block.wool.step` и `item.crossbow.loading_middle` с lower volume (точные registry IDs подтвердить в 1.21.1), а не новые пустые assets. Looping постоянно отсутствует.
