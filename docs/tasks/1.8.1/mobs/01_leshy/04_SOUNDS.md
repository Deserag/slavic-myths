# Моровой Леший — ЗВУКИ И ТАЙМИНГИ
Источники: авторские короткие фоли/реальные vanilla sound events; новые sound IDs только с real `.ogg` или valid aliases. Общая инструкция `../../04_SOUND_AND_ASSET_PIPELINE.md`.

| Момент | Характер звука | Длительность | Ограничение |
|---|---|---:|---|
| idle каждые 10–14 sec | глубокий скрип сухого дерева + низкий выдох, не музыкальный | 0.8–1.3s | volume .55, pitch .72–.85 |
| 0 t превращения | треск ветви с приглушённым гулом, подчёркивает начало превращения | 0.7s | .8 |
| 50 t превращения | двойной хруст коры, затухающий низкий рык | 0.7s | .8 |
| Корни t0 | тихий скрежет древесных жил + стон почвы (раннее предупреждение) | 0.6–1.0s | .8 |
| Корни t24 | три коротких глухих хруста/удар из земли | 0.45s | .9 |
| Вопль t12 | глубокий голос дерева (без реальной человеческой речи), усиленный слегка искажённым ветром | 1.3s | .95; раз в каст |
| hurt/death | штатный wood crack с pitch -0.15/удлинённое осыпание дерева | ≤1s | не дублировать idle |

Набор sound keys (если делаются оригинальные OGG): `entity.mor_leshy.ambient`, `.transform`, `.roots_warn`, `.roots_hit`, `.wail`, `.death`; имена адаптировать к действующему ModSounds стилю. OGG mono 44100Hz, без длинного хвоста >1.5s, peak normalized. Не делать постоянный нарастающий шум от ауры. При отсутствии авторского звука использовать существующий `minecraft:block.wood.break`, `minecraft:block.roots.break`/фактический блок и `minecraft:entity.ravager.roar` по назначению (точные registry names проверить); не регистрировать Event без аудио.
