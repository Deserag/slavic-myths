# Моровой Огненный змей — ЗВУКИ
Сильный воздушный «рептилия+горящий уголь», слышимый до атаки, без заимствования звуков из других игр. **Копии звучат в точности теми же SoundEvent, volume, pitch range**, что оригинал; отличительный «звук клона» запрещён после завершения кастинга.

| Trigger | Sound | Target duration/volume |
|---|---|---|
| ambient every10–14s | низкий шипящий огонь+воздушный змеиный выдох | 0.7–1s / .6 |
| transform begin/finish | разгорание углей и злой низкий хрип | 0.8+0.7s / .8 |
| Моровое пламя start t0 | втягивание воздуха с багровым потрескиванием; ясно, что 3 снаряда скоро | 1.0s/.8 |
| Моровое пламя 3 casts | три выдоха огня, раздельно t22/27/32 | 0.25s/.7 each |
| Огненный бросок start t0 | нарастающий резкий воздушный свист + рычание | .8s/.85 |
| Огненный бросок t18 | свист перемещения | .5s/.75 |
| Двойники t0 | низкий двойной рёв; предупреждение большого приёма | 1.1s/.9 |
| Двойники t30 | три одновременных идентичных всплеска огненной ауры (не привязывать к original) | .6s/.8 |
| hurt/death/clone vanish | одинаковые шипение и резкое крошение углей; клон не должен пикать иначе | 0.4–0.9s/.7 |

Примерный набор `entity.mor_fire_serpent.ambient`, `.transform`, `.flame_charge`, `.flame_shot`, `.dive_charge`, `.dive_move`, `.clone_charge`, `.clone_split`, `.death`; только реальные OGG или valid source-alias. Не проигрывать все звуки в один тик всем трём, кроме звука создания одновременного triad по заданию. Если имеются качественные существующие звуки исходного огненного змея — использовать их в mor форме с натуральным pitch .75–.85, добавлять 2–4 отличимых warning hits, не переписывать baseline события.
