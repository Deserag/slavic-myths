# Моровой Огненный змей — АНИМАЦИИ
- **Idle-flight 40ticks**: плавный S-изгиб через уже имеющиеся сегменты головы/хвоста; wingless тело движется по дуге, голова поворачивается ±5°, jaws opens 3–5°, fins дрожат с задержкой 1–2t друг за другом. Аура из небольших пикселей, не всем сегментам непрерывно.
- **Pursuit**: хвост постепенно изгибается в противофазе головы, фин вперёд/назад поворачивается на 8°, max speed базовая ×1.12. Если рендер уже имеет glide/hover — не дублировать.
- **Morph 50t**: t0–15 существо застывает в воздухе, body segments затягиваются к середине; t16–34 чёрные пятна и красные трещины постепенно проходя от головы к хвосту; t35–50 пасть широко открывается и огонь становится ало-чёрным, рога и fins разворачиваются, в конце звучит короткий вой и атакующий hover. Без падения вниз при 0 velocity.
- **Моровое пламя**: t0–22 морда поднимается на 15°, пасть широко раскрывается, 5 red square particles готовности; t22/27/32 три снаряда последовательно из рта, хвост не прекращает hovering, t33–41 close/recover. Не выпускать сразу 3 без предупреждения.
- **Огненный бросок**: t0–18 изгибает тело и «складывается» змейкой, фин-части прижаты, t18–28 летит вперёд/вниз с yaw по вычисленной collision-safe траектории, пасть направлена по вектору; t29–40 восстанавливает высоту полёта и обычную S-волну. Hit только при реальном пересечении target AABB.
- **Призрачные двойники**: однократно при текущем HP≤50% max, если достигнуто в ACTIVE и есть живой игрок-цель. 30t каст: t0–10 змей останавливается и сворачивается S; t11–20 рядом в двух точках вспыхивают 2 красных клубка пиксельного огня; t21–29 два призрачных силуэта обретают **полную непрозрачность и стандартные texture/color/particles**; на t30 существуют 3 визуально одинаковых участника боя, выполняется shuffle: оригинал и копии на доли секунды скользят вокруг центра по безопасным заранее рассчитанным траекториям без teleport через блоки, чтобы игрок не отслеживал безошибочно исходную позицию. Shuffle длится ≤12t, всем 3 доступны одинаковые краткие movement start cues; потом обычный бой. Нельзя оставлять свечение на одном original после появления.
- **Hurt/death**: обычный hurt без разницы по pitch/particles для настоящего и клонов; клон на lethal hit играет 10ticks ту же условную death-анимацию, затем без лута распадается красными квадратами. Оригинальный змей умирает штатно, клоны завершают исчезновение без награды.
