# Slavic Myths 1.8.1 — «Хворь другого мира» / «Моровые существа»

## НЕМЕДЛЕННЫЙ ПОРЯДОК ДЕЙСТВИЙ ДЛЯ CODEX (прочесть до команд)
Это полное задание на **реализацию**, а не предложение, не план и не просьба произвести аудит. Работать в существующем `Deserag/slavic-myths`, в рабочей базе `main` с сохранением всех пользовательских/параллельных изменений. Вносить только изменения, прямо нужные 1.8.1. Объём ограничен 4 существующими существами, **одним** новым творческим бросаемым предметом и общим моровым состоянием.

1. **ЖЁСТКОЕ ОГРАНИЧЕНИЕ ТОКЕНОВ И ПОИСКА.** Никакого повторного анализа проекта целиком, обхода всех файлов/истории коммитов или глобального рефакторинга. `git status --short`; проверить фактический `gradle.properties` и **узко** найти четыре entity, существующие регистрации/модели/рендереры/атрибуты/спавн, Creative-tab, Книгу сказаний и аудиособытия. Найденные конкретные файлы читать точечно. В проекте есть AGENTS.md и статусные документы — коротко ознакомиться лишь с актуальными разделами, не перечитывать всю многолетнюю историю.
2. **ПРИОРИТЕТ РЕФЕРЕНСОВ.** Все четыре ПОСЛЕДНИХ ОДОБРЕННЫХ Minecraft-voxel изображения находятся в `references/`. Они обязательны как **прямые визуальные эталоны**, а не источник вдохновения. Повторять силуэты, цветовые акценты, характерные детали, материал и расположение багровых трещин; адаптировать только к ограничениям текущих native-моделей Minecraft/реальным пропорциям исходного моба. Не брать ранние реалистичные картинки, не подменять одобрённые референсы интернет-артом и не рисовать обычных людей/фотореализм. `references/README.md` задаёт точное соответствие.
3. Сначала добавить единый механизм морового состояния и тестовое бросаемое зелье; затем индивидуальные визуалы и атаки; затем интеграцию естественного появления и Книги сказаний. Состояние должно переживать сохранение/загрузку и синхронизироваться на клиент.
4. Четыре цели: Моровой Леший, Моровая Полудница, Моровая Кикимора, **Моровой Огненный змей** (мини-босс с двумя двойниками по 30 HP). Не делать Морового Овинника: он исключён окончательно.
5. Версия мода на итоговом JAR: **1.8.1** (Minecraft 1.21.1, NeoForge 21.1.255, Java 21, `mod_id=slavicmyths`; сверить фактическую сборку перед изменением). Не менять идентификаторы старых мобов и блоков. Если рабочая версия уже **выше 1.8.1**, не снижать её, выполнить фичу в текущем контексте и явно отметить конфликт номера; иначе выставить 1.8.1 во всех согласованных источниках версии. НЕ поднимать Minecraft/NeoForge/Curios/JEI.
6. Провести офлайн-сборку, ресурсы, headless/автоматизируемые тесты по существующим инструментам; **НЕ запускать Minecraft, клиент, `runClient`, PolyMC GUI, игровой мир**. Пользователь проводит игровые тесты сам.
7. В конце **обязательно установить успешно собранный JAR в существующий тестовый профиль PolyMC 1.21.1**, с резервной копией старого мода и проверкой хешей; не запускать профиль. Если доступ к PolyMC отсутствует, честно зафиксировать причину, путь JAR и команду установки для пользователя; не создавать ложный отчёт об установке.
8. Не делать commit/push/новую ветку без прямого приказа пользователя. Не переписывать другие изменения.

## Иерархия файлов
- `01_RULES_AND_SCOPE.md` — жёсткие запреты, ограничения и контракт с существующим кодом.
- `02_CORE_SYSTEM.md` — сетевое состояние, persistence, смена модели/AI, естественное появление, Книга.
- `03_POTION.md` — Склянка мора: вид, ресурс, поведение, ограничения, тесты.
- `04_SOUND_AND_ASSET_PIPELINE.md` — звуки, модели, текстуры, эффективная генерация и ресурсы.
- `05_BALANCE_AND_TIMING.md` — единые числа, AI, атаки и параметры.
- `mobs/<slug>/01_VISUAL.md`, `02_ANIMATION.md`, `03_COMBAT_AI.md`, `04_SOUNDS.md`, `05_INTEGRATION.md`, `06_TESTS.md` — шесть отдельных ТЗ на каждого.
- `06_COMMANDS_AND_TESTS.md` — командный контроль, QA-гейты, проверка естественного спавна.
- `07_RELEASE_POLYMC.md` — повышение версии, сборка, резервирование, установка в PolyMC.
- `08_DEFINITION_OF_DONE.md` — точные критерии готовности.
- `references/*.png` — изображения НАПРЯМУЮ вложены в этот архив; использовать при разработке.

## Явно не входит

## Важный термин
Внутриигровая форма — **«моровой / моровая»** (например, «Моровой Леший»). «Мор» — авторская игровая сила; не выдавать это за историческое название отдельного духа.
