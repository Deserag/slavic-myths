Все запуски использовали копию прежнего тестового мира:
`run/saves/SlavicMyths-Smoke-040`. Пользовательский «Новый мир» и исходный Smoke-030 не изменялись.
До начала тестов копия загружалась как мир 0.3.0; missing registry ID не обнаружены.

1. Меню и мир загрузились. Старый тестовый стенд пытался spawn в незагруженных чанках;
   assertion остановил тест. Исправлен стенд: явная загрузка ограниченной тестовой области.
2. Пройдены подношения, NBT, благословение и ритуал. Вызов worldgen Feature из полного
   игрового чанка без WORLD_SURFACE_WG heightmap вызвал NPE. Исправлен только стенд:
   карта высот подготавливается перед прямым вызовом. В штатной генерации она существует.
3. Placement капища и GUI прошли; снимки просмотрены. Тестовый выход без disconnect
   завис в clearLevel, собственный тестовый процесс остановлен. Исправлен порядок выхода.
4. Без JEI: меню, мир, игровые проверки и GUI прошли; мир сохранился и клиент закрылся.
   Forge предупредил, что этот тестовый мир раньше использовал JEI — ожидаемо при его удалении.
5. С JEI: расширенные проверки отношений и creative; подтверждены сохранённые Домовой
   и незавершённый ритуал после настоящего перезапуска. Мир сохранён, клиент закрылся.
6. С JEI: пройдены дополнительные проверки Slowness Лешего, сохранённого escape cooldown,
   запрета повторного escape и регистрации категории JEI. Просмотрены книга, капище и экран JEI.

## Что подтвердил integration smoke

- Наличие пяти vanilla advancement roots и старых рецептов, создание духов, атрибуты и встречи.
- Survival-подношение повышает доверие; молоко возвращает ведро; spam не расходует хлеб.
- Последующие дары расходуют ровно один предмет; creative сохраняет дар.
  Для ускорения только в тестовом NBT обнулялся nextGift; реальное ожидание минуты не измерялось.
- Атака снижает доверие, повторная сильнее; враждебный дух отказывает без расхода.
- Entity NBT сохраняет доверие, дом и persistence; загрузка следующего клиента сохраняет доверие.
- Благословение работает у очага и не повторяется в cooldown.
- Неверный компонент не расходуется. Три правильных расходуются по одному,
  выдаётся ровно один знак, шаг сбрасывается, открывается знание.
- TileEntity NBT сохраняет шаг; последующий реальный запуск читает незавершённый шаг.
- Loot tables трёх блоков и сундука разбираются Minecraft.
- Прямой вызов капища на подготовленном грунте создаёт идол, altar TileEntity и chest;
  повторная попытка отвергает занятую площадку.
- Атака Лешего действительно накладывает Slowness; escape deadline сохраняется и не обновляется
  при ударе во время cooldown. Фактическая дальность/безопасность телепорта в разных ландшафтах
  остаётся ручным сценарием, не выдаётся за измеренный баланс.
- Серверное использование книги открывает клиентский GUI. JEI обнаруживает категорию «Ритуалы».

Снимки: `assets-0.4.png`, `spirits-0.4-ingame.png`, `book-0.4.png`, `shrine-0.4.png`, `jei-0.4.png`

## Performance review

| Система | Работа и ограничения |
| --- | --- |
| Домовой | Репутация только по взаимодействию/урону; NBT только известных UUID. Hearth search только по клику в радиусе 8; vanilla AI goals для pathfinding. Нет распознавания дома/сканирования блоков каждый тик. |
| Леший | Стандартные goals/target; эффект по событию удара; escape максимум 6 кандидатов раз в 600 тиков, не загружает чанки. Зов использует vanilla cadence; поиск игрока только при звуке. |
| Капище | Только chunk worldgen; попытка 1/96, площадка 11×11, проверка четырёх слоёв и грунта. До 605 проверяемых позиций, все в исходном чанке; нет runtime поиска. |
| Жертвенник | Не тикает, хранит один int; действия только по use, 5/20 частиц на принятие/завершение. |
| Книга/данные | Пять стандартных advancement IDs; без глобального состояния игрока или дополнительной capability. Разбиение короткой выбранной статьи на строки при render, страницы ограничены длиной. |
| Сеть | Один S2C varint при открытии книги, vanilla синхронизация достижений/инвентаря. Нет периодических собственных пакетов. |

Измерение самого placement на подготовленном чанке: 4.4638, 4.9077 и 3.943 ms
в запусках 3–5. Это малая выборка без нагрузки и без стоимости генерации чанка, не обещание MSPT.
При загрузке тестового мира/создании стенда был `Can't keep up`; массовой нагрузочной проверки нет.
