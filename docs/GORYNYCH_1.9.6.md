# Использование 1.9.6

Яйцо: вкладка «Мобы» → «Яйцо призыва Змея Горыныча» (`slavicmyths:zmey_gorynych_spawn_egg`). Для самостоятельного тестового боя выбирайте свободную площадку; сюжетные награды связаны с естественным обитателем горы.

Босс появляется в новой/загруженной Змеиной горе, включая команду генерации. При 5% HP остаётся жив: ПКМ по отдельным головам — левая очищающим порошком, средняя пеплом очищения, правая очищенной водой. Порядок произвольный. После спасения ПКМ по Горынычу позволяет получить ожидающую награду/сброшенную чешую при выполнении персональных условий.

| Крафт | Материалы (каждая отдельная единица — в своей ячейке стола 3×3) |
|---|---|
| Собранный оберег `mor_ward` | Огненный фрагмент + водный фрагмент + Око Мора, три ячейки в одном ряду шириной 3; действует персональная сюжетная проверка Лиха/знаний |
| Арбалет трёх дыханий | Змеиный арбалет + чешуя + древняя змеиная сталь + по одной бутылке Мора, огня и бури |
| Драконий шлем/нагрудник/поножи/ботинки | Соответствующая перунитовая часть + чешуя + 2 перунита + 2 алмаза |

Арбалет: Shift+ПКМ разряженным переключает режим. При успешной зарядке одна бутылка выбранного дыхания даёт три заряда, пустая бутылка возвращается; запас раздельный по трём режимам. Без специального запаса работают обычные стрелы. Имя, применимые чары/руны и доля износа сохраняются при апгрейде.

Награда за спасение: 4 чешуи, печать и одна случайная руна. Требуются 3 свободных слота; при нехватке места освободите их и вернитесь/нажмите ПКМ. Дополнительная чешуя доступна участнику спустя 72000 тиков мира (три игровых дня), затем снова с тем же интервалом.

Надетый полный драконий комплект при HP <30% даёт Сопротивление I на 5 секунд с CD 180 секунд. Отдельные части: шлем −25% длительности обычных слепоты/тьмы/тошноты, нагрудник −15% урона огня/взрывов, поножи −30% силы отбрасывания, ботинки −35% падения.

Все игровые сценарии выше пока требуют ручной приёмки: агент не запускал игру.
