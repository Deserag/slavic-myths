# Дворец вечной зимы — утверждённый V2
- 65 × 50 × 63, 39 380 блоков, 32 сундука, 7 стоек.
- Источник: координатная модель Python V2, CRC32 2830284266.
- Купол X=0 Z=29, вход со стороны Z=0, королева в тронном зале (0,25,37).
- Единственный механизм зимних встреч: ячейка 512, снежная тайга/роща, существующий детерминированный выбор QUEEN; вместо открытого спавна строится дворец.
- Рельеф подготавливается внутри контура, естественные склоны и лес не являются причиной отказа; защищены зарегистрированные сооружения и ненатуральные блоки. Чанки готовятся существующим SiteChunks, работа ограничена бюджетом тика.
- Сундуки снабжаются отдельными таблицами добычи; 2 наградных сундука открывают добычу после первого успешного испытания королевы.
- /slavicmyths dev generate winter_palace [x y z] — операторская проверка; точка обозначает центр по X/Z, Y основания.
- Требуется проверка игры, включая сохранение/перезагрузку, доступность всех комнат, бой и генерацию на склоне.
