# Palace of the Four Winds — approved V2
- Native structure: `slavicmyths:four_winds_palace`, desert only, spacing 64 chunks, separation 32, unique salt.
- Exact Python V2 voxel palette resource: 13,930 non-air blocks, 47 × 89 × 59, floor at relative Y=35, four fist towers, five-wide staircase (170 stair blocks), two-layer deck, open underside. Only the 197 ground-pad columns may receive up to six extra foundation blocks on uneven terrain. No solid column below arena.
- World generation places sparse geometry clipped to the current chunk. The origin is the center of the arena projected onto the landing elevation. Reject incompatible terrain rather than fill the entire bounding box.
- Manual operator command: stand on an empty desert landing and run `/slavicmyths dev four_winds_palace generate`. Arena center is 57 blocks south. Requires loaded footprint and empty target blocks. Natural search: `/locate structure slavicmyths:four_winds_palace` or `/slavicmyths dev four_winds_palace search`.
- Bound Storm Idol spawns once when a nonspectator enters the loaded upper arena (not at ground level, not on Peaceful). SavedData tracks the site, UUID and death across saves. Bound bosses target the upper arena and constrain flight; unbound summons retain existing behavior. A boss removed after spawning (e.g. switching to Peaceful) is not automatically replaced, to avoid duplicates.
- Geometry validation: compile FourWindsPlan.java and tools/four_winds/PlanCheck.java using Java 21, run with src/main/resources on the classpath. Native GameTests cover registration, geometry, clipped block placement and boss bounds. Verify natural generation, manual build, traversal, boss encounter, saves and actual visuals in Minecraft.
