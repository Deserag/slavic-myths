# Ant Queen — approved prototype implementation
VI, 650 HP, 20 base damage; bites 20, forelegs 16, abdomen 24. Ground ants 10 HP / 4 damage, flying ants 8 HP / 3 damage + knockback. Phase thresholds 65% and 30%. Ground cap 20/30/40, flying cap 0/10/15. Queen death splays six legs and lowers abdomen without rolling over. Geometry is shared by multipart bounds and renderer. Spawn eggs are available; natural encounter placement is not assigned. Build, geometry check, native runtime and in-game review must pass before release.
