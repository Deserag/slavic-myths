# Пустыни славянской мифологии — тестовый суперплоский мир

Выбор: Создать новый мир → Мир → Суперплоский → Настроить → Пресеты → Пустыни славянской мифологии → Использовать пресет. Генерация сооружений должна быть включена. Для тестов включить творческий режим и команды.

ID: `slavicmyths:slavic_desert`. Настоящий minecraft:flat с единственным биомом minecraft:desert; 160 слоёв (от Y=-64 до Y=95 включительно): 1 бедрок, 143 камня, 12 песчаника, 4 песка. Поверхность для ходьбы Y=96. Толщина нужна для естественных подземелий на 3–4 этажа. Озёра и декоративные features выключены для ровного тестового поля. structure_overrides намеренно отсутствует: все наборы сооружений доступны, а разрешённые биомы и обычные правила генерации продолжают действовать. Ванильные пустынные сооружения тоже могут появляться. Будущие desert-совместимые наборы не требуют обновления пресета. Не изменяет частоту сооружений обычного мира.

Команды:
- `/locate structure slavicmyths:sun_temple`
- `/locate structure slavicmyths:desert_trial_dungeon`
- `/slavicmyths dev sun_temple generate`
- `/slavicmyths dev dungeon generate desert`

Последние две команды — принудительные, изменяют рельеф; естественную генерацию проверять в новых чанках отдельно. `/locate` не заменяет проверку фактически построенного сооружения. Старые сохранения автоматически не конвертируются. Ресурсная проверка не заменяет запуск клиента и проверку worldgen.
