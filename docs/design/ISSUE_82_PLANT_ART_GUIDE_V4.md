## Чёткие художественные требования

- Силуэт должен считываться **в настоящем 16px инвентарном слоте**, а не только при увеличении; угловатые пиксельные пятна без antialias/blur/полупрозрачного контура.
- Разные растения должны отличаться **ростом, ветвлением и фактурой листьев**, не лишь оттенком зелёного.
- Саженцы — именно **малые молодые растения**. Не рисовать взрослую крону, зрелую ягоду размером с ветку, дерево с толстой взрослой древесиной.
- Защита существующего art: если конкретный ягодный саженец уже хорош, он **UNCHANGED**, нельзя заменять его ради «закрытия 11 пунктов». Приоритет №1 — модовые деревья; приоритет №2 — обязательная `cabbage`; ягоды — небольшой polish по фактическому дефекту.
- По капусте сделать **более квадратный, собранный кочан**, сохраняя узнаваемые зеленые слои, лёгкое округление углов допускается. Сравнить на фоне слота с прежним чрезмерно круглым силуэтом. Не менять вид самой растущей культуры без отдельного доказанного дефекта.
- Дополнительное «оквадрачивание» иных модовых растений не входит автоматически. Оставить остальные иконки и особенно vanilla неизменными.

## Приёмка / доказательства

- По каждому **изменённому** ID: старый реальный PNG, новый PNG, одинаковый **1× item slot**, **4× nearest neighbor pixel grid** (только для диагностики) и игровой/реальный клиентский вид после проверки владельцем.
- Для модовых деревьев: item и посаженный саженец в мире (одинаковая камера/свет). Для ягод: item и визуальный smoke check посаженного куста **без изменения взрослой текстуры**. Для капусты: item/дроп, без изменения агромеханик.
- Regression: те же 11 ID в registry и Creative, прежние семена/состояния `age`, worldgen, loot, recipes, NBT, названия/переводы, соседние PNG и модели.
