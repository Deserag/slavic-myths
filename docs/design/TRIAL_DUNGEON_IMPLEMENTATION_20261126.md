# Trial dungeons — first implementation stage (2026-11-26)

Working branch: feature/desert-biome-20261125. Owner approved starting implementation; original concept #542.

This is a **geometry / command / guardian prototype**, not a completed survival dungeon. The standalone Java planner smoke test passed 3,000 layouts at the previous geometry revision; the full NeoForge build is not verified.
Admin command: `/slavicmyths dev dungeon generate desert [floors] [seed]` (3–5, default 4).
Uses the command position as horizontal origin. Fits below surface when possible, otherwise raises the entire plan above surface. Placement is queued on the server thread. The command is destructive within the generated footprint; use a disposable world. Survival block breaking and explosions are cancelled/filtered in registered footprints. Do not use a live save yet.

Included: seeded independently varied floor graphs, loops, different room types, one trial and boss hall per floor, larger 65x59 / 91x77 arenas, physical ladder shafts, fixed biome palette entry point, sparse light, persistent site reservations, boss roster with separate / combined final encounter.

Not yet implemented: precise geometry/route checks (including corridor crossings), actual trial blocks / loot, full attack-source audit, protected secret access, piston/placement safeguards, recovery of interrupted generation, data-driven biome palettes, multiplayer / runtime / Gradle verification. Current command and natural generation include geometry, encounter activation, persistent kill tracking, descent gates, guardian health and outgoing damage modifiers; still not gameplay-complete. Guardian logical HP normalizes incoming damage above the vanilla cap. All encounter behavior requires runtime verification. Missing/discarded guardians are not treated as defeated; recovery and admin reset remain to be implemented. Natural starts now use 96-chunk spacing / 48 separation, conservative candidate clearance and 3–4 underground floors. The vanilla standalone desert-well placed feature is removed in desert biomes and replaced by the integrated structure. Village wells are unaffected. All new worldgen and command behavior require real-client/Gradle verification. Above-ground test well is on top of the complex; use Creative flight to reach it. Existing kurgans are unchanged.

Standalone smoke test: compile DungeonPlan.java and DungeonPlanSmoke.java with javac -d out; java -cp out org.slavicmyths.dungeon.DungeonPlanSmoke.

Build fix: standalone planner regression moved out of src/test/java to tools/dungeon-plan-tests; Gradle check runs it through verifyDungeonPlan (JavaExec). No test-discovery errors are suppressed. User log confirmed compileJava and asset generators succeeded; full build after this correction still needs local verification.

Owner feedback revision 2: new plans use floor pitch 20 instead of 32 (arena clear ceiling heights reduced to fit); two recessed two-block-deep basins with dry crossing axes replace the flooded floor; boss stair modules use three-wide smooth sandstone stairs, gated upper landing and open lower landing. Command spawns all floor guardians after construction at non-peaceful difficulty, with a completion count. Natural encounters keep sequential activation. Old seed-only saved plans load as version 1 and are not automatically rebuilt. Use a fresh disposable world to inspect the revision. Runtime tests and Gradle build are still required.

Regression check: exact Git blobs for DungeonPlan and DungeonPlanSmoke compiled with Java 21; all 3,000 plans passed (606 combined arenas). Pool liners are placed before water; stair gates are visible iron grilles. Minecraft-specific integration not run in this environment.

Revision 3: owner-approved regional guardians (Hala, Indrik, Storm Idol) after floor 1, with no repeated regional guardians, and obligatory Ant Queen/Sand King separate or combined. General optional encounters: podzemnik, large podzemnik, kladovik, registered ovinnik, fire_serpent (single/pair). No Tugarin, Gorynych, Great Poloz, Lamya. No newly added Poloz structure spawns; global existing placements not audited. Optional encounters have independent persisted IDs and never unlock floor gates. New plans version 3, v1/v2 load unchanged. Manual generation attempts all optional and main encounters, natural activation occurs on room entry. Shared dungeon boss bars are restricted to 30 blocks and arena/room (roaming: own floor), ordinary world boss bars unchanged. Actual runtime, AI, combat and full Gradle tests not executed here. Ovinnik is the existing registered fire-spirit candidate, not an invented ognevik ID. Trial/chest/final rewards remain deferred. The six desert bosses now have baseline entity loot tables; see [desert reward backlog](DESERT_REWARDS_BACKLOG_20261126.md).
