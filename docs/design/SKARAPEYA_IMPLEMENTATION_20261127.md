# Скарапея — первичная реализация
Необязательный региональный босс саванны IX, 2400 HP; 20 armor, toughness 6. Порог 1440/600 без лечения, два тела, три состояния оружия. Источник формы — согласованный Python V3, порт основных кривых и пропорций в прямой полигональный рендерер по принципу LamyaRenderer. Семь ядов, два новых эффекта, обычные звуки нотного блока, не отдельные музыкальные записи. Яйцо призыва. Сюжетные ворота не меняются.
Первая версия: серверные зоны и волны, короткие телеграфы, синхронизация формы/атаки/двух ядов, фазы и КД сохраняются. Оружие пока часть рендера босса, не предметы игрока. Нет естественной структуры/спавна, наград, multipart хитбоксов, точного покадрового экспорта Python, собственных аудиофайлов, иконок эффектов и полной локализации. Требуются компиляция, GameTests, проверка клиента и баланс в игре; текущая реализация не является релизом.

## Исправление перемещения
Визуальная деформация нижней части тела обеих форм по фактически пройденному пути: сглаженная история координат, бегущая волна, распрямление колец, возврат к позе покоя, отдельная обработка движения назад. Нижняя поверхность не опускается ниже локальной плоскости основания. Это клиентская анимация; серверные хитбоксы и поведение не меняются. Точное прилегание к неровному рельефу и проверка в игре остаются открытыми.
