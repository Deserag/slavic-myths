# Затерянный оазис / Lost Oasis V1
Approved Python prototype imported into tools/lost_oasis. Gradle exports a versioned block plan; the native piece and the administrative builder share it. Actual envelope 105 × 117 × 47 (prototype Z extrema -57..59 inclusive), center dry arena, eight grounded palm islands, twelve campfires, illuminated annular gallery, three furnished palace levels, royal loggia.
- Natural structure slavicmyths:lost_oasis in minecraft:desert, including slavic_desert flat preset with structures enabled. 64 chunk spacing / 32 separation, distinct salt. Median terrain anchoring; no slope rejection; conservative clearance from other candidate structures. Active columns are levelled, remaining terrain is unchanged. New chunks required.
- /locate structure slavicmyths:lost_oasis or /slavicmyths dev lost_oasis search.
- /slavicmyths dev lost_oasis generate (permission 2). X/Z is middle of the north entrance edge. Terrain/blocks in the occupied footprint are replaced; use a test world. Rejects previously reserved oasis and registered Sun Temple overlap. Other player builds are not protected. Incomplete manual reservations can be restarted at the same anchor; no automatic resume.
- Encounter: Lamya spawns once in royal loggia when both landing floors are loaded. When player enters the dry arena, the same boss moves directly to arena center and activates AI; no dedicated descent animation yet. UUID and death persist. Bound Lamya targets are restricted to encounter area; movement stays on dry arena and bossbar is local. Unbound Lamya unchanged. Existing water removes drought; no phase-driven water replacement yet. Baseline entity loot is now implemented separately; final arena rewards remain deferred (see DESERT_REWARDS_BACKLOG_20261126.md).
- The V1 visual furnishings are approximated by actual vanilla/mod block states; some stairs, containers and beds are functional. Export clears the 9-block-wide main aisle, relocates obstructing lanterns and independently rechecks the final gallery block-light proxy. No suspended islands. Python light audit is a proxy; runtime lighting, pathfinding, client multiplayer, natural placement and manual terrain integration require separate real-game verification.
