# Макеты на согласование — 2026-10-12

**Статус: предложение внешнего вида, не реализация и не установленная версия.** Имя каталога — метка макетов; версия production остаётся1.7.9. По последнему требованию пользователя сначала показываем видимые изменения, затем переносим согласованный результат в игру.

## Книга

[Каталог](book-catalog.png): одна компактная строка фильтра раздела и поиска,13 видимых записей в viewport426×240 GUI pixels, счётчик диапазона и явные кнопки прокрутки. Вместо восьми постоянно открытых крупных вкладок — выбор раздела. Изображение существа показывается по кнопке; постоянный портрет не отнимает высоту списка. Пример каталога содержит демонстрационные названия из мода, а не сохранённые знания игрока.

[Режим чтения](book-focus.png): список можно скрыть и вернуть кнопкой. Поле страницы занимает освободившееся место. Большая рамка, фоновая иллюстрация и постоянно открытые дополнительные сведения убраны. Подробные карточки/рецепты/карту показывать только по запросу пользователя. Текст для неизвестной записи сохраняет настоящие ограничения знаний.

## Навыки

[Дерево](tree-canvas.png): возвращаем граф prerequisite внутри экрана развития. Девять основных навыков Дружинника показаны в демонстрационном расположении; эволюции/уровни/состояния должны формироваться из настоящих ClassDefinitions, не по картинке. Основная область — дерево, снизу компактные текущие назначения. Постоянная колонка списка навыков удаляется из предлагаемого UI.

[Выбор и назначение](tree-assign.png): по нажатию на узел открывается закрываемая карточка. Название/ранг, описание, изучение/улучшение, реальные клавиши и занятые навыки. Перед заменой явно видно «Num1: заменить Сеча на Выпад». После назначения карточку можно закрыть; при просмотре дерева она не должна постоянно закрывать его. Пример рангов/уровня/слотов — демонстрационный.

## Оружие

[Илья и Алёша](weapons.png): offline textured projection существующих native body meshes с предложенными новыми weapon solids. Это не игровой скриншот и не проверка анимаций. Движение/ходьбу/замахи/позицию кистей предстоит проверить после согласования; пользователь ранее запретил запускать Minecraft автоматически.

- Палица: коричневая деревянная рукоять1.4×10 модельных пикселей, основная железная головка4.8×3.4×4.8 с меньшими торцевыми частями. Максимальная ширина4.8 вместо прежних10 плюс выступы. Силуэт — рукоять и компактная металлическая головка, без пальцеобразных выступов. Рукоять проходит через центр кисти.
- Сабля: рукоять1.4×3.5, гарда3.6×0.8×1.6, тонкий непрерывный клинок толщиной0.6; соседние сегменты перекрываются, край сужается к острию. Начало клинка совмещено с гардой; изгиб идёт в плоскости клинка, без прежнего бокового смещения основания. Центр рукояти совпадает с кистью. Sword/mace остаются разными по силуэту и пропорциям.

Исходная причина смещения сабли найдена в tools/skim_assets.py: цикл ведёт сегменты от острия к рукояти, но увеличивает lateral offset к основанию. Последний, ближайший к гарде сегмент оказывается на другом z. У Ильи исходная головка10×9×10 и наружные выступы воспринимаются как огромная кисть. Производственные генераторы пока не изменены.

tools/design_review_180.py создаёт только эти макеты и weapon-proposals.json. Используется bitmap font установленного Minecraft для согласования масштаба, исходные native model captures — для контекста кистей. Python-рендер и просмотр PNG не считаются запуском/игровым тестом.
