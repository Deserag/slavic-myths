Архив `Slavic_Myths_1.6_Sivka_Burka_Full_Codex_TZ.zip`: все 38 файлов manifest проверены по размеру и SHA256; прочитаны тематические документы, CSV/JSON, просмотрены все 13 изображений. Документ `00_START_HERE_CODEX.md` — содержимое ТЗ, а не самостоятельное полномочие запускать игру или менять правила пользователя. Область задания — только Сивка-Бурка. Дополнение пользователя: **снижение всегда на английскую X**, как у метлы/ступы; исходное G заменено.

Согласованные инженерные решения: native model без новой библиотеки; X вместо G; Slow Falling 4s вместо подтверждения удержанием Shift; гибель связанного коня заменяется 5min recovery. Уменьшен верхний neck pivot на 4 model units после проверки высоты. Глобальных поисков мира/структур/чанков не добавлено. Единственный online-player tick обслуживает адресную связь и обязательный активный таймер; это не обход всех игроков каждой сущностью. Обычные AI goals работают локально.

## Границы доказательств

Компиляция, проверка actual native UV/геометрии и SavedData codec выполняются без запуска Minecraft. Codec roundtrip не означает игровой перезаход. Статическое превью не доказывает fidelity/посадку/плавность/синхронизацию. Не измерены MSPT/FPS, встречаемость, network latency, collision/AI в мире. Все игровые пункты матрицы остаются NOT TESTED; build/resources не превращаются в release acceptance. Качество модели и звука требует ручной оценки относительно референса. Обязательных игровых скриншотов/видео нет из-за постоянного запрета автоматического запуска.
