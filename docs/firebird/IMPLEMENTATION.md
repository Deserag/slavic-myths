## Серверная модель

`FirebirdEncounter` — Overworld SavedData, одна резервация event UUID + entity UUID. Проверка расписания каждые 100 ticks; до 16 кандидатов в уже загруженных чанках. Игрок для начала встречи — живой Survival/Adventure в Overworld. Учитывается doMobSpawning; мирная сложность разрешает нейтральную встречу. Начальное расписание +20…30 дней, окно 13500…16500; ночь 13000…22999. Монотонный observed day и processed day защищают от повторного перевода времени назад. Неудачный поиск сохраняет pending schedule. Sleep/time skip не симулирует прошлые встречи.

Бюджет 2/3 с равной вероятностью, маска issued и outcomes сохраняются. Таймеры уменьшаются только при работе загруженной сущности: первый 600…1200, далее 1200…2000. Ролл одного ресурса 10/30/60 фиксируется до попытки выдачи; успешный addFreshEntity отмечает слот. Ресурс — обычный ItemEntity с одним предметом, vanilla pickup/despawn, без владельца. Event/slot provenance сохраняется в persistent data. Проверяется видимый токен перед повторной выдачей. **Это не атомарная транзакция между SavedData, чанком и инвентарём: авария JVM на границе сохранений может потерять или повторить предмет.** Обычный codec/reload не сбрасывает квоту; реальный crash/relog ещё не тестировался.

Unloaded entity не вызывает нового спавна. Резервация закрывается через 48000 game ticks без heartbeat либо через более двух наблюдённых дней; вернувшаяся устаревшая сущность удаляется только при несовпадении своего event/UUID. Chunk forcing отсутствует. Завершение, рассвет и смерть закрывают встречу один раз с новым +20…30 schedule. Убийство не выдаёт остаток квоты; entity loot table пустая. Summon не регистрирует природную встречу и не выдаёт эти ресурсы.

Native PathfinderMob с серверной скоростью/коллизиями; загрузка клиентских классов из common не требуется. Состояния descent, perch, takeoff, cruise, glide, landing, drop, warning, retaliation, depart. Ограниченные поиски безопасного support/неба/loaded clearance; при готовой награде выбирается площадка в 8…18 блоках от наблюдателя. Полёт использует плавное изменение velocity и реальные move/коллизии. При уходе как минимум 100 ticks движения, дальше удаление вдали от игрока или bounded 300 ticks.

3000 реальных health points: в vanilla Attributes.MAX_HEALTH диапазон 1…1024, поэтому локально переопределены getMaxHealth/getAttributeValue для этой сущности. AT снимает final с getMaxHealth, не меняя диапазон и поведение остальных существ. Прямое чтение базового AttributeInstance по-прежнему показывает 1024; публичный getAttributeValue/MAX_HEALTH и фактическое здоровье Жар-птицы — 3000. Обычный урон проходит; огонь/лава не вредят. Ответ — 11 ticks предупреждения, удар на tick 8 следующей 17-tick фазы: 20 HP, range ≤3 и LOS, cooldown 60. Отдельный damage type входит только в bypasses_armor; Resistance, Protection, absorption и iFrames остаются vanilla.

## Ресурсы и воспроизводимость

`tools/firebird_resources.py` создаёт native rig/source JSON, Java mesh, 256² diffuse/emissive atlas и три самостоятельных 64² иконки. Модель 138 костей/267 cuboids: многослойная грудь/бока, трёхзвенные крылья, отдельные маховые и вторичные перья, семь хвостов с tip-сочленениями, хохолок, клюв/когти. Emissive слой fullbright; GLOW particles косметические, без world lighting или изменения блоков. Небольшой статический preview — проекция source geometry, не игровой скриншот и не сертификат совпадения с концептом.

`tools/firebird_audio.py` — собственный детерминированный синтез голосовых гармоник с частотной модуляцией/трелями, фильтрованного шума и коротких созвучий. 12 событий/28 разных mono 44.1kHz Vorbis, manifest с hashes. Сторонние записи/звуки игр не использованы. Cues привязаны к серверным состояниям/маркерам; клиентская копия звука не запускается. Субъективное качество/слышимость не приняты без игры.

## Проверка и ограничения

`gradlew.bat clean build -I tools/firebird-offline.gradle firebirdOfflineChecks`; `tools/verify_firebird_161.py`. Offline fixtures не входят в production JAR. Tests проверяют численные границы, 100k distribution и codec; **они не проверяют реальную сеть, игровые коллизии, запуск dedicated server или загрузку мира**.

Клиент/сервер не запускались по действующим правилам проекта. Fidelity к approved reference, отсутствие clipping в folded wings, параметры фактического полёта, безопасное падение ресурса, runtime звуки/свет/бой/MP/relog/MSPT остаются открытой приёмкой. Нельзя считать статическую модель или успешную компиляцию прохождением этих строк ТЗ.
