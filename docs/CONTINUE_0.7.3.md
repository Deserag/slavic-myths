## DEBUG COMMANDS

- `/slavicmyths dev swamp`: Overworld, permission 2, noise-biome поиск до 8192 блоков.
  Если игрок уже в болоте — минимум 1280 блоков и неболотный участок на прямом пути.
  Это ограниченная проверка отдельного участка, не доказательство связности всего биома.
  Телепорт только на проверенную сухую поверхность с двумя свободными блоками над ней;
  при отсутствии такой точки в 32 блоках отменяется с координатами найденного болота.
- `/slavicmyths dev structure <id>`: шесть ID из таблицы, без swamp_remnants.
  Проверяет реальный валидный StructureStart в кандидатных чанках. Как vanilla locate,
  может довести ещё не исследованный чанк до STRUCTURE_STARTS. Структуру перед игроком
  не создаёт, возвращает координаты; полная постройка размещается обычной генерацией.
- `/slavicmyths dev structure <id> next`: возвращает второй ближайший подтверждённый
  старт в ограниченном поиске. Не помечает структуру исследованной и не меняет references.
  После перехода к найденной структуре можно повторить для сравнения вариантов.

Команды не выдают предметы/достижения и не отключают vanilla achievements.
Обычное посещение структуры, включая последующий ручной телепорт, может открыть
стандартное location-достижение. Новизна чанков при `/dev swamp` не гарантируется.
