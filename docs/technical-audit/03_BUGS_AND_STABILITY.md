# Ошибки и стабильность

Подтверждённых игровых дефектов пока нет.

P2-LIFE-03, потенциально: `ChudFutureSearch.Search` хранит `CommandSourceStack`, а `LAST` хранит последний `Search` по серверу (`src/main/java/org/slavicmyths/chud/ChudFutureSearch.java:19-27,45`). При длительном сеансе удерживается контекст последнего инициатора до остановки сервера; обработчик `stop()` на строке 82 удаляет записи. Проверить удерживаемый граф heap dump и поведение при отключении игрока. Исправление: хранить только необходимые значения и освобождать контекст после завершения; риск — изменение команды `next`.

`BabaYaga.readAdditionalSaveData()` (`src/main/java/org/slavicmyths/yaga/BabaYaga.java:59`) сбрасывает здоровье до 40 при загрузке. Это может быть намеренной механикой бессмертия; дефектом без проверки дизайна не классифицируется.

Сохранения кораблей, боссов, предметов и устойчивость к повреждённым NBT ещё не проверены.

P2-TEST-05: текущий GameTest `needleNoAmmoAndWear` ожидает тройной выстрел сразу после обычного, хотя новый код запрещает его до истечения 8 тиков. См. `05_TEST_COVERAGE.md`. Это подтверждённое расхождение теста с кодом, без фактического запуска GameTest.

P2-TEST-05 и P2-TEST-06: исправлены в тестовом коде/диагностическом скрипте; проверены компиляцией `compilePolkanCheckJava` и запуском `audit_mod_init.py`. Игровой GameTest остаётся невыполненным.
