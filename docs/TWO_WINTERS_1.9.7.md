# Оберег двух зим — 1.9.7

Minecraft 1.21.1 / NeoForge 21.1.255 / Java 21. Предмет slavicmyths:amulet_two_winters находится в существующей вкладке «Магия». Один предмет, без прочности, стак 1; оригинал и копия одинаковы в бою.

Верстак, оригинал: железо / лазурит / железо; перунит / heart_of_eternal_cold / перунит; железо / shard_of_last_night / железо. Обе существующие награды расходуются. Копия: те же края, оригинал в центре, алмаз снизу по центру. Сервер проверяет флаг оригинала и сохранённую квитанцию его реального крафта; исходный оригинал возвращается с полными компонентами, именем и метаданными через стандартный getRemainingItems. Копия не служит шаблоном. Автоматический vanilla Crafter для этих двух рецептов отключён: удостоверение оригинала привязано к событию крафта игрока. Отсутствующий/неизвестный UUID или неверный тип флага не принимается.

В основной руке Shift+ПКМ переключает режим, ПКМ применяет способность или сообщает остаток перезарядки. По умолчанию Морозко. Пассивы при наличии в основном инвентаре, хотбаре или слоте второй руки; активировать второй рукой нельзя. Нет дополнительных GUI и клавиш.

Морозко: итоговый огонь/лава ×0,6, один модификатор сопротивления отбрасыванию +0,2; ближний враждебный атакующий до 3 блоков получает Slow I на 3 с с вероятностью 20%. Ледяной покров гасит огонь и поглощает суммарно до 10 здоровья за срок до 8 с; остаток удара проходит. Запас отдельный, чужое Absorption не редактируется.

Карачун: итоговый урон ×1,15 по подтверждённым обычным адским врагам из узкого расширяемого тега; новое Иссушение длится 65% исходного срока; успешный удар по обычному подходящему противнику имеет 15% шанс Slow I на 3 с. Волна однократно ищет локальные цели до 5 блоков: 6 урона + Slow I 5 с + Weakness I 4 с; боссам из отдельного тега только 3 урона. Игроки, союзники, принадлежащие кому-либо спутники и питомцы исключены. Проверяются расстояние и видимость; нейтральный моб подходит только если уже атакует этого игрока. Фазы/иммунитеты обрабатывает исходный hurt босса.

Обе способности только в Нижнем мире. Общий дедлайн 2400 тиков хранится в существующем persisted PathData игрока по времени основного мира, сохраняется при смене режима, смерти и респавне. Дополнительный дедлайн предмета исключает немедленный повторный каст при передаче; копия наследует этот дедлайн, оригинал при копировании не меняется. Переключение не изменяет срок. Щит прекращается при потере предмета, смерти, выходе из Нижнего мира, переключении на Карачуна и истечении времени.

Без оберега персональная аура Нижнего мира: до 30 с предупреждение; с 30 с Слабость I; с 60 с Слабость II и 1 урон/4 с; с 90 с Слабость II и 2 урона/3 с. Первый удар следует через соответствующий интервал после смены стадии. Используется собственный эффект slavicmyths:nether_aura с уменьшением attack damage как у Weakness: модификаторы отдельно от чужой vanilla Weakness. Снимается только собственный эффект. Получение защиты/выход/смерть сбрасывают отсчёт. При отключении/входе начинается новое непрерывное пребывание; кулдаун сохраняется. Creative, Spectator и системная неуязвимость освобождены от ауры. Портал не изменён.

Периодический обход 37 обычных слотов раз в 20 тиков на игрока. Узкая реакция на Inventory.setChanged допускает раннее обновление при изменении инвентаря и снятие собственного бонуса/щита. Волна имеет один поиск целей при касте; последующие 10 тиков — только кольцо частиц без дополнительного урона. Синхронизация режима использует существующий RPG payload при входе/управлении.

Ресурсы: три предоставленных прозрачных 32×32 pixel sprites, generated модели с ванильным наклоном, RU/EN, короткие vanilla звуки. Генератор tools/winters_assets.py; собственные OGG не нужны.

Ручная проверка после разрешённого запуска: оба рецепта (обычный/Shift/быстрые клики/полный инвентарь/отмена/выброс), чужие Weakness/Absorption, пассивы и сфера цели, щит с серией ударов, передача/смерть/перезаход во время кулдауна, стадии 30/60/90 с у двух игроков, снятие последнего предмета, dedicated server и вид/звук/масштаб значков. Автоматических игровых запусков не было; offline NBT и арифметика не являются этими проверками.
