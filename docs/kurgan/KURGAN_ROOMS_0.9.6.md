# Архитектура помещений 0.9.6

Реализованы отдельные ветви размещения:

| Тип | Отличительные элементы |
|---|---|
| VESTIBULE | горизонтальный вход, угловые опоры, низкая кладка |
| CROSSROADS | три или четыре прохода, резной мотив пола |
| BURIAL | задний подиум, каменное покрытие, гроб и керамика |
| WARRIOR | повторяющиеся боковые погребальные плиты |
| TREASURY | боковые полки с керамикой, две наградные точки |
| RITUAL | срезанные углы, резной мотив, боковые алтари |
| TRAP | видимая нажимная плита и раздатчик, восемь стрел |
| FLOODED | вода глубиной один блок и сухой центральный крест |
| OSSUARY | боковые полки из плит и кости |
| OFFERING | алтари, чаши, керамика с обеих сторон |
| RELIQUARY | короткая секретная ветвь, треснувшая стенка, одна награда |
| COLLAPSED | обломки и плиты вне центрального прохода |
| DESCENT | разнесённые повороты и площадки, разные состояния ступеней |
| DEEP | нижняя камера; у Великого кургана — восьмиугольная защищённая оболочка, восемь опор, высокий потолок, подиум сзади и три ниши |

Существующие мобы и их характеристики сохранены. Внешний вид и реальные бои требуют ручной QA. Не выдавать отдельный switch за визуальную приёмку.

Тёплые подвесные ванильные фонари закреплены у стен под цельным потолком; старые холодные светильники и жаровни оставлены как акценты. Устойчивость размещённых фонарей проверена GameTest. Защита внешней оболочки великой гробницы восстановлена после проходов, в том числе над входом.
