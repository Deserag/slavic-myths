# 08. NPC, поручения, Книга сказаний, поиск

1. **Квест выполним:** `NPC → доступное поручение → конкретный реальный Entity/Structure ID → путь без OP → действие → проверка сервером → награда`. Не требовать отсутствующего в мире моба.
2. **Яга:** доступ, доверие и статусы не противоречат победам/creative bypass; по #272 переход в creative открывает дорогу сразу и право сохраняется после выхода, убийства предусмотренных боссов учитываются один раз.
3. **Баюн и Волк:** естественный канал/гарантируемый сценарный поиск, физический дом/NPC, повторные запросы без удвоения, игрок понимает путь, trust/сохранения индивидуальны.
4. **Проводники:** Яга/Баюн дают полезные сведения о реально существующих мобах, боссах и крупных местах (#297/#283); справочник не пишет «иди убей» без достижимой точки.
5. **Карта:** показывать **числовой центр X/Z и реальный радиус/границы**, без загадочных кругов и неверных указаний. Не выдумывать координату Y; сведения из текущего `SearchArea` (#296).
6. **Разделить механизмы:** поиск уже существующего, выдача области поиска, постановка jobs и явное строительство — разные действия. `/locate` ничего не размещает (#295).
7. **UI:** окно Яги, книга, достижения, tooltips, скролл и панели не перекрываются при небольшом разрешении и в RU/EN.
8. **MP и relog:** прогресс личный/общий по конкретному design contract; смерть NPC, отмена поиска, повторный вход и смена измерения не дублируют награду.
9. **QA:** цепочка от нового survival мира до квеста, отрицательный gate, повторное задание, relog и два игрока с разным прогрессом.

Код: `src/main/java/org/slavicmyths/{yaga,bayun,wolf,tales,navigation,guides,progression,quest185}`; #272, #283, #295–#297.
