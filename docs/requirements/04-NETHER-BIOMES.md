# 04. Новый Ад: общие и поэтапные требования

**Общее:** существующий Nether с vanilla контентом сохраняется; высота/рельеф/лава по #147; видимость, туман, контраст, погода/свет, стабильность границы биомов — проверять в клиенте, не по JSON. Один биом — отдельный патч и свой законченный геймплей, ресурсы, моб-состав, гарантированный босс, выходы/маршруты, статистика генерации, survival/MP.

**Навья роща (уже есть):** `navya_grove`, `navya_heart`; не ломать древесину, свет, жителей/врагов и структуру. Проблемы внешности Корневика, Навки, костяного ползуна и FallingTree проверять по #281; туман/своды/night-vision — #280. Нельзя объявлять исправленными без просмотра установленной игры.

**Второй обсуждённый биом — пепельная равнина (ещё не считать готовым):** просторная местность с невысокими холмами, магма, небольшие лавовые озёра, дымящийся/обугленный камень с магматическими жилами, опасные обжигающие блоки и безопасные проходы; собственная порода древесины с необходимыми строительными формами. Пепельный дух нейтрален до атаки, Углеполз и Искровик агрессивны. Босс **Жареница**, обсуждённые HP 700–800; награды: средняя осквернённая душа, руна, улучшение железной/алмазной брони (+1 HP за часть, +5 HP полный комплект по утверждённой логике), голова. Конкретные ID/частоты/визуал сверять с последним утверждённым Issue перед разработкой; не создавать из этого файла самовольную реализацию.

**«Чертоги заблудших», третий биом/лабиринт — #288–#294:** реальные коридоры и шесть типов залов, грибные оазисы, ориентиры; одобренные блоки/формы по #289–#291. **Ровно пять** утверждённых видов #292: Шептун (4 цвета = один EntityType, HP60), Оскольник (HP90), Гулокрыл (HP30), Эховик (HP60), Грибошмыг (HP60). Стенолаз и Жильник исключены. Босс #293 не подменять самопридуманным, итоговую природную генерацию/гарантию/5 seed — #294. Состояние Issue не означает разрешение реализации.

**Обязательно на каждом этапе:** реальные границы с ванильным Nether, генерация/структура/спавн/босс/лут, природные spawn levels/свет, старый мир, выход после смерти, эксплуатация чанков, FPS/MSPT, два клиента. Никакой финальной приёмки по рендерам-концептам.
