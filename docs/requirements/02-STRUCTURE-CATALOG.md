# 02. Каталог всех способов появления мест

Источник инвентаризации: `docs/implementation/structures275-20261025/all-sites.tsv` — **21 native structure + 9 иных мест**. Реальная генерация/находимость всего каталога в последнем игровом мире НЕ проверена этим документом. Каждая строка требует правил из [01](01-WORLDGEN.md), отдельного биомного и survival-теста.

| Существующее место / ID | Обязательное содержательное условие |
|---|---|
| `abandoned_settlement` | Болотная заброшенная локация; здания, входы, разумное затопление и лут доступны |

| `bandit_camp_medium` | Средний лагерь: отличимая сложность и награда, без перегенерации/спавн-спама |

**Не путать с native structures:**
- `saved/slavicmyths_yaga` — сохраняемая уникальная избушка с живой Ягой; не создавать вторую при повторном запросе.
- `saved/slavicmyths_grey_wolf` — событийное место/встреча Волка; отдельный естественный путь.
- `saved/slavicmyths_ancient_depths` — создаваемый dungeon instance; не выдавать за естественное `structure_set`.
- Features: `ancient_shrine`, `bathhouse`, `bayun_nook`, `deep_pool`, `old_barn`, `path_shrine` — проверять biome modifier, placed/configured feature, фактические блоки и NPC.

**Особое предупреждение:** два `chud_*` набора делят региональный механизм и salt — считать их двумя независимыми корнями статистики нельзя. Контроль данных: 20 `structure_set` для 21 structure ID; два святилища делят set. Источники: #275, #295, #273, #277.
