# Панель оружейных навыков — 22.11.2026

Поручение владельца: компактные иконки слева снизу, размер предмета в инвентаре, масштаб вместе с настройкой GUI Minecraft.

Реализация: WeaponSkillHud, клиентский RenderGuiEvent.Post. Иконка 16×16 GUI pixels; ячейки через 32 GUI pixels, подпись управления половинным шрифтом. Размер окна берётся из GuiGraphics; ручной пересчёт физических пикселей не применяется. Без открытого меню, F1, spectator и чужой камеры. Нет панели у предметов без перечисленных активных навыков.

Подключены: abyss_staff, storm_anchor, pharaohka_trident, storm_harpoon, morozko_staff, karachun_scythe, morovoy_staff, neveya_scythe, lomeya_hammer, lomeya_hammer_offhand, nine_mor_spear, nine_mor_axe. Это первый набор, не весь каталог оружия.

Иконки различают пузырь, водоворот, волну, удар, цепь, ледяные копья, вздох, жатву, воронов, огонь, смену стихии и разрез. У Мора значок зависит от текущей стихии. У гарпуна сохранён индикатор четырёх попаданий.

Морские таймеры используют уже синхронизированные данные предмета; Морозко и Карачун — существующий серверный снимок и время его получения; для посоха Мора серверные сроки копируются в CUSTOM_DATA без изменения сроков или проверки доступности. Замена посоха также обновляет таймер владельца. Независимые таймеры выводятся в секундах. У сестёр и Девятимора общий vanilla cooldown отображается затемнением по штатной доле остатка, без выдуманного числа секунд.

Ребаланс, управление и доступность навыков не меняются. Полная поддержка остальных активных предметов каталога — отдельное оставшееся расширение таблицы.

Проверка клиента: tools/weapon-skill-hud-client.init.gradle; отдельная папка work/weapon-skill-hud-client-20261122, новый плоский мир, громкость 0% (последнее указание владельца); снимки 12 предметов при масштабах 1,2,3. Для abyss_staff вызывается реальный серверный пузырь и его откат. Снимки требуют визуальной проверки, сам факт создания файла не является PASS.
