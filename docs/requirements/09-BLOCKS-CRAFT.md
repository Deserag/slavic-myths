# 09. Новые блоки, стройматериалы, станции, хозяйственное ремесло

1. **Для каждого блока:** registry + item, blockstate/model/texture, loot/drop, hardness/tool tags, crafting/placement, collision/light/waterlogging/rotation, RU/EN и вкладка Creative.
2. **Для пород дерева:** бревно, древесина, доски, ступени, плиты и прочие формы **ровно по утверждённому семейству**; двери/ограды/таблички и их текстуры/loot не забывать, если заявлен полный набор.
3. **Одна функция:** кухня, печь, пресс, бочка, ткацкий станок, кузница/бронник, ритуальная чаша выполняют обещанную операцию с реальным расходом/возвратом и без дюпа. Меню — не доказательство крафта.
4. **Связи предметов:** найденное сырьё → изготовление → фактическое применение. Для каждого нового материала перечислить producers и consumers, иначе не добавлять пустой предмет.
5. **Многоблочные постройки/машины:** neighbour updates, block entity, rotate, break/loot, worldgen шаблон и loading, ownership и безопасный сетевой доступ.
6. **Фермерство:** семена, рост, урожай, компост, полив/потребление инструмента, животные, рецепты; одинаковое поведение в одиночной и MP.
7. **Совместимость:** существующая мебель/сундуки/инвентари и сохранённые машины продолжают работать; не заменять ID.

Опора: `ModBlocks`, `ModTiles`, `Farming`, `Kitchen`, `Brewing`, `Industry`, `Wood`, `Furniture`. #286: аудит 923 строк каталога — **источник классификации**, не 923 игровых PASS. До добавления новых блоков сверить рабочие рецепты и `tools/verify_current_resources.py`.
