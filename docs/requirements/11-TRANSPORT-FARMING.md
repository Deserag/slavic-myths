# 11. Полёт, езда, животные и хозяйство

1. **Транспорт:** метла, ступа, Сивка-Бурка и новые средства должны иметь ясный способ получения, старт/посадку, управление/поворот/прыжок/высоту, ограничение скорости, безопасную высадку и отмену.
2. **Сивка:** без долгого разгона перепрыгивает ожидаемые препятствия; управление без седла не хаотично; нельзя исчезать после кормления или перезахода; полёт/скорость сравнивать с требуемым поведением и проверять модель всадника на clipping. Не менять числа без принятого ТЗ.
3. **Состояние:** владелец/приручение/инвентарь, пассажиры, движение/загрузка чанков, смерть/смена измерения/перезаход не дублируют и не удаляют сущность.
4. **Естественная встреча:** для редкой Сивки применять текущую согласованную политику #271, включая личные активные дни и расстояние; не заменять её мгновенным гарантированным spawn.
5. **Деревья:** новое дерево — природная форма + древесная продукция; совместимость рубки по связанным брёвнам, включая FallingTree, без бесконечных повторных ударов.
6. **Фермы и животные:** спавн, приручение, разведение, корм, рост растений, урожай, приготовление/заготовка, сохранение; нет скрытого OP-only получения.
7. **Приёмка:** обычный игрок открывает/получает механику, пробует в разных биомах, делает relog и тест с пассажиром/двумя игроками.

Источники: `src/main/java/org/slavicmyths/{sivka,flight,hunt,wood,farming,garden,husbandry}`; #271, #281; `MOD_CONTENT.md`.
