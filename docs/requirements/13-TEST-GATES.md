# 13. Минимальные gates по типам задач

| Тип | PASS можно заявить только после |
|---|---|
| Любая правка | Проверен scope/HEAD; Java21 clean build; ресурсы/production JAR; матрица критериев и ссылки на доказательства |
| Структура | Реальные блоки+NBT в новых чанках 5 seed; разрешённый **и запрещённый** биом; нормальный/сложный рельеф; внутренняя проходимость/контейнеры/NPC |
| Команды | `locate` не меняет мир; explicit create отдельно; ошибка честна; cancel/timeout и chunk tickets чистые |
| Редкая структура/встреча | Реальные частоты/дистанции по новым чанкам и игровым дням; доступны игроку без OP; не только theoretical candidate |
| Босс | Реальный бой и агро вблизи/издалека; фазы, союзники, смерть, гарантированный трофей, save/MP, один финальный результат |
| Оружие/инструмент | Добывается/крафтится в survival; настоящий attack/break + target; чары/руны/износ; GUI и held модели |
| Броня/аксессуар | Надеть/снять, цифры защиты/эффект, смерть/рelog/MP, снять бонус без residue |
| Станция/ритуал | Реальный ввод/расход/выход, правильная последовательность; повтор/отмена и antidupe, UI/MP |
| Лут | Все реальные контейнеры, проба большого числа прогонов, расчёт награды **за целую** структуру + ручной survival |
| GUI/модель/звук | RU/EN, реальные client кадры/аудио, 854×480, GUI scale, animation/clipping, визуальное принятие владельцем |
| Релиз/инсталляция | SHA источника и установленного JAR, backup, duplicate0, старый мир, ручное разрешение владельца |

**Правила результата:** `PASS` только для реально выполненной проверки; `NOT_RUN` при запрете Minecraft/сервер/PolyMC, `BLOCKED` при отсутствии материала/разрешения, `FAIL` при воспроизведённом дефекте. Ноль реальных запусков = ноль игровых PASS. Автоматический тест без клиента не доказывает UI. Статус «Готово» ставит только владелец. Для каждого теста приложить `seed | координаты | biome | build/SHA | шаги | наблюдение | скрин/лог | результат`.

**Обязательный чек-лист владельцу:** новый survival мир → достижение контента без OP → negative case → сохранение/relog → копия старого мира → MP по необходимости → отдельные OP-команды только диагностики. См. `AGENTS.md` и #269/#275.
