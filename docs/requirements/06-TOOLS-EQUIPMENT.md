# 06. Инструменты, броня, украшения, руны

**Каждый инструмент:** понятный рабочий блок/режим, скорость и допустимые материалы, износ, зачарования, корректные breaking drops/permissions, отсутствие double-break, reset после отмены и сохранение между входами. Не превращать всякую новую вещь в бесполезный декор.

**Чудь #258/#298:** четыре функциональных предмета: клиентский фонарь, двухрежимная кирка, мультиинструмент с формами топор/кирка/лопата, безопасный подъёмник. Сохранить одобренные принципы: тёмный металл + бронза/медь + умеренная бирюза; **реальный утверждённый силуэт обязателен** — текущий плоский `handheld`-арт кирки и трёх форм отвергнут владельцем. Переключение формы не теряет руны/чары/NBT/урон; фонарь не ставит тайные блоки света; подъёмник не телепортирует в лаву, стену или чужую защищённую зону.

**Инструментальные руны:** ограниченный журнал связанных блоков, без повторной траты прочности/добычи и без обхода claims; Fortune/Silk Touch совместимы только по утверждённым правилам. Отдельно тестировать естественные деревья и модовые породы.

**Броня #287:** не делать массового редизайна. Проверять реальную защиту, toughness, durability, set bonuses, +HP, repair/enchants, tooltips, damage sources, снятие, смерть, relog и MP. Не путать обычную броню и аксессуары.

**Украшения Curios #278:** все существующие item IDs, типы слотов, два кольца, надевание/снятие, фактический эффект, server authority и sync, смерть/relog/MP. Предмет с обещанным эффектом без работающего эффекта = FAIL.

**Крафт:** не вводить новые рецепты, материалы или стоимость «для красоты». Новый предмет должен иметь получение без OP, смысл применения и ясное ограничение. Источники: `ModGear`, `ToolRune*`, `UniqueEquipment*`, `Accessories*`; отчёты `chud258`, `items286-20261026`.
