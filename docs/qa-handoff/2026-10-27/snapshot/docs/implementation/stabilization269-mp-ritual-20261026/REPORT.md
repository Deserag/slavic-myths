## Как проверить в Minecraft

1. Два игрока на отдельном сервере/тестовом мире с2.0.5-HELL, без исходного личного сохранения. Найти святилище исследованием, получить угольки/порошок предусмотренным игровым способом. Оба пытаются открыть закрытый тайник; ожидается отказ. Неверный предмет не должен активировать ритуал.
2. Для огня оба почти одновременно используют по угольку. Для ключа оба пробуют очистить один узел, проверяют ещё закрытый тайник, затем второй узел. Ожидается расход только одного реагента на действие мира; завершённый узел не расходует новый порошок.
3. Оба открывают разблокированный тайник и одновременно забирают награду. Проверить суммарные предметы у обоих, включая курсоры. Опустошённый тайник не должен выдавать вторую копию. Оба выходят; перезапустить сервер и оба клиента, повторить доступ и ритуал. Тайник должен остаться пустым.
4. OP-диагностика отдельно: `/locate structure slavicmyths:sanctuary_unfading_fire`, `/locate structure slavicmyths:abode_pure_spring`. Поиск не должен создавать сооружение. Не считать dev placement доказательством Survival/natural доступности.
