## Что означает естественная генерация

Мир не строит все удалённые сооружения в момент нажатия «Создать». Он сохраняет seed/правила, а настоящие starts/блоки возникают при генерации соответствующих чанков. Это не требует поручения Яги, `/summon` или dev-create. Поручение Яги — другой путь: поиск завершённой ManualStructureRecords записи города, иначе явная локальная очередь ChudCreationJobs.

Новый изолированный save: work/stabilization269-scout-20261027/saves/Stabilization269; seed2692026, normal Overworld, generate_features=true. В пустую папку был скопирован только level.dat прежнего QA-мира; region/entities/playerdata/TaleData не копировались. Встроенная Data.Player в метаданных унаследовала диагностический инвентарь/позицию, поэтому это не прохождение Survival с нуля. Личные миры/PolyMC не запускались и не менялись. ## Предложения, без реализации

1. Сначала позволять поручению выбирать уже естественно существующее подходящее место; явно создавать новое только при отсутствии цели и безопасной площадке. Поиск должен оставаться ограниченным/асинхронным, без сканирования мира каждый tick и без выдачи координат несуществующего site.
2. Яга: отдельные варианты поручений «город Чуди», «заброшенный комплекс», «крепость Горыныча», «городище». Для городов выбирать существующие variant0–2, а не только0. Конкретный допуск по прогрессу и соотношения требуют согласования. Жители Чуди могут стать альтернативным поручителем abandoned после согласования условий/награды.
3. Для нового создания предложить кольцо500–1500 блоков от поручителя, до3 безопасных площадок; цель публиковать только после завершения. Уже полученный Target сохранять. Для старых дальних записей предложить предел поиска6000 блоков, затем объяснимый отказ/отдельное создание. Это новые параметры, в код не внесены.
4. Для редкости крепости и городища сначала принять цель: каждый тип в среднем реже III в comparable biomes/terrain, затем подобрать placement по расширенной выборке нескольких seeds. Простое увеличение spacing при нынешних terrain-отказах может сделать контент практически недоступным. Готовые числа frequency/spacing сейчас не назначаются.
5. Босс в заброшенном комплексе — отдельный ещё не реализованный scope. Требуются выбор босса, способ открытия gate, условия боя и награда; существующий FutureGateId не делает его реализованным.
