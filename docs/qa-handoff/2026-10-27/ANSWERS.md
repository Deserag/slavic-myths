## Что согласовать до реализации

- Выбор существующей естественной цели прежде локального создания; bounded/asynchronous поиск и безопасные отказы.
- Поручения для разных вариантов Чуди/abandoned/крепости/городища; условия прогресса и альтернативный поручитель из Чуди.
- В отчёте разведки есть конкретный **предлагаемый, не принятый** вариант расстояний: новое создание500–1500, максимум3безопасных площадки; предел поиска старой цели6000. Не использовать эти числа как утверждённый баланс.
- Редкость крупных сооружений относительноIII: сначала критерий/несколько seeds/terrainacceptance, затем числа. Простое разрежение при нынешних отказах может скрыть контент почти полностью.
- Кто босс abandoned, допуск/открытие/бой/награда — отдельное решение, не «починка уже реализованного».
- Предложения по недоступным/малополезным предметам, новым рецептам/получению/торговле/ценам из #286 остаются только предложениями.
