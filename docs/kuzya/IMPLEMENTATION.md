# Кузя 1.6.6

`KuzyaContent` регистрирует NPC/звуки через существующие реестры. `KuzyaEntity` владеет серверными маршрутами, сценами, гостевыми таймерами, защитой и NBT; synced clip/voice передают начало клиенту. `KuzyaResidence` проверяет канонического жителя при join и добавляет explicit status/repair. `YagaHut` создаёт жителя внутри существующей атомарной транзакции, `YagaHutPlan` изменяет только интерьер новых домов, `YagaData` сохраняет идентичность и revision.

`KuzyaAssets` содержит импортированные ключи/маркеры и измеренные аудио-envelope; `client/KuzyaMesh` и `KuzyaClient` изолированы Dist.CLIENT. Рендерер интерполирует клипы, привязывает шаги к движению, решает опору стоп и анимирует отдельные пряди/лицо. `tools/kuzya_resources.py` воспроизводит rig/atlas/audio/keyframes и дополняет существующие локализации/теги без отката остальных систем.

Fixtures `tools/kuzya-tests`, `tools/kuzya-runtime` включаются только opt-in init scripts и исключены из production JAR. Генерация остаётся северной; старые дома не мигрируются автоматически. Детали evidence, команды, ограничения и установка: [REPORT](../verification/kuzya-1.6.6/REPORT.md).


## Доработка 1.6.7

Генератор явно читает UTF-8 и подключает `film-voices.json`: пять активных voices, category routing и совместимые старые aliases. Измеренные envelopes получены из итоговых OGG. Сервер хранит абсолютный дедлайн занятия, реакции не сдвигают его. Ресурсы/изоляция и реальная autonomous/ПКМ/печь проверены; человеческая аудио/визуальная приёмка остаётся открытой. [Отчёт](../verification/kuzya-1.6.7/REPORT.md).
