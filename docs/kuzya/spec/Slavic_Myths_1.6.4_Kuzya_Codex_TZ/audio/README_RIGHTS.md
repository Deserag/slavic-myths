# Sound files provenance & status
`ready/sfx/` = 28 originally generated foley `.ogg` via deterministic synthesizer and noise models made for this package. `ready/voice_draft/` = 20 original Russian **TTS/synthesized** speech `.ogg`; **not** 1980s animation audio, not actor likeness, and not polished studio voice acting. All these are physically usable with Minecraft sound engine and are not empty.

Code and generation script provided separately in package if reproduction needed; use files directly. No implied license to the Kuzya character, its visual appearance, or any archival TV film/audio.
