# Управление: сочетания клавиш

Активные навыки из дерева используют три серверных слота. Значения по умолчанию: **Ctrl+1**, **Ctrl+2**, **Ctrl+3** (верхний цифровой ряд). Обычные 1/2/3 выбирают предметы на панели. Ультимативный навык и меню класса сохраняют прежние отдельные привязки.

В меню класса → «Управление» или в окне активного слота нажмите на привязку, удерживайте **Ctrl, Shift или Alt**, затем нажмите основную клавишу либо кнопку мыши. Нажатие одного модификатора не завершает ввод. Поддерживается один модификатор с одной клавишей. Нажмите «Сохранить»; Esc отменяет изменение. Эти же сочетания поддерживаются штатным меню Minecraft → Настройки → Управление благодаря native NeoForge KeyModifier. Существующие пользовательские настройки автоматически не сбрасываются.

Новые действия мода по возможности должны использовать настраиваемую native KeyMapping с модификатором, если это уменьшает конфликт кнопок. Проверять обе комбинации: с модификатором и без него; не дублировать ручной глобальный опрос клавиатуры. Сервер по-прежнему проверяет наличие навыка, расход и cooldown. Изменения других кнопок по умолчанию требуют отдельного назначения, чтобы не ломать привычное управление.

## Стандарт оружейных действий (Issue #528, решение владельца 22.11.2026)

У любого оружия с активными умениями есть **не более четырёх прямых действий**: **ЛКМ** — основная атака (обычный удар либо выстрел), **ПКМ** — основное дополнительное действие предмета, **Shift+ЛКМ** и **Shift+ПКМ** — два активных умения. Необязательные пассивные свойства не требуют кнопки. Нельзя вводить циклический выбор навыка, вспомогательные буквенные клавиши или режимы исключительно ради увеличения числа входов. Не обязательно использовать все четыре действия.

**Обязательная реализация для нового оружия:** `org.slavicmyths.combat.WeaponInputHandler` на предмете, `client/WeaponInputRouter.java` для распознавания сочетаний и единственный `combat/WeaponInputNetwork.java` для передачи действия на сервер. Каждый перехватываемый ввод надо **явно разрешить через `intercepts(...)`**; по умолчанию интерфейс ничего не перехватывает, чтобы новое оружие случайно не потеряло ванильные ЛКМ/ПКМ. Если обычное действие зависит от наведения в воздух/на блок/сущность, использовать перегрузку с `HitResult.Type`. Сервер получает только один из четырёх кодов и сам проверяет предмет в **основной руке**, цель, откат и затраты; отправленные клиентом сведения об оружии или уроне не принимаются. Shift-навык не должен сопровождаться ванильным ударом или обычным ПКМ. Для обычного оружия без активных навыков ванильные действия не перехватывать. Данные о рунах, перезарядках и режиме предметов сохранять по существующим правилам; регистрационные ID и save-форматы не менять.

**Посох Мора:** **ЛКМ — выстрел**, **ПКМ — Мор/Огонь**, **Shift+ЛКМ — призыв воронов**, **Shift+ПКМ — массовая атака**. Ранее использовавшиеся отдельные R/J/K для этого посоха отменены. Посох не выполняет дополнительную обычную melee-атаку при ЛКМ. Урон, стоимость, CD и эффект каждого действия неизменны. Специальный HUD/иконки — отдельная задача.

**Уже переведены:** Посох Мора; Посох Морозко (ЛКМ по воздуху — ледяной снаряд, ЛКМ по цели — обычное ближнее попадание, ПКМ удерживать — поток, Shift+ЛКМ — сосульки, Shift+ПКМ — волна); Посох Бездны (ЛКМ — обычный ближний удар, ПКМ — выстрел, Shift+ЛКМ — защитный пузырь, Shift+ПКМ — вихрь). Старые G/V для навыков Морозко и V для пузыря Бездны больше не регистрируются. Клавиша зеркала Морозко и управление навыками классов не затрагиваются.

**Дополнительно переведены:** коса Карачуна (ЛКМ — особый взмах, Shift+ЛКМ — Последнее дыхание, Shift+ПКМ — Чёрная жатва; крыло Карачуна — отдельный аксессуар), копьё Девяти Моров (ПКМ — четыре призрачных копья, Shift+ПКМ — круговой удар), секира Девяти Моров (ПКМ — Разлом Мора, Shift+ПКМ — Последний приговор). Для копья и секиры обычная ЛКМ остаётся ванильной атакой; щит и амулет рассматриваются отдельно.

**Статус:** остальные предметы со своими событиями Shift/ПКМ, в том числе наградное оружие сестёр и адское оружие, требуют самостоятельной проверки маршрутов в Issue #528. Общая инфраструктура сама по себе не меняет поведение предметов, которые ещё не реализуют `WeaponInputHandler`. Тесты сборки и игрового взаимодействия для указанных миграций пока не подтверждены.

## Установленный профиль и контекстные действия

В тестовом профиле PolyMC сохранены Ctrl+1/2/3. Прежние пользовательские Num4 для финальной способности и Num6 для меню сохранены; стандартные привязки нового профиля — U и K. Обновление JAR не сбрасывает options.txt. Предыдущие действия с настройками: [квитанция](implementation/guides236/skill-combos-installed.json).

У кирки мастера Чуди и мультиинструмента Shift+ПКМ по воздуху меняет режим/форму. Подъёмник используется удержанием ПКМ около 1,5 секунды. Фонарь светит в основной или второй руке. Стандартные контекстные кнопки полёта: снижение X, торможение R, груз B; доступность действия зависит от средства перемещения.

Остальные специальные действия зимней и ночной экипировки, редких рун и предметов переназначаются в штатном меню управления. Одинаковая кнопка в разных контекстах не означает одинаковый навык; сверяйте описание предмета и конфликт привязок.

## Единый ввод активных навыков оружия (с 22.11.2026)

Дополнительные активные навыки оружия используют **Shift + ЛКМ** и/или **Shift + ПКМ**.
Обычные ЛКМ/ПКМ сохраняют свою функцию (атака, выстрел, зарядка, метание или блок). Сочетание с Shift должно вызывать только соответствующий навык, без параллельного обычного удара. Клавиши навыков **класса** (Ctrl+1/2/3 и ультимейт) и **аксессуаров** — самостоятельная подсистема.

- Посох Бездны: ПКМ — выстрел; Shift+ПКМ — водоворот; Shift+ЛКМ — защитный пузырь (вместо V).
- Посох Морозко: ЛКМ по воздуху — снаряд, ПКМ (удержание) — поток; Shift+ЛКМ — сосульки (вместо G), Shift+ПКМ — волна (вместо V). Зеркальце остаётся аксессуаром.
- Коса Карачуна: ЛКМ — обычная серия ударов; Shift+ЛКМ — Последний вздох (вместо G), Shift+ПКМ — Чёрная жатва (вместо V). Чёрное крыло использует собственную клавишу аксессуара.
- Посох Мора: ПКМ — выстрел; Shift+ПКМ — переключение стихии (вместо R); Shift+ЛКМ — вороны в режиме МОР (вместо J) либо огненно-моровой удар в режиме ОГОНЬ (вместо K).
- Якорь, трезубец Фараонки, парные молоты, коса Невеи и прочее оружие с Shift+ПКМ сохраняют существующий серверный обработчик и доступные способности. Для предметов с двумя и более навыками правила независимости их перезарядок будут рассмотрены в отдельной задаче.

При появлении нового оружия с активными навыками разработчик обязан использовать этот стандарт без введения отдельных буквенных клавиш. Технический контракт и регрессионные проверки: [WEAPON_SKILL_INPUT_STANDARD_20261122.md](requirements/WEAPON_SKILL_INPUT_STANDARD_20261122.md).
