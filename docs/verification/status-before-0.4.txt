- [ ] Новые мобы/духи/NPC, структуры, измерения; ничего из 0.3.0 не добавлено.

## Известные проблемы

- [ ] PolyMC: исходный экземпляр имеет Forge 36.2.34 и не загруженную игру; в логе ошибка метаданных.
  Новый профиль подготовлен отдельно; запуск и загрузка зависимостей в нём ещё не подтверждены.
- [ ] Оба dev-run при закрытии Minecraft завершились сообщением Gradle о потере связи с daemon;
  падения мода в игровом журнале нет. Повторный запуск дошёл до загрузки атласов/меню.
- [ ] Захват окна Computer Use завершался таймаутом; визуальный просмотр меню/инвентаря не подтверждён.
- [ ] Стандартные предупреждения ForgeGradle о mappings и устаревших функциях Gradle остаются.

Генерация только в новых чанках; статистика одного мира не является гарантией баланса.
Достижения в сохранении получены при тестировании предметов, не доказывают survival-получение.
Git-репозитория нет; автоматических commit не делалось.
