# Slavic Myths 1.7.1 — результат реализации, 2026-10-11

Реализован пакет Ильи Муромца и Идолища Поганого из `docs/specs/1.7.1`. Это кандидат для игровой приёмки: клиентская визуальная/звуковая приёмка и настоящий multiplayer ещё не пройдены. Minecraft 1.21.1 / NeoForge 21.1.255 / Java 21 сохранены. Изменения пользователя не откатывались; commit не создавался.

## Реализация

- Илья: 280 HP, независимая модель высотой 2.5 блока, левый щит и правая шипованная палица; физическая защита, конечный фронтальный заслон, одиночный перехват, вызов, палица t19, круговой удар, одноразовый кризис и отступление при 42 HP. Реальное восстановление на протяжении 1100 ticks, безопасное удаление на >=24 блока и один возврат. Для нанесения урона боссу требуется недавнее участие владельца.
- Идолище: 900 HP, модель 9 блоков, две multipart кисти, переход при 315 HP. Кулак, три зоны топота, захват/бросок/спасение через правую кисть и R, собственные обычные зомби, прерываемое поедание, дыхание, разбег, стена/оглушение и совместная атака. Урон проходит штатную броню/Resistance. Зоны топота не повторяют попадание и проверяют преграду на уровне земли; направления разбега зафиксированы.
- Серверная история побед и канонический UUID героя; debug-встречи не открывают прогресс. Призыв во время боя/дублирование запрещены. Наград, XP, рецептов, новых achievements и будущих классов нет.
- Клиентские модели/36 анимаций, HUD, меню L с одним доступным героем, предупреждения с цветом и разным рисунком. RU/EN и 33 исходных OGG; речь заменена текстовыми репликами с невербальными оригинальными звуками согласно разрешённому fallback ТЗ.
- Двор создаётся только явной командой оператора в свободном загруженном пространстве. Существующие блоки и жидкости не удаляются, максимум 256 записей за серверный тик, атаки блоки не ломают. Природный спавн/структуры будущих этапов не добавлены.

Не объявляем весь Definition of Done завершённым.

Minecraft и NeoForge не обновляются. Старый экземпляр 1.16.5 не затрагивается.

## Краткая ручная проверка

Использовать отдельный тестовый мир. L → Илья **до** босса; `/slavicmyths encounter courtyard` в свободном месте, затем пройти в готовый двор и `/slavicmyths encounter idolishche`. R — попытка освобождения из захвата. Проверить обе модели со всех сторон, совпадение удара t19 и захвата, контрастные предупреждения при минимум частиц, звуки/субтитры, полноценный бой и multiplayer/relog.
