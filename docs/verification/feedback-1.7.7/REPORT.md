# Исправления по игровому отзыву — 1.7.7, 2026-10-12

Платформа: Minecraft 1.21.1 / NeoForge 21.1.255 / Java 21. Mod ID и registry IDs сохранены. Рабочая копия уже содержала большой набор пользовательских изменений; reset/clean Git и commit не выполнялись.

## Найденные причины и изменения

- Обычный AI требовал, чтобы противник уже выбрал игрока своей целью. В creative это часто не происходит; Добрыня также терял цель после переключения врага на самого героя. `HeroThreats` даёт четырём существующим контроллерам ближайшего видимого hostile в локальном радиусе 10/14/20, на прежних cooldown, включая slime через `Enemy`. Нейтральные мобы атакуются только при агрессии; союзники, spectator/offline owner и Дух земли исключены. После удаления владельца из уровня цель не приобретается. Никакого глобального обхода или force-load чанков.
- Враги из яиц не были обычными `Monster`; часть вообще не начинала AI с creative-владельцем. Только standalone/debug Идолище, Маринка, Ским, Картаус и Калин допускаются общим поиском героя. Их debug-контроллеры могут выбирать любого живого призванного богатыря. Настоящие сюжетные связи, допуск/история победы и запрет призыва/отзыва посреди боя сохраняются. Debug Идолище не перепривязывает Илью к настоящему испытанию; standby у других героев применяется к сюжетному Идолищу, а не к standalone тесту.
- Четыре независимые большие панели заменены одним клиентским `HeroHud`: максимум два стабильных ряда внизу слева, масштаб 0.75, каждый ряд примерно 120×16 GUI px, имя и HP с короткой полосой. Recovery и оковы имеют отдельную подпись. HUD скрывается в экранах/при F1 и уважает прежний config. Активные навыки уменьшены до 65%, стоят у нижнего правого края; на узком GUI — над хотбаром, без прежнего подъёма на 116 px. Passive badge сохранён.
- Лица Ильи, Добрыни, Алёши, Финиста, Маринки и Картауса получили пиксельные глаза/брови/рот/бороду на основной голове. Убраны выпирающие носы, крупные глазные кубы и пересекающиеся пряди; волосы — аккуратная крышка/затылок. Илья менее широк, меховой воротник ниже. Металл и кожа больше не имеют случайного контрастного камуфляжа: мягкие кромки пластин, спокойная кожа, отдельный узор кольчуги. Кости/пивоты и длины атак сохранены. Копьё, булава, сабли, меч, посохи и щиты сохраняют свои разные формы.
- Runtime нашёл `slavicmyths:kartaus_ryzhiy_us` в `reward_interruptible`, хотя существующий ID — `slavicmyths:kartaus`. Исправлена ссылка, а не registry ID.
