# Исправление поиска Чуди — 2026-10-09

Пользователь сообщил о зависании и отсутствии результата у обеих команд поиска подземелий. В этой итерации запрещены любые запуски Minecraft: клиент и headless сервер не запускались.

## Причины по исходникам

Обычный `LocateCommand` Minecraft1.21.1 вызывает `findNearestMapStructure` синхронно. При редких подходящих клетках он многократно выполняет дорогие native-проверки рельефа Чуди в серверном потоке. Предыдущая native QA измеряла3–6 секунд для отдельных принятых B-кандидатов; это историческое измерение, а не профилирование текущего зависания.

Обе `/sm … locate` проверяли только загруженные starts. Использовавшийся `ServerChunkCache.getChunk(... FULL, false)` всё равно содержит `managedBlock`/`join` для незавершённого future; флаг `false` сам по себе не гарантирует немедленного ответа. Нужный API готовых чанков — `getChunkNow`.

## Изменения

- Оба точных vanilla ID `slavicmyths:chud_city` и `slavicmyths:chud_abandoned` направлены в фоновый поиск отдельными Brigadier literals. Другие ID сохраняют vanilla обработчик; вложенный `/execute … run locate` получает корректно преобразованный source обычным диспетчером.
- `/sm city locate` и `/sm abandoned locate` немедленно читают готовые чанки через `getChunkNow`; при отсутствии запускают тот же поиск. Добавлены `search`, фильтры `attached/medium/great`, `status/cancel/next`.
- Один worker с низким приоритетом и одна активная задача, без очереди дорогих поисков. На страницу до96 кандидатов, кооперативный лимит60 секунд. Сообщение о старте сразу, прогресс каждые2 секунды, итог при успехе/отсутствии/лимите/отмене/ошибке. Внутренний вызов генератора может закончиться после истечения лимита; отмена проверяется между noise-колонками и соседними планами.
- Продолжение сохраняет исходный центр, измерение, seed, тип, страницу и незавершённого кандидата. Новый запрос не пропускает непроверенный остаток страницы после тайм-лимита.
- Worker получает registry, generator, random state, template manager и самостоятельный неизменяемый height accessor. Он не получает `ServerLevel`, не читает блоки и не создаёт чанки. Native seed planning использует стандартные generation inputs. Сообщения отправляются обратно через серверный executor. Нет tick-поиска миров/игроков.
- Остановка сервера отменяет поиск и освобождает продолжение. Для выключенной генерации структур/неподходящего измерения выдаётся явный ответ.
- Сохранённые планы, registry ID, сетка, геометрия и требования к рельефу не менялись. Результат — кандидат для новых чанков; в ранее сгенерированных чанках постройка может отсутствовать. Ограниченный поиск не доказывает отсутствие во всём мире и не гарантирует ближайшую существующую постройку.

## Проверки и ограничения

Plain JVM `SearchOfflineChecks` не загружает Minecraft: проверяет deadline, прерывание, очистку, изоляцию worker, Brigadier exact-ID precedence, сохранение vanilla маршрута, вложенный execute и существующий `/sm` alias. Лог и сертификат сборки находятся рядом с отчётом.

Финальные результаты: `clean build searchOfflineChecks` PASS32с,11 offline checks PASS,11992 resource/production checks PASS. Все926 compiled classes побайтно совпали с JAR;21 класс планов/геометрии/сохранения совпал с baseline. SHA256 нового JAR: `6ae23610d8390cc6e5792b8ad70048851ed5ea2bca8fea7618427c5edc75e524`.

Новые игровые проверки не выполнялись по запрету пользователя. Исторические14/14 native GameTests и11982 проверки ресурсов относятся к прежнему JAR `ca2a1e9e7ab2ebfb740edee54f7318f604a04119d5aa6f8b49c05e8699810103`; они не считаются runtime-проверкой исправленного JAR. Полная приёмка1.5.2 остаётся открытой: исторически natural medium5, unique attached1, great0; визуальная QA, survival, multiplayer, перезаход и MSPT не проверены.

Перенос исправления в PolyMC выполняется только как development candidate после clean build, offline checks и строгих resource/production gates. `--offline-fix` требует отдельный сертификат точного SHA и явно фиксирует `OPEN_RUNTIME_NOT_RUN`; обычная установка по-прежнему требует соответствующие native gates. Прежний JAR сохраняется, остальные файлы профиля сравниваются побайтно. Minecraft не запускается.
