## Изменения

Обе существующие structure_set используют новый native placement type `slavicmyths:chud_region`, наследующий RandomSpreadStructurePlacement. Сетка256 чанков /separation160 /salt1128813892 сохранена: старая потенциальная точка всегда первая. В той же области добавлены девять фиксированных запасных точек на сетке3×3 в допустимом диапазоне смещения0..95 чанков. Если исходная точка совпадает с запасной, дубликат удаляется: всего9–10 точек. Это не десять независимых комплексов: общий `ChudRegionPlanner` выбирает **один** принятый root на область для А или Б. А+Б остаются одним root.

Сначала проверяется прежняя точка — это сохраняет приоритет ранее подходящих координат. Запасные точки ранжируются по mountain biome preference, затем по высоте поверхности. Горы больше не обязательны: biome tags А/Б разрешают `#minecraft:is_overworld`, реальный каменный объём/жидкости/покрытие остаются проверками. Произвольный12% отсев негорных лесов удалён.

Исправлена проверка нижнего предела Б: старый padded native bbox `-44` ошибочно применялся ко всем профилям. Теперь минимальная фактическая конструкция учитывает shell и опоры: medium−31; great profiles−44/−36/−22; attached−58. Native bbox и NBT **не изменены**, массивы комнат/маршрутов/профили и geometry сохранены. Требование16 блоков над minY применяется к реальным нижним конструкциям. Жидкости, доля породы60%, покрытие12/15, чужие структуры и native reference window не ослаблены.

Все новые точки остаются в прежнем допустимом квадрате0..95 чанков. Поэтому минимальная разница центров независимых соседних областей161×16=2576, при envelope диаметром278 минимальный горизонтальный gap2298≥2000. Проверены отрицательные координаты и соседние области по обеим осям/диагоналям.

Native structure start создаётся в выбранном owning chunk, не в исходном отвергнутом чанке: bbox остаётся в штатном окне ±8 чанков. Registry ID существующих структур/pieces сохранены. Старые чанки не обходятся и не перегенерируются; сохранённые pieces читают прежние планы. Результат seed-поиска для уже созданной области всё равно не доказывает наличие start в старом мире.

## Производительность и карта

128 полных immutable region plans /1024 завершённых site outcomes в ограниченных кэшах. При отмене незавершённой области уже законченные site checks не теряются, `next` продолжает текущую область. На одну планировку кэшируется до8192 noise columns между вариантами/А/Б, без chunk loading. Нет tick scans. Остановка сервера очищает кэш, epoch исключает запись старых результатов после очистки.

`ChudSearchCommands` использует тот же `ChudRegionPlanner.select`, что native worldgen; возвращает координаты и root принятого плана. Это основа для будущих меток, сама система выдачи карт в этот патч не добавляется. Exact vanilla `/locate structure slavicmyths:chud_city|chud_abandoned` направлены в этот resolver. Vanilla общий locate по тегам/сторонние cartographer вызовы не адаптированы для дополнительных слотов; новый поиск и будущая выдача меток должны использовать общий resolver. Не выдавать generic vanilla lookup за проверенную интеграцию карт.

Страница теперь означает до96 **областей**, каждая с9–10 местами. Масштаб сетки4096 сохранён, он обеспечивает минимум2000 между границами, а не гарантирует постройку каждые2000. Лимит60 секунд кооперативный, фоновые progress/cancel/status/next сохранены. Работа новых кандидатов в реальном noise terrain и её стоимость пока не измерены.
