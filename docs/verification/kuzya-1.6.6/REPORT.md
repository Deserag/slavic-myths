# Кузя и интерьер Яги — кандидат 1.6.6

Реализация по предоставленному архиву поверх согласованной 1.6.5 с песиголовцами. Minecraft 1.21.1, NeoForge 21.1.255, Java 21. Это кандидат для клиентской приёмки, а не подтверждение всей матрицы ТЗ.

## Реализовано

Один канонический `slavicmyths:kuzya` при новой атомарной генерации дома Яги, UUID дома/жителя и версия интерьера в SavedData/NBT. Нативная модель: 66 костей, 156 кубов, 36 отдельных прядей, отдельные веки/брови/челюсть и реквизит. 33 клипа используют 169 CSV-ключей; походка привязана к расстоянию, стопы имеют IK. 48 предоставленных OGG включают 20 оригинальных синтетических черновых русских реплик: это не озвучка актёра и не звук мультфильма. Рот использует измеренную громкость выбранного голоса, реплики имеют локализованные субтитры.

Сервер управляет домашними сценами, маршрутом по физическим ступеням на печь, сном, едой, делами, ответом на ПКМ и накопительным временем гостей. Нет глобального сканирования игроков каждый тик, телепортации при подъёме или загрузки чанков ради AI. Кузя защищён от урона/обычного перемещения игроком; административное удаление возможно. Новый интерьер сохраняет внешнюю форму дома, вход, ноги, Ягу и котёл. На столе реальные блюда существующей системы, в единственной бочке умеренный vanilla loot. Старые дома автоматически не перестраиваются.

## Команды

Разрешение уровня 2. Из Overworld игроком: `/slavicmyths dev yaga generate` (без координат; существующая генерация вокруг игрока, один дом). `/slavicmyths dev yaga locate`; `/slavicmyths dev yaga kuzya status`. Для явно выбранного старого дома или восстановления отсутствующего жителя: `/slavicmyths dev yaga kuzya repair`; чанки должны быть загружены, место свободно. Repair не перестраивает старый интерьер.
