# Древние глубины 1.5.3.1: плоский мир и диагностика

Пользователь обнаружил отказ `/sm depths generate` в стандартном flat. В 1.5.3 применялось только подземное размещение: нижняя отметка bbox уходила ниже бедрока. Это противоречило прямому требованию пользователя разрешить командное размещение над поверхностью; ограничение из приложенного описания было ошибочно поставлено выше этого требования. Универсальное сообщение о сухом месте скрывало реальные причины; общий timeout тоже выдавал это сообщение, даже при неполных 16 попытках.

## Исправление

FlatLevelSource распознаётся по установленному API, как у существующих команд Чуди. Для плоского мира origin = максимальная отметка сухого входа +32; нижняя отметка сохранённого bbox = поверхность +1. Вся структура переносится вместе, включая лестницы, содержимое, вход и карту. Подземные roof probes пропускаются, вариант крыши CLOSED. Команда и предмет карты используют общий путь. В обычном мире origin не поднимается, действуют прежние подземные проверки.

Native references сами по себе не запрещают свободный объём над flat: проверяется реальное пересечение с bbox native starts. Проверки ручных сооружений, сохранённых экземпляров В, границы/высоты и защищённых блоков остаются. End portal/frame не заменяются ни в одном режиме. Registry IDs, сохранённые планы, SavedData и А/Б не изменены. Восстановление использует уже сохранённый origin.

Кандидаты учитывают причины отказа. По исчерпании выводятся переведённые причины и их количество. Timeout отдельно сообщает кандидат и этап; карта до записи остаётся неактивированной. Данные поиска не создают COMPLETE при отказе. Сообщение flat даёт действительные координаты поднятого входа.
