# Проверка Древних глубин 1.5.3.1

Перезапустите Minecraft самостоятельно, чтобы загрузить 1.5.3.1. Агент игру не запускал. Подходит прежний тестовый четырёхслойный flat: постройка появляется над поверхностью. В обычном Overworld — под землёй. Радиус входа по X/Z остаётся 1500–2000 от позиции при активации.

```mcfunction
/sm depths generate
/sm depths status
/sm depths locate
/sm depths map
/give @s slavicmyths:ancient_depths_map
/gamemode spectator
/tp @s X Y Z
/gamemode survival
```

`generate` создаёт один экземпляр и после завершения выдаёт карту. `status` сообщает текущий этап. `locate` показывает ближайший завершённый экземпляр. `map` и `/give` выдают неактивированную карту: ПКМ из любой руки запускает общий генератор обычным игроком. `/slavicmyths` эквивалент `/sm`. Для `/tp` используйте реальные X/Y/Z из завершения или locate; не подставляйте высоту травы вместо высоты поднятого входа. Команды требуют OP2, использование предмета OP не требует.

Краткая ручная проверка: на прежнем flat выполнить generate, дождаться COMPLETE и проверить через locate/teleport всю постройку над поверхностью. Пройти спуски/мост/выходы из ям, проверить два сундука, двух стражей и пустую финальную арену. Активировать новую карту, проверить RED_X и повторный ПКМ без нового объекта. Сохранить/выйти/войти и проверить карту/содержимое без дублей. В обычном тестовом мире проверить подземное размещение. В Nether/End карта должна отказать без расхода. При отказе сообщаются причины; при тайм-ауте — этап и кандидат.
