# Классы, Книга сказаний и исправление загрузки — 1.7.8

Дата: 2026-10-12. Minecraft1.21.1 / NeoForge21.1.255 / Java21 / official mappings. Registry IDs, знания/достижения, серверные правила обучения/назначения и баланс сохранены.

## Причины и результат

1. **Сбой загрузки 1.7.7 — реальная регрессия.** После переноса HUD три наружных класса BrightFalconClient/SkimClient/MarinkaClient остались GAME subscribers без собственных @SubscribeEvent методов. NeoForge прекращал клиентскую загрузку. Наружные аннотации удалены; внутренние MOD subscribers рендереров/цветов сохраняются. Это подтверждено реальными повторными клиентскими запусками. Новый bytecode gate проверяет объявленные handlers всех 173 subscribers и отвергает старый JAR1.7.7 по этой же причине.
2. **Классовое дерево.** Постоянная правая карточка удалена. Дерево занимает всю рабочую ширину страницы; пиктограммы32 вместо44, изображения24 вместо32. Горизонтальное расстояние между ветками использует свободную ширину, без увеличения самих иконок. Существующие prerequisite links/уровни/ранги не меняются; panning/hit testing следуют отображённым координатам. Hover показывает описание, эффект, перезарядку/длительность/дальность, rank/blocker и назначенную клавишу. Обучение остаётся явной серверной кнопкой внизу, слот назначается прежним действием.
3. **Клавиши.** Footer использует фактические назначения Minecraft вместо I/II/III. На «Управлении» каждая строка связывает номер и название навыка с редактируемой клавишей. Конфликт с1 называется «Быстрый доступ, слот1»; конфликт с другим классовым действием включает его номер/название, остальные — категорию и действие. Полные конфликты есть в tooltip, Escape отменяет захват, passive не получает выдуманной клавиши. Никакого автоматического снятия vanilla bindings.
4. **Книга.** Стандартный renderBackground/blur заменён обычным прозрачным затемнением; shader blur не запускается. Книга шире, категории подписаны словами; короткие tab captions раскрываются полными tooltip. Для обычных записей — прямой список без обязательного chapter→section→entry пути; история Back/Forward, уровни знания, страницы, рецепты/подсказки/награды сохраняются. Поиск по названиям и метаданным охватывает все обычные категории; у деяний — titles/descriptions с контекстными ancestors. UiSearch игнорирует регистр, лишние пробелы и различие е/ё. Очистка явная, нет результатов — явная подпись. Init очищает старые widgets, поэтому обновление snapshot не размножает кнопки.
5. **Древо книги.** Поддеревья получают отдельные интервалы, родители центрируются над детьми; используются настоящие Parent IDs. Positions кешируются по группе/поиску и обновлению данных. Есть drag, вертикальный/горизонтальный scroll, Ctrl+колесо zoom0.4…1.6 и reset. Tooltip учитывает границы canvas.
6. **Длинные подписи.** Навигационная строка книги32px/две строки. Shared FolkUi/ClassTheme buttons показывают bounded word wrap, при переполнении — многоточие и полное название по наведению. Tooltip навыков/достижений переносится по реальной ширине GUI; короткий счётчик не заходит на читательскую страницу. Font fitting проверялся на настоящем Minecraft Font. RU/EN подключены; GUI PNG и другие старые ресурсы не перекрашивались.
