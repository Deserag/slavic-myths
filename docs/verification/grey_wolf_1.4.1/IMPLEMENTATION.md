## Формула редкости и границы

Для одинаковых R исследованных/зарегистрированных регионов текущего мира: `N_W(R) ≤ min(12, floor(0.4 × N_T_verified(R)))`. Следовательно `E[N_W(R)] / R ≤ 0.4 × E[N_T_verified(R)] / R`; это гарантия фактически созданных encounters, независимо от разницы пригодности биомов. Seed-only eligibility: `P_W=.10`, `P_T=.25`, отношение `.40`; без квоты одного такого отношения было бы недостаточно, поскольку вероятность пригодной лесной поляны `q_W` не обязана равняться вероятности пригодной локации Тугарина `q_T`. Пробу10000 seed candidates тестировали только как вероятность фильтра, не как частоту встреч. Квота считает safe natural записи существующего HuntRecords, не debug спавны.

После gates установлен production с SHA-256 `ffd6a11453ccc34442996edf3ad62fd287595189d55332be9c805b672f03798d`;188 прочих файлов экземпляра (исключая отдельный backup tree) совпадают побайтно. Сохранено5609 файлов исходного baseline;12 изменённых общих файлов перечислены в resource_gates.json. Резервная копия предыдущего1.3.4.5.5 указана в installation receipt.

## Воспроизведение проверок

Задавать JAVA_HOME для команды: `C:/Program Files/Java/jdk-21.0.12`.

- `gradlew.bat clean build` — production без fixtures.
- `gradlew.bat -PgreyWolfCheck runGreyWolfChecks` — итоговые15 native GameTests.
- `gradlew.bat -PgreyWolfModelOfflineCheck verifyGreyWolfModel` — native bake модели.
- `gradlew.bat -PcombatRuntimeCheck -PuniqueEquipmentCheck -PuniqueRestartPhase=verify runCombatFixes runUniqueEquipmentChecks` —63+23 регрессионных GameTests.
- `gradlew.bat -PrareRuneOfflineCheck -PruneReworkOfflineCheck -ParmorOfflineCheck -PtugarinModelOfflineCheck verifyRareRunes verifyRuneRework verifyArmorRunes verifyTugarinModels` —20491+355+147+9176 offline checks.
- `python tools/grey_wolf_resources.py` и `python tools/grey_wolf_previews.py` — воспроизводимые актуальные геометрия, atlas, icon, локализация, sounds catalog, biome tag и геометрические previews.
- `python tools/verify_grey_wolf.py` — JSON/PNG/OGG/production JAR, версия/Java21, сохранность baseline и предыдущих сапог.

В этой итерации выполнены **13 headless серверных запусков, 0 клиентских**:11 wolf launches +2 regression launches. Промежуточные сбои:1 mixed-PvP fixture;3 проверки окончания раны выявили/уточнили серверный переход и время fixture. Итоговые наборы зелёные. Native wound test вручную вызывает doTick fake ServerPlayer один раз на серверный тик; это проверка native эффектов, не реального клиентского подключения. Часть длительных фаз форсируется timeline clock для изолированных проверок; не выдаётся за реальный длительный бой.

Геометрические previews не являются игровыми скриншотами; сравнение Steve — proxy высотой1.8. Нельзя считать offline bake проверкой рендера, SavedData roundtrip настоящим перезаходом, seeded sample измеренной естественной частотой, выполнение GameTests измеренным MSPT. Не сделана ручная клиентская приёмка: текстуры/анимации/звук в игре, настоящие два игрока, relog и карта, естественная встреча в исследовании, измерение MSPT. Причина: автоматический запуск клиента запрещён; конкретный список в MANUAL_QA.md. Обязательные игровая логика и ресурсы реализованы, ручные acceptance gates остаются открытыми.
