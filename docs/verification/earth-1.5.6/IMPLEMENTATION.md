# Реализация требований пакета Earth Spirit MODULAR V2

Запрос пользователя и уточнения имеют приоритет над документами архива. 72 файла поставленного манифеста проверены по размеру/SHA256. Тексты спецификаций использованы как требования к моду; указания внешним агентам не запускают дополнительные задачи. Решения о сне, уроне, допуске наковальни и награде сохранены в `docs/earth-spirit/DECISIONS.md`. Дополнительный запрос заменяет яйцо босса поставленным игроком блоком для плоского мира.

Запирающий камень сохраняет ID `slavicmyths:earth_heart_seal`. В настоящей арене он запускает её единственного босса; поставленный вручную камень расходуется после успешного создания тестового босса без arena ID. Оба пути активируются атакой или разрушением, только на сервере; при тесноте ручной камень не расходуется. Дополнительных столбов, ворот или лута для ручного вызова не создаётся. Название — игровое, а не утверждение об историческом славянском термине. Яйцо босса исключено; яйцо малого слуги оставлено для отладки.

Преддверие адаптировано до 7 блоков внутри реального уже вырезанного объёма. Поиск, размеры/маршрут/крыша Древних глубин и А/Б не расширены. Старые сохранённые Глубины не переоборудуются. Проверены восемь вариантов существующего `DepthsLayout`; это проверка планов, а не генерация мира в игре. Во время сна сохраняются здоровье, фаза, столбы и замороженные таймеры; ворота открыты. После повторного входа есть recovery, волны не догоняют пропущенное время.

Столб визуально поднимается от своего синхронизированного якоря к точному wrist transform через RenderLayer. Логическая точка выпуска рассчитана по той же цепочке суставов; offline-проверка сравнивает её с реальными native ModelPart pivots. Залп отображает все оставшиеся камни у кисти и выпускает их по одному. Урон происходит только сервером; один target UUID учитывается один раз на actor/cast, прямое попадание столбом исключает дополнительный splash той же цели. Коллизии мира проверяют весь длинный столб с ограниченным шагом; чанки не запрашиваются ради полёта.

Это модель ванильной брони и toughness без чар/эффектов/щита, не измеренные удары в игре. Protection также проверен через установленный `CombatRules`. Прямой `setHealth(current−damage)` и скрытый bypass брони не используются. Melee cooldown отсчитывается от начала каста: базовый интервал 50 тиков при отсутствии конкурирующих умений. Минимальное recovery тяжёлых кастов — 32 тика. Summon timer начинается после ACTIVE и очередного завершённого каста; в сне заморожен.

Common config использует умолчания пакета. Размер wave/cap/pillar count и допустимое число камней остаются фиксированным контрактом арены; HP, скорость, фазы, interval, shot interval, pressure, rune modifiers и cooldown доступны с перезапуском. Начальные HP/скорость применяются новым сущностям; сохранённые NBT сущности не переписываются произвольно. Клиент и сервер должны использовать одинаковый COMMON-баланс; первый QA выполняется с defaults. CLIENT config отдельно выключает дрожание/наклон камеры.

Игровая приёмка **OPEN**: не запускались клиент, сервер, worldgen или game tests. Реальное поднятие/блокирование/прыжок/щит, полёт и частота атак, расстояние knockback, персонажи/освещение/аудио, multiplayer, логин/разгрузка чанков, FPS/MSPT требуют пользователя. Собственные OGG поставлены как прототипы архива; их субъективное качество не объявлено production audio PASS. Состояние ресурсов и компиляция не объявляются VISUAL/COMBAT/RUNTIME PASS.
